### 一、 物理起源：从“无限池”到“绝对存量”

在多项分布（芯片测试）中，假设产线有几十万颗芯片，你抽 10 颗，抽到一颗 A 档，对整个宏观概率 $p_1$ 的影响微乎其微，概率可以近似看作恒定不变。

但现在，情况变了。

假设你面前只有**绝对封闭的 $N=100$ 个独立沙盒（或资产）**。

其中：

- A 档资产有 $K_1 = 50$ 个
    
- B 档资产有 $K_2 = 30$ 个
    
- C 档资产有 $K_3 = 20$ 个
    

你现在要从中**无放回地**抽取 $n = 10$ 个。

当你第一个抽到了 A 档资产，剩下的池子里 A 档就只剩 49 个，总数变成了 99。**下一次抽到 A 的物理概率瞬间从 50/100 暴跌到了 49/99，而抽到 B 和 C 的概率则被动飙升！**

这种每一次动作都在**物理上不可逆地改变系统未来命运**的过程，就是超几何分布。

### 二、 数学公式的“上帝视角解剖”

在求多维超几何分布的联合概率时：最终抽出 $x_1$ 个 A 档，$x_2$ 个 B 档，$x_3$ 个 C 档的几率是多少？

它的数学公式比多项分布还要简洁纯粹，因为它完全摒弃了概率 $p$，直接使用最暴力的**几何组合数**：

$$P(X_1=x_1, X_2=x_2, \dots, X_k=x_k) = \frac{\binom{K_1}{x_1} \binom{K_2}{x_2} \dots \binom{K_k}{x_k}}{\binom{N}{n}}$$

_(注：$\binom{A}{B}$ 代表组合数，即从 $A$ 个中取 $B$ 个)_

**硬核解剖：**

1. **分母 $\binom{N}{n}$（全局的上帝视野）**：
    
    这是大自然的绝对底线。从总共 $N$ 个物品里，不管三七二十一闭着眼睛抓 $n$ 个，总共有多少种抓法？这就是整个概率空间的**绝对总面积（多重宇宙的总数）**。
    
2. **分子 $\binom{K_1}{x_1} \dots \binom{K_k}{x_k}$（局部的精确坍缩）**：
    
    为了让你恰好抽到 $x_1$ 个 A 档，这 $x_1$ 个必须**全部且只能**从那 $K_1$ 个 A 档的池子里出，有 $\binom{K_1}{x_1}$ 种可能；同理，B 档的 $x_2$ 个必须全从 $K_2$ 里面出……
    
    把这些局部的小组合全部乘起来，就是能满足你特定要求的“微观路径总数”。
    

把特定的微观路径数，除以全宇宙的总路径数，就是存量掠夺的绝对概率。

### 三、 协方差的“双重死锁”（比多项分布更惨烈）

在多项分布中，因为你抽取的总数 $n$ 是固定的，变量之间存在“零和博弈”，导致协方差为负：$\text{Cov}(X_i, X_j) = -n p_i p_j$。

但在多维超几何分布中，存在着极其残酷的**双重死锁**：

1. **抽样数量死锁**：你总共只抽 $n$ 个（你拿了 A，就不能拿 B）。
    
2. **物理存量死锁**：总池子 $N$ 是有限的（你把 A 拿光了，A 就彻底绝种了）。
    

这导致它的协方差比多项分布还要负得更深！它的数学公式里，多了一个极其致命的物理修正系数，叫作**有限总体修正系数 (FPCF)**：

$$\text{Cov}(X_i, X_j) = -n \left(\frac{K_i}{N}\right) \left(\frac{K_j}{N}\right) \times \left( \frac{N - n}{N - 1} \right)$$

盯住最后那个系数 **$\frac{N - n}{N - 1}$**：

- 当你的抽取量 $n$ 逼近总存量 $N$ 时，这个系数趋向于 $0$。方差和协方差全部瞬间归零！
    
- **物理意义**：当你要把池子里的 100 个东西全部抽走（$n=100$）时，结局是100%注定的（你必得 50个A，30个B，20个C），系统中不再有任何随机性，波动彻底死亡。
- 在算 $\text{Cov}(I_m, J_r)$ 之前，我们需要先算基础的期望值。

对于指示变量（只取 0 和 1），它的期望值在数学上**严格等于它取 1 的概率**：

$$E[I_m] = 1 \times P(I_m = 1) + 0 \times P(I_m = 0) = P(I_m = 1)$$

那么，**在无放回抽样中，第 $m$ 次抽到红球的概率 $P(I_m=1)$ 是多少？**

不要去想前面抽了什么！根据概率论的**对称性原理（或者叫抽签公平性）**，无论你是第 1 个抽还是第 $m$ 个抽，只要你没看前面的结果，你抽中红球的概率和第一个人摸奖的概率是一模一样的。

- 所以：$E[I_m] = P(I_m=1) = \frac{K_1}{N}$
    
- 同理：$E[J_r] = P(J_r=1) = \frac{K_2}{N}$
    

### 第四阶段：攻克双重求和（核心难点）

这个双重求和 $\sum_{m=1}^{n} \sum_{r=1}^{n} \text{Cov}(I_m, J_r)$ 总共有 $n \times n = n^2$ 项。

我们必须把这 $n^2$ 项分成两类来算：一类是 $m = r$（同一次抽球），另一类是 $m \neq r$（不同次抽球）。

#### 情况 1：当 $m = r$ 时（即同一次抽球），共有 $n$ 项

此时我们要计算 $\text{Cov}(I_m, J_m)$。

套用第一阶段的计算公式：

$$\text{Cov}(I_m, J_m) = E[I_m J_m] - E[I_m]E[J_m]$$

- **算 $E[I_m J_m]$**：$I_m J_m$ 等于 1 的前提是：在第 $m$ 次抽球时，你**既**抽到了红球，**又**抽到了黑球。这在物理上是不可能的（互斥事件）。所以 $P(I_m=1 \text{ 且 } J_m=1) = 0$。因此 $E[I_m J_m] = 0$。
    
- **代入公式**：
    
    $$\text{Cov}(I_m, J_m) = 0 - \left(\frac{K_1}{N}\right) \times \left(\frac{K_2}{N}\right) = - \frac{K_1 K_2}{N^2}$$
    
    这种 $m = r$ 的项总共有 $n$ 个。所以**第一部分的累加和为**：
    
    $$-n \frac{K_1 K_2}{N^2}$$
    

#### 情况 2：当 $m \neq r$ 时（即不同次抽球），共有 $n(n-1)$ 项

比如 $m=1$（第 1 次抽），$r=2$（第 2 次抽）。

此时我们要计算 $\text{Cov}(I_m, J_r) = E[I_m J_r] - E[I_m]E[J_r]$。

- **算 $E[I_m J_r]$**：这等于 $P(I_m=1 \text{ 且 } J_r=1)$，即**第 $m$ 次抽到红球，且第 $r$ 次抽到黑球的联合概率**。
    
    同样利用对称性，这个概率等于“第 1 次抽到红球，且第 2 次抽到黑球”的概率。
    
    - 第 1 次抽到红球的概率：$\frac{K_1}{N}$
        
    - 在拿走一个红球后，总球数变 $N-1$，黑球依然是 $K_2$ 个。所以第 2 次抽到黑球的条件概率是：$\frac{K_2}{N-1}$
        
    - 联合概率相乘：$E[I_m J_r] = \frac{K_1}{N} \times \frac{K_2}{N-1}$
        
- **代入公式**：
    
    $$\text{Cov}(I_m, J_r) = \left( \frac{K_1}{N} \cdot \frac{K_2}{N-1} \right) - \left( \frac{K_1}{N} \cdot \frac{K_2}{N} \right)$$
    
    把公因式 $\frac{K_1 K_2}{N}$ 提出来：
    
    $$\text{Cov}(I_m, J_r) = \frac{K_1 K_2}{N} \left( \frac{1}{N-1} - \frac{1}{N} \right)$$
    
    括号里通分：$\frac{N - (N-1)}{N(N-1)} = \frac{1}{N(N-1)}$。
    
    所以最终得到：
    
    $$\text{Cov}(I_m, J_r) = \frac{K_1 K_2}{N^2 (N-1)}$$
    
    这种 $m \neq r$ 的项总共有 $n(n-1)$ 个。所以**第二部分的累加和为**：
    
    $$n(n-1) \frac{K_1 K_2}{N^2 (N-1)}$$
    

### 第五阶段：最后的代数拼装

现在，宏观协方差等于【情况 1】加上【情况 2】：

$$\text{Cov}(X_1, X_2) = \underbrace{ -n \frac{K_1 K_2}{N^2} }_{\text{情况 1}} + \underbrace{ n(n-1) \frac{K_1 K_2}{N^2 (N-1)} }_{\text{情况 2}}$$

到了这一步，我们只需要极其仔细地提取公因式。

我们把 **$-n \frac{K_1 K_2}{N^2}$** 作为公因式强行提出来：

$$\text{Cov}(X_1, X_2) = -n \frac{K_1 K_2}{N^2} \left[ 1 - \frac{n-1}{N-1} \right]$$

接下来，只需对中括号里的式子进行初中水平的通分运算：

$$1 - \frac{n-1}{N-1} = \frac{N-1}{N-1} - \frac{n-1}{N-1} = \frac{(N-1) - (n-1)}{N-1} = \frac{N - 1 - n + 1}{N-1} = \frac{N - n}{N - 1}$$

将这个极其干净的结果代回原式：

$$\text{Cov}(X_1, X_2) = -n \frac{K_1 K_2}{N^2} \left( \frac{N - n}{N - 1} \right)$$

为了让公式物理意义更明显，我们把分母的 $N^2$ 拆成两个 $N$，分别放在 $K_1$ 和 $K_2$ 之下，得到**最终形态**：

$$\text{Cov}(X_1, X_2) = -n \left(\frac{K_1}{N}\right) \left(\frac{K_2}{N}\right) \left( \frac{N - n}{N - 1} \right)$$

推导彻底结束。从微观的一次次伸手抓球，到最终的负向死锁，都在这几步严密的代数重组中完成了闭环。
