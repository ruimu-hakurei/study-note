如果多项分布是“上帝拥有无限资源的掷骰子”，那么**三项分布（Trinomial Distribution）**就是这个宇宙中最精简的**“三足鼎立”零和博弈模型**。

在三项分布中，系统只有三种绝对互斥的状态（比如量化订单簿里的：买入、卖出、撤单）。

总资源是 $n$。三个状态的发生次数分别是 $X_1, X_2, X_3$，对应的基础概率是 $p_1, p_2, p_3$。

因为是绝对封闭系统，所以存在两条死锁铁律：

1. $X_1 + X_2 + X_3 = n$
    
2. $p_1 + p_2 + p_3 = 1$
    

现在，我们要对这个三维系统求**边际分布（Marginal Distribution）**。

换句话说：**如果你是一个只关心“买入单（$X_1$）”，对“卖出”和“撤单”漠不关心的风控算法，你在自己的单边视角下，会看到什么样的物理世界？**

### 一、 物理直觉：维度的“暴力降维与合并”

在求边际分布时，我们前面说过，核心动作是“锁定一个维度，把其他所有维度积分或求和抹杀掉”。

在三项分布中，当你只盯着 $X_1$ 看时，剩下的 $X_2$ 和 $X_3$ 对你来说失去了区分的意义。

大自然会自动把 $X_2$ 和 $X_3$ 强行揉碎、捏合成一个全新的混沌状态——**“非 $X_1$”**。

- 原本的概率空间是：$\{状态1, 状态2, 状态3\}$
    
- 降维后的概率空间变成了：$\{状态1, 非状态1\}$
    

这说明什么？**三项分布（乃至任意多项分布）的任意单一维度的边际分布，都会在物理上绝对坍缩退化为最基础的——二项分布（Binomial Distribution）！**

### 二、 数学引擎的硬核推导（代数闭环）

我们用纯粹的代数，亲手把这个降维坍缩的过程推导出来。

已知三项分布的联合概率密度（PMF）公式：

$$P(X_1 = x, X_2 = y, X_3 = n - x - y) = \frac{n!}{x! y! (n - x - y)!} p_1^x p_2^y p_3^{n - x - y}$$

现在要求 $X_1$ 的边际分布 $P(X_1 = x)$。

操作法则：把 $X_1$ 锁定为常数 $x$，然后对所有可能的 $X_2$（即变量 $y$）进行**全域求和**。

因为总数是 $n$，$X_1$ 已经占了 $x$ 个，那么 $X_2$ 最少可以是 $0$ 个，最多只能是 $n - x$ 个。

所以求和公式为：

$$P(X_1 = x) = \sum_{y=0}^{n-x} \frac{n!}{x! y! (n - x - y)!} p_1^x p_2^y p_3^{n - x - y}$$

**第一步：提取无关常量**

在对 $y$ 求和的世界里，所有只包含 $n$、$x$、$p_1$ 的项都是常数，统统踢到求和符号外面去：

我们不仅要把常数踢出去，还要为了凑公式，在分子上强行补上一个 $(n-x)!$，并在分母上除以一个 $(n-x)!$。

$$P(X_1 = x) = \frac{n!}{x! (n-x)!} p_1^x \sum_{y=0}^{n-x} \frac{(n-x)!}{y! (n - x - y)!} p_2^y p_3^{n - x - y}$$

**第二步：二项式定理的“空间折叠”**

注意看求和符号后面的那一长串东西，它正好就是组合数 $\binom{n-x}{y}$ 乘以概率项：

$$\sum_{y=0}^{n-x} \binom{n-x}{y} p_2^y p_3^{(n-x)-y}$$

根据牛顿的**二项式定理（Binomial Theorem）**，这一大串和式，完美等于两个底数相加的对应次幂：

$$(p_2 + p_3)^{n-x}$$

**第三步：终极拼装与物理死锁**

因为系统的总概率死锁铁律是 $p_1 + p_2 + p_3 = 1$，所以：

$$p_2 + p_3 = 1 - p_1$$

把这个结果代回第一步踢出来的常数项中：

$$P(X_1 = x) = \frac{n!}{x! (n-x)!} p_1^x (1 - p_1)^{n-x}$$

写成经典的组合数形式：

$$P(X_1 = x) = \binom{n}{x} p_1^x (1 - p_1)^{n-x}$$

**推导结束。**

这正是标准的二项分布公式 $X_1 \sim B(n, p_1)$。

### 三、 工程与量化的终极启示

为什么我们要花力气去推导这个看似理所当然的“边际退化”？因为它在工程建模中具有决定性的指导意义。

- **算力解放**：在量化高频交易中，如果你有 100 只股票构成的多项分布（100 个维度的联合矩阵），你要监控“苹果公司”的单只股票异动。你**不需要**去维护和计算那个庞大的 100 维联合概率张量。多项分布的边际坍缩定理告诉你，你完全可以把其他 99 只股票粗暴地打包成“非苹果资产”，直接用一维的二项分布去计算它的独立阈值。这让芯片的算力消耗从 $O(N^k)$ 瞬间暴跌到 $O(1)$。
    
- **信息丢失的代价**：当你使用边际的“二项分布”来做单边风控时，你计算出的方差是 $\text{Var}(X_1) = n p_1 (1 - p_1)$。这个方差看起来极其稳定。但你永远不要忘了，在你求和抹杀 $X_2$ 和 $X_3$ 的那一刻，你把它们之间那致命的**负协方差** $\text{Cov}(X_1, X_2) = -n p_1 p_2$ 给彻底扔进了垃圾桶。
    

如果系统发生局部倾斜（比如 $X_2$ 遭遇突发黑天鹅），你手中那个孤立的二项分布风控模型是绝对感知不到的，直到灾难通过负协方差传导，将你的 $X_1$ 彻底撕裂。
