

### 1. 样本点 (Sample Point)

- **数学记号**：通常记为 $\omega$。
    
- **严谨定义**：随机试验中每一个**不可再分的、最基本的结果**。它是构成概率论世界的“原子”。
    
- **经典模型**：在“掷一颗六面骰子”的试验中，“掷出点数 1”就是一个样本点，记为 $\omega_1$。
    

### 2. 样本空间 (Sample Space)

- **数学记号**：通常记为 $\Omega$。
    
- **严谨定义**：随机试验中**所有可能出现的样本点**构成的集合。即 $\Omega = \{\omega_1, \omega_2, \dots \}$。
    
- **经典模型**：
    
    - **有限型**：掷一次骰子，$\Omega = \{1, 2, 3, 4, 5, 6\}$。
        
    - **可数无限型**：不断抛掷硬币直到出现正面为止，记录抛掷的次数。$\Omega = \{1, 2, 3, \dots \}$。
        
    - **连续型**：在区间 $[0, 1]$ 内随机取一个实数，$\Omega = \{x \mid 0 \le x \le 1\}$。
        

### 3. 随机事件 (Random Event)

- **数学记号**：通常记为 $A, B, C \dots$
    
- **严谨定义**：样本空间 $\Omega$ 的**子集**。当且仅当该子集内的一个样本点（$\omega \in A$）出现时，我们就称事件 $A$ 发生了。
    
- **经典模型**：在掷骰子试验中，定义事件 $A$ 为“掷出偶数点”。用集合语言表述就是 $A = \{2, 4, 6\}$。显然 $A \subset \Omega$。当掷出 2、4 或 6 时，事件 $A$ 发生。
    

### 4. 事件域 (Event Space / $\sigma$-代数)

- **数学记号**：通常记为 $\mathcal{F}$ （或大写花体字）。
    
- **严谨定义**：它是样本空间 $\Omega$ 的某些子集构成的**集合族**（即“集合的集合”）。为了能在数学上严谨地定义概率，这个集合族必须满足三条纯代数公理：
    
    1. **包含必然事件**：$\Omega \in \mathcal{F}$。
        
    2. **对立封闭性**：若 $A \in \mathcal{F}$，则其补集 $\bar{A} \in \mathcal{F}$。
        
    3. **可列并封闭性**：若有一系列集合 $A_1, A_2, \dots \in \mathcal{F}$，则它们的并集 $\bigcup_{i=1}^{\infty} A_i \in \mathcal{F}$。
        
- **纯数学本质**：在离散数学（如骰子、摸球）中，$\mathcal{F}$ 通常就是样本空间的所有子集构成的“幂集”。但在连续数学中（如在实数轴上取点），由于存在不可测集（如维塔利集合），不能给任意子集都分配概率。因此，$\mathcal{F}$ 的作用是筛选出所有“在数学上可以合法测量大小（概率）的子集”。
    

### 5. 随机变量 (Random Variable)

- **数学记号**：通常记为大写字母 $X, Y, Z$。
    
- **严谨定义**：它是一个定义在样本空间 $\Omega$ 上的**实值函数**，将每一个样本点映射为一个实数。
    
    - 数学映射关系：$X: \Omega \rightarrow \mathbb{R}$，即 $X = X(\omega), \ \omega \in \Omega$。
        
    - **测度论要求（可测性）**：为了让随机变量有意义，对于任意实数 $x$，集合 $\{\omega: X(\omega) \le x\}$ 必须属于事件域 $\mathcal{F}$（即必须是一个合法事件）。
        
- **经典模型**：假设同时抛两枚均匀的硬币，样本空间为 $\Omega = \{(正,正), (正,反), (反,正), (反,反)\}$。
    
    我们定义一个随机变量 $X$ 为“出现正面的总次数”。那么这个映射函数为：
    
    - $X(正,正) = 2$
        
    - $X(正,反) = 1$
        
    - $X(反,正) = 1$
        
    - $X(反,反) = 0$
        
- **纯数学本质**：随机变量的作用是将抽象的“集合元素（$\omega$）”强制转化为“实数（$x$）”。完成了这一步，概率论就彻底接入了微积分（求导、积分）和线性代数的世界。
    

**总结它们在数学推导中的逻辑链条：**

在一个空间（**样本空间 $\Omega$**）里，装满了基本元素（**样本点 $\omega$**）。我们挑出一些元素组成子集（**随机事件 $A$**）。为了防止数学悖论，我们用一个规则（**事件域 $\mathcal{F}$**）限定了哪些子集是合法的。最后，为了方便用公式计算，我们构造了一个函数（**随机变量 $X$**），把这些集合里的元素全部映射成了实数轴上的数字。这五步走完，经典的概率计算体系就正式确立了。
