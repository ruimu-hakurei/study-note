# 有效性（Efficiency）

**有效性（Efficiency）**是数理统计中用来衡量估计量**精度与波动大小**的核心准则。

如果说“无偏性”保证了估计量在无数次实验的平均意义下**打得准（没有系统偏差）**，那么“有效性”则衡量了估计量每次落点的**散布紧密程度（方差越小越有效）**。

## 一、 有限样本下的有效性定义

设 $\hat{\theta}_1$ 和 $\hat{\theta}_2$ 是待估参数 $\theta$ 的两个**无偏估计量**（即 $E(\hat{\theta}_1) = E(\hat{\theta}_2) = \theta$）。

- **有效性优劣比较**：
    
    若在整个[[参数空间]] $\Theta$ 上恒有：
    
    $$Var(\hat{\theta}_1) \le Var(\hat{\theta}_2)$$
    
    且至少存在一个参数点等号不成立，则称 **$\hat{\theta}_1$ 比 $\hat{\theta}_2$ 更有效**。
    
- **相对有效性（Relative Efficiency）**：
    
    定义 $\hat{\theta}_1$ 相对于 $\hat{\theta}_2$ 的相对效率为两者的方差之比：
    
    $$e(\hat{\theta}_1, \hat{\theta}_2) = \frac{Var(\hat{\theta}_2)}{Var(\hat{\theta}_1)}$$
    
    若 $e > 1$，说明 $\hat{\theta}_1$ 的精度高于 $\hat{\theta}_2$。
    

## 二、 方差的理论极限：Cramér-Rao 不等式与 CRLB 下界

为了衡量一个无偏估计量是否已经“好到了极致”，统计学给出了所有无偏估计量能达到的**方差理论下限**——**克拉美-罗下界（Cramér-Rao Lower Bound, CRLB）**。

**1. Fisher 信息量（Fisher Information）**

设单个样本的对数似然函数为 $\ln f(x; \theta)$，定义 Fisher 信息量为：

$$I(\theta) = E\left[ \left(\frac{\partial \ln f(X; \theta)}{\partial \theta}\right)^2 \right] = -E\left[ \frac{\partial^2 \ln f(X; \theta)}{\partial \theta^2} \right]$$

容量为 $n$ 的[[总体与样本抽样|独立同分布]]样本包含的总体信息量为 $I_n(\theta) = n I(\theta)$。

**2. Cramér-Rao 不等式**

在满足常规正则条件（如积分求导可交换、支撑集与 $\theta$ 无关等）的前提下，对于 $\theta$ 的**任意无偏估计量** $\hat{\theta}$，其方差必然满足：

$$Var(\hat{\theta}) \ge \frac{1}{n I(\theta)} \quad (\text{CRLB 下界})$$

- **绝对有效估计量（Efficient Estimator）**：
    
    若某个无偏估计量 $\hat{\theta}^*$ 的方差**严格达到了 CRLB 下界**，即：
    
    $$Var(\hat{\theta}^*) = \frac{1}{n I(\theta)}$$
    
    则称 $\hat{\theta}^*$ 为 $\theta$ 的**有效估计量（或绝对有效估计量）**。
    
- **绝对效率**：定义为 $e(\hat{\theta}) = \frac{\text{CRLB}}{Var(\hat{\theta})} \le 1$。当且仅当 $e = 1$ 时达到绝对有效。
    

## 三、 核心进阶概念：UMVUE（一致最小方差无偏估计）

CRLB 下界虽然优美，但**并不一定能在所有问题中达到**（CRLB 只是充分条件，许多分布下最小方差仍然严格高于 CRLB）。为了在没有达到 CRLB 时依然选出最好的估计，数理统计定义了 **UMVUE**：

- **定义**：若无偏估计量 $\hat{\theta}^*$ 对参数空间中任意 $\theta$ 以及任意其他无偏估计量 $\hat{\theta}$，恒满足：
    
    $$Var(\hat{\theta}^*) \le Var(\hat{\theta})$$
    
    则称 $\hat{\theta}^*$ 为 $\theta$ 的**一致最小方差无偏估计（Uniformly Minimum Variance Unbiased Estimator, UMVUE）**。
    

**如何构造与求解 UMVUE？两大黄金定理：**

1. **Rao-Blackwell 定理（方差压缩器）**：
    
    设 $\hat{\theta}$ 是任意无偏估计，$T$ 是**[[充分统计量]]**。构造条件期望：
    
    $$\theta^* = E(\hat{\theta} \mid T)$$
    
    - $\theta^*$ 仍然无偏：$E(\theta^*) = \theta$；
        
    - 方差单调不增：$Var(\theta^*) = Var(\hat{\theta}) - E\big[Var(\hat{\theta} \mid T)\big] \le Var(\hat{\theta})$。
        
2. **Lehmann-Scheffé 定理（唯一最优判据）**：
    
    如果统计量 $T$ 不仅是**充分统计量**，同时还是**完备统计量（Complete Statistic）**，那么由它构造出的无偏估计量 $g(T)$ 必然是**全局唯一的 UMVUE**。
    

## 四、 大样本下的渐近有效性（Asymptotic Efficiency）

在小样本下构造绝对有效估计通常较为困难，但在大样本（$n \to \infty$）时，可以利用极限分布来讨论渐近性质：

- **定义**：若估计量序列 $\hat{\theta}_n$ 满足渐近正态性：
    
    $$\sqrt{n}(\hat{\theta}_n - \theta) \xrightarrow{d} N\big(0, \, \sigma_{\text{asymp}}^2\big)$$
    
    且其渐近方差达到了 Fisher 信息量的倒数极限，即 $\sigma_{\text{asymp}}^2 = \frac{1}{I(\theta)}$，则称 $\hat{\theta}_n$ 是**渐近有效估计量（Asymptotically Efficient Estimator）**。
    
- **[[MLE|极大似然估计]]（MLE）的渐近最优性**：
    
    在正则条件下，**极大似然估计 $\hat{\theta}_{\text{MLE}}$ 恒为渐近有效估计量**，其渐近方差自动收敛到 CRLB 下界。
    

## 五、 概念对比与总结

|**概念**|**核心关注点**|**数学判据**|
|---|---|---|
|**无偏性 (Unbiasedness)**|中心位置是否无系统偏差|$E(\hat{\theta}) = \theta$|
|**有效性 (Efficiency)**|无偏估计中谁的方差更小|$Var(\hat{\theta}_1) \le Var(\hat{\theta}_2)$|
|**有效估计量 (CRLB 达到者)**|方差是否达到了理论极限下界|$Var(\hat{\theta}) = \frac{1}{n I(\theta)}$|
|**UMVUE**|无偏估计族中的全局方差最小值|$\forall \hat{\theta}, Var(\hat{\theta}^*) \le Var(\hat{\theta})$（即使未达 CRLB）|
|**渐近有效性**|大样本下的极限方差是否最优|$\lim_{n \to \infty} n Var(\hat{\theta}_n) = \frac{1}{I(\theta)}$（如 MLE）|

## 六、 经典例题：均匀分布 $U(0,\theta)$ 的无偏估计有效性比较

设总体 $X \sim U(0, \theta)$，待估参数为 $\theta$，比较两个无偏估计量的有效性：

$$\hat{\theta}_1 = \frac{n+1}{n} X_{(n)} \quad (\text{基于次序极值}), \qquad \hat{\theta}_2 = 2\bar{X} \quad (\text{矩估计})$$

目标是证明二者均无偏，并通过方差对比说明 $\hat{\theta}_1$ 远比 $\hat{\theta}_2$ 有效。

### 6.1 估计量 $\hat{\theta}_1 = \frac{n+1}{n}X_{(n)}$ 的期望与方差

令标准化变量 $Y_k = \frac{X_k}{\theta} \overset{\text{i.i.d.}}{\sim} U(0, 1)$，则极值统计量满足 $Y_{(n)} = \frac{X_{(n)}}{\theta}$。

**1. 求 $Y_{(n)}$ 的概率分布**

对于 $y \in (0, 1)$，其分布函数与概率密度函数为：

$$F_{Y_{(n)}}(y) = P(Y_{(n)} \le y) = [P(Y_1 \le y)]^n = y^n$$

$$f_{Y_{(n)}}(y) = F'_{Y_{(n)}}(y) = n y^{n-1}$$

**2. 求一阶矩与二阶矩**

$$E[Y_{(n)}] = \int_0^1 y \cdot n y^{n-1} \, dy = n \int_0^1 y^n \, dy = \frac{n}{n+1}$$

$$E[Y_{(n)}^2] = \int_0^1 y^2 \cdot n y^{n-1} \, dy = n \int_0^1 y^{n+1} \, dy = \frac{n}{n+2}$$

**3. 计算方差**

$$Var(Y_{(n)}) = E[Y_{(n)}^2] - [E(Y_{(n)})]^2 = \frac{n}{n+2} - \frac{n^2}{(n+1)^2} = \frac{n}{(n+2)(n+1)^2}$$

**4. 还原得到 $\hat{\theta}_1$ 的期望与方差**

- **期望（无偏性）**：
    
    $$E[\hat{\theta}_1] = \frac{n+1}{n} E[X_{(n)}] = \frac{n+1}{n} \theta E[Y_{(n)}] = \frac{n+1}{n} \theta \cdot \frac{n}{n+1} = \theta \quad (\text{无偏})$$
    
- **方差**：
    
    $$Var(\hat{\theta}_1) = \left(\frac{n+1}{n}\right)^2 \theta^2 Var(Y_{(n)}) = \frac{(n+1)^2}{n^2} \theta^2 \cdot \frac{n}{(n+2)(n+1)^2} = \frac{\theta^2}{n(n+2)}$$
    

### 6.2 估计量 $\hat{\theta}_2 = 2\bar{X}$ 的期望与方差

因为 $X_i \sim U(0, \theta)$：

- 单个样本期望与方差为：$E(X_i) = \frac{\theta}{2}$，$Var(X_i) = \frac{\theta^2}{12}$
    
- [[样本均值与样本方差|样本均值]]满足：$E(\bar{X}) = \frac{\theta}{2}$，$Var(\bar{X}) = \frac{Var(X_i)}{n} = \frac{\theta^2}{12n}$
    

代入 $\hat{\theta}_2 = 2\bar{X}$：

- **期望（无偏性）**：
    
    $$E[\hat{\theta}_2] = 2 E(\bar{X}) = 2 \cdot \frac{\theta}{2} = \theta \quad (\text{无偏})$$
    
- **方差**：
    
    $$Var(\hat{\theta}_2) = 4 Var(\bar{X}) = 4 \cdot \frac{\theta^2}{12n} = \frac{\theta^2}{3n}$$
    

### 6.3 有效性比较与结论

比较两者的方差之比：

$$\frac{Var(\hat{\theta}_1)}{Var(\hat{\theta}_2)} = \frac{\frac{\theta^2}{n(n+2)}}{\frac{\theta^2}{3n}} = \frac{3}{n+2}$$

- 当 $n = 1$ 时，两者方差相同；
    
- 当 $n > 1$ 时，$\frac{3}{n+2} < 1 \implies Var(\hat{\theta}_1) < Var(\hat{\theta}_2)$，因此 **$\hat{\theta}_1$ 比 $\hat{\theta}_2$ 更有效**。
    

### 6.4 本题的核心理论启示

1. **收敛速度的本质差异（$O(1/n^2)$ vs $O(1/n)$）**：
    
    - 基于[[矩估计]]的 $\hat{\theta}_2$ 方差下降速度是常规的 $O\left(\frac{1}{n}\right)$；
        
    - 基于充分统计量（次序极值 $X_{(n)}$）的 $\hat{\theta}_1$ 方差下降速度达到了 **$O\left(\frac{1}{n^2}\right)$（超有效性，Super-efficiency）**，样本量越大，极值估计的精度优势呈平方级放大。
        
2. **充分统计量的威力**：
    
    对于均匀分布 $U(0, \theta)$，$X_{(n)}$ 是 $\theta$ 的充分完备统计量，而 $\bar{X}$ 不是。由 Lehmann-Scheffé 定理，基于 $X_{(n)}$ 修正出的 $\hat{\theta}_1$ 是全局方差最小的 **UMVUE**。
