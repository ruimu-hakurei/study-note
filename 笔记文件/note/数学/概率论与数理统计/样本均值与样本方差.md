**样本均值（Sample Mean）**与**样本方差（Sample Variance）**是数理统计中最基础、最重要的两个统计量，分别用来度量样本数据的**中心位置（集中趋势）**和**离散程度（波动大小）**。

设 $X_1, X_2, \dots, X_n$ 是来自总体 $X$ 的[[总体与样本抽样|独立同分布]]（i.i.d.）样本，总体的真实期望为 $E(X) = \mu$，真实方差为 $Var(X) = \sigma^2$。

---

## 一、样本均值 $\bar{X}$

- **数学定义**：所有样本观测值的算术平均数：

    $$\bar{X} = \frac{1}{n} \sum_{i=1}^n X_i$$

- **期望（[[无偏性]]）**：

    $$E(\bar{X}) = E\left(\frac{1}{n} \sum_{i=1}^n X_i\right) = \frac{1}{n} \cdot n\mu = \mu$$

    样本均值的期望恰好等于总体均值，因此 $\bar{X}$ 是总体均值 $\mu$ 的**无偏估计**。

- **方差与[[相合性]]**：

    $$Var(\bar{X}) = Var\left(\frac{1}{n} \sum_{i=1}^n X_i\right) = \frac{1}{n^2} \cdot n\sigma^2 = \frac{\sigma^2}{n}$$

    随着样本容量 $n \to \infty$，$Var(\bar{X}) \to 0$。根据辛钦[[大数定律]]，$\bar{X} \xrightarrow{P} \mu$（具备**相合性**）。

---

## 二、样本方差 $S^2$

- **数学定义**：

    $$S^2 = \frac{1}{n-1} \sum_{i=1}^n (X_i - \bar{X})^2$$

- **为什么分母是 $n-1$ 而不是 $n$（无偏修正）？**

    - 若直接除以 $n$，记作 $S_n^2 = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2$，展开求期望可得：

        $$E(S_n^2) = \frac{n-1}{n}\sigma^2 < \sigma^2$$

        此时它会**低估**总体的真实方差（因为样本点围绕样本均值 $\bar{X}$ 的离散程度，天然小于围绕真实均值 $\mu$ 的离散程度）。

    - 将分母调整为 $n-1$（即利用自由度进行贝塞尔修正）后：

        $$E(S^2) = \frac{n}{n-1} E(S_n^2) = \sigma^2$$

        因此，分母为 $n-1$ 的 $S^2$ 才是总体方差 $\sigma^2$ 的**无偏估计**。

> 上面只给出了结论，下一节展开完整的推导过程与直观解释。

---

## 三、为什么分母是 $n-1$：详细推导与直观解释

### 3.1 详细数学推导

设 $S_n^2 = \frac{1}{n} \sum_{i=1}^n (X_i - \bar{X})^2$。

1. **配项拆解离差平方**：

    在括号内部加上并减去总体的真实均值 $\mu$：

    $$X_i - \bar{X} = (X_i - \mu) - (\bar{X} - \mu)$$

    展开平方项：

    $$(X_i - \bar{X})^2 = [(X_i - \mu) - (\bar{X} - \mu)]^2 = (X_i - \mu)^2 - 2(X_i - \mu)(\bar{X} - \mu) + (\bar{X} - \mu)^2$$

2. **对所有样本求和**：

    对 $i = 1$ 到 $n$ 求和：

    $$\sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n (X_i - \mu)^2 - 2(\bar{X} - \mu)\sum_{i=1}^n (X_i - \mu) + \sum_{i=1}^n (\bar{X} - \mu)^2$$

    注意到 $\sum_{i=1}^n (X_i - \mu) = \sum_{i=1}^n X_i - n\mu = n\bar{X} - n\mu = n(\bar{X} - \mu)$。

    代入化简中间交叉项：

    $$\sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n (X_i - \mu)^2 - 2n(\bar{X} - \mu)^2 + n(\bar{X} - \mu)^2$$

    $$\sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n (X_i - \mu)^2 - n(\bar{X} - \mu)^2$$

3. **两边同时求期望**：

    $$E\left[\sum_{i=1}^n (X_i - \bar{X})^2\right] = \sum_{i=1}^n E\left[(X_i - \mu)^2\right] - n E\left[(\bar{X} - \mu)^2\right]$$

    根据方差的定义：

    - $E\left[(X_i - \mu)^2\right] = Var(X_i) = \sigma^2$

    - $E\left[(\bar{X} - \mu)^2\right] = Var(\bar{X}) = \frac{\sigma^2}{n}$

    代入计算：

    $$E\left[\sum_{i=1}^n (X_i - \bar{X})^2\right] = n\sigma^2 - n \cdot \left(\frac{\sigma^2}{n}\right) = n\sigma^2 - \sigma^2 = (n-1)\sigma^2$$

4. **代入 $S_n^2$ 的定义**：

    $$E(S_n^2) = E\left[ \frac{1}{n} \sum_{i=1}^n (X_i - \bar{X})^2 \right] = \frac{1}{n} \cdot (n-1)\sigma^2 = \frac{n-1}{n}\sigma^2$$

### 3.2 核心直观解释

- **丢失了 1 个自由度**：计算真实方差本该看每个样本点与**真实中心 $\mu$** 的距离 $\sum(X_i - \mu)^2$；但因为 $\mu$ 未知，只能用**样本中心 $\bar{X}$** 代替。

- **最小二乘性质**：数学上，使二次函数 $\sum (X_i - c)^2$ 取得最小值的常数 $c$ 恰恰就是样本均值 $\bar{X}$。因此无论样本怎么抽，总有：

    $$\sum_{i=1}^n (X_i - \bar{X})^2 \le \sum_{i=1}^n (X_i - \mu)^2$$

    由于始终被压缩了一部分波动（少算了 $\bar{X}$ 偏离 $\mu$ 的方差 $\frac{\sigma^2}{n}$），直接除以 $n$ 得到的均值就会严格小于真实方差 $\sigma^2$。将分母修正为 $n-1$，才能把这部分偏小的值补齐（即贝塞尔修正）。

---

## 四、常用快捷计算公式

在实际手算或编程计算中，样本方差常展开为以下等价形式以减少浮点误差与计算量：

$$S^2 = \frac{1}{n-1} \left( \sum_{i=1}^n X_i^2 - n\bar{X}^2 \right)$$

---

## 五、正态总体下的三大核心抽样分布性质

当总体服从[[正态分布]] $X \sim N(\mu, \sigma^2)$ 时，样本均值与样本方差具备极强的代数与分布性质：

1. **样本均值的正态性**：

    $$\bar{X} \sim N\left(\mu, \, \frac{\sigma^2}{n}\right)$$

2. **样本方差服从[[卡方分布]]**：

    $$\frac{(n-1)S^2}{\sigma^2} = \frac{\sum_{i=1}^n (X_i - \bar{X})^2}{\sigma^2} \sim \chi^2(n-1)$$

3. **均值与方差的独立性（Fisher 定理）**：

    对于正态总体，统计量 $\bar{X}$ 与 $S^2$ **相互独立**。这一性质直接推导出了后续用于假设检验与区间估计的 **Student's t 分布**：

    $$\frac{\bar{X} - \mu}{S / \sqrt{n}} \sim t(n-1)$$
