> **先找枢轴量 → 再用分布分位点截出概率 → 最后把不等式反解成参数区间。**

各类题目的差别主要只是：用的是 $Z$ 分布、$t$ 分布、$\chi^2$ 分布，还是 $F$ 分布。

---

# 〇、先统一分位数约定（否则上下限必写反）

本篇一律采用**上侧分位数**约定（与国内教材一致）：对任一分布，记号 $q_\alpha$ 满足

$$P\{\,\text{该统计量} > q_\alpha\,\} = \alpha$$

即 **下标越小，分位点越靠右（越大）**。于是

$$z_{\alpha/2} > 0,\qquad \chi^2_{1-\alpha/2}(k) < \chi^2_{\alpha/2}(k),\qquad F_{1-\alpha/2} < F_{\alpha/2}$$

双侧截取概率时永远写成"小的在左、大的在右"：

$$P\left\{q_{1-\alpha/2} \le Q \le q_{\alpha/2}\right\} = 1-\alpha$$

> ⚠️ **这是本章最大的坑**。$Z$ 和 $t$ 因为对称，可以偷懒写 $\pm z_{\alpha/2}$，看不出约定；但 $\chi^2$ 和 $F$ **不对称**，一旦把 $\alpha/2$ 和 $1-\alpha/2$ 记反，区间就整个倒过来。
>
> 另外注意：$\sigma^2$、$\theta$ 这类参数出现在枢轴量**分母**时，反解会让上下限**交换**；出现在**分子**时则不会。下面每处都会标出来。

以下恒设 $S^2 = \dfrac{1}{n-1}\sum_{i=1}^n (X_i-\bar X)^2$ 为[[样本均值与样本方差|样本方差]]。

---

# 一、单正态总体置信区间

设

$$X_1,\dots,X_n \overset{\text{i.i.d.}}{\sim} N(\mu,\sigma^2)$$

这里最常见有三种情况：

1. 求 $\mu$ 的区间，$\sigma^2$ 已知；
2. 求 $\mu$ 的区间，$\sigma^2$ 未知；
3. 求 $\sigma^2$ 的区间，$\mu$ 未知。

---

## 1. 求 $\mu$，且 $\sigma^2$ 已知

因为

$$\bar X \sim N\!\left(\mu,\ \frac{\sigma^2}{n}\right)$$

标准化：

$$Z = \frac{\bar X-\mu}{\sigma/\sqrt{n}} \sim N(0,1)$$

取中间概率：

$$P\left\{-z_{\alpha/2} \le \frac{\bar X-\mu}{\sigma/\sqrt{n}} \le z_{\alpha/2}\right\} = 1-\alpha$$

反解 $\mu$：

$$\boxed{\ \mu \in \left[\ \bar X - z_{\alpha/2}\frac{\sigma}{\sqrt{n}},\ \ \bar X + z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\ \right]\ }$$

这是最基础的一个。它的结构就是：

$$\boxed{\ \text{样本均值} \pm \text{临界值} \times \text{标准误}\ }$$

---

## 2. 求 $\mu$，且 $\sigma^2$ 未知

这时真实 $\sigma$ 不知道，就用样本标准差 $S$ 替代。[[枢轴量法|枢轴量]]变成：

$$T = \frac{\bar X-\mu}{S/\sqrt{n}} \sim t(n-1)$$

于是置信区间：

$$\boxed{\ \mu \in \left[\ \bar X - t_{\alpha/2}(n-1)\frac{S}{\sqrt{n}},\ \ \bar X + t_{\alpha/2}(n-1)\frac{S}{\sqrt{n}}\ \right]\ }$$

所以你可以记：

> **正态均值：方差已知用 $Z$，方差未知用 $t$。**

---

## 3. 求 $\sigma^2$ 的区间

这个时候用的是 $\chi^2$ 分布。对于正态总体，有：

$$\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$$

按上侧分位数约定，**小的在左、大的在右**：

$$P\left\{\chi^2_{1-\alpha/2}(n-1) \le \frac{(n-1)S^2}{\sigma^2} \le \chi^2_{\alpha/2}(n-1)\right\} = 1-\alpha$$

注意 $\sigma^2$ 在**分母**上，取倒数时不等号方向翻转，因此上下限**交换**：

$$\frac{1}{\chi^2_{\alpha/2}(n-1)} \le \frac{\sigma^2}{(n-1)S^2} \le \frac{1}{\chi^2_{1-\alpha/2}(n-1)}$$

反解 $\sigma^2$ 得到：

$$\boxed{\ \frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)} \ \le\ \sigma^2 \ \le\ \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\ }$$

若要 $\sigma$ 的区间，两端直接开方即可。

> **记忆要点**：分母上"小分位点配大区间端"。左端配 $\chi^2_{\alpha/2}$（大分位点），右端配 $\chi^2_{1-\alpha/2}$（小分位点）。这个地方是考试特别容易写反的。

---

# 二、两正态总体均值差区间

现在有两组**相互独立**的样本：

$$X_1,\dots,X_{n_1} \overset{\text{i.i.d.}}{\sim} N(\mu_1,\sigma_1^2), \qquad Y_1,\dots,Y_{n_2} \overset{\text{i.i.d.}}{\sim} N(\mu_2,\sigma_2^2)$$

我们想估计 $\mu_1-\mu_2$。

---

## 1. 两个方差都已知

因为 $\bar X - \bar Y$ 的均值是 $\mu_1-\mu_2$，方差是（由独立性直接相加）

$$\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}$$

所以：

$$Z = \frac{(\bar X-\bar Y)-(\mu_1-\mu_2)}{\sqrt{\dfrac{\sigma_1^2}{n_1}+\dfrac{\sigma_2^2}{n_2}}} \sim N(0,1)$$

得到：

$$\boxed{\ \mu_1-\mu_2 \ \in\ (\bar X-\bar Y) \pm z_{\alpha/2}\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}\ }$$

---

## 2. 方差未知但相等

假设 $\sigma_1^2 = \sigma_2^2 = \sigma^2$，但这个共同方差不知道。

这时把两组样本方差按自由度加权合并，定义**合并方差**：

$$S_p^2 = \frac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{n_1+n_2-2}$$

然后有：

$$T = \frac{(\bar X-\bar Y)-(\mu_1-\mu_2)}{S_p\sqrt{\dfrac{1}{n_1}+\dfrac{1}{n_2}}} \sim t(n_1+n_2-2)$$

于是区间：

$$\boxed{\ \mu_1-\mu_2 \ \in\ (\bar X-\bar Y) \pm t_{\alpha/2}(n_1+n_2-2)\,S_p\sqrt{\frac{1}{n_1}+\frac{1}{n_2}}\ }$$

> 自由度 $n_1+n_2-2$ 的来历：两组各损失一个自由度用于估计各自的均值。

---

## 3. 方差未知且不等

这时候不能直接合并方差。常用 **Welch 方法**：

$$\frac{(\bar X-\bar Y)-(\mu_1-\mu_2)}{\sqrt{\dfrac{S_1^2}{n_1}+\dfrac{S_2^2}{n_2}}} \ \dot\sim\ t(\nu)$$

（$\dot\sim$ 表示近似服从。）区间：

$$\boxed{\ \mu_1-\mu_2 \ \in\ (\bar X-\bar Y) \pm t_{\alpha/2}(\nu)\sqrt{\frac{S_1^2}{n_1}+\frac{S_2^2}{n_2}}\ }$$

其中自由度 $\nu$ 由 **Welch–Satterthwaite 公式**近似：

$$\nu = \frac{\left(\dfrac{S_1^2}{n_1}+\dfrac{S_2^2}{n_2}\right)^{2}}{\dfrac{\left(S_1^2/n_1\right)^2}{n_1-1}+\dfrac{\left(S_2^2/n_2\right)^2}{n_2-1}}$$

一般不是整数，需要查表时向下取整。考试若重点讲"方差相等"，通常主要考前一种合并方差。

---

# 三、两正态总体方差比区间

现在目标不是均值差，而是 $\dfrac{\sigma_1^2}{\sigma_2^2}$。对于两个独立正态总体，有：

$$\frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \sim F(n_1-1,\ n_2-1)$$

整理成"样本方差比 $\div$ 总体方差比"：

$$\frac{S_1^2/S_2^2}{\sigma_1^2/\sigma_2^2} \sim F(n_1-1,\ n_2-1)$$

按上侧分位数约定截概率：

$$P\left\{F_{1-\alpha/2}(n_1-1,n_2-1) \le \frac{S_1^2/S_2^2}{\sigma_1^2/\sigma_2^2} \le F_{\alpha/2}(n_1-1,n_2-1)\right\} = 1-\alpha$$

待估的 $\sigma_1^2/\sigma_2^2$ 同样在**分母**上，反解后上下限**交换**：

$$\boxed{\ \frac{S_1^2/S_2^2}{F_{\alpha/2}(n_1-1,\,n_2-1)} \ \le\ \frac{\sigma_1^2}{\sigma_2^2} \ \le\ \frac{S_1^2/S_2^2}{F_{1-\alpha/2}(n_1-1,\,n_2-1)}\ }$$

查表时常用倒数关系把左尾换成右尾：

$$F_{1-\alpha/2}(k_1,k_2) = \frac{1}{F_{\alpha/2}(k_2,\,k_1)}$$

（注意两个自由度**交换了位置**。）所以你可以记：

> **单个正态方差 $\to \chi^2$；两个正态方差之比 $\to F$。**

这是非常重要的一组对应。

---

# 四、均匀分布置信区间

现在假设

$$X_1,\dots,X_n \overset{\text{i.i.d.}}{\sim} U(0,\theta)$$

其中 $\theta$ 未知。

这类题和[[正态分布]]不一样，因为参数 $\theta$ 决定了分布的**右端点**。这时最有用的统计量不是样本均值，而是最大[[次序统计量]]：

$$X_{(n)} = \max(X_1,\dots,X_n)$$

因为最大值和 $\theta$ 的关系最直接。

---

## 1. 最大值的分布

对于 $0 < x < \theta$，有：

$$P\{X_{(n)} \le x\} = P\{X_1\le x,\dots,X_n\le x\} \overset{\text{独立}}{=} \left(\frac{x}{\theta}\right)^{n}$$

令 $t = x/\theta$，则

$$P\left\{\frac{X_{(n)}}{\theta} \le t\right\} = t^{n}, \qquad 0<t<1$$

因此 $\dfrac{X_{(n)}}{\theta}$ 的分布**完全不依赖 $\theta$**，这就是枢轴量。

然后从它的分布里截取概率，就能反解 $\theta$。

---

## 2. 一个常见单侧区间

取 $t = \alpha^{1/n}$，则

$$P\left\{\frac{X_{(n)}}{\theta} \ge \alpha^{1/n}\right\} = 1 - \left(\alpha^{1/n}\right)^{n} = 1-\alpha$$

而 $\dfrac{X_{(n)}}{\theta} \ge \alpha^{1/n}$ 等价于

$$\theta \le \frac{X_{(n)}}{\alpha^{1/n}}$$

同时由 $U(0,\theta)$ 的定义，必然有 $\theta \ge X_{(n)}$（这是恒成立的，不消耗置信度）。所以

$$\boxed{\ X_{(n)} \ \le\ \theta \ \le\ \frac{X_{(n)}}{\alpha^{1/n}}\ }$$

其覆盖概率**恰好**是 $1-\alpha$。这类题的核心不是背最终形式，而是：

> **均匀分布端点参数 $\to$ 看最大次序统计量。**

---

# 五、指数分布置信区间

假设

$$X_1,\dots,X_n \overset{\text{i.i.d.}}{\sim} \text{Exp}(\lambda)$$

这里 $\lambda$ 是率参数（密度 $f(x)=\lambda e^{-\lambda x},\ x>0$）。有一个非常重要的结论：

$$\sum_{i=1}^n X_i \sim \text{Ga}(n,\lambda)$$

进一步（Gamma 与 $\chi^2$ 的关系）：

$$2\lambda\sum_{i=1}^n X_i \sim \chi^2(2n)$$

于是 $2\lambda\sum X_i$ 就是一个枢轴量。

---

## 求 $\lambda$ 的区间

$$P\left\{\chi^2_{1-\alpha/2}(2n) \le 2\lambda\sum_{i=1}^n X_i \le \chi^2_{\alpha/2}(2n)\right\} = 1-\alpha$$

这次 $\lambda$ 在**分子**上，同除以正数 $2\sum X_i$ 即可，**上下限不交换**：

$$\boxed{\ \frac{\chi^2_{1-\alpha/2}(2n)}{2\sum_{i=1}^n X_i} \ \le\ \lambda \ \le\ \frac{\chi^2_{\alpha/2}(2n)}{2\sum_{i=1}^n X_i}\ }$$

> 对比第一节第 3 小节：那里 $\sigma^2$ 在分母、上下限要换；这里 $\lambda$ 在分子、不用换。**判断依据永远是"待估参数在枢轴量的哪一侧"，不是死记。**

如果教材用的是均值参数 $\theta = \dfrac{1}{\lambda}$，那只需对上式两端取倒数，此时上下限**交换**：

$$\frac{2\sum X_i}{\chi^2_{\alpha/2}(2n)} \le \theta \le \frac{2\sum X_i}{\chi^2_{1-\alpha/2}(2n)}$$

---

# 六、两点分布（比例）置信区间

两点分布通常就是 Bernoulli：

$$X_i \overset{\text{i.i.d.}}{\sim} \text{Bernoulli}(p)$$

我们要估计 $p$。样本均值

$$\bar X = \frac{1}{n}\sum_{i=1}^n X_i$$

就是样本中 $1$ 的比例。大样本情况下，根据[[Lindeberg-Levy 中心极限定理|中心极限定理]]：

$$\bar X \ \dot\sim\ N\!\left(p,\ \frac{p(1-p)}{n}\right)$$

标准化：

$$\frac{\bar X-p}{\sqrt{p(1-p)/n}} \ \dot\sim\ N(0,1)$$

但这里有一个问题：**分母里面还有未知的 $p$**，严格说它不是枢轴量。常见做法是用 $\bar X$ 代替分母中的 $p$，得到近似标准误

$$\widehat{\mathrm{SE}} = \sqrt{\frac{\bar X(1-\bar X)}{n}}$$

最终得到常见的近似区间（Wald 区间）：

$$\boxed{\ p \ \in\ \bar X \pm z_{\alpha/2}\sqrt{\frac{\bar X(1-\bar X)}{n}}\ \quad(\text{近似})}$$

不过小样本或者 $p$ 靠近 $0$、$1$ 时这个近似不好（$\bar X = 0$ 或 $1$ 时区间宽度直接退化为 $0$），实际统计中常用 **Wilson 区间**等方法。

---

# 七、泊松分布置信区间

假设

$$X_1,\dots,X_n \overset{\text{i.i.d.}}{\sim} P(\lambda)$$

因为 $E(X_i) = \lambda$、$\operatorname{Var}(X_i) = \lambda$，所以样本均值 $\bar X$ 可以估计 $\lambda$。

---

## 大样本近似

根据中心极限定理：

$$\bar X \ \dot\sim\ N\!\left(\lambda,\ \frac{\lambda}{n}\right) \qquad\Longrightarrow\qquad \frac{\bar X-\lambda}{\sqrt{\lambda/n}} \ \dot\sim\ N(0,1)$$

同样地，分母含未知的 $\lambda$，用 $\bar X$ 代替：

$$\widehat{\mathrm{SE}} = \sqrt{\frac{\bar X}{n}}$$

因此：

$$\boxed{\ \lambda \ \in\ \bar X \pm z_{\alpha/2}\sqrt{\frac{\bar X}{n}}\ \quad(\text{近似})}$$

---

## 更精确的方法

因为 $\displaystyle S = \sum_{i=1}^n X_i \sim P(n\lambda)$，利用 Poisson 与 $\chi^2$ 的关系可构造**精确区间**（Garwood 区间）：

$$\boxed{\ \lambda_L = \frac{\chi^2_{1-\alpha/2}(2S)}{2n}, \qquad \lambda_U = \frac{\chi^2_{\alpha/2}\big(2(S+1)\big)}{2n}\ }$$

注意两点：

- 上下限的**自由度不同**（$2S$ 与 $2S+2$），这是离散分布做精确区间的典型特征；
- 当 $S = 0$ 时约定 $\lambda_L = 0$。

如果课程目前重点是基础区间估计，先掌握正态近似形式就够了。

---

# 八、你真正应该建立的"分布对应表"

| 问题 | 典型枢轴分布 | 枢轴量 |
| :--- | :--- | :--- |
| 正态均值，方差已知 | $Z$ | $\dfrac{\bar X-\mu}{\sigma/\sqrt n}$ |
| 正态均值，方差未知 | $t(n-1)$ | $\dfrac{\bar X-\mu}{S/\sqrt n}$ |
| 单正态总体方差 | $\chi^2(n-1)$ | $\dfrac{(n-1)S^2}{\sigma^2}$ |
| 两正态总体方差比 | $F(n_1-1,n_2-1)$ | $\dfrac{S_1^2/S_2^2}{\sigma_1^2/\sigma_2^2}$ |
| 两正态均值差，方差已知 | $Z$ | 见二.1 |
| 两正态均值差，方差未知但相等 | $t(n_1+n_2-2)$ | 见二.2 |
| 两正态均值差，方差未知不等 | $t(\nu)$ 近似 | Welch |
| 指数分布率参数 | $\chi^2(2n)$ | $2\lambda\sum X_i$ |
| Bernoulli 比例，大样本 | $Z$ 近似 | $\dfrac{\bar X-p}{\sqrt{\bar X(1-\bar X)/n}}$ |
| Poisson 参数，大样本 | $Z$ 近似 | $\dfrac{\bar X-\lambda}{\sqrt{\bar X/n}}$ |
| 均匀分布端点 | —— | $\dfrac{X_{(n)}}{\theta}$ |

所以你以后看到题目，第一反应应该不是"背哪个公式"，而是：

> **这个参数能不能构造出一个分布已知的枢轴量？**

# 九、为什么正态分布会出现 $Z$、$t$、$\chi^2$、$F$ 四个分布？

这其实是整块区间估计最漂亮的地方。设 $X_i \overset{\text{i.i.d.}}{\sim} N(\mu,\sigma^2)$，正态总体有几个经典结构：

**① 标准化 $\to Z$**

$$\frac{\bar X-\mu}{\sigma/\sqrt{n}} \sim N(0,1)$$

所以求均值、方差已知时用 $Z$。

**② 样本方差 $\to \chi^2$**

$$\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$$

所以单个总体方差用 $\chi^2$。

**③ 两者相除 $\to t$**

关键事实：正态总体下 $\bar X$ 与 $S^2$ **相互独立**。由 $t$ 分布的定义 $t = \dfrac{N(0,1)}{\sqrt{\chi^2(k)/k}}$（分子分母独立）：

$$\frac{\dfrac{\bar X-\mu}{\sigma/\sqrt n}}{\sqrt{\dfrac{(n-1)S^2/\sigma^2}{n-1}}} = \frac{\bar X-\mu}{S/\sqrt{n}} \sim t(n-1)$$

$\sigma$ 在分子分母上**恰好约掉**了——这正是 $\sigma$ 未知时仍能构造枢轴量的原因。

**④ 两个 $\chi^2$ 相除 $\to F$**

$$F = \frac{\chi_1^2/\nu_1}{\chi_2^2/\nu_2} \quad (\text{两者独立})$$

所以两个正态总体方差之比自然用 $F$。

也就是说：

$$\boxed{\ Z \rightarrow \chi^2 \rightarrow t \rightarrow F\ }$$

不是四套互不相关的公式，而是都从正态分布的结构里生出来的。

# 十、最后给你一个做题判断流程

| 题目说 | 先问 | 用什么 |
| :--- | :--- | :--- |
| 正态总体，求均值 | 方差知道吗？ | 知道 $\to Z$；不知道 $\to t(n-1)$ |
| 正态总体，求方差 | —— | $\chi^2(n-1)$，**注意上下限交换** |
| 两个正态总体，求方差比 | —— | $F(n_1-1,n_2-1)$，**注意上下限交换** |
| 两个正态总体，求均值差 | 两个方差？ | 已知 $\to Z$；未知但相等 $\to$ 合并方差 $+\ t(n_1+n_2-2)$；未知且不等 $\to$ Welch $t$ |
| 均匀分布端点参数 | —— | 最大次序统计量 $X_{(n)}$ |
| 指数分布 | —— | $2\lambda\sum X_i \sim \chi^2(2n)$ |
| Bernoulli / 两点分布 / 比例 | 样本大吗？ | 大样本 $\to \bar X +$ 正态近似 |
| Poisson 参数 | 样本大吗？ | 大样本 $\to$ 正态近似；精确 $\to$ 转 $\chi^2$ |

最核心的一句话还是：

> **区间估计不是背区间，而是找到一个"分布已知、又含未知参数"的枢轴量，然后把概率不等式反解成参数范围。**
