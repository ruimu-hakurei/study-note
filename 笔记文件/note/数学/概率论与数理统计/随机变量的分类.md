## 第一大类：离散型随机变量 (Discrete Random Variables)

**核心特征**：它取的值是可以“一个一个数出来”的。

哪怕它能取无限个值（比如 $1, 2, 3 \dots$ 一直到无穷），只要它是可数无穷，它就属于离散型。它的图像在实数轴上是一堆孤立的散点。

- **描述工具：分布律 / 概率质量函数 (PMF, Probability Mass Function)**
    
    对于离散型随机变量，我们可以精确地讨论它取某一个具体数值的概率。
    
    $$P(X = x_k) = p_k, \quad (k = 1, 2, \dots)$$
    
    根据概率的规范性，所有这些散点的概率加起来必须等于 1：
    
    $$\sum_{k} p_k = 1$$
    
- **经典代表**：
    
    - **伯努利分布 (0-1分布)**：只取 0 或 1，非黑即白。
        
    - **二项分布**：抛 $n$ 次硬币，出现正面的次数（取值范围 $0, 1, \dots, n$）。
        
    - **泊松分布**：一天内打进客服中心的电话数量（取值范围可以一直到正无穷，但全都是整数）。
        

## 第二大类：连续型随机变量 (Continuous Random Variables)

**核心特征**：它取的值铺满了整个区间，**“根本数不过来”**（不可数无穷）。

比如身高、时间、温度、误差。你不可能穷举出所有的温度，因为在 $25^\circ\text{C}$ 和 $26^\circ\text{C}$ 之间，有无数个极其微小的实数。

- **致命的认知突变：单点概率为 0**
    
    这正是我们在“几何概型”里聊过的现象。因为实数轴上有点的无限稠密性，连续型随机变量取任何一个**极其精确的单点数值**的概率，在数学上都等于 0：
    
    $$P(X = a) = 0$$
    
    既然单点概率为 0，我们再去求“等于某个值”的概率就毫无意义了。所以，连续型的核心逻辑是**求区间**（比如求温度落在 $25^\circ\text{C}$ 到 $25.1^\circ\text{C}$ 之间的概率）。
    
- **描述工具：概率密度函数 (PDF, Probability Density Function)**
    
    为了描述区间概率，数学家引入了密度函数 $f(x)$。**注意，$f(x)$ 绝对不是概率，它是概率的“密集程度”！** 只有把它放进积分里，算出来的面积才是真正的概率：
    
    $$P(a \le X \le b) = \int_{a}^{b} f(x) dx$$
    
    整个实数轴上的概率总和为 1，对应着密度曲线下的总面积为 1：
    
    $$\int_{-\infty}^{+\infty} f(x) dx = 1$$
    
- **经典代表**：
    
    - **均匀分布**：在一段区间内完全等概率发生（几何概型的进阶版）。
        
    - **指数分布**：描述等待下一次事件发生的时间（自带神奇的“无记忆性”）。
        
    - **正态分布 (高斯分布)**：宇宙中最伟大的钟形曲线，中心极限定理的终极形态。
        

## 统一天下的终极武器：累积分布函数 (CDF)

不管是离散型的“一个个加起来”，还是连续型的“求积分算面积”，计算体系完全撕裂了。为了在更高维度的数学表达上统一这两大类随机变量，柯尔莫哥洛夫等数学家启用了最核心的工具：**分布函数 (Cumulative Distribution Function, 记作 $F(x)$)**。

它的定义极其简单粗暴，没有任何前置门槛：

$$F(x) = P(X \le x)$$

这就是我们在那个“抽球最大编号”题目里用到的那个降维打击的思路（求最大值小于等于 $i$ 的概率）。

- **对于离散型**：$F(x)$ 是一个**阶梯函数**，每到一个取值点，概率就往上跳一格。
    
    $$F(x) = \sum_{x_k \le x} P(X = x_k)$$
    
- **对于连续型**：$F(x)$ 是一个**绝对平滑的连续曲线**，它是密度函数 $f(x)$ 的变上限积分。
    
    $$F(x) = \int_{-\infty}^{x} f(t) dt$$
    

$F(x)$ 完美地涵盖了所有的随机变量。它永远是一个单调不减的函数，左极限是从 0 开始（不可能比负无穷还小），右极限无限逼近 1（必然小于正无穷）。有了它，离散和连续的鸿沟在纯数学分析的层面上就被彻底填平了。
