证明指数分布的数学期望（均值）和方差，核心工具是微积分中的**分部积分法**（$\int u dv = uv - \int v du$）以及计算无穷极限时的**洛必达法则**。

已知指数分布 $X \sim \text{Exp}(\lambda)$ 的概率密度函数为：

$$f(x) = \begin{cases} \lambda e^{-\lambda x} & x \ge 0 \\ 0 & x < 0 \end{cases}$$

下面我们一步步进行推导。

### 一、 数学期望 $E(X) = \frac{1}{\lambda}$ 的证明

根据连续型随机变量数学期望的定义，我们要计算的积分是：

$$E(X) = \int_0^\infty x \cdot f(x) dx = \int_0^\infty x \lambda e^{-\lambda x} dx$$

**第一步：构造分部积分**

为了方便运算，我们将 $\lambda e^{-\lambda x} dx$ 凑成微分 $d(-e^{-\lambda x})$。

令 $u = x$，那么 $du = dx$。

令 $dv = \lambda e^{-\lambda x} dx$，那么 $v = -e^{-\lambda x}$。

代入分部积分公式：

$$E(X) = \left[ -x e^{-\lambda x} \right]_0^\infty - \int_0^\infty (-e^{-\lambda x}) dx$$

**第二步：计算前项极限**

前项为 $\left[ -x e^{-\lambda x} \right]_0^\infty$。

- 代入下限 $x = 0$：$-0 \cdot e^0 = 0$。
    
- 代入上限 $x \to \infty$：我们需要求极限 $\lim_{x \to \infty} \frac{-x}{e^{\lambda x}}$。这是一个 $\frac{\infty}{\infty}$ 型未定式，使用洛必达法则（分子分母同时求导），得到 $\lim_{x \to \infty} \frac{-1}{\lambda e^{\lambda x}} = 0$。
    

所以，前项等于 0。

**第三步：计算后项积分**

期望的表达式现在只剩下后项：

$$E(X) = 0 + \int_0^\infty e^{-\lambda x} dx$$

计算这个基本积分：

$$E(X) = \left[ -\frac{1}{\lambda} e^{-\lambda x} \right]_0^\infty = \left( -\frac{1}{\lambda} \cdot 0 \right) - \left( -\frac{1}{\lambda} \cdot 1 \right) = \frac{1}{\lambda}$$

**结论：** 数学期望 $E(X) = \frac{1}{\lambda}$ 证明完毕。

### 二、 方差 $Var(X) = \frac{1}{\lambda^2}$ 的证明

计算方差的通用公式是：

$$Var(X) = E(X^2) - [E(X)]^2$$

既然已经求出 $E(X) = \frac{1}{\lambda}$，我们只需要求出 $E(X^2)$ 即可。

**第一步：写出 $E(X^2)$ 的积分**

$$E(X^2) = \int_0^\infty x^2 \lambda e^{-\lambda x} dx$$

同样凑微分，令 $u = x^2$（则 $du = 2x dx$），令 $dv = \lambda e^{-\lambda x} dx$（则 $v = -e^{-\lambda x}$）。

代入分部积分公式：

$$E(X^2) = \left[ -x^2 e^{-\lambda x} \right]_0^\infty - \int_0^\infty (-e^{-\lambda x}) (2x) dx$$

**第二步：计算前项极限**

前项为 $\left[ -x^2 e^{-\lambda x} \right]_0^\infty$。

- 下限代入 $x=0$，结果为 0。
    
- 上限 $x \to \infty$，求极限 $\lim_{x \to \infty} \frac{-x^2}{e^{\lambda x}}$。连续使用两次洛必达法则：
    
    $$\lim_{x \to \infty} \frac{-2x}{\lambda e^{\lambda x}} \xrightarrow{\text{再求导}} \lim_{x \to \infty} \frac{-2}{\lambda^2 e^{\lambda x}} = 0$$
    
    前项依然等于 0。
    

**第三步：化简后项，巧妙利用 $E(X)$**

现在 $E(X^2)$ 只剩下后项积分：

$$E(X^2) = \int_0^\infty 2x e^{-\lambda x} dx$$

为了凑出我们熟悉的期望表达式，我们提取常数 2，并在积分内部乘除一个 $\lambda$：

$$E(X^2) = \frac{2}{\lambda} \int_0^\infty x (\lambda e^{-\lambda x}) dx$$

注意看积分号内部，这完全就是数学期望 $E(X)$ 的定义！

所以：

$$E(X^2) = \frac{2}{\lambda} \cdot E(X) = \frac{2}{\lambda} \cdot \frac{1}{\lambda} = \frac{2}{\lambda^2}$$

**第四步：代入方差公式**

最后，将 $E(X^2)$ 和 $E(X)$ 代入方差公式：

$$Var(X) = E(X^2) - [E(X)]^2$$

$$Var(X) = \frac{2}{\lambda^2} - \left( \frac{1}{\lambda} \right)^2$$

$$Var(X) = \frac{2}{\lambda^2} - \frac{1}{\lambda^2} = \frac{1}{\lambda^2}$$

**结论：** 方差 $Var(X) = \frac{1}{\lambda^2}$ 证明完毕。
