# 常见分布的特征函数

特征函数 $\varphi(t) = E(e^{itX})$ 是连接概率论与复变函数的桥梁。掌握常见分布的特征函数，不仅能让你在做题时实现"降维打击"，更是推导中心极限定理和大数定律的基础。

下面将概率论中最核心的几种离散型和连续型分布的特征函数及其推导逻辑进行全面梳理。

---

## 一、常见离散型分布的特征函数

对于离散型随机变量，特征函数的计算本质上是求级数和：$\varphi(t) = \sum e^{itx_k} P(X = x_k)$。

### 1.1 两点分布（伯努利分布）$B(1, p)$

- **分布律**：$P(X=1) = p$, $P(X=0) = q = 1-p$
- **特征函数推导**：

    $$\varphi(t) = E(e^{itX}) = e^{it \cdot 1} \cdot p + e^{it \cdot 0} \cdot q = q + p e^{it}$$

- **结论**：$\varphi(t) = 1 - p + p e^{it}$

### 1.2 二项分布 $B(n, p)$

- **物理意义**：$n$ 次独立重复的伯努利试验成功次数的总和。
- **特征函数推导**：利用特征函数"独立变量之和等于特征函数之积"的核武器性质。设 $X = \sum_{k=1}^n X_k$，其中 $X_k \sim B(1, p)$ 且相互独立。

    $$\varphi_X(t) = \prod_{k=1}^n \varphi_{X_k}(t) = (q + p e^{it})^n$$

- **结论**：$\varphi(t) = (1 - p + p e^{it})^n$

### 1.3 泊松分布 $P(\lambda)$

- **分布律**：$P(X=k) = \frac{\lambda^k}{k!} e^{-\lambda}$ ($k = 0, 1, 2, \dots$)
- **特征函数推导**：利用泰勒展开式 $\sum_{k=0}^{\infty} \frac{x^k}{k!} = e^x$。

    $$\varphi(t) = \sum_{k=0}^{\infty} e^{itk} \frac{\lambda^k}{k!} e^{-\lambda} = e^{-\lambda} \sum_{k=0}^{\infty} \frac{(\lambda e^{it})^k}{k!} = e^{-\lambda} e^{\lambda e^{it}}$$

- **结论**：$\varphi(t) = e^{\lambda (e^{it} - 1)}$

## 二、常见连续型分布的特征函数

对于连续型随机变量，特征函数的计算本质上是求傅里叶积分：$\varphi(t) = \int_{-\infty}^{+\infty} e^{itx} f(x) dx$。

### 2.1 均匀分布 $U(a, b)$

- **密度函数**：在区间 $[a, b]$ 上 $f(x) = \frac{1}{b-a}$，其他地方为 0。
- **特征函数推导**：

    $$\varphi(t) = \int_a^b e^{itx} \frac{1}{b-a} dx = \frac{1}{b-a} \cdot \left. \frac{e^{itx}}{it} \right\vert{}_a^b = \frac{e^{itb} - e^{ita}}{it(b-a)}$$

- **结论**：$\varphi(t) = \frac{e^{itb} - e^{ita}}{it(b-a)}$ （注意：当 $t=0$ 时，利用洛必达法则可得 $\varphi(0)=1$）

### 2.2 指数分布 $E(\lambda)$

- **密度函数**：$f(x) = \lambda e^{-\lambda x}$ ($x > 0$)
- **特征函数推导**：

    $$\varphi(t) = \int_0^{+\infty} e^{itx} \lambda e^{-\lambda x} dx = \lambda \int_0^{+\infty} e^{-(\lambda - it)x} dx = \frac{\lambda}{\lambda - it}$$

- **结论**：$\varphi(t) = \frac{\lambda}{\lambda - it}$

### 2.3 正态分布 $N(\mu, \sigma^2)$（绝对核心）

这是概率论中最重要、推导也最需要技巧的特征函数。

- **第一步：标准正态分布 $N(0, 1)$ 的特征函数**

    设 $Z \sim N(0, 1)$，$f(z) = \frac{1}{\sqrt{2\pi}} e^{-z^2/2}$。

    利用配方法（或对 $t$ 求导构造微分方程 $\varphi'(t) = -t \varphi(t)$），最终可以解得其特征函数极其优美：

    $$\varphi_Z(t) = e^{-\frac{1}{2}t^2}$$

    _(注意：标准正态分布的特征函数形状与它的密度函数形状完全一致，这也是正态分布的极度特殊之处)_。

- **第二步：一般正态分布 $N(\mu, \sigma^2)$ 的特征函数**

    利用线性变换性质：若 $X = \sigma Z + \mu$，则 $\varphi_X(t) = E(e^{it(\sigma Z + \mu)}) = e^{i\mu t} E(e^{i(\sigma t)Z}) = e^{i\mu t} \varphi_Z(\sigma t)$。

    代入标准正态的特征函数：

    $$\varphi_X(t) = e^{i\mu t} e^{-\frac{1}{2}(\sigma t)^2}$$

- **结论**：$\varphi(t) = e^{i\mu t - \frac{1}{2}\sigma^2 t^2}$

## 三、正态分布特征函数的完整证明（微分方程法）

正态分布特征函数的推导，是概率论中极其经典且极具美感的一段数学证明。在茆诗松等高等概率论教材中，通常会避开复杂的复变函数留数定理，而是采用一种非常精妙的"微分方程法（积分分部法）"来完成推导。

我们将这个推导过程分为两大阶段：先拿下标准正态分布 $N(0,1)$，再通过线性变换推广到一般正态分布 $N(\mu, \sigma^2)$。

### 3.1 第一阶段：标准正态分布 $Z \sim N(0, 1)$ 的特征函数证明

设 $Z$ 服从标准正态分布，其概率密度函数为：

$$f(z) = \frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}}$$

根据特征函数的定义，我们要计算的目标积分是：

$$\varphi(t) = E(e^{itZ}) = \int_{-\infty}^{+\infty} e^{itz} \frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}} dz$$

#### 第一步：对特征函数求导

为了计算这个复杂的积分，我们对等式两边关于实数变量 $t$ 进行求导。

因为积分区间与 $t$ 无关，我们可以将导数符号直接拿到积分号内部（这一步在绝对收敛的条件下是严格成立的）：

$$\varphi'(t) = \frac{d}{dt} \int_{-\infty}^{+\infty} e^{itz} \frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}} dz = \int_{-\infty}^{+\infty} \frac{\partial}{\partial t} (e^{itz}) \frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}} dz$$

对 $e^{itz}$ 求 $t$ 的偏导数，会多出一个 $iz$：

$$\varphi'(t) = \int_{-\infty}^{+\infty} iz \cdot e^{itz} \frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}} dz$$

将其重新整理一下，把常数 $i$ 提出来：

$$\varphi'(t) = i \int_{-\infty}^{+\infty} e^{itz} \left( z \frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}} \right) dz$$

#### 第二步：祭出分部积分法

观察上面积分括号里的部分 $z e^{-\frac{z^2}{2}}$。根据微积分知识，这恰好是 $-e^{-\frac{z^2}{2}}$ 的导数！

也就是说：

$$d\left( -e^{-\frac{z^2}{2}} \right) = z e^{-\frac{z^2}{2}} dz$$

现在，我们对原积分使用**分部积分公式** $\int u dv = uv - \int v du$：

- 令 $u = e^{itz}$，则 $du = it e^{itz} dz$
- 令 $dv = z \frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}} dz$，则 $v = -\frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}}$

代入分部积分公式：

$$\varphi'(t) = i \left[ \left. e^{itz} \left( -\frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}} \right) \right\vert{}_{-\infty}^{+\infty} - \int_{-\infty}^{+\infty} \left( -\frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}} \right) (it e^{itz} dz) \right]$$

#### 第三步：化简边界与积分

**1. 处理边界项**：

当 $z \to \pm\infty$ 时，$e^{itz} = \cos(tz) + i\sin(tz)$ 是有界的（模长永远为 1），而 $e^{-\frac{z^2}{2}}$ 以极快的速度衰减到 0。因此，第一部分的边界项直接等于 0。

**2. 处理剩余积分**：

把第二部分中的负号和常数整理出来：

$$\varphi'(t) = i \left[ 0 + it \int_{-\infty}^{+\infty} e^{itz} \frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}} dz \right]$$

注意看积分符号里的那一长串——它**完完全全就是特征函数 $\varphi(t)$ 的原始定义**！

所以：

$$\varphi'(t) = i \cdot (it) \cdot \varphi(t) = i^2 t \varphi(t) = -t \varphi(t)$$

#### 第四步：求解常微分方程

我们得到了一阶线性常微分方程：

$$\frac{d\varphi(t)}{dt} = -t \varphi(t)$$

分离变量并积分：

$$\frac{d\varphi(t)}{\varphi(t)} = -t dt$$

$$\int \frac{d\varphi(t)}{\varphi(t)} = \int -t dt$$

$$\ln \varphi(t) = -\frac{1}{2}t^2 + C$$

$$\varphi(t) = e^{-\frac{1}{2}t^2 + C} = A e^{-\frac{1}{2}t^2}$$

最后，利用初始条件确定常数 $A$。根据特征函数定义，当 $t=0$ 时：

$$\varphi(0) = E(e^{i \cdot 0 \cdot Z}) = E(1) = 1$$

所以 $A = 1$。

**结论**：标准正态分布的特征函数为

$$\varphi_Z(t) = e^{-\frac{1}{2}t^2}$$

### 3.2 第二阶段：一般正态分布 $X \sim N(\mu, \sigma^2)$ 的特征函数证明

有了标准正态分布的特征函数，推导一般正态分布就不需要再做恶心的积分了，只需利用特征函数的**线性变换性质**。

#### 第一步：构建线性关系

已知任意正态分布 $X \sim N(\mu, \sigma^2)$ 都可以由标准正态分布 $Z \sim N(0, 1)$ 经过简单的线性缩放和平移得到：

$$X = \sigma Z + \mu$$

#### 第二步：代入特征函数定义展开

根据期望的线性性质和指数运算法则：

$$\varphi_X(t) = E(e^{itX}) = E\left(e^{it(\sigma Z + \mu)}\right)$$

$$\varphi_X(t) = E\left(e^{it\sigma Z + it\mu}\right) = E\left(e^{it\mu} \cdot e^{i(t\sigma)Z}\right)$$

因为 $e^{it\mu}$ 是一个与随机变量 $Z$ 无关的确定性常数，可以把它提到期望外面：

$$\varphi_X(t) = e^{i\mu t} \cdot E\left(e^{i(t\sigma)Z}\right)$$

#### 第三步：套用标准结果

观察后面那一项 $E\left(e^{i(t\sigma)Z}\right)$，它其实就是标准正态特征函数 $\varphi_Z$ 在变量取值为 $(t\sigma)$ 时的结果。

所以：

$$\varphi_X(t) = e^{i\mu t} \cdot \varphi_Z(t\sigma)$$

将我们第一阶段千辛万苦求出的 $\varphi_Z(\cdot) = e^{-\frac{1}{2}(\cdot)^2}$ 代入：

$$\varphi_X(t) = e^{i\mu t} \cdot e^{-\frac{1}{2}(t\sigma)^2} = e^{i\mu t} \cdot e^{-\frac{1}{2}\sigma^2 t^2}$$

合并指数项，得到**最终结论**：

$$\varphi_X(t) = e^{i\mu t - \frac{1}{2}\sigma^2 t^2}$$

## 四、常见分布特征函数速查表

在考试或推导中，以下表格的内容通常需要形成肌肉记忆，直接默写调用：

| **分布名称** | **记号**             | **概率分布 / 密度函数**                                                       | **特征函数 φ(t)**                          |
| -------- | ------------------ | --------------------------------------------------------------------- | -------------------------------------- |
| **两点分布** | $B(1, p)$          | $P(X=1)=p, P(X=0)=1-p$                                                | $1 - p + p e^{it}$                     |
| **二项分布** | $B(n, p)$          | $P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$                               | $(1 - p + p e^{it})^n$                 |
| **泊松分布** | $P(\lambda)$       | $P(X=k) = \frac{\lambda^k}{k!} e^{-\lambda}$                          | $e^{\lambda (e^{it} - 1)}$             |
| **均匀分布** | $U(a, b)$          | $f(x) = \frac{1}{b-a}, \; x \in [a, b]$                               | $\frac{e^{itb} - e^{ita}}{it(b-a)}$    |
| **指数分布** | $E(\lambda)$       | $f(x) = \lambda e^{-\lambda x}, \; x > 0$                             | $\frac{\lambda}{\lambda - it}$         |
| **标准正态** | $N(0, 1)$          | $f(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}$                             | $e^{-\frac{1}{2}t^2}$                  |
| **一般正态** | $N(\mu, \sigma^2)$ | $f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $e^{i\mu t - \frac{1}{2}\sigma^2 t^2}$ |
