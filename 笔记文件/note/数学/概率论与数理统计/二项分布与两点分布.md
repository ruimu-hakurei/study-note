## 1. 两点分布 (Two-Point / Bernoulli Distribution)

两点分布，又称 **0-1 分布** 或 **伯努利分布**。它是所有离散型随机变量中最基础的形态。

### 1.1 严密数学定义

设随机变量 $X$ 只取两个可能的值（通常设为 $0$ 和 $1$），代表一次试验中某个事件的“发生”与“不发生”。

其概率分布律（PMF）定义为：

$$P(X = 1) = p, \quad (0 < p < 1)$$

$$P(X = 0) = 1 - p$$

通常为了书写简便，我们会记 $q = 1 - p$。我们称 $X$ 服从参数为 $p$ 的伯努利分布，记作 $X \sim B(1, p)$ 或 $X \sim \text{Bernoulli}(p)$。

### 1.2 核心定理：期望与方差

**【定理】** 若 $X \sim \text{Bernoulli}(p)$，则其数学期望和方差分别为：

$$E(X) = p$$

$$D(X) = p(1 - p)$$

**【严密推导证明】**

1. **证明期望 $E(X)$**：
    
    根据离散型期望的定义 $E(X) = \sum x_i P(X = x_i)$：
    
    $$E(X) = 1 \cdot p + 0 \cdot (1 - p) = p$$
    
2. **证明方差 $D(X)$**：
    
    调用我们之前证明过的万能计算公式 $D(X) = E(X^2) - [E(X)]^2$。
    
    先算平方的期望 $E(X^2)$：
    
    $$E(X^2) = 1^2 \cdot p + 0^2 \cdot (1 - p) = p$$
    
    代入方差公式：
    
    $$D(X) = p - p^2 = p(1 - p)$$
    
    **证明完毕。**
    

**【物理意义】**

方差 $p(1-p)$ 是一个开口向下的抛物线。当 $p = 0.5$（比如抛一枚绝对均匀的硬币）时，方差达到最大值 $0.25$。这完美契合了直觉：**当两件事发生的概率五五开时，系统的不确定性（波动程度）最大。**

## 2. 二项分布 (Binomial Distribution)

将上面的伯努利试验**独立地重复** $n$ 次，这就构成了大名鼎鼎的二项分布。

### 2.1 严密数学定义

设随机变量 $Y$ 表示在 $n$ 次独立重复的伯努利试验中，事件 $A$（单次发生概率为 $p$）发生的**总次数**。

$Y$ 的取值空间为 $k \in \{0, 1, 2, \dots, n\}$。

其概率分布律定义为：

$$P(Y = k) = C_n^k p^k (1 - p)^{n-k}, \quad k = 0, 1, \dots, n$$

我们称 $Y$ 服从参数为 $n$ 和 $p$ 的二项分布，记作 $Y \sim B(n, p)$。

_注：公式中的 $C_n^k$（组合数）代表了从 $n$ 次试验中挑选出 $k$ 次发生 $A$ 事件的排列组合方式。_

### 2.2 核心定理：期望与方差

**【定理】** 若 $Y \sim B(n, p)$，则其数学期望和方差分别为：

$$E(Y) = np$$

$$D(Y) = np(1 - p)$$

**【严密推导证明：降维打击法】**

很多教科书在这里会用组合数公式 $C_n^k$ 去硬算求和，不仅推导极其繁琐，而且完全掩盖了二项分布的物理本质。我们直接使用**随机变量的拆分**与**期望方差的线性性质**来进行降维打击。

**第一步：构造示性函数（拆分原子）**

我们将总次数 $Y$ 拆解为 $n$ 个独立的 0-1 变量。

设 $X_i$ 为第 $i$ 次试验的结果：

$$X_i = \begin{cases} 1, & \text{第 } i \text{ 次事件发生} \\ 0, & \text{第 } i \text{ 次事件不发生} \end{cases}$$

显然，每一个 $X_i$ 都是一个两点分布 $X_i \sim \text{Bernoulli}(p)$，并且它们**相互独立**。

总次数 $Y$ 就可以完美表达为这 $n$ 个变量的代数和：

$$Y = X_1 + X_2 + \dots + X_n$$

**第二步：计算期望（利用无条件可加性）**

根据期望的线性加法性质（任意变量相加，期望直接相加）：

$$E(Y) = E(X_1 + X_2 + \dots + X_n) = E(X_1) + E(X_2) + \dots + E(X_n)$$

因为每个 $E(X_i) = p$：

$$E(Y) = \underbrace{p + p + \dots + p}_{n \text{ 个}} = np$$

**第三步：计算方差（利用独立性前提下的可加性）**

这里是绝对的重点！因为这 $n$ 次试验是**独立重复**的，所以 $X_1, X_2, \dots, X_n$ 相互独立。

根据我们之前推导过的铁律：只有在**相互独立**的前提下，方差才能直接相加。

$$D(Y) = D(X_1 + X_2 + \dots + X_n) = D(X_1) + D(X_2) + \dots + D(X_n)$$

因为每个 $D(X_i) = p(1-p)$：

$$D(Y) = \underbrace{p(1-p) + p(1-p) + \dots + p(1-p)}_{n \text{ 个}} = np(1-p)$$

**证明完毕。**

## 3. 两者关系总结表

为了工程应用中的快速调用，将二者的核心参数对比汇总如下：

|**特性维度**|**两点分布 (0-1 分布)**|**二项分布**|
|---|---|---|
|**符号记法**|$X \sim B(1, p)$|$Y \sim B(n, p)$|
|**物理意义**|1 次孤立的非黑即白试验|$n$ 次独立重复试验中的成功总数|
|**取值范围**|$0, 1$|$0, 1, 2, \dots, n$|
|**数学期望**|$p$|$np$|
|**方差**|$p(1 - p)$|$np(1 - p)$|
|**底层联系**|系统的”基本原子”|由 $n$ 个独立”原子”累加而成的”宏观系统”|
