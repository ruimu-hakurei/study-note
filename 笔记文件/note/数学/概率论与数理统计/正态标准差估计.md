估计正态总体 $X \sim N(\mu, \sigma^2)$ 的尺度参数——**标准差 $\sigma$**，比估计方差 $\sigma^2$ 更加微妙。核心难点在于：**平方根是非线性凹函数，导致方差的无偏估计在开根号后必然产生系统性偏差（系统性低估）**。

正态标准差的估计方法主要分为**无偏修正估计**、**[[MLE|极大似然估计]]**、**一阶绝对离差估计**与**基于极差的工业快估法**。

### 一、 样本标准差 $S$ 的偏差与无偏修正系数 $c_4$

[[样本均值与样本方差|样本方差]]定义为：

$$S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$$

尽管 $E(S^2) = \sigma^2$ 是无偏的，但直接取算术平方根 $S = \sqrt{S^2}$ 时，根据 **Jensen 不等式**（$\sqrt{\cdot}$ 为严格凹函数）：

$$E(S) = E\left(\sqrt{S^2}\right) < \sqrt{E(S^2)} = \sigma$$

这意味着，**原始样本标准差 $S$ 必然系统性低估真实标准差 $\sigma$**。

**1. 精确期望 $E(S)$ 的数学推导**

由正态抽样定理：

$$\frac{(n-1)S^2}{\sigma^2} = Y \sim \chi^2(n-1)$$

则 $S = \sigma \sqrt{\frac{Y}{n-1}}$，对 $S$ 求期望：

$$E(S) = \frac{\sigma}{\sqrt{n-1}} E\left(Y^{1/2}\right)$$

利用[[卡方分布]]的 $\lambda$ 阶矩公式（取 $\lambda = \frac{1}{2}$，自由度为 $k = n-1$）：

$$E(Y^{1/2}) = \frac{\Gamma\left(\frac{k+1}{2}\right)}{\Gamma\left(\frac{k}{2}\right)} \cdot 2^{1/2} = \sqrt{2} \frac{\Gamma\left(\frac{n}{2}\right)}{\Gamma\left(\frac{n-1}{2}\right)}$$

代入可得：

$$E(S) = c_4(n) \cdot \sigma$$

其中常数因子 $c_4(n)$（质量控制与统计学中称为 $c_4$ 因子）为：

$$c_4(n) = \sqrt{\frac{2}{n-1}} \frac{\Gamma\left(\frac{n}{2}\right)}{\Gamma\left(\frac{n-1}{2}\right)} < 1$$

**2. 构造 $\sigma$ 的严格无偏估计量**

对 $S$ 进行常数除法修正，即可得到标准差 $\sigma$ 的**一致最小方差无偏估计（UMVUE）**：

$$S^* = \frac{S}{c_4(n)} = \frac{1}{c_4(n)} \sqrt{\frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2} \implies E(S^*) = \sigma$$

- 当 $n=2$ 时，$c_4(2) = \sqrt{2/\pi} \approx 0.7979$（偏差高达 20%）；
    
- 当 $n=10$ 时，$c_4(10) \approx 0.9727$；
    
- 当 $n \to \infty$ 时，$c_4(n) \to 1$（渐近无偏）。
    

### 二、 极大似然估计（MLE）

在正态总体下，联合似然函数对 $\sigma$ 直接求导（或利用不变性原理）：

- **$\mu$ 未知时**：
    
    $$\hat{\sigma}_{\text{MLE}} = \sqrt{\frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2} = \sqrt{\frac{n-1}{n}} S$$
    
    其期望为 $E(\hat{\sigma}_{\text{MLE}}) = \sqrt{\frac{n-1}{n}} c_4(n) \sigma < \sigma$。
    
- **$\mu = \mu_0$ 已知时**：
    
    $$\hat{\sigma}_{\text{MLE}} = \sqrt{\frac{1}{n}\sum_{i=1}^n (X_i - \mu_0)^2}$$
    
    此时自由度为 $n$，修正系数对应变为 $c_4(n+1)$。
    

### 三、 均值绝对离差估计（$L_1$ 体系与鲁棒替代）

利用[[正态分布]]的一阶绝对中心矩 $E(\vert{}X - \mu\vert{}) = \sqrt{\frac{2}{\pi}} \sigma$，可以构造无需计算平方和的标准差估计量：

$$d = \sqrt{\frac{\pi}{2}} \cdot \frac{1}{n}\sum_{i=1}^n \vert{}X_i - \bar{X}\vert{}$$

- **[[无偏性]]**：$E(d) \approx \sigma$（经小样本常数微调后严格无偏）。
    
- **渐近相对效率（ARE）**：
    
    $$\text{ARE}(d, S) = \frac{Var(S)}{Var(d)} = \frac{1}{\pi - 2} \approx 87.6\%$$
    
    在正态假定下，其精度损失约 $12.4\%$，但优势在于**对异常孤立噪点（Outliers）的敏感度远低于基于平方和的 $S$**。
    

### 四、 工业统计与控制图中的极差法（Range Method）

在工业过程质量控制（SPC / 六西格玛 / $\bar{X}-R$ 控制图）中，为了避免在车间现场进行开方计算，通常使用**样本极差 $R = X_{(n)} - X_{(1)}$** 估计 $\sigma$：

$$\hat{\sigma}_R = \frac{R}{d_2(n)} = \frac{\max(X) - \min(X)}{d_2(n)}$$

- $d_2(n) = E\left(\frac{X_{(n)} - X_{(1)}}{\sigma}\right)$ 是标准正态顺序统计量极差的期望值（可通过查表获得，如 $n=5$ 时 $d_2 = 2.326$）。
    
- **应用特点**：当样本批量较小（$n \le 10$，尤其是 $n=4 \sim 5$ 时），极差法的效率极高（相对效率超过 95%），计算极简且抗连续小波动能力好。
    

### 五、 正态标准差估计方法总结

|**估计方法**|**构造公式**|**无偏性**|**核心适用场景**|
|---|---|---|---|
|**无偏样本标准差 $S^*$**|$\frac{S}{c_4(n)} = \frac{\sqrt{\frac{1}{n-1}\sum (X_i-\bar{X})^2}}{c_4(n)}$|**严格无偏 (UMVUE)**|小样本科研推断、精确理论分析|
|**样本标准差 $S$**|$\sqrt{\frac{1}{n-1}\sum(X_i-\bar{X})^2}$|有偏（系统性偏小）|大样本统计（$n>30$）、标准 $t$ 检验与置信区间|
|**修正绝对离差 $d$**|$\sqrt{\frac{\pi}{2}} \frac{1}{n}\sum \Vert{}X_i - \bar{X}\Vert{}$|近似无偏|存在偶发脉冲干扰、需抗噪的鲁棒信号处理|
|**极差估计法 $\hat{\sigma}_R$**|$\frac{X_{(n)} - X_{(1)}}{d_2(n)}$|严格无偏|工业过程控制（SPC $\bar{X}-R$ 控制图）、小样本快速快估|
