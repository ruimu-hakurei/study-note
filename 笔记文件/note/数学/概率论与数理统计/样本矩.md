样本矩（Sample Moments）**是数理统计中用来全面刻画样本数据分布特征的量化指标，也是**[[矩估计]]法（Method of Moments）的直接理论依据。

它的核心思想是：**用样本数据的算术平均去对应和估计总体的理论期望。**

设 $X_1, X_2, \dots, X_n$ 是来自总体 $X$ 的[[总体与样本抽样|独立同分布]]样本。

**一、 样本矩的两大分类**

**1. 样本原点矩（Sample Raw Moments）**

围绕原点 $0$ 计算的 $k$ 阶平均值，通常记为 $A_k$ 或 $m_k'$：

$$A_k = \frac{1}{n} \sum_{i=1}^n X_i^k \quad (k = 1, 2, 3, \dots)$$

- **$k=1$（样本一阶原点矩）**：
    
    $$A_1 = \frac{1}{n} \sum_{i=1}^n X_i = \bar{X}$$
    
    即**样本均值**，用来估计总体的真实期望 $\mu = E(X)$。
    
- **$k=2$（样本二阶原点矩）**：
    
    $$A_2 = \frac{1}{n} \sum_{i=1}^n X_i^2$$
    
    所有样本平方的平均值，用来估计总体的二阶矩 $E(X^2)$。
    

**2. 样本中心矩（Sample Central Moments）**

围绕样本中心 $\bar{X}$ 计算的 $k$ 阶离差平均值，通常记为 $B_k$ 或 $m_k$：

$$B_k = \frac{1}{n} \sum_{i=1}^n (X_i - \bar{X})^k \quad (k = 1, 2, 3, \dots)$$

- **$k=1$（样本一阶中心矩）**：
    
    $$B_1 = \frac{1}{n} \sum_{i=1}^n (X_i - \bar{X}) = 0$$
    
    恒等于 0（因为所有点关于样本均值的正负离差相互抵消）。
    
- **$k=2$（样本二阶中心矩）**：
    
    $$B_2 = \frac{1}{n} \sum_{i=1}^n (X_i - \bar{X})^2 = S_n^2$$
    
    即未作无偏修正的[[样本均值与样本方差|样本方差]]，用来估计总体的中心方差 $\sigma^2 = Var(X)$。
    
- **$k=3$（与偏度相关）**：用来衡量样本数据分布的**不对称程度（偏斜方向）**。
    
- **$k=4$（与峰度相关）**：用来衡量样本分布尾部的厚度与尖锐程度。
    

**二、 样本矩与总体矩的对应关系**

|**阶数**|**总体理论矩（未知参数）**|**样本经验矩（由数据计算）**|**统计作用**|
|---|---|---|---|
|**一阶原点矩**|$\alpha_1 = E(X) = \mu$|$A_1 = \bar{X} = \frac{1}{n}\sum X_i$|度量中心位置|
|**二阶中心矩**|$\mu_2 = Var(X) = \sigma^2$|$B_2 = \frac{1}{n}\sum (X_i - \bar{X})^2$|度量离散程度|
|**$k$ 阶原点矩**|$\alpha_k = E(X^k)$|$A_k = \frac{1}{n}\sum X_i^k$|刻画高阶特征|
|**$k$ 阶中心矩**|$\mu_k = E[(X-\mu)^k]$|$B_k = \frac{1}{n}\sum (X_i - \bar{X})^k$|刻画形态分布|

**三、 核心统计性质**

- **[[无偏性]]（针对原点矩）**：
    
    $$E(A_k) = E\left(\frac{1}{n}\sum_{i=1}^n X_i^k\right) = \frac{1}{n}\sum_{i=1}^n E(X_i^k) = E(X^k) = \alpha_k$$
    
    任意阶样本原点矩都是相应总体原点矩的**无偏估计**。
    
- **强相合性（[[大数定律]]保障）**：
    
    若总体 $k$ 阶矩 $E(X^k)$ 存在，令 $Y_i = X_i^k$，根据柯尔莫哥洛夫强大数定律：
    
    $$A_k = \frac{1}{n}\sum_{i=1}^n Y_i \xrightarrow{\text{a.s.}} E(X^k)$$
    
    当样本量 $n \to \infty$ 时，样本矩以概率 1 无限逼近总体矩。
    
- **渐近正态性（[[Lindeberg-Levy 中心极限定理|中心极限定理]]保障）**：
    
    当 $n$ 很大时，样本矩标准化后渐近服从正态分布。
    

**四、 最经典的应用：矩估计法（Method of Moments）**

当总体分布含有未知参数 $\theta_1, \theta_2, \dots, \theta_m$ 时，皮尔逊（Karl Pearson）提出了矩估计法：

1. **建立理论方程**：用参数表示出总体的理论矩 $\alpha_k = g_k(\theta_1, \dots, \theta_m)$。
    
2. **令样本矩等于总体矩**：建立方程组
    
    $$\begin{cases} A_1 = \alpha_1(\theta_1, \dots, \theta_m) \\ A_2 = \alpha_2(\theta_1, \dots, \theta_m) \\ \vdots \end{cases}$$
    
3. **反解参数**：解出未知参数的表达式，即得到未知参数的矩估计量 $\hat{\theta}$。
