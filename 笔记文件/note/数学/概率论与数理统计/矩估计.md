矩估计（Method of Moments, MOM）是数理统计中最古老、直观的参数估计方法之一，由英国统计学家卡尔·皮尔逊（Karl Pearson）于 1894 年提出。

它的核心哲学思想就是**替换原理（Plug-in Principle / Substitution Principle）**：**用样本的经验特征去直接替换总体的理论特征。**

**一、 替换原理（Substitution Principle）**

替换原理是[[大数定律]]最直接的工程与统计落地方式：

- **理论依据（辛钦大数定律）**：
    
    只要总体的 $k$ 阶原点矩 $\alpha_k = E(X^k)$ 存在，当样本容量 $n \to \infty$ 时，样本的 $k$ 阶原点矩 $A_k = \frac{1}{n} \sum_{i=1}^n X_i^k$ 必定[[依概率收敛]]于总体理论矩：
    
    $$A_k \xrightarrow{P} \alpha_k$$
    
- **替换思想**：
    
    既然[[样本矩]]是大样本下理论矩的极佳近似，那么在未知总体参数 $\theta_1, \dots, \theta_m$ 时，**直接将理论矩表达式中的总体矩替换为样本矩**，解出的参数值即为估计量。
    

**二、 矩估计法的标准推导步骤**

设总体 $X$ 的分布含有 $m$ 个待估参数 $\theta_1, \theta_2, \dots, \theta_m$：

1. **计算总体的理论矩（解析表达）**：
    
    计算总体的前 $m$ 阶原点矩（与参数建立函数关系）：
    
    $$\begin{cases} \alpha_1 = E(X) = g_1(\theta_1, \theta_2, \dots, \theta_m) \\ \alpha_2 = E(X^2) = g_2(\theta_1, \theta_2, \dots, \theta_m) \\ \quad \vdots \\ \alpha_m = E(X^m) = g_m(\theta_1, \theta_2, \dots, \theta_m) \end{cases}$$
    
2. **计算样本矩（数据统计量）**：
    
    $$A_k = \frac{1}{n} \sum_{i=1}^n X_i^k \quad (k = 1, 2, \dots, m)$$
    
    _(其中一阶样本矩即为样本均值 $A_1 = \bar{X}$)_
    
3. **应用替换原理建立矩方程组**：
    
    令 $\alpha_k = A_k$：
    
    $$\begin{cases} g_1(\theta_1, \dots, \theta_m) = A_1 = \bar{X} \\ g_2(\theta_1, \dots, \theta_m) = A_2 = \frac{1}{n}\sum X_i^2 \\ \quad \vdots \\ g_m(\theta_1, \dots, \theta_m) = A_m = \frac{1}{n}\sum X_i^m \end{cases}$$
    
4. **反解方程组**：
    
    解出参数 $(\hat{\theta}_1, \dots, \hat{\theta}_m)$，即为**矩估计量**。
    

**三、 经典分布的矩估计示例**

**1. 均匀分布 $U(a, b)$（双参数估计）**

- **理论矩**：
    
    $$E(X) = \frac{a+b}{2}, \quad Var(X) = \frac{(b-a)^2}{12} \implies E(X^2) = Var(X) + [E(X)]^2 = \frac{(b-a)^2}{12} + \left(\frac{a+b}{2}\right)^2$$
    
- **利用均值与[[样本均值与样本方差|样本方差]]快速替换**（中心矩等价替换）：
    
    $$\frac{\hat{a}+\hat{b}}{2} = \bar{X}, \qquad \frac{(\hat{b}-\hat{a})^2}{12} = S_n^2 = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2$$
    
- **解方程可得**：
    
    $$\hat{a}_{\text{MOM}} = \bar{X} - \sqrt{3}S_n, \qquad \hat{b}_{\text{MOM}} = \bar{X} + \sqrt{3}S_n$$
    

**2. 正态分布 $N(\mu, \sigma^2)$**

- 理论值：$E(X) = \mu$，$Var(X) = \sigma^2$
    
- 建立方程：$\mu = \bar{X}$，$\sigma^2 = \frac{1}{n}\sum (X_i-\bar{X})^2$
    
- 解得矩估计量：
    
    $$\hat{\mu}_{\text{MOM}} = \bar{X}, \qquad \widehat{\sigma^2}_{\text{MOM}} = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2 = S_n^2$$
    

**四、 矩估计法的优缺点与现代评价**

- **核心优点**：
    
    - **概念直观、计算极简**：不需要知道似然函数或做复杂的极大值求导，只需算几个幂和解代数方程；
        
    - **对分布形式的依赖较低**：哪怕不知道精确的概率密度形态，只要能算出一二阶矩，就能给出参数估计；
        
    - **天然具备一致性（Consistency）**：由大数定律与连续映射定理保证，只要样本量 $n \to \infty$，矩估计必定依概率收敛于真值。
        
- **主要局限与缺点**：
    
    - **有效性通常不如[[MLE|极大似然估计]]（MLE）**：矩估计往往**没有利用[[充分统计量]]**（如均匀分布中矩估计方差为 $O(1/n)$，而基于极值的 MLE 方差为 $O(1/n^2)$），精度损失明显；
        
    - **估计值可能越界**：例如估计均匀分布 $U(0, \theta)$ 时，$\hat{\theta}_{\text{MOM}} = 2\bar{X}$ 可能算出一个小于最大观测值 $X_{(n)}$ 的荒谬结果（物理上样本点落到了边界外）。
