# 充分统计量（Sufficient Statistic）

充分统计量是数理统计中关于"数据降维与信息压缩"的核心概念。

它的核心本质是：**一个统计量 $T(\mathbf{X})$ 能够将庞大的原始样本数据压缩为一个（或几个）简明数值，同时 100% 完整保留样本中关于未知参数 $\theta$ 的全部统计信息，没有任何有效信息损失。**

## 一、严格的数学定义

设样本 $\mathbf{X} = (X_1, X_2, \dots, X_n)$ 来自具有分布族 $\{P_\theta : \theta \in \Theta\}$ 的总体，$\theta$ 为未知参数，$T = T(\mathbf{X})$ 为一个统计量。

- **充分性定义**：若在**给定 $T(\mathbf{X}) = t$ 的条件下，样本 $\mathbf{X}$ 的条件概率分布与未知参数 $\theta$ 完全无关**，则称 $T(\mathbf{X})$ 是参数 $\theta$ 的**充分统计量**。

- **物理 / 几何直观**：给定 $T(\mathbf{X}) = t$，相当于把整个 $n$ 维样本空间划分成一层层「等值面」（level set）。若无论 $\theta$ 取何值，样本点在同一等值面上的相对分布（条件分布）都完全相同，就说明 $\theta$ 只控制等值面本身的宏观位置（即 $T$ 的取值），而等值面内部的微观细节不含任何关于 $\theta$ 的信息。

## 二、经典例题：伯努利样本和为充分统计量

设 $X_1, \dots, X_n$ 相互独立且同分布于 $B(1,\theta)$（两点分布），证明样本和 $T = \sum_{i=1}^n X_i$ 是 $\theta$ 的充分统计量。

**（1）分子：样本的联合分布律。** 当 $\sum_{i=1}^n x_i = t$（样本和等于 $t$）时，由独立性，联合分布律为

$$P(X_1=x_1,\dots,X_n=x_n) = \prod_{i=1}^n \theta^{x_i}(1-\theta)^{1-x_i} = \theta^{\sum_{i=1}^n x_i}(1-\theta)^{n-\sum_{i=1}^n x_i} = \theta^t (1-\theta)^{n-t}$$

**（2）分母：统计量 $T$ 的边缘分布。** 因为 $T = \sum_{i=1}^n X_i \sim B(n,\theta)$，故

$$P(T=t) = \binom{n}{t}\theta^t (1-\theta)^{n-t}$$

**（3）条件概率的化简与结论。** 代入条件概率公式：

$$P(X_1=x_1,\dots,X_n=x_n \mid T=t) = \frac{P(X_1=x_1,\dots,X_n=x_n,\,T=t)}{P(T=t)} = \frac{\theta^t(1-\theta)^{n-t}}{\binom{n}{t}\theta^t(1-\theta)^{n-t}} = \frac{1}{\binom{n}{t}}$$

（当 $\sum_{i=1}^n x_i = t$ 时，联合事件 $\{X_1=x_1,\dots,X_n=x_n,\ T=t\}$ 与 $\{X_1=x_1,\dots,X_n=x_n\}$ 等价。）

最终得到的条件概率 $\dfrac{1}{\binom{n}{t}}$ **完全不包含未知参数 $\theta$**。这说明给定 $T$ 的取值后，样本的具体取值分布与 $\theta$ 无关，从而严格证明了 $T = \sum_{i=1}^n X_i$ 是 $\theta$ 的充分统计量。

> 直接按定义验证需要计算条件分布，比较繁琐；实际判定充分性通常用 [[因子分解定理]]（Fisher–Neyman 因子分解定理），它把这个问题转化为对联合概率函数做因式分解。

## 三、极小充分统计量（最小充分统计量）

### 定义

若统计量 $T^*$ 满足：

1. $T^*$ 本身是 $\theta$ 的充分统计量；
2. 对 $\theta$ 的**任意一个充分统计量 $T$**，都存在函数 $l(\cdot)$，使得 $T^* = l(T)$（即 $T^*$ 是 $T$ 的函数）。

则称 $T^*$ 是 $\theta$ 的**极小充分统计量**（minimal sufficient statistic）。
