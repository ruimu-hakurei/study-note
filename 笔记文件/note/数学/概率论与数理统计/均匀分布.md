### 一、 连续型均匀分布 (Continuous Uniform Distribution)

当一个随机变量可以在一段连续的区间 $[a, b]$ 内取任意实数值，且取任何一个同等长度子区间的概率都相同时，我们就说这个变量服从连续型均匀分布，记作 $X \sim U(a, b)$。

#### 1. 核心数学公式

- **概率密度函数 (PDF)：**
    
    由于总概率为 $1$，且区间长度为 $b-a$，所以在这段区间内的概率密度是一个常数：
    
    $$f(x) = \begin{cases} \frac{1}{b-a} & \text{当 } a \le x \le b \\ 0 & \text{其他情况} \end{cases}$$
    
    > 在图像上，这表现为一个宽为 $b-a$，高为 $\frac{1}{b-a}$ 的矩形。
    
- **累积分布函数 (CDF)：**
    
    表示随机变量小于等于某个值 $x$ 的概率：
    
    $$F(x) = \begin{cases} 0 & \text{当 } x < a \\ \frac{x-a}{b-a} & \text{当 } a \le x \le b \\ 1 & \text{当 } x > b \end{cases}$$
    

#### 2. 重要性质

对于 $X \sim U(a, b)$，其最重要的统计特征如下：

- **数学期望（均值）：** $E(X) = \frac{a+b}{2}$
    
    _(完全符合直觉，均值就在区间的正中点)_
    
- **方差：** $Var(X) = \frac{(b-a)^2}{12}$
    
    _(方差只与区间的跨度有关，跨度越大，数据越分散)_
    

#### 3. 现实生活中的例子

- **等公交车：** 假设某路公交车严格每 15 分钟来一班，你随机时刻到达车站，那么你需要等待的时间 $X$ 就服从 $U(0, 15)$ 的均匀分布。
    
- **程序生成随机数：** 各种编程语言里的 `rand()` 或 `random()` 函数，默认生成的通常是服从 $U(0, 1)$ 的连续型均匀分布。
    

### 二、 离散型均匀分布 (Discrete Uniform Distribution)

当一个随机变量只能取有限个离散的值，并且每个值出现的概率完全相等时，它就服从离散型均匀分布。

#### 1. 核心数学公式

假设随机变量可以取 $n$ 个不同的值：$x_1, x_2, \dots, x_n$。

- **概率质量函数 (PMF)：**
    
    $$P(X = x_i) = \frac{1}{n}$$
    

如果这些取值是连续的整数，比如从 $a$ 到 $b$（共 $n = b-a+1$ 个整数），那么：

- **数学期望（均值）：** $E(X) = \frac{a+b}{2}$
    
- **方差：** $Var(X) = \frac{n^2-1}{12}$
    

#### 2. 现实生活中的例子

- **掷骰子：** 掷一颗质地均匀的六面骰子，点数 $X$ 只能取 1, 2, 3, 4, 5, 6，每个点数出现的概率都是 $\frac{1}{6}$。
    
- **抽扑克牌：** 从一副洗匀的 52 张扑克牌中随机抽出一张，抽到每一张的具体概率都是 $\frac{1}{52}$。
    

### 三、 总结对比表

为了方便记忆，可以将两者的核心特征进行简单对比：

|**特性**|**连续型均匀分布**|**离散型均匀分布**|
|---|---|---|
|**样本空间**|区间 $[a, b]$ 内的所有实数|有限个离散值 (如 $n$ 个)|
|**概率表示**|$f(x) = \frac{1}{b-a}$ (概率密度)|$P(X = x_i) = \frac{1}{n}$ (单个点概率)|
|**视觉图像**|平顶矩形|等高的离散柱状图|
|**经典应用**|随机数生成、蒙特卡洛模拟|抽奖模型、博弈论基础（如骰子）|
