# 抽样基本定理（正态总体抽样分布基本定理 / Fisher 定理）

**抽样基本定理（正态总体抽样分布基本定理 / Fisher 定理）**是数理统计学中连接“样本数据”与“总体参数推断”的基石。它专门描述了**来自正态总体的简单随机样本，其常用统计量（样本均值、[[样本均值与样本方差|样本方差]]）本身的精确概率分布以及它们之间的内在统计关系**。

## 一、定理核心表述（单正态总体）

设总体 $X \sim N(\mu, \sigma^2)$，$X_1, X_2, \dots, X_n$ 是来自该总体的容量为 $n$ 的简单随机样本。

定义样本均值与样本方差分别为：

$$\bar{X} = \frac{1}{n} \sum_{i=1}^n X_i, \qquad S^2 = \frac{1}{n-1} \sum_{i=1}^n (X_i - \bar{X})^2$$

抽样基本定理包含以下**四大核心结论**：

### 1.1 样本均值的精确正态性

样本均值 $\bar{X}$ 依然服从正态分布，期望保持不变，方差按样本量缩小至 $\frac{1}{n}$：

$$\bar{X} \sim N\left(\mu, \, \frac{\sigma^2}{n}\right) \implies \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)$$

### 1.2 样本方差的卡方分布律

标准化后的样本方差服从自由度为 $n-1$ 的[[卡方分布]]：

$$\frac{(n-1)S^2}{\sigma^2} = \frac{\sum_{i=1}^n (X_i - \bar{X})^2}{\sigma^2} \sim \chi^2(n-1)$$

_（自由度损失 $1$ 的几何本质：受线性约束 $\sum (X_i - \bar{X}) = 0$ 的影响，原本 $n$ 维独立的样本空间被投影到了一个 $n-1$ 维的超平面上。）_

### 1.3 均值与方差的相互独立性（Fisher 定理最精妙结论）

$$\bar{X} \text{ 与 } S^2 \text{ 相互独立}$$

_在非正态总体中，样本均值与样本方差通常是不独立的；**$\bar{X}$ 与 $S^2$ 相互独立是正态总体的本质充要特征**。_

### 1.4 结合生成的 Student's $t$ 分布

利用前三条结论（标准正态除以独立的卡方根号），消去未知参数 $\sigma$ 后构造出 $t$ 统计量：

$$T = \frac{\bar{X} - \mu}{S / \sqrt{n}} \sim t(n-1)$$

## 二、几何推导与正交变换法（证明）

### 2.1 前置知识回顾

#### 卡方分布的定义

若 $Z_1,Z_2,\dots,Z_k$ 相互独立，且都服从标准正态分布 $N(0,1)$，则它们的平方和

$$\sum_{i=1}^k Z_i^2 \sim \chi^2(k)$$

称为**自由度为 $k$ 的卡方分布**。自由度本质就是「独立标准正态变量的个数」。

#### 一个容易对比的结论

如果我们用**总体真实均值 $\mu$** 来计算离均差，那么：

$$\frac{\sum_{i=1}^n (X_i - \mu)^2}{\sigma^2} = \sum_{i=1}^n \left( \frac{X_i - \mu}{\sigma} \right)^{\!2}$$

每一项 $\frac{X_i-\mu}{\sigma}$ 都是独立的标准正态变量，因此这个平方和严格服从 $\boldsymbol{\chi^2(n)}$，自由度为 $n$。

### 2.2 直观理解：为什么自由度是 $n-1$？

把总体均值 $\mu$ 换成样本均值 $\bar{X}$ 后，自由度从 $n$ 变成了 $n-1$，核心原因是：**样本均值本身是由样本计算出来的，它给离均差施加了一个线性约束，消耗了 1 个自由度**。

具体来说，$n$ 个离均差 $X_1-\bar{X},\ X_2-\bar{X},\ \dots,\ X_n-\bar{X}$ 并不是完全自由的，它们满足一个恒等式：

$$\sum_{i=1}^n (X_i - \bar{X}) = \sum X_i - n\bar{X} = n\bar{X} - n\bar{X} = 0$$

也就是说：只要确定了前 $n-1$ 个离均差，第 $n$ 个就被这个等式唯一确定了，不能自由取值。因此真正独立变化的量只有 $n-1$ 个，对应卡方分布的自由度就是 $n-1$。

### 2.3 严谨推导：正交变换法

这是该结论的标准证明方法，核心思路是通过正交变换，把「带约束的离均差平方和」转化为「$n-1$ 个独立标准正态的平方和」。

#### 步骤 1：标准化变量

令 $Y_i = \frac{X_i - \mu}{\sigma}$，则 $Y_1,\dots,Y_n$ 是[[总体与样本抽样|独立同分布]]的标准正态变量 $N(0,1)$。

我们的目标量可以改写为：

$$\frac{\sum_{i=1}^n (X_i - \bar{X})^2}{\sigma^2} = \sum_{i=1}^n (Y_i - \bar{Y})^2$$

其中 $\bar{Y} = \frac{1}{n}\sum Y_i = \frac{\bar{X}-\mu}{\sigma}$。

#### 步骤 2：构造正交矩阵

构造一个 $n$ 阶正交矩阵 $\boldsymbol{A}$，满足：

- 第一行所有元素都是 $\frac{1}{\sqrt{n}}$，即第一行向量为 $\left( \frac{1}{\sqrt{n}},\frac{1}{\sqrt{n}},\dots,\frac{1}{\sqrt{n}} \right)$
- 剩下的 $n-1$ 行只需满足正交矩阵的要求（行向量单位正交），具体形式不影响结论。

正交矩阵有两个关键性质：

1. **保范性**：向量长度的平方在正交变换下不变，即若 $\boldsymbol{Z} = \boldsymbol{A}\boldsymbol{Y}$，则 $\sum_{i=1}^n Z_i^2 = \sum_{i=1}^n Y_i^2$。
2. **保正态独立性**：独立标准正态向量经过正交变换后，仍然是独立标准正态向量。

#### 步骤 3：做正交变换

令向量 $\boldsymbol{Z} = \boldsymbol{A}\boldsymbol{Y}$，其中 $\boldsymbol{Y}=(Y_1,\dots,Y_n)^T$，$\boldsymbol{Z}=(Z_1,\dots,Z_n)^T$。

先计算第一个分量 $Z_1$：

$$Z_1 = \frac{1}{\sqrt{n}}Y_1 + \frac{1}{\sqrt{n}}Y_2 + \dots + \frac{1}{\sqrt{n}}Y_n = \sqrt{n}\,\bar{Y}$$

因此 $Z_1^2 = n\bar{Y}^2$。

#### 步骤 4：拆分平方和

根据正交变换的保范性：

$$\sum_{i=1}^n Y_i^2 = \sum_{i=1}^n Z_i^2 = Z_1^2 + \sum_{i=2}^n Z_i^2$$

我们把离均差平方和展开：

$$\sum_{i=1}^n (Y_i - \bar{Y})^2 = \sum_{i=1}^n Y_i^2 - 2\bar{Y}\sum Y_i + n\bar{Y}^2$$

代入 $\sum Y_i = n\bar{Y}$，化简得：

$$\sum_{i=1}^n (Y_i - \bar{Y})^2 = \sum_{i=1}^n Y_i^2 - n\bar{Y}^2$$

将保范性的结论代入，替换 $\sum Y_i^2$ 和 $n\bar{Y}^2=Z_1^2$：

$$\sum_{i=1}^n (Y_i - \bar{Y})^2 = \left(Z_1^2 + \sum_{i=2}^n Z_i^2\right) - Z_1^2 = \sum_{i=2}^n Z_i^2$$

#### 步骤 5：得出分布

由正交变换的性质，$Z_1,Z_2,\dots,Z_n$ 相互独立，且都服从 $N(0,1)$。因此 $\sum_{i=2}^n Z_i^2$ 恰好是 **$n-1$ 个独立标准正态变量的平方和**，根据卡方分布的定义：

$$\sum_{i=2}^n Z_i^2 \sim \chi^2(n-1)$$

代回原变量，就得到了最终结论：

$$\frac{(n-1)S^2}{\sigma^2} = \sum_{i=1}^n (Y_i - \bar{Y})^2 \sim \chi^2(n-1)$$

### 2.4 两个重要的衍生结论

#### 样本均值与样本方差相互独立

从上面的推导可以直接得到：

- $\bar{X}$ 只和 $Z_1$ 有关
- $S^2$ 只和 $Z_2,\dots,Z_n$ 有关；而 $Z_1$ 与 $Z_2,\dots,Z_n$ 相互独立，因此**正态样本的样本均值 $\bar{X}$ 与样本方差 $S^2$ 相互独立**。这是正态总体独有的重要性质。

#### 样本方差是无偏估计

利用卡方分布的期望性质 $E\left[\chi^2(k)\right] = k$，可以直接验证[[无偏性]]：

$$E\left[ \frac{(n-1)S^2}{\sigma^2} \right] = n-1$$

两边整理得：

$$E[S^2] = \sigma^2$$

这也解释了为什么样本方差的分母是 $n-1$ 而不是 $n$——只有除以 $n-1$，才能得到总体方差的无偏估计。

### 2.5 适用前提与注意事项

1. **严格成立的条件**：仅当总体服从**正态分布**时，这个卡方分布的结论才精确成立。
2. **大样本近似**：对于非正态总体，当样本量 $n$ 很大时，该结论可以近似使用，但属于渐近结果。
3. **自由度的本质**：自由度 = 独立变量个数 - 约束条件个数。这里用样本均值估计总体均值，相当于增加了 1 个约束，因此自由度减 1。

## 三、推广：双正态总体的抽样定理

设两组独立样本分别来自 $X \sim N(\mu_1, \sigma_1^2)$ 和 $Y \sim N(\mu_2, \sigma_2^2)$，容量分别为 $n_1, n_2$，样本方差分别为 $S_1^2, S_2^2$：

- **方差比服从 $F$ 分布**：

    $$\frac{S_1^2 / \sigma_1^2}{S_2^2 / \sigma_2^2} \sim F(n_1 - 1, \, n_2 - 1)$$

    若在原假设 $\sigma_1^2 = \sigma_2^2$ 成立下，两样本方差比直接服从 $F(n_1-1, n_2-1)$（方差齐性检验的基础）。

- **方差相等时的均值差推断（合并方差 $S_p^2$）**：

    若已知 $\sigma_1^2 = \sigma_2^2 = \sigma^2$，定义合并样本方差（Pooled Variance）：

    $$S_p^2 = \frac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{n_1 + n_2 - 2}$$

    则均值差的 $t$ 统计量为：

    $$\frac{(\bar{X} - \bar{Y}) - (\mu_1 - \mu_2)}{S_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}} \sim t(n_1 + n_2 - 2)$$

---

## 四、核心应用价值

- **参数估计的无偏性与最优性**：抽样定理证明了 $S^2$ 是总体方差 $\sigma^2$ 的无偏估计，且在正态假定下是最小方差无偏估计（UMVUE）；

- **构建三大统计推断工具的理论源头**：参数未知的[[总体置信区间|置信区间]]构建、单/双样本 $t$ 检验、方差卡方检验以及方差分析（ANOVA）的数学[[有效性]]，完全由该定理背书。
