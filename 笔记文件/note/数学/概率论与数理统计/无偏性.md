无偏性（Unbiasedness）是数理统计中评价点估计量好坏的最基础、最经典的准则之一。它的直观物理含义是：**虽然单次抽样算出来的估计值可能偏大或偏小，但如果进行无数次重复独立抽样，所有估计值的算术平均（数学期望）将严格命中总体的真实参数真值，不存在系统性偏差。**

**一、 严格的数学定义**

设样本 $\mathbf{X} = (X_1, X_2, \dots, X_n)$ 来自总体分布族 $\{P_\theta : \theta \in \Theta\}$，$\theta$ 是待估计的未知总体参数。

- **定义**：若统计量 $\hat{\theta} = \hat{\theta}(X_1, \dots, X_n)$ 的数学期望在整个[[参数空间]] $\Theta$ 上恒等于参数真值 $\theta$，即满足：
    
    $$E_\theta(\hat{\theta}) = \theta \quad (\forall \theta \in \Theta)$$
    
    则称 $\hat{\theta}$ 是参数 $\theta$ 的**无偏估计量（Unbiased Estimator）**。
    
- **偏差函数（Bias）**：
    
    若等式不成立，定义估计量的偏差为：
    
    $$\text{Bias}(\hat{\theta}) = E(\hat{\theta}) - \theta$$
    
    当 $\text{Bias}(\hat{\theta}) = 0$ 时即为无偏；若随着样本量 $n \to \infty$ 时满足 $\lim_{n \to \infty} \text{Bias}(\hat{\theta}) = 0$，则称其为**渐近无偏估计量**。
    

**二、 经典统计量的无偏性推导**

**1. 样本均值 $\bar{X}$ 是总体均值 $\mu$ 的无偏估计**

设总体期望 $E(X) = \mu$：

$$E(\bar{X}) = E\left(\frac{1}{n}\sum_{i=1}^n X_i\right) = \frac{1}{n}\sum_{i=1}^n E(X_i) = \frac{1}{n} \cdot (n\mu) = \mu$$

_（无论总体服从何种分布，只要均值存在，样本均值恒为总体均值的无偏估计。）_

**2. [[样本均值与样本方差|样本方差]] $S^2$ 与分母 $n-1$ 的由来（修正无偏性）**

设总体方差为 $\sigma^2$。若定义未修正的二阶中心矩为 $S_n^2 = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2$：

利用恒等式 $\sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n (X_i - \mu)^2 - n(\bar{X} - \mu)^2$ 求期望：

$$E\left[\sum_{i=1}^n (X_i - \bar{X})^2\right] = \sum_{i=1}^n E\big[(X_i - \mu)^2\big] - n E\big[(\bar{X} - \mu)^2\big] = n\sigma^2 - n \cdot \left(\frac{\sigma^2}{n}\right) = (n-1)\sigma^2$$

因此：

- 未修正估计量存在负偏差：$E(S_n^2) = \frac{n-1}{n}\sigma^2 \ne \sigma^2$（系统性偏小）；
    
- 引入修正因子 $\frac{n}{n-1}$，定义 $S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$，得到：
    
    $$E(S^2) = \frac{1}{n-1} \cdot (n-1)\sigma^2 = \sigma^2$$
    
    这就是样本方差分母必须使用自由度 $n-1$（Bessel 修正）的数学根源。
    

**三、 无偏性的重要性质与反直觉特征**

**1. 非线性变换不保持无偏性（Jensen 不等式）**

若 $\hat{\theta}$ 是 $\theta$ 的无偏估计，对于非线性函数 $g(\cdot)$，$g(\hat{\theta})$ 通常**不再是** $g(\theta)$ 的无偏估计。

- **经典反例**：虽然样本方差 $S^2$ 是 $\sigma^2$ 的无偏估计（$E(S^2) = \sigma^2$），但**样本标准差 $S = \sqrt{S^2}$ 绝对不是总体标准差 $\sigma$ 的无偏估计**：
    
    由 Jensen 不等式（平方根为严格凹函数）：
    
    $$E(S) = E(\sqrt{S^2}) < \sqrt{E(S^2)} = \sigma$$
    
    （即样本标准差 $S$ 平均而言总是系统性低估真实标准差 $\sigma$）。
    

**2. 无偏估计不一定存在，甚至可能不合理**

- 某些参数（例如在截断分布或特定离散模型中）在数学上可能根本构造不出无偏估计；
    
- 即使存在无偏估计，其取值也可能脱离实际物理意义（例如估计几何分布参数的某些无偏估计量可能在特定点取负数或非整数）。
    

**四、 无偏性在评判体系中的局限与权衡**

评价估计量好坏的终极指标是**[[均方误差]]（Mean Squared Error, MSE）**：

$$\text{MSE}(\hat{\theta}) = E\big[(\hat{\theta} - \theta)^2\big] = Var(\hat{\theta}) + \big[\text{Bias}(\hat{\theta})\big]^2$$

- **方差-偏差权衡（Bias-Variance Tradeoff）**：
    
    - 无偏性只保证了 $\text{Bias} = 0$，此时 $\text{MSE} = Var(\hat{\theta})$；
        
    - 但有时**适度引入一点偏差（Bias），可以换取方差（Variance）的大幅剧烈下降**，从而使整体 MSE 更小、预测更稳健。
        
    - **典型实例**：
        
        - 机器学习与控制中的**岭回归（Ridge Regression / $L_2$ 正则化）**：放弃无偏性，加入权重衰减，换取更小的估计方差和更强的泛化能力；
            
        - 正态方差估计中，使用除以 $n+1$ 的估计量 $\frac{1}{n+1}\sum (X_i-\bar{X})^2$ 虽然有偏，但其 MSE 严格小于无偏的 $S^2$。
            

**五、 进阶理论：从无偏性到最优估计（UMVUE）**

为了在“无数个无偏估计”中挑出最好的一员，数理统计建立了一套严格的最优无偏理论：

1. **Cramér-Rao 不等式（CRLB 下界）**：给出了任何无偏估计量所能达到的方差理论下限 $\frac{1}{I(\theta)}$（其中 $I(\theta)$ 为 [[Cramér–Rao不等式|Fisher 信息]]量）；
    
2. **Rao-Blackwell 定理**：利用[[充分统计量]]对粗糙的无偏估计取[[条件期望与条件方差|条件期望]]，方差单调不增；
    
3. **Lehmann-Scheffé 定理**：当统计量既具备**充分性**又具备**完备性**时，基于其构造的无偏估计即为全局最优的**一致最小方差无偏估计（UMVUE）**。
