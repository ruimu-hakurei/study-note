## 一、核心定义

设 $\{X_n\}$ 是一列随机变量，其分布函数分别为 $F_n(x) = P(X_n \le x)$；$X$ 是一个随机变量，其分布函数为 $F(x) = P(X \le x)$。

如果对于 $F(x)$ 的**每一个连续点 $x$**，都有：

$$\lim_{n \to \infty} F_n(x) = F(x)$$

那么我们就称序列 $\{X_n\}$ **按分布收敛**（或依分布收敛、弱收敛）于 $X$，记作：

$$X_n \xrightarrow{d} X$$

### 为什么定义里强调"必须是 $F(x)$ 的连续点"？

这是一个极其经典的细节（比如茆诗松教材里常强调的反例）：

- 假设 $X_n \equiv \frac{1}{n}$（退化的常数序列），显然当 $n \to \infty$ 时，它应该收敛到常数 $0$（即退化分布 $X \equiv 0$）。
- 我们看分布函数：
    - $F_n(x)$ 在 $x < \frac{1}{n}$ 时为 0，在 $x \ge \frac{1}{n}$ 时为 1。
    - $F(x)$ 在 $x < 0$ 时为 0，在 $x \ge 0$ 时为 1。
- 如果看 $x = 0$ 这个点：$F_n(0) = 0$，但 $F(0) = 1$，此时 $\lim F_n(0) = 0 \neq 1$！
- 如果不排除间断点，连"$\frac{1}{n} \to 0$"这种最显然的收敛都会被判定为不收敛。而 $x = 0$ 刚好是 $F(x)$ 的间断点，排除掉间断点后，在所有连续点（$x < 0$ 或 $x > 0$）上都有 $\lim F_n(x) = F(x)$，定义得以完美成立。

## 二、物理直觉：两个"完全不相关的变量"也可以依分布收敛

按分布收敛只看**统计规律**，不看**样本点绑定**。

> **经典硬币比喻**：
>
> 假设投掷一枚均匀硬币，正面为 1，反面为 0。
>
> - 让 $X_n$ 永远代表第 $n$ 次投掷的结果。
> - 让 $X$ 代表另一个人投掷这枚硬币的结果。
>
> 在任何一次试验中，$X_n$ 和 $X$ 的取值可能完全相反（比如 $X_n = 1, X = 0$），所以 $\vert{}X_n - X\vert{}$ 根本不会趋于 0，因此它**不满足**几乎处处收敛、矩收敛或依概率收敛。
>
> 但是，$X_n$ 的分布永远是 $P(X_n=1)=0.5, P(X_n=0)=0.5$，与 $X$ 的分布完全一致！
>
> 这种"分布形态的终极逼近"，就是**按分布收敛**。

## 三、中心极限定理：按分布收敛的最伟大实践

按分布收敛在数理统计中地位极高，**中心极限定理（Central Limit Theorem）** 就是它的最伟大实践。

对于独立同分布（i.i.d.）的随机变量序列 $X_1, X_2, \dots, X_n$，均值为 $\mu$，方差为 $\sigma^2$：

样本均值的标准化形式：

$$Z_n = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}}$$

中心极限定理并不是说 $Z_n$ 本身变成了某个标准正态分布的数值，而是说：

**当 $n \to \infty$ 时，$Z_n$ 的分布函数按分布收敛于标准正态分布 $N(0, 1)$ 的分布函数 $\Phi(x)$：**

$$Z_n \xrightarrow{d} N(0, 1)$$

这就是为什么我们在样本量很大时，敢放心地用正态分布表格去查二项分布、泊松分布等各种分布的概率！

## 四、判别武器：连续定理（特征函数法）

在实际计算中，直接去对分布函数 $F_n(x)$ 求极限往往非常痛苦。数学家勒维（Lévy）给出了一个极为强悍的判别定理——**特征函数连续定理**：

设 $X_n$ 的特征函数为 $\varphi_n(t) = E(e^{itX_n})$，$X$ 的特征函数为 $\varphi(t) = E(e^{itX})$。

$$X_n \xrightarrow{d} X \iff \lim_{n \to \infty} \varphi_n(t) = \varphi(t) \quad (\text{对任意 } t \text{ 逐点成立})$$

**为什么这个定理强？**

特征函数把复杂的积分/累加转换成了普通的连续函数极限。在证明"二项分布渐近正态"、"泊松分布渐近正态"时，只要把特征函数做泰勒展开，取极限看能不能凑出 $e^{-\frac{1}{2}t^2}$（标准正态的特征函数），就能瞬间完成证明！

## 五、四种收敛形态的关系

至此，概率论的四大收敛形态全员到齐，它们的强弱阶梯为：

$$\text{几乎处处收敛 (a.s.)} \implies \text{依概率收敛 (P)} \implies \text{按分布收敛 (d)}$$

$$\text{矩收敛 } (L^r) \implies \text{依概率收敛 (P)} \implies \text{按分布收敛 (d)}$$

**按分布收敛是金字塔的最底层（最弱条件）**。

### 唯一特例（常考填空题）

若 $X_n \xrightarrow{d} c$（**注意：极限必须是一个确定常数 $c$**），则可以**反向推出** $X_n \xrightarrow{P} c$！

也就是说，当极限退化为常数时，依分布收敛与依概率收敛完全等价。

### 6.1 依概率收敛 $\implies$ 按分布收敛（$P \implies d$）

这个证明充满了微积分里的"$\varepsilon$ 切割放缩技巧"。我们要强行把分布函数 $F_n(x)$ 夹在目标函数 $F(x)$ 的两边。

**已知**：$X_n \xrightarrow{P} X$。

**求证**：$X_n \xrightarrow{d} X$，即对 $F(x)$ 的任意连续点 $x$，有 $\lim_{n\to\infty} F_n(x) = F(x)$。

**证明过程**：

**步骤 1**：对于任意给定的微小正数 $\varepsilon > 0$，利用全概率法则对 $X_n \le x$ 这个事件进行切分：

$$F_n(x) = P(X_n \le x) = P(X_n \le x, \; X \le x+\varepsilon) + P(X_n \le x, \; X > x+\varepsilon)$$

**步骤 2**：对右边两项分别放缩——

- 第一项：两个条件同时满足的概率，肯定小于等于其中任意一个条件满足的概率，所以 $P(X_n \le x, \; X \le x+\varepsilon) \le P(X \le x+\varepsilon) = F(x+\varepsilon)$。
- 第二项：既然 $X_n \le x$ 但 $X > x+\varepsilon$，说明这两个变量之间的距离必定大于 $\varepsilon$。所以 $P(X_n \le x, \; X > x+\varepsilon) \le P(\vert{}X_n - X\vert{} > \varepsilon)$。

将两项合并，得到**右侧上界**：

$$F_n(x) \le F(x+\varepsilon) + P(\vert{}X_n - X\vert{} > \varepsilon)$$

**步骤 3**：用完全对称的手法，从 $F(x-\varepsilon)$ 出发，可以夹出**左侧下界**：

$$F(x-\varepsilon) - P(\vert{}X_n - X\vert{} > \varepsilon) \le F_n(x)$$

**步骤 4**：两边夹击。现在我们有了：

$$F(x-\varepsilon) - P(\vert{}X_n - X\vert{} > \varepsilon) \le F_n(x) \le F(x+\varepsilon) + P(\vert{}X_n - X\vert{} > \varepsilon)$$

**步骤 5**：让 $n \to \infty$。因为已知依概率收敛，所以 $P(\vert{}X_n - X\vert{} > \varepsilon) \to 0$。不等式变为：

$$F(x-\varepsilon) \le \liminf F_n(x) \le \limsup F_n(x) \le F(x+\varepsilon)$$

**步骤 6**：最后，让 $\varepsilon \to 0$。因为 $x$ 是 $F(x)$ 的**连续点**，所以 $F(x-\varepsilon)$ 和 $F(x+\varepsilon)$ 都会无缝逼近 $F(x)$。

$$F(x) \le \lim_{n \to \infty} F_n(x) \le F(x)$$

极限等于 $F(x)$，证明完毕！$\blacksquare$

### 6.2 按分布收敛于常数 $\implies$ 依概率收敛（$d \implies P$）

如果按分布收敛的尽头是一个死死不动的常数 $c$，底层的分布收敛就能逆袭推导出依概率收敛。

**已知**：$X_n \xrightarrow{d} c$。常数 $c$ 的分布函数是一个阶跃函数：$x < c$ 时 $F(x)=0$，$x \ge c$ 时 $F(x)=1$。

**求证**：$X_n \xrightarrow{P} c$，即 $\lim_{n \to \infty} P(\vert{}X_n - c\vert{} \ge \varepsilon) = 0$。

**证明过程**：

**步骤 1**：打开依概率收敛的绝对值不等式：

$$P(\vert{}X_n - c\vert{} \ge \varepsilon) = P(X_n \ge c+\varepsilon) + P(X_n \le c-\varepsilon)$$

**步骤 2**：用分布函数 $F_n(x)$ 重写上面的概率：

- $P(X_n \le c-\varepsilon) = F_n(c-\varepsilon)$。
- $P(X_n \ge c+\varepsilon)$ 为了避开边界的等号问题，我们可以放缩成 $P(X_n > c+\frac{\varepsilon}{2}) = 1 - F_n(c+\frac{\varepsilon}{2})$。

所以：

$$P(\vert{}X_n - c\vert{} \ge \varepsilon) \le 1 - F_n(c+\frac{\varepsilon}{2}) + F_n(c-\varepsilon)$$

**步骤 3**：因为 $c+\frac{\varepsilon}{2}$ 和 $c-\varepsilon$ 都不等于 $c$，避开了阶跃函数唯一的间断点，所以它们都是连续点。直接取 $n \to \infty$ 的极限，利用依分布收敛的定义：

- $F_n(c+\frac{\varepsilon}{2}) \to F(c+\frac{\varepsilon}{2}) = 1$
- $F_n(c-\varepsilon) \to F(c-\varepsilon) = 0$

**步骤 4**：代入原式：

$$\lim_{n \to \infty} P(\vert{}X_n - c\vert{} \ge \varepsilon) \le 1 - 1 + 0 = 0$$

概率不可能为负，直接证死。$\blacksquare$
