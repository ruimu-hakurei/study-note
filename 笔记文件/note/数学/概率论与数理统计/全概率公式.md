## 1. 前置核心概念：样本空间的“划分” (Partition)

要想用全概率公式，我们必须先在样本空间 $\Omega$ 中找到一套**完备事件组**（也叫划分）。

假设有一组事件 $B_1, B_2, \dots, B_n$，如果它们同时满足以下两个条件，我们就称它们是对样本空间的一个“划分”：

1. **不重不漏（互斥）**：任意两个事件绝不相交。即当 $i \neq j$ 时，$B_i \cap B_j = \emptyset$。
    
2. **包罗万象（完备）**：它们的所有可能加起来，必定构成整个样本空间。即 $\bigcup_{i=1}^n B_i = \Omega$。
    

> **直观理解**：就像是你把一个大蛋糕（样本空间 $\Omega$）切成了 $n$ 块（$B_1$ 到 $B_n$）。每一块都不重叠，拼起来刚好是一个完整的蛋糕。

## 2. 全概率公式的推导与形态

现在，我们的目标是求某个复杂事件 $A$ 的概率 $P(A)$。

**第一步：利用集合的交并运算**

既然 $B_1 \dots B_n$ 构成了全集 $\Omega$，那么事件 $A$ 必然可以被这 $n$ 块蛋糕“切割”成 $n$ 个不重叠的小碎块：

$$A = A \cap \Omega = A \cap (B_1 \cup B_2 \cup \dots \cup B_n)$$

根据分配律展开：

$$A = (AB_1) \cup (AB_2) \cup \dots \cup (AB_n)$$

**第二步：利用概率的有限可加性**

因为 $B_i$ 之间是互不相交的，所以切出来的碎块 $AB_i$ 之间也必然互不相交。我们可以直接把并集转化为概率的加法：

$$P(A) = P(AB_1) + P(AB_2) + \dots + P(AB_n) = \sum_{i=1}^n P(AB_i)$$

**第三步：代入乘法公式**

对于每一个碎块 $P(AB_i)$，我们不知道它直接发生的概率，但我们可以套用刚才学的乘法公式 $P(AB_i) = P(B_i)P(A\vert{}B_i)$。代入进去，就得到了最终的**全概率公式**：

$$P(A) = \sum_{i=1}^n P(B_i) P(A\vert{}B_i)$$

## 3. 全概率公式的物理意义：加权平均

这个公式的右边由两部分组成，极具现实意义：

- **$P(B_i)$**：每一条路径（或每一种场景）发生的**先验概率（权重）**。
    
- **$P(A\vert{}B_i)$**：在这条特定的路径下，目标事件 $A$ 发生的**条件概率**。
    

所以，全概率公式的本质就是求一个“加权平均值”。

### 经典模型演示：工厂次品率问题

**设定**：一个公司有三家工厂生产同一种零件。

- 工厂 1 承担了 50% 的产量，次品率为 1%。
    
- 工厂 2 承担了 30% 的产量，次品率为 2%。
    
- 工厂 3 承担了 20% 的产量，次品率为 5%。
    
    **问题**：从仓库里随便抽一个零件，它是次品（事件 $A$）的概率是多少？
    

**套用公式解题**：

直接算次品率很难，但我们可以按照工厂来源对样本空间进行“划分”：$B_1$ (来自工厂1), $B_2$ (来自工厂2), $B_3$ (来自工厂3)。

1. **找权重 $P(B_i)$**：$P(B_1) = 0.5$，$P(B_2) = 0.3$，$P(B_3) = 0.2$。
    
2. **找条件概率 $P(A\vert{}B_i)$**：$P(A\vert{}B_1) = 0.01$，$P(A\vert{}B_2) = 0.02$，$P(A\vert{}B_3) = 0.05$。
    
3. **汇总全概率**：
    
    $$P(A) = 0.5 \times 0.01 + 0.3 \times 0.02 + 0.2 \times 0.05$$
    
    $$P(A) = 0.005 + 0.006 + 0.010 = 0.021 \text{ (即 2.1\%)}$$
