在概率论中，当我们掌握了一个随机变量 $X$ 的分布，想要去求它的函数 $Y = g(X)$ 的分布时，就触及到了**变量替换（函数的分布）**。

与连续型随机变量（需要动用微积分、求导数、以及引入雅可比行列式来缩放面积）不同，离散型变量的替换没有微积分的那些弯弯绕绕。它的底层逻辑极其野蛮、纯粹，完全建立在一条物理法则之上：**概率质量守恒**。

我们可以将离散型变量替换的数学机制，拆解为以下几个核心维度。

### 1. 核心铁律：没有雅可比，只有“质量搬运”

在离散世界里，随机变量 $X$ 的取值是一个个孤立的“点”（状态），比如 $x_1, x_2, \dots, x_n$。每个点上都附着了一个明确的**概率质量（Probability Mass）** $p_i = P(X = x_i)$。

当我们应用一个函数 $Y = g(X)$ 时，相当于在两个世界之间建立了一个传送门。

- **连续世界**的传送会改变空间的体积（拉伸或挤压），所以需要乘以导数（雅可比行列式）来修正概率密度。
    
- **离散世界**的传送，空间没有体积可言。函数 $g(x)$ 的作用仅仅是**把 $x_i$ 上的概率质量，原封不动地搬运到目标状态 $y_j = g(x_i)$ 上**。
    

总概率永远是 1，不增不减。

### 2. 第一种形态：单射映射的“无损平移”

如果函数 $y = g(x)$ 是严格单调的，或者在 $X$ 的取值范围内是一一对应（单射）的。

**数学表现：**

对于每一个目标状态 $y_i$，都有唯一的一个源状态 $x_i$ 与之对应，即 $x_i = g^{-1}(y_i)$。

此时，概率质量发生“无损转移”：

$$P(Y = y_i) = P(X = g^{-1}(y_i))$$

**实例推演：**

假设 $X$ 取值为 $\{-1, 0, 1\}$，概率分别为 $\{0.2, 0.5, 0.3\}$。

令 $Y = 2X + 1$。

这是一个完美的一一对应，目标状态变为：

- 当 $X = -1$ 时，$Y = -1$，概率 $P(Y=-1) = 0.2$
    
- 当 $X = 0$ 时，$Y = 1$，概率 $P(Y=1) = 0.5$
    
- 当 $X = 1$ 时，$Y = 3$，概率 $P(Y=3) = 0.3$
    

整个分布列的形状完全没有改变，只是横坐标的刻度被重新映射了。

### 3. 第二种形态：多对一映射的“状态坍缩”与“概率叠加”

这是离散变量替换中最核心、也最容易出考点的部分。如果函数 $y = g(x)$ **不是**一一对应的（比如绝对值函数、平方函数、取整函数），就会发生**多个不同的源状态 $x$，被映射到同一个目标状态 $y$ 的情况。**

**数学表现：**

此时，进入同一个目标状态 $y_j$ 的所有概率质量，必须无条件相加。

$$P(Y = y_j) = \sum_{x_k : g(x_k)=y_j} P(X = x_k)$$

**实例推演：**

假设 $X$ 是一个离散均匀分布，取值为 $\{-2, -1, 0, 1, 2\}$，每个点的概率都是 $\frac{1}{5}$。

令 $Y = X^2$。

我们来观察状态是如何“坍缩”的：

1. **目标状态 $Y = 0$**：
    
    只有源状态 $X = 0$ 能映射过来。
    
    $$P(Y = 0) = P(X = 0) = \frac{1}{5}$$
    
2. **目标状态 $Y = 1$**：
    
    源状态 $X = -1$ 和 $X = 1$ 的平方都是 1。两条支路的概率在此处发生物理碰撞并叠加：
    
    $$P(Y = 1) = P(X = -1) + P(X = 1) = \frac{1}{5} + \frac{1}{5} = \frac{2}{5}$$
    
3. **目标状态 $Y = 4$**：
    
    源状态 $X = -2$ 和 $X = 2$ 共同映射过来：
    
    $$P(Y = 4) = P(X = -2) + P(X = 2) = \frac{1}{5} + \frac{1}{5} = \frac{2}{5}$$
    

原本 5 个状态的离散空间，经过平方函数的非线性变换，**坍缩**成了 3 个状态 $\{0, 1, 4\}$。信息在这一过程中丢失（你无法通过 $Y=1$ 反推 $X$ 到底是 1 还是 -1），但总概率 $1/5 + 2/5 + 2/5 = 1$ 绝对守恒。

### 4. 典型的工程与物理映射意义

在数字信号处理和工程系统中，离散变量的替换和“状态坍缩”是极其底层的数学模型：

- **数字量化（取整变换）：** 比如 $Y = \lfloor X \rfloor$（向下取整）。模拟世界中的微小波动被 ADC 采样为离散的数字值。所有落在 $2.0$ 到 $2.9$ 之间的微观离散状态，全部坍缩到数字态 $2$ 上。
    
- **绝对值整流（绝对值变换）：** 比如 $Y = \vert{}X\vert{}$。在处理交流数字信号时，将负半轴的能量（概率质量）全部折叠叠加到正半轴上。
    
- **阈值截断（阶跃变换）：** 比如激活函数或限幅器，当 $X > 10$ 时，强制令 $Y = 10$。此时，源状态空间中所有大于 10 的无穷多个状态的概率，将全部累加，化作目标状态 $Y=10$ 处的一根巨大的概率脉冲。
