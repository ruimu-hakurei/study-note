### 1. 常数的期望就是常数本身

如果 $C$ 是一个常数（比如 $C = 5$），那么：

$$E(C) = C$$

> **物理直觉**：这很好理解。如果一个骰子的六个面全都是 5，那你无论怎么掷，长期算下来的平均值必定是 5。它没有任何随机性。

### 2. 数乘与平移性质（缩放自如）

如果 $X$ 是一个随机变量，$a$ 和 $b$ 是常数，那么：

$$E(aX + b) = aE(X) + b$$

> **物理直觉**：
> 
> - **平移 ($+b$)**：如果你把工厂里所有员工的真实工资（随机变量 $X$）都固定涨薪 500 元，那么公司的“平均工资”自然也会精准地上涨 500 元。
>     
> - **数乘 ($\times a$)**：如果把温度从摄氏度换算成华氏度（进行固定比例放大），平均温度也会按同等比例放大。
>     

### 3. 最伟大的超能力：无条件可加性 (Linearity of Expectation)

这是整个概率论中最强大、最不可思议的性质之一。对于**任意**两个随机变量 $X$ 和 $Y$：

$$E(X + Y) = E(X) + E(Y)$$

你可以把它推广到任意 $n$ 个随机变量：

$$E(X_1 + X_2 + \dots + X_n) = E(X_1) + E(X_2) + \dots + E(X_n)$$

**【高能预警：这里的绝对降维打击】**

注意我上面的措辞是“任意”**！这个公式**根本不需要 $X$ 和 $Y$ 相互独立！

哪怕 $X$ 和 $Y$ 之间有极其复杂的强关联、甚至互相排斥，它们的期望依然可以直接相加。

> **经典应用（信封问题）**：
> 
> 假设有 100 封写好地址的信和 100 个写好地址的信封。你闭着眼睛把信随机塞进信封。问：信和信封刚好匹配的**平均封数**是多少？
> 
> 如果用全概率公式硬算，由于塞错一封信会影响其他的信，这 100 个事件互相严重干涉，计算量是天文数字。
> 
> 但利用“无条件可加性”：我们定义 $X_i$ 为“第 $i$ 封信装对”的事件（对为 1，错为 0）。显然单封信装对的概率是 $\frac{1}{100}$，所以 $E(X_i) = \frac{1}{100}$。
> 
> 总匹配数 $E(X) = E(X_1 + X_2 + \dots + X_{100}) = 100 \times \frac{1}{100} = 1$。
> 
> 完全无视它们之间的干涉，一秒口算得出结论：不管有多少封信，平均总是会蒙对 1 封。

### 4. 乘法性质（必须跨越“独立”门槛）

加法可以无视一切条件，但乘法极其严格。**只有当 $X$ 和 $Y$ 相互独立时**，才会有：

$$E(XY) = E(X)E(Y)$$

> **避坑指南**：如果你在做题或写代码（比如处理卡尔曼滤波的协方差矩阵）时，没有证明 $X$ 和 $Y$ 是独立的，**绝对不能**把它们的乘积期望拆开！如果它们不独立，$E(XY)$ 和 $E(X)E(Y)$ 之间的那个差值，就是大名鼎鼎的**协方差（Covariance）**，它专门用来衡量两个变量是同向联动还是反向掣肘。

### 总结：期望的本质是“线性算子”

在高等数学的视角下，结合第 2 条和第 3 条，期望 $E$ 其实就是一个完美的**线性算子**。

对于任意常数 $a, b$ 和任意随机变量 $X, Y$：

$$E(aX + bY) = aE(X) + bE(Y)$$

正是因为这个绝对线性的保障，我们才敢在工程控制、信号处理和机器学习中，放心地对含有噪声的信号进行线性叠加和矩阵变换。

我们用最简单的离散型随机变量来做严密推导。

假设 $X$ 和 $Y$ 存在极其复杂的关联，它们的**联合概率**为 $P(X=x_i, Y=y_j) = p_{ij}$。

我们要算的是总体 $(X+Y)$ 的期望。根据期望的最底层定义，我们要把“每一个可能的值”乘上“它发生的概率”，然后全部加起来：

$$E(X+Y) = \sum_i \sum_j (x_i + y_j) p_{ij}$$

接下来，见证数学逻辑的自动运转（只需要用到初中的乘法分配律）：

**第一步：把括号拆开**

$$E(X+Y) = \sum_i \sum_j (x_i p_{ij} + y_j p_{ij})$$

**第二步：把求和拆成两坨**

$$E(X+Y) = \sum_i \sum_j x_i p_{ij} + \sum_i \sum_j y_j p_{ij}$$

**第三步：重新打包（最神妙的一步）**

看前面那一坨 $\sum_i \sum_j x_i p_{ij}$。对于 $x_i$ 来说，求和符号 $\sum_j$ 跟它没关系，可以把它提出来：

$$\sum_i x_i \left( \sum_j p_{ij} \right)$$

括号里的 $\sum_j p_{ij}$ 是什么意思？它的意思是“把 $X=x_i$ 时，$Y$ 取所有可能值的联合概率全加起来”。根据我们在全概率公式里学的**边缘概率**法则，这就等于 $X=x_i$ 独立发生的概率 $P(X=x_i)$！

$$\sum_j p_{ij} = P(X=x_i)$$

把这个结果代回去，前面那一坨就变成了：

$$\sum_i x_i P(X=x_i) = E(X)$$

同理，后面那一坨把 $y_j$ 提出来，把关于 $i$ 的概率全加起来，就变成了：

$$\sum_j y_j P(Y=y_j) = E(Y)$$

**结论**：

$$E(X+Y) = E(X) + E(Y)$$

**反思推导过程：**

在这个证明的任何一个步骤中，我们有没有假设过 $P(X, Y) = P(X)P(Y)$（即两者独立）？

**一次都没有！**

我们仅仅是把一堆复杂的加法，换了一个求和的顺序而已。不论 $p_{ij}$ 内部的数值分配有多么畸形、多么极端，只要加法的分配律成立，这个等式就绝对成立。连续型变量的二重积分推导也是完全一样的逻辑。

## 2. 物理视角的“上帝账本”

如果数学公式让你觉得抽象，我们来看一个极其直观的现实例子——**“赌场与赌徒的博弈”**。

假设你开了一家赌场，里面有两个游戏：$X$（掷骰子）和 $Y$（抽扑克）。

为了吸引人，你搞了一个极其变态的**强关联规则**：

- **规则**：如果客人在 $X$ 游戏里赢了 100 块，系统就会作弊，让他在 $Y$ 游戏里绝对输掉 100 块。它们不仅相关，而且是完美的负相关（互相排斥）。
    

现在问：作为一个赌场老板，你看的是**总体期望 $E(X+Y)$**。这个规则会改变赌场的长期平均流水吗？

**算账逻辑：**

老板根本不需要去管每个赌徒在两桌之间是怎么串联的。

老板的账本上只有两条总计：

1. **$X$ 桌的账本**：单独看骰子桌，它的平均收益 $E(X)$ 是固定的。
    
2. **$Y$ 桌的账本**：单独看扑克桌，它的平均收益 $E(Y)$ 也是固定的。
    

只要 $X$ 桌每天平均赚 1 万，$Y$ 桌每天平均赚 2 万，那么整个赌场每天必定平均赚 3 万。

**即便这两个桌子的输赢是死死绑定在一起的（极度不独立），对宏观的“均值（总盘子）”也毫无影响。**

因为期望本质上就是一个“宏观算总账”的工具。只要把每个微观个体的贡献加起来，无论他们私底下是怎么互相拆借、互相影响的，总财富的平均值是跑不掉的。

## 3. 为什么直觉会骗我们？（混淆了“期望”与“方差”）

人类的直觉其实极其敏锐，你觉得“变量之间的强关联一定会产生某种影响”，这个直觉是完全正确的！

**错只错在：这种影响没有作用在“期望（均值）”上，而是全部作用在了“方差（风险/波动）”上！**

如果我们要算 $(X+Y)$ 的方差（即波动大小），公式是这样的：

$$D(X+Y) = D(X) + D(Y) + 2 \cdot \text{Cov}(X, Y)$$

在这里，变量之间的关联性终于露出了獠牙：**协方差 $\text{Cov}(X, Y)$**。

- 如果 $X$ 和 $Y$ **正相关**（同涨同跌），协方差为正，总体的波动会剧烈放大（风险暴增）。
    
- 如果 $X$ 和 $Y$ **负相关**（此消彼长），协方差为负，总体的波动会被抵消（这就是金融里”对冲基金”降低风险的数学本质）。
