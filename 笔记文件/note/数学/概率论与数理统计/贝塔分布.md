### 1. 欧拉第一积分：贝塔函数的诞生

在推导伽玛函数（欧拉第二积分）时，我们曾提到过欧拉对多项式积分的把玩。欧拉定义的**第一类积分**，也就是贝塔函数 $B(\alpha, \beta)$，其纯数学定义为有限区间 $[0, 1]$ 上的定积分：

$$B(\alpha, \beta) = \int_0^1 x^{\alpha-1} (1-x)^{\beta-1} dx \quad (\alpha > 0, \beta > 0)$$

为了将这个积分转化为概率密度函数，我们和推导伽玛分布时一样，进行**强行归一化**。将 $B(\alpha, \beta)$ 除过去，就得到了**贝塔分布的概率密度函数 (PDF)**：

$$f(x) = \frac{1}{B(\alpha, \beta)} x^{\alpha-1} (1-x)^{\beta-1} \quad (0 \le x \le 1)$$

记作 $X \sim \text{Beta}(\alpha, \beta)$。

### 2. 神级推导：贝塔函数与伽玛函数的终极纽带

在微积分的历史上，有一个极其优美且震撼的定理：**贝塔函数完全可以由伽玛函数表达**。

即：

$$B(\alpha, \beta) = \frac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha+\beta)}$$

这个公式是怎么来的？我们通过**双重积分与极坐标变换**来硬核推导。

**第一步：写出伽玛函数的平方形式**

我们已知 $\Gamma(\alpha) = \int_0^\infty u^{\alpha-1} e^{-u} du$。

做一个极其巧妙的变量代换：令 $u = x^2$，则 $du = 2x dx$。

代入伽玛函数：

$$\Gamma(\alpha) = \int_0^\infty (x^2)^{\alpha-1} e^{-x^2} (2x dx) = 2 \int_0^\infty x^{2\alpha-1} e^{-x^2} dx$$

同理，对于 $\beta$，我们用变量 $y$：

$$\Gamma(\beta) = 2 \int_0^\infty y^{2\beta-1} e^{-y^2} dy$$

**第二步：二重积分的乘积拼装**

将这两个伽玛函数相乘。由于积分变量 $x$ 和 $y$ 是相互独立的，定积分的乘积可以写成二重积分：

$$\Gamma(\alpha)\Gamma(\beta) = \left( 2 \int_0^\infty x^{2\alpha-1} e^{-x^2} dx \right) \left( 2 \int_0^\infty y^{2\beta-1} e^{-y^2} dy \right)$$

$$\Gamma(\alpha)\Gamma(\beta) = 4 \int_0^\infty \int_0^\infty x^{2\alpha-1} y^{2\beta-1} e^{-(x^2+y^2)} dx dy$$

此时，积分区域是整个第一象限（$x > 0, y > 0$）。

**第三步：极坐标变换的降维打击**

面对形如 $x^2+y^2$ 的指数，引入极坐标是微积分的本能：

令 $x = r\cos\theta$，$y = r\sin\theta$。

面积微元 $dx dy = r dr d\theta$。

因为是第一象限，所以角度 $\theta$ 从 $0$ 积分到 $\frac{\pi}{2}$，半径 $r$ 从 $0$ 积分到 $+\infty$。

代入二重积分：

$$\Gamma(\alpha)\Gamma(\beta) = 4 \int_0^{\pi/2} \int_0^\infty (r\cos\theta)^{2\alpha-1} (r\sin\theta)^{2\beta-1} e^{-r^2} r dr d\theta$$

将含有 $r$ 的项和含有 $\theta$ 的项彻底分离开来，组成两个独立的定积分：

$$\Gamma(\alpha)\Gamma(\beta) = \left( 2 \int_0^\infty r^{2\alpha-1+2\beta-1+1} e^{-r^2} dr \right) \cdot \left( 2 \int_0^{\pi/2} \cos^{2\alpha-1}\theta \sin^{2\beta-1}\theta d\theta \right)$$

化简前面 $r$ 的指数：$2\alpha-1+2\beta-1+1 = 2(\alpha+\beta)-1$。

**第四步：审判时刻**

盯住分离后的这两个积分。

前面的积分：

$$2 \int_0^\infty r^{2(\alpha+\beta)-1} e^{-r^2} dr$$

根据我们在第一步的推导，这**完完全全就是 $\Gamma(\alpha+\beta)$ 的定义式**！

后面的积分：

$$2 \int_0^{\pi/2} \cos^{2\alpha-1}\theta \sin^{2\beta-1}\theta d\theta$$

我们来对它做一个变量代换：令 $t = \cos^2\theta$。

则 $dt = 2\cos\theta(-\sin\theta) d\theta \implies -dt = 2\cos\theta\sin\theta d\theta$。

当 $\theta = 0$ 时，$t = 1$；当 $\theta = \pi/2$ 时，$t = 0$。

将后面积分改写：

$$2 \int_0^{\pi/2} (\cos^2\theta)^{\alpha-1} (\sin^2\theta)^{\beta-1} (\cos\theta\sin\theta d\theta)$$

代入 $t$ 和 $-dt$：

$$\int_1^0 t^{\alpha-1} (1-t)^{\beta-1} (-dt) = \int_0^1 t^{\alpha-1} (1-t)^{\beta-1} dt$$

看！这个积出来的结果，**一字不差地正是贝塔函数 $B(\alpha, \beta)$ 的定义式**！

我们将这两部分重新拼合，那个永恒的等式瞬间定格：

$$\Gamma(\alpha)\Gamma(\beta) = \Gamma(\alpha+\beta) \cdot B(\alpha, \beta)$$

移项即得：

$$B(\alpha, \beta) = \frac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha+\beta)}$$

### 3. 利用纽带秒杀期望与方差

既然有了贝塔函数与伽玛函数的转换公式，求贝塔分布 $X \sim \text{Beta}(\alpha, \beta)$ 的矩（期望和方差）就变成了一场极度舒适的代数消消乐。

**一阶矩（期望 $E(X)$）：**

根据定义式：

$$E(X) = \int_0^1 x \cdot \frac{x^{\alpha-1}(1-x)^{\beta-1}}{B(\alpha, \beta)} dx$$

将 $x$ 乘进去，指数变成 $\alpha$（即 $(\alpha+1)-1$）：

$$E(X) = \frac{1}{B(\alpha, \beta)} \int_0^1 x^{(\alpha+1)-1} (1-x)^{\beta-1} dx$$

后面的积分恰好是新的贝塔函数 $B(\alpha+1, \beta)$，因此：

$$E(X) = \frac{B(\alpha+1, \beta)}{B(\alpha, \beta)}$$

现在，展开为伽玛函数，并利用递推公式 $\Gamma(z+1) = z\Gamma(z)$：

$$E(X) = \frac{ \frac{\Gamma(\alpha+1)\Gamma(\beta)}{\Gamma(\alpha+1+\beta)} }{ \frac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha+\beta)} } = \frac{\Gamma(\alpha+1)}{\Gamma(\alpha)} \cdot \frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha+\beta+1)}$$

$$E(X) = \frac{\alpha \Gamma(\alpha)}{\Gamma(\alpha)} \cdot \frac{\Gamma(\alpha+\beta)}{(\alpha+\beta) \Gamma(\alpha+\beta)}$$

约分后，得到极其干净的结论：

$$E(X) = \frac{\alpha}{\alpha+\beta}$$

**二阶矩 $E(X^2)$ 与方差 $D(X)$：**

同理，将 $x^2$ 乘进去：

$$E(X^2) = \frac{B(\alpha+2, \beta)}{B(\alpha, \beta)} = \frac{\Gamma(\alpha+2)}{\Gamma(\alpha)} \cdot \frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha+\beta+2)}$$

连续降阶两次：

$$E(X^2) = \frac{(\alpha+1)\alpha}{(\alpha+\beta+1)(\alpha+\beta)}$$

代入方差公式 $D(X) = E(X^2) - [E(X)]^2$：

$$D(X) = \frac{\alpha(\alpha+1)}{(\alpha+\beta)(\alpha+\beta+1)} - \frac{\alpha^2}{(\alpha+\beta)^2}$$

通分，公分母为 $(\alpha+\beta)^2(\alpha+\beta+1)$：

$$D(X) = \frac{\alpha(\alpha+1)(\alpha+\beta) - \alpha^2(\alpha+\beta+1)}{(\alpha+\beta)^2(\alpha+\beta+1)}$$

展开分子：

$$\alpha(\alpha^2 + \alpha\beta + \alpha + \beta) - (\alpha^3 + \alpha^2\beta + \alpha^2)$$

$$= \alpha^3 + \alpha^2\beta + \alpha^2 + \alpha\beta - \alpha^3 - \alpha^2\beta - \alpha^2$$

所有的高次项全部绝妙地相消，分子只剩下 $\alpha\beta$。

最终结果：

$$D(X) = \frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$$

### 4. 物理/工程意义：贝叶斯推断的“信仰更新器”

为什么工程学和数据科学如此痴迷贝塔分布？因为它完美契合了**贝叶斯定理（先验 $\times$ 似然 $\propto$ 后验）**。

假设你拿到一个硬币（或者某个有成功/失败两种状态的电子元器件），你想知道它“抛出正面的真实概率 $p$”是多少。

1. 一开始，你一无所知，假设 $p$ 在 $[0, 1]$ 之间是均匀分布的。这其实就是 $\text{Beta}(1, 1)$。
    
2. 现在，你开始做实验（二项分布）。你抛了硬币，发现出现了 $\alpha-1$ 次正面，$\beta-1$ 次反面。
    
3. 根据贝叶斯定理，你将新的观测数据乘进先验概率中，你会惊讶地发现，后验概率分布**仍然是一个贝塔分布**，变成了 $\text{Beta}(\alpha, \beta)$！
    

**贝塔分布的参数 $\alpha$ 和 $\beta$ 有着绝对直观的物理意义：**

- $\alpha$ 相当于你观察到的“成功”次数（加上基底 1）。
    
- $\beta$ 相当于你观察到的“失败”次数（加上基底 1）。
    
- 期望 $E(X) = \frac{\alpha}{\alpha+\beta}$，正是“成功次数 / 总次数”，即最直观的概率估计。
    
- 随着你做的实验越来越多（$\alpha$ 和 $\beta$ 变得极大），方差 $D(X)$ 的分母呈三次方的速度膨胀，方差极速坍缩。这条曲线会像一根钢针一样，死死钉在那个真实的概率 $p$ 上。
