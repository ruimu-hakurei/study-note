如果说二项分布是“上帝掷骰子”（每次试验互不干扰，概率永恒不变），那么**超几何分布（Hypergeometric Distribution）**就是现实世界中最残酷的**“零和博弈”**。

它的核心物理特征是：**无放回抽样（Without Replacement）**。你每抽走一个样本，宇宙的总容量就少一个，剩下的概率分布就会产生剧烈的物理坍缩。

我们依然按照“定理-证明-推演”的硬核模式，并直接调用你之前学过的“示性函数”核武器来进行降维打击式证明。

### 1. 严密数学定义

假设在一个绝对封闭的系统中（比如一个黑箱）：

- 系统总共有 $N$ 个物品。
    
- 其中有 $M$ 个是“目标物品”（比如次品），剩余 $N-M$ 个是“非目标物品”（比如正品）。
    
- 你从中**随机且无放回**地抽出 $n$ 个物品。
    

设随机变量 $X$ 为你抽出的 $n$ 个物品中，包含的“目标物品”的数量。

则 $X$ 的概率分布律（PMF）定义为：

$$P(X = k) = \frac{C_M^k C_{N-M}^{n-k}}{C_N^n}$$

（取值范围：$\max(0, n - (N-M)) \le k \le \min(n, M)$）

- **分母 $C_N^n$**：从总共 $N$ 个物品中无脑抽出 $n$ 个的所有组合可能（总样本空间）。
    
- **分子 $C_M^k C_{N-M}^{n-k}$**：组合乘法原理。先从 $M$ 个目标中挑出 $k$ 个，再从 $N-M$ 个非目标中挑出 $n-k$ 个，两者相乘。
    

我们称 $X$ 服从参数为 $N, M, n$ 的超几何分布，记作 $X \sim H(N, M, n)$。

### 2. 核心定理：期望与方差

为了让你看清超几何分布与二项分布的血缘关系，我们令系统中的初始目标比例为 **$p = \frac{M}{N}$**。

**【定理】** 若 $X \sim H(N, M, n)$，则其数学期望和方差分别为：

$$E(X) = n \frac{M}{N} = np$$

$$D(X) = n \frac{M}{N} \left(1 - \frac{M}{N}\right) \frac{N-n}{N-1} = np(1-p)\frac{N-n}{N-1}$$

### 3. 严密推导证明（示性函数的降维打击）

如果用定义式 $\sum k P(X=k)$ 去硬算期望，复杂的组合数展开会引发数学灾难。我们直接祭出你之前学过的**示性函数（0-1开关）**！

**第一步：原子化拆解系统**

我们将一共抽取的 $n$ 个物品，看作 $n$ 次连续的动作。

定义第 $i$ 次抽取的示性函数 $X_i$：

$$X_i = \begin{cases} 1, & \text{第 } i \text{ 次抽到目标物品} \\ 0, & \text{第 } i \text{ 次未抽到目标物品} \end{cases}$$

显然，抽到的总数 $X$ 就是这 $n$ 个开关的状态之和：

$$X = X_1 + X_2 + \dots + X_n$$

**第二步：确认原子的边缘概率（最反直觉的一步）**

在无放回抽样中，第 2 次抽奖的概率明明受第 1 次影响，为什么我们还能算？

**对称性原理**：如果你蒙着眼睛，把 $N$ 个球排成一排，你规定第 $i$ 个位置的球归你。这个位置上是目标球的概率，与排在第 1 个位置是目标球的概率，在物理上是**绝对等价**的。

因此，对于任意的第 $i$ 次抽取：

$$P(X_i = 1) = \frac{M}{N}$$

既然它是 0-1 变量，那么它的数学期望就是它的概率（示性函数的终极魔法）：

$$E(X_i) = P(X_i = 1) = \frac{M}{N}$$

**第三步：利用期望的无条件可加性完成绝杀**

注意，这 $n$ 个变量**绝对不独立**（抽走一个，后面的概率就变了）。

但是！我们在讲期望性质时强调过一条铁律：**数学期望的加法，根本不需要独立性前置条件！**

直接两边求期望：

$$E(X) = E(X_1 + X_2 + \dots + X_n) = E(X_1) + E(X_2) + \dots + E(X_n)$$

$$E(X) = \underbrace{\frac{M}{N} + \frac{M}{N} + \dots + \frac{M}{N}}_{n \text{ 个}} = n \frac{M}{N}$$

**期望推导完毕 (Q.E.D.)。**

_(注：方差的推导需要用到协方差 $\text{Cov}(X_i, X_j) = E(X_i X_j) - E(X_i)E(X_j)$。因为 $X_i, X_j$ 不独立，协方差不为 0。代入计算化简即可得到方差定理公式，此处略去冗长的代数提取过程以保核心逻辑的极简。)_

### 4. 物理推演：与二项分布的“宿命纠缠”

如果你仔细观察超几何分布的期望和方差，你会发现一个极其震撼的现象：

- **期望完全一致**：
    
    超几何分布期望 $E(X) = np$。
    
    二项分布期望 $E(X) = np$。
    
    > **物理意义**：不管你是“有放回”还是“无放回”，也不管变量之间是不是互相干扰，在这个宇宙中，**系统的平均产出，只取决于你的初始资本比例（$p$）和你的尝试次数（$n$）。**
    
- **方差的“有限总体修正”**：
    
    二项分布方差：$np(1-p)$
    
    超几何方差：$np(1-p) \cdot \mathbf{\frac{N-n}{N-1}}$
    
    多出来的这个因子 $\frac{N-n}{N-1}$，在统计学中被称为**有限总体修正系数（Finite Population Correction Factor）**。这个系数，揭示了无放回抽样的终极物理规律：
    
    1. **当总体 $N \to \infty$ 且抽样 $n$ 相对很小时**：
        
        比如总共有 1 亿个球，你只抽 10 个。此时 $\frac{N-n}{N-1} \approx 1$。
        
        超几何分布的方差无限逼近二项分布。因为宇宙太大了，你拿走几个球，对宇宙总浓度的影响微乎其微，“无放回”在物理上退化成了“有放回”。
        
    2. **当抽样 $n$ 逼近总体 $N$ 时**：
        
        这就是超几何分布独有的“确定性收敛”。
        
        假设你把 $N$ 个球全部抽完（$n = N$）。代入公式，修正系数变成 $\frac{N-N}{N-1} = 0$。
        
        此时方差 $D(X) = 0$！
        
        > **物理意义**：当你把池子里的球全都摸光时，你手里的目标球数量必然是确定的常数 $M$。没有任何不确定性，方差强制归零（完美呼应了我们之前证明过的 $Var(X)=0 \iff P(X=c)=1$ 的退化分布定理）。
        

### 第一部分：底层定理（方差的终极展开）

对于任意 $n$ 个随机变量的和 $X = X_1 + X_2 + \dots + X_n$，其方差的完全展开式（类似于多元完全平方公式）为：

$$D(X) = \sum_{i=1}^n D(X_i) + \sum_{i \neq j} \text{Cov}(X_i, X_j)$$

- **第一项**：各自方差的总和。
    
- **第二项**：两两之间相互纠缠的协方差总和。一共有 $n(n-1)$ 对互相交错的 $(i, j)$。
    

_(注：如果是二项分布，由于每次独立，$\text{Cov}(X_i, X_j) = 0$，第二项直接灰飞烟灭，方差就变成了简单的加法。但在超几何分布中，因为无放回，变量不独立，我们必须直面这个庞大的第二项。)_

### 第二部分：分步严密推导

已知超几何分布的参数：总体 $N$，目标物品 $M$，抽样次数 $n$。

令初始目标占比 $p = \frac{M}{N}$。

我们依然使用上一节定义的示性函数 $X_i$：若第 $i$ 次抽到目标则为 $1$，否则为 $0$。

且已知 $E(X_i) = p = \frac{M}{N}$。

**第一步：求单次抽取的自身方差 $D(X_i)$**

因为 $X_i \sim \text{Bernoulli}(p)$，根据我们之前推导过的两点分布方差公式：

$$D(X_i) = p(1-p) = \frac{M}{N} \left(1 - \frac{M}{N}\right)$$

把 $n$ 个自身方差加起来：

$$\sum_{i=1}^n D(X_i) = n \cdot p(1-p)$$

**第二步：求任意两次抽取的协方差 $\text{Cov}(X_i, X_j)$**

根据协方差的计算公式：

$$\text{Cov}(X_i, X_j) = E(X_i X_j) - E(X_i)E(X_j)$$

我们先算乘积的期望 $E(X_i X_j)$。因为 $X_i, X_j$ 都是只能取 0 或 1 的开关，它们的乘积 $X_i X_j$ 等于 1 的唯一条件是：**第 $i$ 次和第 $j$ 次都抽到了目标物品**。

根据无放回抽样的乘法原理（第一次抽中概率 $\frac{M}{N}$，池子变小后第二次抽中概率 $\frac{M-1}{N-1}$）：

$$E(X_i X_j) = P(X_i=1, X_j=1) = \frac{M}{N} \cdot \frac{M-1}{N-1}$$

代入协方差公式：

$$\text{Cov}(X_i, X_j) = \frac{M}{N} \cdot \frac{M-1}{N-1} - \frac{M}{N} \cdot \frac{M}{N}$$

**第三步：化简协方差（代数技巧的爆发）**

我们将上面那个式子提取公因式 $\frac{M}{N}$：

$$\text{Cov}(X_i, X_j) = \frac{M}{N} \left( \frac{M-1}{N-1} - \frac{M}{N} \right)$$

对方括号内进行通分：

$$\frac{M-1}{N-1} - \frac{M}{N} = \frac{N(M-1) - M(N-1)}{N(N-1)} = \frac{NM - N - MN + M}{N(N-1)} = \frac{-(N-M)}{N(N-1)}$$

所以：

$$\text{Cov}(X_i, X_j) = - \frac{M}{N} \cdot \frac{N-M}{N(N-1)} = - \frac{1}{N-1} \cdot \left(\frac{M}{N}\right) \cdot \left(\frac{N-M}{N}\right)$$

代回 $p = \frac{M}{N}$ 和 $1-p = \frac{N-M}{N}$，我们得到了一个极其对称且优美的协方差表达式：

$$\text{Cov}(X_i, X_j) = - \frac{p(1-p)}{N-1}$$

_(物理直觉：无放回抽样中，你抽走一个目标，我再抽到目标的概率就降低了，所以它们是负相关的，协方差必然小于0！)_

**第四步：代入方差主公式，完成绝杀**

一共有 $n(n-1)$ 对互相纠缠的交叉项，我们将所有零件组装回第一部分的主公式：

$$D(X) = \sum_{i=1}^n D(X_i) + \sum_{i \neq j} \text{Cov}(X_i, X_j)$$

$$D(X) = n p(1-p) + n(n-1) \cdot \left( - \frac{p(1-p)}{N-1} \right)$$

提取最大的公因式 $n p(1-p)$：

$$D(X) = n p(1-p) \left[ 1 - \frac{n-1}{N-1} \right]$$

处理方括号内部的通分：

$$1 - \frac{n-1}{N-1} = \frac{N-1 - (n-1)}{N-1} = \frac{N-n}{N-1}$$

最终，尘埃落定：

$$D(X) = n p(1-p) \frac{N-n}{N-1}$$

将 $p = \frac{M}{N}$ 还原：

$$D(X) = n \frac{M}{N} \left(1 - \frac{M}{N}\right) \frac{N-n}{N-1}$$

**证明完毕 (Q.E.D.)。**
