**### 1. 从积分到概率密度：强行归一化

一个合法的概率密度函数，其全空间积分必须等于 **1**。

既然已知 $\int_0^\infty x^{\alpha-1} e^{-x} dx = \Gamma(\alpha)$，我们只需要把等式右边的常数 $\Gamma(\alpha)$ 除过去，立刻就能得到一个天生的概率密度函数（PDF）：

$$\int_0^\infty \frac{x^{\alpha-1} e^{-x}}{\Gamma(\alpha)} dx = 1$$

为了让这个数学玩具能够拟合真实的物理世界（比如带上单位，或者调整事件发生的快慢），我们对变量 $x$ 进行一个简单的尺度拉伸，引入一个**率参数（Rate Parameter） $\lambda$**（要求 $\lambda > 0$）：

令 $x = \lambda t$，则微分 $dx = \lambda dt$。代入上面的积分式：

$$\int_0^\infty \frac{(\lambda t)^{\alpha-1} e^{-\lambda t}}{\Gamma(\alpha)} \lambda dt = 1$$

整理一下积分号内部的表达式，我们就得到了**伽玛分布的概率密度函数** $f(t)$：

$$f(t) = \frac{\lambda^\alpha}{\Gamma(\alpha)} t^{\alpha-1} e^{-\lambda t} \quad (t > 0)$$

我们记作 $X \sim \text{Gamma}(\alpha, \lambda)$。

- **$\alpha$（形状参数 Shape）**：决定了分布曲线的长相。它本质上代表了“事件发生的次数”。
    
- **$\lambda$（率参数 Rate）**：决定了分布的宽窄。它代表了“单位时间内事件发生的平均速率”。
    

### 2. 物理意义：泊松过程中的“时间等候者”

伽玛分布绝对不是数学家在纸上随便凑出来的，它是泊松过程（Poisson Process）在时间维度上的连续镜像。

想象你站在马路边等公交车，或者在一台盖革计数器旁监测放射性原子的衰变：

1. **指数分布（Exponential Distribution）**：描述的是“等到**第 1 个**质点衰变（或第 1 辆公交车到来）”所需要的时间。
    
2. **伽玛分布（Gamma Distribution）**：描述的是“等到**第 $\alpha$ 个**质点衰变”所需要的总时间。
    

也就是说，如果 $X_1, X_2, \dots, X_n$ 是 $n$ 个相互独立的、服从参数为 $\lambda$ 的指数分布的随机变量，那么它们的总和：

$$Y = X_1 + X_2 + \dots + X_n$$

**必定服从参数为 $(n, \lambda)$ 的伽玛分布！**

这解释了为什么 $\alpha$ 被称为形状参数。当 $\alpha=1$ 时，它就是指数分布，曲线是一路向下滑梯的；但当 $\alpha$ 越来越大时（比如等到第 10 辆车），等待时间极短的概率会变成 0，曲线会鼓起一个包，随着 $\alpha$ 趋于无穷大，根据中心极限定理，这个包最终会演变成完美的**正态分布的钟形曲线**。

### 3. 硬核推导：为什么等待 $\alpha$ 个事件的时间恰好是它？

这里我们提供一个极其优雅的微积分推导，展示这个概率密度函数是如何从离散的“抛硬币/泊松分布”中坍缩出来的。

假设在单位时间内，事件发生的平均速率是 $\lambda$。根据泊松分布，在时间 $t$ 内，恰好发生 $k$ 次事件的概率为：

$$P(N(t) = k) = \frac{(\lambda t)^k}{k!} e^{-\lambda t}$$

现在，我们令连续随机变量 $T$ 为“**等到第 $n$ 个事件发生所经历的时间**”。我们要推导 $T$ 的概率密度函数 $f(t)$。

**第一步：写出累积分布函数 (CDF)**

累积分布函数 $F(t) = P(T \le t)$，意思是“等待第 $n$ 个事件发生的时间小于等于 $t$”。

这句话在物理上等价于：**“在时间 $t$ 内，发生的事件总数至少有 $n$ 个。”**

利用对立事件，我们可以把它写成：

$$F(t) = 1 - P(\text{时间 } t \text{ 内发生的事件少于 } n \text{ 个})$$

$$F(t) = 1 - \sum_{k=0}^{n-1} P(N(t) = k)$$

将泊松分布的公式代入：

$$F(t) = 1 - \sum_{k=0}^{n-1} \frac{(\lambda t)^k}{k!} e^{-\lambda t}$$

**第二步：求导得到概率密度函数 (PDF)**

PDF 是 CDF 的导数。我们对等式两边关于时间 $t$ 求导：

$$f(t) = \frac{d}{dt} F(t) = - \frac{d}{dt} \sum_{k=0}^{n-1} \frac{\lambda^k t^k}{k!} e^{-\lambda t}$$

对里面的一般项 $\frac{\lambda^k t^k}{k!} e^{-\lambda t}$ 运用乘积求导法则：

$$\frac{d}{dt} \left( \frac{\lambda^k t^k}{k!} e^{-\lambda t} \right) = \frac{k \lambda^k t^{k-1}}{k!} e^{-\lambda t} - \lambda \frac{\lambda^k t^k}{k!} e^{-\lambda t}$$

化简前一项（因为 $k / k! = 1 / (k-1)!$）：

$$= \lambda \frac{(\lambda t)^{k-1}}{(k-1)!} e^{-\lambda t} - \lambda \frac{(\lambda t)^k}{k!} e^{-\lambda t}$$

**第三步：多米诺骨牌般的绝杀消元 (Telescoping Sum)**

把导数展开成级数求和，你会看到一个极其壮观的数学现象——**裂项相消**！

- 当 $k=0$ 时：导数为 $-\lambda e^{-\lambda t}$
    
- 当 $k=1$ 时：导数为 $\lambda e^{-\lambda t} - \lambda (\lambda t) e^{-\lambda t}$
    
- 当 $k=2$ 时：导数为 $\lambda (\lambda t) e^{-\lambda t} - \lambda \frac{(\lambda t)^2}{2!} e^{-\lambda t}$
    
- ...
    
- 当 $k=n-1$ 时：导数为 $\lambda \frac{(\lambda t)^{n-2}}{(n-2)!} e^{-\lambda t} - \lambda \frac{(\lambda t)^{n-1}}{(n-1)!} e^{-\lambda t}$
    

由于我们求 PDF 时前面有一个负号 $f(t) = - \sum$，这些项加起来之后，除了最后面的那一项，**前面所有的项全部互相抵消殆尽！**

最后只剩下最后一项的负号部分（被外面的负号变成正号）：

$$f(t) = \lambda \frac{(\lambda t)^{n-1}}{(n-1)!} e^{-\lambda t}$$

因为 $n$ 是整数，我们利用之前推导过的伽玛函数与阶乘的终极接驳公式 $(n-1)! = \Gamma(n)$，将其代入：

$$f(t) = \frac{\lambda^n}{\Gamma(n)} t^{n-1} e^{-\lambda t}$$

这正是我们一开始通过强行归一化得到的伽玛分布 PDF。

### 4. 矩的优雅计算：伽玛递推公式的降维打击

既然有了这个密度的定义，如果我们要求它的期望 $E(X)$ 和方差 $D(X)$，在普通的微积分课上需要极其繁琐的分部积分。但掌握了伽玛函数核心递推公式 $\Gamma(\alpha+1) = \alpha\Gamma(\alpha)$ 的我们，可以直接秒杀。

**求期望 $E(X)$**：

$$E(X) = \int_0^\infty t \cdot \frac{\lambda^\alpha}{\Gamma(\alpha)} t^{\alpha-1} e^{-\lambda t} dt$$

将外面的 $t$ 合并进去：

$$E(X) = \frac{\lambda^\alpha}{\Gamma(\alpha)} \int_0^\infty t^\alpha e^{-\lambda t} dt$$

为了让后面的积分再次凑成伽玛函数，我们补一个 $\lambda$：

$$E(X) = \frac{\lambda^\alpha}{\Gamma(\alpha)} \cdot \frac{\Gamma(\alpha+1)}{\lambda^{\alpha+1}}$$

利用 $\Gamma(\alpha+1) = \alpha\Gamma(\alpha)$ 约分，所有的 $\Gamma$ 瞬间灰飞烟灭，剩下的结果极度干净：

$$E(X) = \frac{\alpha}{\lambda}$$
根据概率论中方差的计算公式，方差等于平方的期望减去期望的平方：

$$D(X) = E(X^2) - [E(X)]^2$$

我们已经有了期望 $E(X)$，现在唯一需要攻克的目标就是**二阶原点矩 $E(X^2)$**。

### 第一步：构建二阶矩的积分式

根据期望的定义式，我们将 $t^2$ 乘入伽玛分布的概率密度函数中：

$$E(X^2) = \int_0^\infty t^2 \cdot \frac{\lambda^\alpha}{\Gamma(\alpha)} t^{\alpha-1} e^{-\lambda t} dt$$

将常数系数提到积分号外，并将积分号内部的 $t^2$ 与 $t^{\alpha-1}$ 合并：

$$E(X^2) = \frac{\lambda^\alpha}{\Gamma(\alpha)} \int_0^\infty t^{\alpha+1} e^{-\lambda t} dt$$

### 第二步：利用伽玛积分公式降维打击

我们审视剩下的这个反常积分：

$$\int_0^\infty t^{\alpha+1} e^{-\lambda t} dt$$

根据伽玛函数的广义积分公式 $\int_0^\infty x^{z-1} e^{-\lambda x} dx = \frac{\Gamma(z)}{\lambda^z}$，我们要对齐指数。

这里的 $t$ 的指数是 $\alpha + 1$，对应公式中的 $z - 1$，因此 $z = \alpha + 2$。

直接套用伽玛积分的结论，该积分为：

$$\frac{\Gamma(\alpha+2)}{\lambda^{\alpha+2}}$$

### 第三步：代数化简与伽玛递推公式的绝杀

将上一步求出的积分结果代回 $E(X^2)$ 的等式中：

$$E(X^2) = \frac{\lambda^\alpha}{\Gamma(\alpha)} \cdot \frac{\Gamma(\alpha+2)}{\lambda^{\alpha+2}}$$

首先处理 $\lambda$ 的幂次：$\lambda^\alpha$ 和分母的 $\lambda^{\alpha+2}$ 约分，分母上留下 $\lambda^2$。

$$E(X^2) = \frac{\Gamma(\alpha+2)}{\lambda^2 \Gamma(\alpha)}$$

现在，召唤伽玛函数最核心的灵魂递推公式 $\Gamma(z+1) = z\Gamma(z)$。我们对分子连续降阶两次：

$$\Gamma(\alpha+2) = (\alpha+1)\Gamma(\alpha+1) = (\alpha+1)\alpha\Gamma(\alpha)$$

代入上式中：

$$E(X^2) = \frac{(\alpha+1)\alpha\Gamma(\alpha)}{\lambda^2 \Gamma(\alpha)}$$

分子分母的 $\Gamma(\alpha)$ 完美抵消殆尽，得到极其干净的二阶矩：

$$E(X^2) = \frac{\alpha(\alpha+1)}{\lambda^2} = \frac{\alpha^2 + \alpha}{\lambda^2}$$

### 第四步：计算最终方差

将求得的二阶矩 $E(X^2)$ 和之前求出的期望 $E(X) = \frac{\alpha}{\lambda}$ 代入方差的总公式：

$$D(X) = E(X^2) - [E(X)]^2$$

$$D(X) = \frac{\alpha^2 + \alpha}{\lambda^2} - \left(\frac{\alpha}{\lambda}\right)^2$$

$$D(X) = \frac{\alpha^2 + \alpha}{\lambda^2} - \frac{\alpha^2}{\lambda^2}$$

分子进行简单的减法：$\alpha^2 + \alpha - \alpha^2 = \alpha$。

最终结果确立：

$$D(X) = \frac{\alpha}{\lambda^2}$$

### 第一步：看透连续型随机变量的“物理故事”

笔记的第一行写着：

$$Y \sim Ga(n, \lambda), \quad Y = X_1 + \dots + X_n, \quad X_1, \dots, X_n \stackrel{i.i.d.}{\sim} Exp(\lambda)$$

这其实讲了一个极其经典的“排队等候”故事：

- **$Exp(\lambda)$（指数分布）**：它描述的是“等待**下一次**随机事件发生所需的时间”。比如，你在公交站等下一辆公交车，或者在服务器端等待下一个用户的网络请求到达，这个等待的时间 $X$ 就服从指数分布。
    
- **$Ga(n, \lambda)$（伽马分布）**：它描述的是“等待**连续发生 $n$ 次**随机事件所需的**总时间**”。比如，你要等齐 $n$ 辆公交车过去，或者服务器要处理完 $n$ 个并发请求。
    

**神级拆解逻辑：**

你要等 $n$ 个事件发生的总时间 $Y$，在物理上绝对等价于：

等第 1 个事件的时间 $X_1$ + 等第 2 个事件的时间 $X_2$ + $\dots$ + 等第 $n$ 个事件的时间 $X_n$。

因为每次等待都是完全独立且规律相同的，所以 $X_1, \dots, X_n$ 是独立同分布（i.i.d.）的指数分布。

### 第二步：提取底层零件的特征函数

既然伽马分布 $Y$ 被拆成了 $n$ 个指数分布 $X$ 的和，我们只需要看指数分布 $X \sim Exp(\lambda)$ 的特征函数。

指数分布的概率密度函数是 $f(x) = \lambda e^{-\lambda x}$。通过简单的积分，它的特征函数可以求得：

$$\varphi_X(t) = \int_0^{+\infty} e^{itx} \lambda e^{-\lambda x} dx = \frac{\lambda}{\lambda - it}$$

为了配合笔记里的书写格式，我们把分子分母同除以 $\lambda$：

$$\varphi_X(t) = \frac{1}{1 - \frac{it}{\lambda}} = \left( 1 - \frac{it}{\lambda} \right)^{-1}$$

### 第三步：特征函数连乘（降维打击）

笔记的最后一行写着：

$$\therefore \varphi_Y(t) = \left( 1 - \frac{it}{\lambda} \right)^{-n}$$

这一步就是我们前面反复赞美的“特征函数独立和化积”绝技：

既然 $Y = X_1 + \dots + X_n$，且它们相互独立，那么 $Y$ 的特征函数就是单个 $X$ 特征函数的 $n$ 次方。

$$\varphi_Y(t) = [\varphi_X(t)]^n = \left[ \left( 1 - \frac{it}{\lambda} \right)^{-1} \right]^n = \left( 1 - \frac{it}{\lambda} \right)^{-n}$$
