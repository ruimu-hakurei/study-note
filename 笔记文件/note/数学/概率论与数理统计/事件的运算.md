### 1. 交换律 (Commutative Law)

前后位置随便换，结果不改变。

- **并集**：$A \cup B = B \cup A$
    
- **交集**：$A \cap B = B \cap A$（在概率论中通常直接简写连在一起：$AB = BA$）
    

### 2. 结合律 (Associative Law)

当式子里**只有同一种运算符号**（全都是并集，或者全都是交集）时，括号随便打，先算谁都行。

- **并集**：$(A \cup B) \cup C = A \cup (B \cup C) = A \cup B \cup C$
    
- **交集**：$(A \cap B) \cap C = A \cap (B \cap C) = ABC$
    

### 3. 分配律 (Distributive Law) —— ⭐ 考试最爱考，也最容易出错！

当遇到交集和并集**混合**出现时，就得像初中代数里的“乘法分配律” $a \times (b + c) = a \times b + a \times c$ 一样把它展开。

- **交集对并集的分配**（最符合直觉）：
    
    $$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$
    
    > **直白翻译**：必须满足 $A$ 发生，**且**（$B$ 或 $C$ 至少发生一个）。这等价于：要么（$A$ 且 $B$ 发生），要么（$A$ 且 $C$ 发生）。
    
- **并集对交集的分配**（代数里没有这个操作，但在集合运算里是成立的！）：
    
    $$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$$
    
    > **直白翻译**：要么 $A$ 发生，要么（$B$ 且 $C$ 必须同时发生）。它等价于：（$A$ 或 $B$ 发生）**且**（$A$ 或 $C$ 发生）。
    
    
    >## 德摩根定律 (De Morgan's laws)

在做概率论的证明题和计算题时，你经常需要把“并集”和“交集”互相转换，这时候必须用到德摩根定律。它的口诀是“长杠变短杠，开口反方向”：

1. **$\overline{A \cup B} = \bar{A} \cap \bar{B}$**
    
    - **直观理解**：“并非（至少有一个好）” = “温度是坏的 **且** 湿度也是坏的”。
        
2. **$\overline{A \cap B} = \bar{A} \cup \bar{B}$**
    
    - **直观理解**：“并非（两个都完美）” = “要么温度坏了，要么湿度坏了（或者都坏了）”。
### 1. 并集的对立事件

对于 $n$ 个事件 $A_1, A_2, \dots, A_n$，它们的并集的对立等于它们各自对立事件的交集：

$$\overline{\bigcup_{i=1}^n A_i} = \bigcap_{i=1}^n \overline{A_i}$$

展开来写就是：

$$\overline{A_1 \cup A_2 \cup \dots \cup A_n} = \overline{A_1} \cap \overline{A_2} \cap \dots \cap \overline{A_n}$$

> **直白翻译**：“并非（至少发生一个）” 等价于 “所有事件都**不**发生”。
> 
> **硬件场景**：假设你的板子上有 $n$ 个传感器，事件 $A_i$ 表示“第 $i$ 个传感器发生故障”。
> 
> 左边表示：系统**没有**出现“至少一个传感器故障”的情况。
> 
> 右边表示：1号没故障 **且** 2号没故障 **且**... $n$号没故障（系统完美运行）。

### 2. 交集的对立事件

对于 $n$ 个事件 $A_1, A_2, \dots, A_n$，它们的交集的对立等于它们各自对立事件的并集：

$$\overline{\bigcap_{i=1}^n A_i} = \bigcup_{i=1}^n \overline{A_i}$$

展开来写就是：

$$\overline{A_1 \cap A_2 \cap \dots \cap A_n} = \overline{A_1} \cup \overline{A_2} \cup \dots \cup \overline{A_n}$$

> **直白翻译**：“并非（全部都发生）” 等价于 “至少有一个**不**发生”。
> 
> **硬件场景**：为了保证姿态解算准确，你需要融合 $n$ 个模块的数据。事件 $A_i$ 表示“第 $i$ 个模块数据有效”。
> 
> 左边表示：系统**没有**达成“所有模块数据都有效”的理想状态。
> 
> 右边表示：要么1号失效，要么2号失效……（至少有一个模块掉线了）。
