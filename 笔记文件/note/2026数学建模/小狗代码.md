# 第 0 部分：先把四个基础概念搞懂

代码里反复用到四个概念，先讲清楚，后面看代码就顺了。

## 0.1 坐标系和"示向度"

题目规定：**东是 x 轴正方向，北是 y 轴正方向，角度从东逆时针转**。

- 正东 = 0°，正北 = 90°，正西 = 180°，正南 = 270°。
- "示向度" = 站在检测点，看向干扰源的方向角。

例：你站在原点 (0,0)，干扰源在 (500,300)（右上方）。方向角 = `atan2(300, 500)` ≈ 31°。这就是你测到的示向度。

## 0.2 误差扇形（楔形）

`/measure` 返回的示向度**有 ±1° 误差**。所以"干扰源在 31° 方向"这句话，实际含义是：

> 干扰源在 **29° 到 33° 之间** 的某个方向。

从检测点出发，29°~33° 之间的区域，是一个**扇形（像一块披萨的一角）**。干扰源一定在这个扇形里。我们叫它"楔形 wedge"。

## 0.3 叉积（cross product）：判断"一个点在一条射线的哪一侧"

两个二维向量 u=(ux,uy)、v=(vx,vy) 的叉积（这里只取 z 分量，是个标量）：

```
cross(u, v) = ux*vy - uy*vx
```

**几何含义**：结果的正负号表示 v 相对 u 的方向——
- `cross(u, v) > 0`：v 在 u 的**逆时针**一侧；
- `cross(u, v) < 0`：v 在 u 的**顺时针**一侧；
- `cross(u, v) = 0`：v 和 u 在同一条线上。

这个"判断在一侧还是另一侧"的能力，是整个定位算法的地基。

## 0.4 半平面（half-plane）

一条直线把平面分成两半，每一半就是**半平面**。数学上写成：

```
a·x = ax*x + ay*y ≤ b
```

它表示"满足这个不等式的所有点 (x,y) 的集合"。例如 `x ≤ 5` 就是"直线 x=5 左侧的所有点"。

**为什么有用？** 因为"干扰源在 29°~33° 扇形里"这句话，可以精确翻译成"干扰源同时满足两个半平面不等式"：
- 一个不等式表示"在 33° 射线的一侧"；
- 另一个表示"在 29° 射线的另一侧"。

两个半平面一起，正好卡出一个扇形。多个检测点的扇形叠一起，就是"多个半平面的交集 = 凸多边形"，这个多边形就是**干扰源可能的位置区域**。

# 第 1 部分：geometry.py —— 纯几何

这个文件不联网、不发指令，只做数学计算。**先看这个文件，因为它最难，也是最核心的。**

## 1.1 顶部两个常量

```python
BEARING_ERROR_DEG = 1.0   # 示向度误差 ±1°
ARENA_R = 1800.0          # 目标区域半径 1800 米
```

## 1.2 `normalize_deg(deg)` —— 把角度归一到 [0,360)

```python
def normalize_deg(deg):
    return deg % 360.0
```

`%` 是取余。作用：把任意角度（比如 -10°、370°）都转成 0~360 之间的等价角度。
- `-10 % 360 = 350`（-10° 和 350° 是同一个方向）
- `370 % 360 = 10`

## 1.3 `angle_diff(a, b)` —— 两个角度的差（范围 -180 到 180）

```python
def angle_diff(a, b):
    return ((a - b + 180.0) % 360.0) - 180.0
```

作用：算 a 相对 b 转了多少度，结果落在 (-180, 180] 之间，方便判断"是不是差了半圈"。

例：`angle_diff(350, 10)`：a-b = 340，加 180 = 520，`% 360` = 160，减 180 = **-20**。意思是"350° 比 10° 逆时针少 20°"（等价于顺时针多 20°）。这比直接 `350-10=340` 好用多了，因为 340° 和 -20° 是同一个方向差，但 -20 更直观。

**这个函数在"单测点归航"里用来判断方位是否翻转了 180°**（后面会讲）。

## 1.4 `wedge_halfplanes(px, py, bearing, error)` —— 把一条示向度变成两个半平面（核心）

```python
def wedge_halfplanes(px, py, bearing_deg, error_deg=BEARING_ERROR_DEG):
    th = math.radians(bearing_deg)      # 角度转弧度（Python 三角函数用弧度）
    e = math.radians(error_deg)
    out = []
    for ang, side in ((th - e, 'ge'), (th + e, 'le')):
        ux, uy = math.cos(ang), math.sin(ang)   # 边界射线的方向向量
        if side == 'ge':
            out.append(((uy, -ux), uy * px - ux * py))
        else:
            out.append(((-uy, ux), ux * py - uy * px))
    return out
```

**它要解决什么**：输入"检测点 (px,py) 和一条示向度 bearing（带 ±error 误差）"，输出"两个半平面约束"。每个约束是 `((a), b)`，意思是 `a.x*x + a.y*y <= b`。

**为什么用叉积而不用 tan？** 因为 tan 在 90° 会变成无穷大（除零），而且 359° 和 0° 之间跨越会出各种边界 bug。叉积没有这些问题。

**推导（这是最关键的几行，仔细看）**：

设边界射线方向向量 u=(ux,uy)。射线从检测点 p=(px,py) 射出。对于任意点 g=(x,y)，向量 (g-p) 是从 p 指向 g 的。

叉积 `cross(u, g-p)` 能判断 g 在射线 u 的哪一侧（见 0.3）。把它展开：

```
cross(u, g-p) = ux*(y-py) - uy*(x-px)
              = (-uy)*x + ux*y + (uy*px - ux*py)
```

扇形有两条边界：
1. **下边界**（角度 th-e）：要求干扰源在它的**逆时针一侧**，即 `cross(u, g-p) >= 0`。
   把上面展开式 `>= 0` 移项整理，就变成 `uy*x - ux*y <= uy*px - ux*py`，
   即 `a=(uy, -ux)`, `b = uy*px - ux*py`。← 对应代码 `side == 'ge'` 那一行。

2. **上边界**（角度 th+e）：要求干扰源在它的**顺时针一侧**，即 `cross(u, g-p) <= 0`。
   直接就是 `(-uy)*x + ux*y <= ux*py - uy*px`，
   即 `a=(-uy, ux)`, `b = ux*py - uy*px`。← 对应 `side == 'le'` 那一行。

**用具体数字验证一下**：检测点 (0,0)，示向度 90°（正北），误差 45°。扇形是 45°~135°。

- 点 g=(0,1)（正北）应该在扇形内。
  - 下边界 45°：u=(cos45,sin45)=(0.707,0.707)，cross(u,g-p)=0.707*1 - 0.707*0 = 0.707 >= 0 ✓
  - 上边界 135°：u=(-0.707,0.707)，cross = -0.707*1 - 0.707*0 = -0.707 <= 0 ✓
  - 两条都满足 → 在扇形内 ✓

- 点 g=(1,0)（正东，0°，在扇形外）。
  - 下边界 45°：cross = 0.707*0 - 0.707*1 = -0.707，不满足 >= 0 → 在扇形外 ✓

## 1.5 `halfplane_intersect(halfplanes)` —— 求半平面交集（交会区域）

```python
def halfplane_intersect(halfplanes, tol=1e-9):
    hs = list(halfplanes)
    # 加上目标区域矩形框的四条边，保证区域有界：
    hs += [((1.0,0.0), ARENA_R), ((-1.0,0.0), ARENA_R),
           ((0.0,1.0), ARENA_R), ((0.0,-1.0), ARENA_R)]
    n = len(hs)
    pts = []
    for i in range(n):
        a1, b1 = hs[i]
        for j in range(i+1, n):
            a2, b2 = hs[j]
            det = a1[0]*a2[1] - a1[1]*a2[0]        # 两条直线方向的行列式
            if abs(det) < 1e-12:                    # 几乎平行 → 无交点，跳过
                continue
            x = (b1*a2[1] - b2*a1[1]) / det         # 解二元一次方程组求交点
            y = (a1[0]*b2 - a2[0]*b1) / det
            if all(a[0]*x + a[1]*y <= c + tol for a, c in hs):  # 交点要满足所有约束
                pts.append((x, y))
    return convex_hull(pts)                          # 把这些交点包成凸多边形
```

**它要解决什么**：给一堆半平面 `a·x <= b`，求它们共同满足的区域（即交集）。这个交集是个凸多边形，多边形的顶点就是"某些边界线两两相交的交点"。

**逐行解释**：

1. `hs += [(1,0,1800), ...]`：加上四条边界 `x<=1800, -x<=1800, y<=1800, -y<=1800`（即 `-1800<=x,y<=1800` 的正方形框）。**为什么加？** 没有它，几个扇形的交集可能是一条无限延伸的带子（无界），就没法求"直径"了。加上框，区域就一定有界。这不是作弊——因为题目本来就说干扰源在半径 1800 内，正方形框只是把"真实场地边界"写成约束。

2. 双重循环 `for i ... for j ...`：枚举**每一对**直线，求它们的交点。

3. `det` 是两条直线方向向量的行列式。`det=0` 表示两条直线平行（永远不相交），跳过。

4. `x = (b1*a2[1] - b2*a1[1]) / det`：这是解二元一次方程组
   ```
   a1.x*x + a1.y*y = b1
   a2.x*x + a2.y*y = b2
   ```
   的克莱默法则公式。交点就是 (x,y)。

5. `if all(...)`：这个交点不一定在所有半平面内。比如两个不相邻的半平面，它们的直线交点在很远的地方，根本不在交集区域里。所以要**检查它是否满足所有约束**，只保留真正落在区域里的交点。

6. 最后 `convex_hull(pts)`：保留下来的交点就是多边形的顶点，但可能是乱序、可能有重复，用凸包把它们排成有序的多边形。

## 1.6 `convex_hull(points)` —— 凸包（单调链算法）

```python
def _dedup(points, tol=1e-6):
    pts = sorted(points)
    out = []
    for p in pts:
        if not out or math.hypot(p[0]-out[-1][0], p[1]-out[-1][1]) > tol:
            out.append(p)
    return out

def convex_hull(points):
    pts = _dedup(points)
    if len(pts) <= 2:
        return pts
    def cross(o, a, b):
        return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])
    lower = []
    for p in pts:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)
    upper = []
    for p in reversed(pts):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)
    return lower[:-1] + upper[:-1]
```

**它要解决什么**：给一堆点，返回包住它们的最小凸多边形的顶点（按顺序排好）。

- `_dedup`：先去重。把点排序，相邻且距离极近（<tol）的视为同一个点，去掉。
- `cross(o,a,b)`：算向量 (a-o) 和 (b-o) 的叉积，判断转向。叉积 <= 0 表示"向右转或直行"（即 b 在 a-o 的顺时针侧）。
- 单调链算法：把所有点按 x 排好，从左到右走一遍得到"下凸壳"，从右到左走一遍得到"上凸壳"，拼起来就是完整凸包。

**这个算法是标准算法，你不需要背细节**，只要知道：**输入一堆点 → 输出按逆时针排好的凸多边形顶点**。

## 1.7 `polygon_centroid(poly)` —— 多边形质心（面积加权）

```python
def polygon_centroid(poly):
    n = len(poly)
    if n == 0: return (0.0, 0.0)
    if n == 1: return poly[0]
    if n == 2: return ((poly[0][0]+poly[1][0])/2, (poly[0][1]+poly[1][1])/2)
    A = 0.0; cx = cy = 0.0
    for i in range(n):
        x0, y0 = poly[i]
        x1, y1 = poly[(i+1) % n]          # 下一个顶点（最后一个接回第一个）
        cr = x0*y1 - x1*y0                # 鞋带公式的一项
        A += cr
        cx += (x0+x1)*cr
        cy += (y0+y1)*cr
    A *= 0.5
    if abs(A) < 1e-12:                     # 面积≈0（退化）时退化成顶点平均
        xs = [p[0] for p in poly]; ys = [p[1] for p in poly]
        return (sum(xs)/n, sum(ys)/n)
    return (cx/(6.0*A), cy/(6.0*A))        # 质心公式
```

**它要解决什么**：求多边形"中心点"，作为干扰源位置的估计值。

- 前面 n=0/1/2 是退化情况（空、一个点、一条线段）的兜底。
- `cr = x0*y1 - x1*y0` 是**鞋带公式**（shoelace formula）的一项，累加 `A += cr` 后 `A/2` 就是多边形面积。
- 质心公式：`cx = Σ(x0+x1)*cr / (6A)`。这是多边形面积加权质心的标准公式（课本公式，直接用）。

**为什么用质心不用别的？** 交会区域是"干扰源可能在哪"的集合，质心是"最中间"的点，作为估计最合理。

## 1.8 `polygon_diameter(poly)` —— 直径 = 最远顶点对

```python
def polygon_diameter(poly):
    best = 0.0
    for i in range(len(poly)):
        for j in range(i+1, len(poly)):
            d = math.hypot(poly[i][0]-poly[j][0], poly[i][1]-poly[j][1])
            if d > best: best = d
    return best
```

双重循环枚举所有顶点对，取距离最大的那一对。这就是论文第 1 问说的"区域直径"（凸多边形的最远两点一定在顶点上）。

## 1.9 `nominal_intersection(bearings)` —— 最小二乘交点（兜底用）

```python
def nominal_intersection(bearings):
    Axx = Axy = Ayy = 0.0
    bx = by = 0.0
    for px, py, b in bearings:
        r = math.radians(b)
        nx, ny = -math.sin(r), math.cos(r)   # 方位线的法向量
        d = nx*px + ny*py
        Axx += nx*nx; Axy += nx*ny; Ayy += ny*ny
        bx += nx*d; by += ny*d
    det = Axx*Ayy - Axy*Axy
    if abs(det) < 1e-12:
        return (sum(p[0] for p in bearings)/len(bearings), sum(p[1] for p in bearings)/len(bearings))
    gx = (Ayy*bx - Axy*by)/det
    gy = (Axx*by - Axy*bx)/det
    return (gx, gy)
```

**它要解决什么**：当扇形交集退化成"没有多边形"（比如只有 1~2 条示向度，或示向度全平行）时，半平面交求不出质心。这时退而求其次：把每条示向度当成一条**精确的直线**（忽略误差），求这些直线的最小二乘交点。

- 一条方位线的方程可以写成法向量形式 `nx*x + ny*y = d`（法向量 (nx,ny)=(-sin,cos) 垂直于方位线）。
- 多条直线不会精确交于一点（因为有误差），就求"最接近所有直线"的那个点，这是最小二乘问题。上面累加的正规方程就是最小二乘解的公式。

**这个函数只在极端退化时用**，正常情况下 `locate` 会走半平面交。

## 1.10 `locate(bearings)` —— 定位总入口

```python
def locate(bearings, error_deg=BEARING_ERROR_DEG):
    hps = []
    for px, py, b in bearings:                    # 每条示向度
        hps += wedge_halfplanes(px, py, b, error_deg)   # 变成两个半平面
    poly = halfplane_intersect(hps)               # 求所有半平面的交集
    if len(poly) >= 3:
        return {'polygon': poly,
                'centroid': polygon_centroid(poly),
                'diameter': polygon_diameter(poly)}
    cent = nominal_intersection(bearings)         # 退化 → 最小二乘兜底
    return {'polygon': poly, 'centroid': cent, 'diameter': 0.0}
```

**输入**：`bearings = [(px1,py1,θ1), (px2,py2,θ2), ...]` —— 同一个干扰源从不同检测点测到的多条示向度。

**流程**：每条示向度 → 两个半平面；全部半平面 → 求交集（多边形）；多边形 → 质心（估计位置）+ 直径（不确定度）。若多边形退化（顶点<3），退回最小二乘交点。

**这就是论文第 1 问的实现。**

## 2.1 `HttpRobot` —— 接真实模拟器

### `__init__` 和 `_new_rid`

```python
class HttpRobot:
    def __init__(self, robot_id, base_url="http://127.0.0.1:2026"):
        self.base_url = base_url          # 模拟器地址
        self.robot_id = robot_id          # 参赛队号
        self._req_seq = 0                 # 请求序号，用于生成唯一 request_id
        self.virtual_time_s = 0.0         # 记录当前虚拟时间

    def _new_rid(self, tag):
        self._req_seq += 1
        return f"{tag}-{self._req_seq}"   # 例如 "measure-5"
```

`request_id` 必须每个动作唯一，这里用"标签+递增序号"自动生成。

### `_post` —— 发一次 HTTP 请求

```python
    def _post(self, path, payload, timeout=5.0):
        body = json.dumps(payload, ensure_ascii=False).encode("utf-8")  # dict → JSON 字符串
        req = Request(self.base_url + path, data=body,
                      headers={"Content-Type": "application/json; charset=utf-8"},
                      method="POST")
        with urlopen(req, timeout=timeout) as resp:
            return json.loads(resp.read().decode("utf-8"))               # JSON → dict
```

- `json.dumps` 把 Python 字典转成 JSON 文本；`json.loads` 反向。
- `urlopen` 是 Python 标准库发 HTTP 请求的函数。

### `_post_retry` —— 带重试的请求（幂等）

```python
    def _post_retry(self, path, payload, max_retries=8):
        last = None
        for _ in range(max_retries):
            try:
                r = self._post(path, payload)
                if r.get("accepted") is True:        # 只有被接受才更新虚拟时间
                    vt = r.get("virtual_time_s", 0)
                    if isinstance(vt, (int, float)):
                        self.virtual_time_s = vt
                return r
            except (URLError, HTTPError, TimeoutError, ConnectionError, OSError) as e:
                last = e
                time.sleep(1.0)                       # 网络失败，等 1 秒重试
        raise last
```

**关键点**：网络失败时**复用同一个 payload（含同一个 request_id）重发**。因为题目规定：重试同一个动作必须复用原 request_id，模拟器才会返回第一次的结果、不会重复执行。这里"重试"用循环自动完成。

`accepted=true` 才更新 `virtual_time_s`，因为 `accepted=false` 时响应里的 `virtual_time_s` 是 0（不代表真实时刻）。

### `_base` —— 构造通用字段

```python
        return {"arena_id": "default", "robot_id": self.robot_id, "request_id": rid}
```

### 四个动作：`enter` / `measure` / `clear` / `exit`

```python
    def enter(self):
        r = self._post_retry("/enter", self._base(self._new_rid("enter")))
        return r if r.get("accepted") is True else None

    def measure(self, x, y, channel):
        p = self._base(self._new_rid("measure"))
        p["position"] = {"x": x, "y": y}
        p["channel"] = channel
        r = self._post_retry("/measure", p)
        if r.get("accepted") is not True:
            return ("no_signal", None)
        res = r.get("measure_result")
        if res == "direction": return ("direction", r.get("svd_deg"))
        if res == "near":      return ("near", None)
        return ("no_signal", None)

    def clear(self, x, y, channel):
        p = self._base(self._new_rid("clear"))
        p["position"] = {"x": x, "y": y}
        p["channel"] = channel
        r = self._post_retry("/clear", p)
        if r.get("accepted") is not True:
            return "no_target_in_range"
        return r.get("clear_result", "no_target_in_range")

    def exit(self):
        r = self._post_retry("/exit", self._base(self._new_rid("exit")))
        return r.get("exit_reason")
```

注意 `measure` 把模拟器返回的三种结果统一成**元组**返回，方便上层判断：

| 模拟器返回 | 统一后 |
|-----------|--------|
| `measure_result="direction", svd_deg=123.45` | `('direction', 123.45)` |
| `measure_result="near"` | `('near', None)` |
| `measure_result="no_signal"` | `('no_signal', None)` |

`clear` 统一成 `'success'` / `'no_target_in_range'` 字符串。

## 2.2 `FakeRobot` —— 离线仿真（照附件2的物理规则）

这是"假的模拟器"，规则完全照题目附件 2 写，这样**不开真机也能调策略**。

### `__init__`

```python
class FakeRobot:
    def __init__(self, jammers, seed=0):
        self.jammers = [dict(j) for j in jammers]   # 干扰源列表，每个是 dict
        self.cleared = set()                        # 已清除的频道集合
        self.rng = random.Random(seed)              # 随机数（控制±1°误差），seed 保证可复现
        self.virtual_time_s = 0.0                   # 虚拟时间
        self.last_pos = (0.0, 0.0)                  # 机器狗当前位置 
        self.cur_channel = 1                        # 测向机当前频道
        self.move_dist = 0.0                        # 累计移动距离（统计用）
        self.n_measure = 0                          # 统计：measure 次数
        self.n_clear = 0                            # 统计：clear 次数
```

### `_advance` —— 推进虚拟时间（移动+动作耗时）

```python
    def _advance(self, x, y, action_s, switch_s=0.0):
        dist = math.hypot(x - self.last_pos[0], y - self.last_pos[1])  # 从上一位置到新位置的直线距离
        self.move_dist += dist
        self.virtual_time_s += dist / 5.0 + switch_s + action_s        # 移动÷5m/s + 换频道 + 动作
        self.last_pos = (x, y)
```

虚拟时间规则（附件2）：移动耗时 = 距离÷速度(5m/s)，加换频道耗时，加动作耗时。

### `measure` —— 模拟一次检测

```python
    def measure(self, x, y, channel):
        self.n_measure += 1
        switch = 1.0 if channel != self.cur_channel else 0.0   # 频道变了才花 1 秒
        self._advance(x, y, 5.0, switch)                       # 移动 + 换频道 + 检测 5s
        self.cur_channel = channel
        j = self._jammer(channel)                              # 找该频道的干扰源
        if j is None:
            return ("no_signal", None)                          # 该频道没有干扰源
        d = math.hypot(x - j['x'], y - j['y'])                  # 到干扰源的距离
        if d <= 5.0 and self._in_coverage(j, x, y):
            return ("near", None)                               # 太近(≤5m) → near
        if d <= j['reception'] and self._in_coverage(j, x, y):
            true_deg = math.degrees(math.atan2(j['y']-y, j['x']-x)) % 360.0  # 真实方向
            err = self.rng.uniform(-1.0, 1.0)                   # ±1° 随机误差
            svd = round((true_deg + err) % 360.0, 2)            # 加误差，保留两位小数
            return ("direction", svd)
        return ("no_signal", None)                              # 超出接收半径
```

逻辑链条（完全对应附件2）：
1. 该频道无干扰源 → `no_signal`；
2. 距离 ≤5m → `near`（太强测不到方向）；
3. 距离 ≤ 接收半径 → `direction`（真实方向 + ±1° 误差，两位小数）；
4. 否则（超出接收半径）→ `no_signal`。

### `clear` —— 模拟清除

```python
    def clear(self, x, y, channel):
        self.n_clear += 1
        self._advance(x, y, 3.0, 0.0)        # 先按"未发现"3 秒计
        j = self._jammer(channel)
        if j is not None and math.hypot(x - j['x'], y - j['y']) <= 20.0:
            self.cleared.add(channel)
            self.virtual_time_s += 2.0        # 成功清除补 2 秒（3+2=5 秒）
            return "success"
        return "no_target_in_range"
```

规则：距离 ≤20m → `success`（总 5 秒）；否则 `no_target_in_range`（3 秒）。

### `_jammer` / `truth`

```python
    def _jammer(self, channel):
        for j in self.jammers:
            if j['channel'] == channel and channel not in self.cleared:  # 未被清除的
                return j
        return None

    def truth(self, channel):
        for j in self.jammers:
            if j['channel'] == channel:
                return (j['x'], j['y'])      # 返回真实位置（只在离线调试时用）
```

`_jammer` 只返回"还存在（未清除）"的干扰源；`truth` 返回真实坐标，离线验证"估计准不准"用，真机上没有这功能。

### `make_default_jammers` —— 生成随机干扰源场景

```python
def make_default_jammers(count=12, seed=1, directional=False):
    rng = random.Random(seed)
    channels = rng.sample(range(1, 21), count)     # 从 20 个频道随机挑 count 个
    jammers = []
    for c in channels:
        r = ARENA_R_IMPORT * math.sqrt(rng.random())   # 均匀分布在圆盘内（sqrt 保证面密度均匀）
        a = rng.uniform(0, 2 * math.pi)
        jammers.append({'channel': c,
                        'x': r * math.cos(a), 'y': r * math.sin(a),
                        'reception': rng.uniform(1000.0, 1500.0),   # 接收半径 1000~1500
                        'directional': directional, ...})
    return jammers
```

- `sample(range(1,21), count)`：随机挑不重复的频道。
- `r = R * sqrt(随机数)`：注意是 `sqrt`，因为要让点在圆盘里**面积均匀**（否则靠近圆心的点会太密）。

## 3.2 `survey_points` 和 `_ring` —— 生成巡测点

```python
def survey_points(mode='full'):
    if mode == 'lean':   # 默认：纯环 10 点 ρ=920（无圆心点）
        return _ring(920.0, 10, 0.0)
    if mode == 'mid':
        return [(0.0, 0.0)] + _ring(900.0, 6, 0.0) + _ring(1700.0, 8, math.pi / 8)
    return [(0.0, 0.0)] + _ring(900.0, 8, 0.0) + _ring(1720.0, 12, math.pi / 12)  # full

def _ring(radius, n, offset):
    return [(radius * math.cos(2 * math.pi * k / n + offset),
             radius * math.sin(2 * math.pi * k / n + offset)) for k in range(n)]
```

`_ring(radius, n, offset)`：在半径 `radius` 的圆上均匀放 `n` 个点。`2*pi*k/n` 是第 k 个点的角度，`offset` 是整体旋转一个角度。这是一个列表推导式（`[f(k) for k in range(n)]` = 循环生成列表的简写）。

返回的是一串坐标 `[(x,y), ...]`，机器狗会依次去这些点测。

**注意 `lean` 是"纯环"——没有圆心点 `(0,0)`。为什么？** 因为圆心距环上每一点只有 ρ=920m < 1000m，**纯环本身就覆盖了圆心**，再单独放一个圆心测点纯属多余；而"圆心→环"这段路（~1km）是白走的。去掉圆心、把环收紧到 10 个点，巡测路径最短。这就是"纯环 10@920"——覆盖半径 967.7m（边缘最坏），对 1000m 的接收下限留 32m 余量。

> 对比：之前用的是"圆心 + 7@1100"（8 个点、覆盖 939m），纯环 10@920 路径更短、还快约 4~5%。

## 3.3 `homing` —— 归航（沿方位逼近干扰源）

```python
def homing(robot, channel, x, y, bearing, max_walk=120.0):
    b = bearing
    step = 10.0
    walked = 0.0
    for _ in range(30):
        if robot.clear(x, y, channel) == 'success':      # 先试试当前位置能不能直接清
            return True
        u = (math.cos(math.radians(b)), math.sin(math.radians(b)))  # 方位方向的单位向量
        x, y = x + step * u[0], y + step * u[1]          # 沿方位前进 10m
        walked += step
        r = robot.measure(x, y, channel)                  # 走到新位置再测一次
        if r[0] == 'near':
            return robot.clear(x, y, channel) == 'success'  # 已经到 5m 内，清
        if r[0] == 'direction':
            b = r[1]                                       # 用新方位更新方向
        else:
            break                                          # 失联，放弃
        if walked > max_walk:
            break
    return False
```

**逻辑**：从估计点出发，沿"指向干扰源的方位"每 10m 走一步；每步先 `clear` 一次（万一已经进入 20m 清除圈），再 `measure` 更新方位。

**为什么 10m 一步、为什么能几步就中**：因为已经离得很近（估计误差一般 <30m），而近距离方位 ±1° 的横截误差只有 `10m * tan1° ≈ 0.17m`，所以沿着方位走**几乎不会跑偏**，几步内就会进入干扰源的 20m 清除圈。

## 3.4 `line_homing` + `_back_home` —— 只有一条示向度时的归航

```python
def line_homing(robot, channel, x, y, bearing, max_dist=1500.0):
    b = bearing
    step = 120.0
    walked = 0.0
    while walked < max_dist:
        u = (math.cos(math.radians(b)), math.sin(math.radians(b)))
        nx, ny = x + step * u[0], y + step * u[1]          # 大步走 120m
        r = robot.measure(nx, ny, channel)
        if r[0] == 'near':
            return robot.clear(nx, ny, channel) == 'success'
        if r[0] == 'direction':
            nb = r[1]
            if abs(angle_diff(nb, b)) > 90.0:               # 方位翻转 >90° = 越过了！
                return _back_home(robot, channel, nx, ny, nb, step)   # 往回小步搜
            x, y = nx, ny
            b = nb
            walked += step
        else:
            break
    return False
```

**背景**：这种情形是"某个干扰源只有一个测点够得着"，所以我们**只有一条示向度，知道方向、不知道距离**。但题目保证接收半径 ≤1500m，所以干扰源在沿这条方位的 **0~1500m** 之间的某处。

**策略**：用 **120m 大步**沿方位走，边走边测。关键是看**方位有没有翻转**：

- 没越过干扰源时，测到的方位一直指向干扰源（方向基本不变）；
- **一旦走过头（越过干扰源），方位会瞬间翻转约 180°**——这是"已经过了"的信号。

检测到翻转（`angle_diff > 90°`），就知道干扰源在刚走的这 120m 区间内，然后调 `_back_home` 往回小步找。

```python
def _back_home(robot, channel, x, y, bearing, span):
    b = bearing
    s = 12.0
    for _ in range(int(span / s) + 3):
        if robot.clear(x, y, channel) == 'success':        # 每 12m 清一次
            return True
        u = (math.cos(math.radians(b)), math.sin(math.radians(b)))
        x, y = x + s * u[0], y + s * u[1]
        r = robot.measure(x, y, channel)
        if r[0] == 'near':
            return robot.clear(x, y, channel) == 'success'
        if r[0] == 'direction':
            b = r[1]
        else:
            break
    return False
```

往回用 **12m 小步**，每步 `clear`（20m 清除圈，12m 步长保证不漏），直到命中。

## 3.5 `spiral_clear` —— 螺旋兜底

```python
def spiral_clear(robot, channel, cx, cy, max_radius):
    if robot.clear(cx, cy, channel) == 'success':
        return True
    r = CLEAR_SPACING                      # 从 12m 半径开始
    while r <= max_radius:
        n = max(8, int(2 * math.pi * r / CLEAR_SPACING))   # 这圈放多少个点
        for k in range(n):
            a = 2 * math.pi * k / n
            if robot.clear(cx + r * math.cos(a), cy + r * math.sin(a), channel) == 'success':
                return True
        r += CLEAR_SPACING                 # 半径每次 +12m
    return False
```

**逻辑**：以 (cx,cy) 为中心，一圈一圈往外扩，每圈在圆周上均匀撒点逐个 `clear`。相邻点间距约 12m，保证干扰源一旦落在搜索半径内，必有点在它 20m 内。

这是"实在没辙了"的最后兜底——正常流程几乎走不到这里。

## 3.6 `clear_channel` —— 清除一个干扰源（决策中枢）

```python
def clear_channel(robot, channel, estimate):
    if isinstance(estimate, dict):        # estimate 可能是 dict（有质心+直径）
        cx, cy = estimate['centroid']
        diam = estimate['diameter']
    else:                                 # 也可能是 near 直接给的坐标
        cx, cy = estimate
        diam = 40.0

    res = robot.measure(cx, cy, channel)  # ① 走到估计点复测
    if res[0] == 'near':
        return robot.clear(cx, cy, channel) == 'success'
    if res[0] != 'direction':
        return spiral_clear(robot, channel, cx, cy, max(40.0, diam * 0.7 + 30.0))

    b = res[1]
    if diam > LATERAL_DIAM:              # ② 直径>150m=真共线退化，做侧向精修
        perp = (-math.sin(math.radians(b)), math.cos(math.radians(b)))  # 垂直方向
        lat = min(250.0, max(100.0, diam * 0.5))                        # 侧移距离
        for side in (1.0, -1.0):          # 左右两侧都试
            px = cx + side * lat * perp[0]
            py = cy + side * lat * perp[1]
            r2 = robot.measure(px, py, channel)     # 侧向测一次
            if r2[0] == 'near':
                return robot.clear(px, py, channel) == 'success'
            if r2[0] == 'direction':
                est2 = locate([(cx, cy, b), (px, py, r2[1])])   # 两条近正交方位重新定位
                ex, ey = est2['centroid']
                if homing(robot, channel, ex, ey, r2[1], max_walk=60.0):
                    return True

    if homing(robot, channel, cx, cy, b):   # ③ 正常归航
        return True
    return spiral_clear(robot, channel, cx, cy, max(40.0, diam * 0.7 + 30.0))  # ④ 兜底
```

**决策流程**（这是整个清除的核心）：

1. **走到估计点复测**：拿到一条近距离的精确方位。若 `near`（已经在 5m 内）直接清。
2. **判断是否退化**：如果交会区域直径 `diam > LATERAL_DIAM`（=150m，真共线退化），说明之前的示向度几乎共线、质心可能偏离超过归航上限 120m，距离不可靠。这时**垂直方向侧移一段**再测一条，两条近正交方位交叉就能精确定位（这就是第 2 问"二次观测改善几何"的落地）。轻度拉长（60~150m）光靠归航就能走，不横移。
3. **正常归航**：直径不大时，直接沿方位 `homing`。
4. **兜底**：都失败就螺旋。

## 3.7 `order_estimates` —— 清除顺序（最近邻 + 2-opt）

```python
def order_estimates(estimates, start):
    items = [(c, _pos_of(estimates[c])) for c in estimates]   # (频道, 估计位置) 列表
    if not items:
        return []
    order = []
    cur = start
    rem = items[:]
    while rem:                                            # 最近邻：每次去离当前位置最近的那个
        i = min(range(len(rem)), key=lambda k: _dist(cur, rem[k][1]))
        order.append(rem[i])
        cur = rem[i][1]
        rem.pop(i)
    # 2-opt：路径 = start -> order[0] -> ... -> order[-1]
    pts = [('S', start)] + [(c, p) for c, p in order]
    n = len(pts)
    improved = True
    while improved:
        improved = False
        for i in range(1, n - 2):
            for j in range(i + 1, n - 1):
                d_old = _dist(pts[i][1], pts[i+1][1]) + _dist(pts[j][1], pts[j+1][1])
                d_new = _dist(pts[i][1], pts[j][1])   + _dist(pts[i+1][1], pts[j+1][1])
                if d_new < d_old - 1e-9:               # 反转这段更短就反转
                    pts[i+1:j+1] = list(reversed(pts[i+1:j+1]))
                    improved = True
    return [c for c, _ in pts[1:]]
```

**它要解决什么**：清除多个干扰源要"挨个跑过去"，顺序不同，总路程不同。这是**旅行商问题**。

- `min(range(len(rem)), key=lambda k: ...)`：在剩余点里找"离当前位置最近"的那个。`lambda` 是匿名函数，`key=` 指定"按什么比大小"。
- **2-opt**：贪心最近邻得到的顺序不一定最好。2-opt 反复检查"把其中一段**反过来走**会不会更短"，会就反转。这是 TSP 的经典局部优化。

## 3.8 `run` —— 主流程

```python
def run(robot, channels=CHANNELS, survey='full', verbose=True):
    if robot.enter() is None:
        print('进入失败')
        return {'cleared': 0, 'ok': False}

    # ---- ① 巡测 ----
    measurements = {c: [] for c in channels}   # 频道 → [(测点, 示向度), ...]
    near = {}                                   # 频道 → 直接 near 到的坐标
    found = set()                               # 已发现过信号的频道
    last_pos = (0.0, 0.0)
    for sx, sy in survey_points(survey):        # 遍历每个巡测点
        last_pos = (sx, sy)
        for c in channels:                      # 遍历每个频道
            if c in near:
                continue
            if len(found) >= MAX_JAMMERS and c not in found:   # 找满16个，剩下的空频道跳过
                continue
            if len(measurements[c]) >= MAX_BEARINGS:           # 攒够3条跳过
                continue
            res = robot.measure(sx, sy, c)
            if res[0] == 'direction':
                measurements[c].append((sx, sy, res[1]))
                found.add(c)
            elif res[0] == 'near':
                near[c] = (sx, sy)
                found.add(c)

    # ---- ② 定位 ----
    estimates = {}
    for c in channels:
        if c in near:                            # near 到的，位置几乎已知
            estimates[c] = near[c]
        elif len(measurements[c]) >= 2:          # ≥2 条示向度 → 半平面交定位
            estimates[c] = locate(measurements[c])
        # 1 条示向度的先跳过，最后单独处理；0 条的是空频道

    # ---- ③ 清除 ----
    cleared = []
    for c in order_estimates(estimates, last_pos):   # 按优化好的顺序
        ok = clear_channel(robot, c, estimates[c])
        if ok:
            cleared.append(c)

    # ---- ④ 单测点兜底 ----
    for c in channels:
        if c not in estimates and len(measurements[c]) == 1:
            x, y, b = measurements[c][0]
            if line_homing(robot, c, x, y, b):
                cleared.append(c)

    robot.exit()
    return {'cleared': len(cleared), 'ok': True}
```

这就是整个策略的骨架，四步：**巡测 → 定位 → 清除 → 兜底**。

```python
        robot = FakeRobot(jammers, seed=args.seed + 100)    # 离线仿真
        r = run(robot, survey=args.survey)
        print(f'干扰源总数 {len(jammers)}，清除 {r["cleared"]}')
        print(f'虚拟用时 {robot.virtual_time_s:.0f}s，移动 {robot.move_dist/1000:.1f}km')
```

`argparse` 解析命令行参数。`--real` 决定用真机 `HttpRobot` 还是离线 `FakeRobot`。

# 第 4 部分：完整走一遍（具体例子）

假设有 12 个干扰源，我们看**5 号频道**从发现到清除的全过程：

1. **巡测**：机器狗依次去纯环上的 10 个测点（半径 920m）。在第一个点 (920,0) 测 5 号频道 → `direction 30.5°`，记入 `measurements[5] = [(920,0,30.5)]`。在下一个环点测 → `direction 78.2°`，变两条。再下一个 → 攒够 3 条，**后面跳过不测 5 号了**。

2. **定位**：`locate([(920,0,30.5),(...), (...)])` 把 3 条示向度变成 6 个半平面，求交集 → 一个小多边形。返回 `centroid=(480,300)`、`diameter=12.5m`。

3. **清除**：`clear_channel(robot, 5, 那个estimate)`：
   - `measure(480,300,5)` → `direction 31.0°`（很近了）；
   - `diam=12.5 < 60`，不退化，直接 `homing`；
   - `homing` 第一步 `clear(480,300,5)` → 干扰源真值 (495,308)，距离 `sqrt(15²+8²)=17m ≤20m` → **`success`，命中！**

4. 换下一个频道，直到全清，最后 `exit`。
