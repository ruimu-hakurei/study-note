## 报错不要靠猜

| 现象 | 首先检查 | 不建议的反应 |
|---|---|---|
| `command not found` | 拼写、`command -v`、PATH、是否安装 | 直接到处复制二进制 |
| `Permission denied` | 用户身份、文件与父目录权限、挂载选项 | 一律 sudo 或 chmod 777 |
| `No such file or directory` | `pwd`、路径、大小写、符号链接目标 | 立即创建一个同名空文件 |
| 脚本有 `^M`、`bad interpreter` | Windows CRLF 换行、shebang、解释器是否存在 | 随意更改系统解释器链接 |
| `No space left on device` | `df -h`、`df -i`、具体挂载点 | 递归删除系统目录 |
| 程序退出后端口仍占用 | PID、子进程、服务自动重启策略 | 反复 kill -9 不查原因 |
| 程序崩溃 | stderr、日志、GDB、内存检测器 | 仅增加 sleep 掩盖问题 |

## 常用命令速查

| 要做什么 | 优先想到 |
|---|---|
| 看当前位置 | `pwd` |
| 看文件 | `ls -lah`、`file`、`stat` |
| 看长日志 | `less`、`tail -F` |
| 搜内容 | `grep`、`rg` |
| 搜路径 | `find`、`rg --files` |
| 看权限与身份 | `ls -l`、`ls -ld`、`id` |
| 看进程 | `ps`、`top`、`pgrep` |
| 看服务与日志 | `systemctl status`、`journalctl` |
| 看磁盘 | `df -h`、`df -i`、`du -sh` |
| 看网络 | `ip`、`ss`、`curl` |
| 查帮助 | `man`、`--help`、Bash 的 `help` |
| 检查脚本语法 | `bash -n` |
| 编译调试 C | `gcc`、`make`、`gdb` |

## 执行修改命令前的检查

- [ ] 当前是在本机还是 SSH 远端？
- [ ] 当前用户和工作目录是什么？
- [ ] 是否涉及递归、通配符、符号链接或挂载点？
- [ ] 是否会覆盖、删除、改权限或中断正在运行的服务？
- [ ] 能否先用只读查询、预览或 `--dry-run`？
- [ ] 是否有备份，以及实际可用的恢复办法？
