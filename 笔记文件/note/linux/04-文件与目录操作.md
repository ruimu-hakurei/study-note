## 在专用目录里练习

```bash
mkdir -p ~/linux-lab
cd ~/linux-lab
mkdir -p src logs backup
touch notes.txt                 # 不存在则创建；已存在则更新时间戳
cp -i notes.txt backup/         # 覆盖前询问
mv -i notes.txt study.txt       # 移动或重命名，覆盖前询问
```

```bash
cp -a src backup/              # 保留常见属性地复制目录
file study.txt                 # 判断文件类型
stat study.txt                 # 查看更完整的元数据
```

## 删除不是放入回收站

```bash
rm -i -- ./study.txt           # 删除前询问；-- 表示选项到此结束
rmdir ./empty-dir             # 仅删除空目录，不存在或非空会报错
```

> [!danger] 高风险操作
> `rm -r` 会递归删除，`-f` 会省去许多确认。命令行删除通常没有回收站。不要对 `/`、家目录、挂载盘根目录或未检查的变量使用递归删除，也不要把 `sudo` 当作报错后的默认解决办法。

## 链接：名字如何指向文件

```bash
ln -s ./src source-link        # 符号链接：保存另一个路径
ln ./data.txt ./data-hardlink  # 硬链接：给已有文件增加一个名字
```

符号链接可跨文件系统，目标消失后会变成悬空链接。普通文件硬链接通常不能跨文件系统；两个名字关联同一个 inode，不是复制两份数据。

```text
符号链接名 → 目标路径 → 文件
硬链接名 A ─┐
硬链接名 B ─┴→ 同一个 inode / 数据
```

删除一个硬链接名不必然删除数据：若仍有其他硬链接或打开的文件描述符引用，数据可能继续存在。
