先看 `/etc/os-release`，再选适合当前发行版的命令。软件包名可能不同。

| 需求 | Ubuntu / Debian 常见命令 | Fedora 常见命令 |
|---|---|---|
| 搜索 | `apt search gcc` | `dnf search gcc` |
| 查看详情 | `apt show gcc` | `dnf info gcc` |
| 安装 | `sudo apt install gcc` | `sudo dnf install gcc` |
| 移除 | `sudo apt remove 包名` | `sudo dnf remove 包名` |

```bash
# Debian / Ubuntu：刷新可用包索引，不是升级全部软件
sudo apt update

# 按需要安装 C 开发工具，会更改系统软件包
sudo apt install build-essential gdb
```

`update` 刷新索引，`upgrade` 升级已安装软件，`install` 安装指定包，不能混淆。执行移除、自动清理或大范围升级前应检查软件包列表，尤其是在开发板和服务器上。

> [!warning] 软件来源
> 优先使用可信发行版仓库或项目官方渠道。不要看到安装失败就添加来源不明的仓库，也不要不检查内容就执行网络下载脚本。
