## 按文件大小选择查看方式

```bash
cat ./small.txt                # 一次显示短文件
less ./large.log               # 分页查看大文件
head -n 20 ./app.log            # 前 20 行
tail -n 50 ./app.log            # 后 50 行
tail -F ./app.log               # 持续跟踪，适合会轮转的日志
wc -l ./app.log                 # 统计换行数
```

二进制文件不要直接用 `cat` 输出到终端。可以先运行 `file`，再用 `od` 或 `xxd` 等工具查看字节。

## 内容搜索与路径搜索不是一回事

```bash
grep -n 'ERROR' ./app.log        # 在内容里查找，显示行号
grep -ni 'timeout' ./app.log     # 忽略大小写
grep -nF 'a.b[0]' ./main.c       # -F：按普通字符串，不按正则表达式
grep -RIn --include='*.c' 'malloc' ./src
```

如果安装了 ripgrep，可使用：

```bash
rg -n 'malloc' ./src
rg --files ./src                # 列出文件路径
```

`rg` 默认通常跳过隐藏文件和被忽略的文件；要搜索完整范围时，先理解 `.gitignore`、`--hidden`、`--no-ignore` 的影响。

```bash
find ./src -type f -name '*.c'   # 根据文件名搜索；引号避免 Shell 提前展开 *
find ./logs -type f -size +10M   # 查找较大文件，只列出，不删除
```

## 通配符与正则表达式

```text
Shell 通配符 *.c：匹配文件名，由 Shell 处理
grep 正则 ERROR.*timeout：匹配文本内容，由 grep 处理
```

不要把 `grep '*.c'` 当成搜索 C 文件的通用写法。

## 简单编辑

```bash
nano ./notes.txt
```

Nano 常用 `Ctrl+O` 保存、`Ctrl+X` 退出。若使用 Vim：`i` 进入插入模式，Esc 返回普通模式，`:wq` 保存退出，`:q!` 放弃未保存修改。修改系统配置前应备份并确认格式。
