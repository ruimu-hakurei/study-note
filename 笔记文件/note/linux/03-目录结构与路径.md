## Linux 从根目录开始

```text
/
├─ home/       普通用户目录
├─ root/       root 用户的家目录
├─ etc/        系统配置
├─ usr/        大量程序、库和共享资源
├─ var/        经常变化的数据，如日志、缓存
├─ tmp/        临时文件
├─ dev/        设备节点
├─ proc/       进程和内核信息的虚拟文件系统
├─ sys/        设备与内核对象的虚拟接口
├─ run/        本次启动期间的运行数据
├─ boot/       启动相关文件
└─ mnt/        常用临时挂载点
```

现代发行版中 `/bin`、`/sbin`、`/lib` 等可能是指向 `/usr` 下对应目录的符号链接，不必因为布局不同就认为系统异常。

## 路径的含义

| 写法 | 含义 |
|---|---|
| `/home/student/project` | 绝对路径，从 `/` 开始 |
| `src/main.c` | 相对路径，从当前工作目录开始 |
| `.` | 当前目录 |
| `..` | 上一级目录 |
| `~` | Shell 展开的当前用户家目录 |

```bash
pwd                        # 我在哪里
cd /etc                    # 进入绝对路径
cd ..                      # 返回上级
cd                         # 回到家目录
cd -                       # 回到上一次目录
ls -lah                    # 包含隐藏文件的详细列表
```

以 `.` 开头的名字通常被视作隐藏文件，如 `.bashrc`。Linux 常见文件系统区分大小写，`main.c` 与 `Main.c` 可以是两个文件。

> [!tip] 三个问题
> 执行命令前先确认：**当前目录是什么、操作对象是什么、会不会覆盖已有内容。**
