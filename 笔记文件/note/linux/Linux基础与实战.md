# Linux 学习目录

> [!abstract] 使用方法
> 本套笔记已经拆成 **21 篇独立主题笔记 + 1 篇总目录**。点击下面的主题进入；每篇开头和结尾都能返回目录或跳到上一篇、下一篇。首次学习按编号顺序阅读，查问题时按主题进入即可。

> [!note] 阅读约定
> 命令默认在 **Linux 的 Bash 终端**中执行，不是 Windows PowerShell。以常见 GNU/Linux 环境为主；嵌入式 BusyBox、容器和不同发行版可能缺少某些工具或选项。示例中的用户名、路径、服务名需要按实际环境替换。

> [!warning] 实验范围
> 初学时用普通用户，在自己创建的练习目录中操作。涉及 `sudo`、删除、磁盘分区、服务重启的命令会修改系统，不能整页盲目复制执行。本篇中的安装、提权、磁盘与服务管理命令均未在你的电脑上执行。

## 参考资料

命令选项以本机 `man` 和 `--help` 为准；以下用于继续查证，而不是要求第一次全部读完：

- [GNU Bash 官方手册](https://www.gnu.org/s/bash/manual/bash.html)：引号、参数、脚本、管道与退出状态。
- [GNU Coreutils 官方手册](https://www.gnu.org/software/coreutils/manual/coreutils.html)：常见文件、文本与权限工具。
- [systemctl 官方手册源文件](https://github.com/systemd/systemd/blob/main/man/systemctl.xml)：服务状态与管理语义。
- [journalctl 官方手册](https://www.freedesktop.org/software/systemd/man/255/journalctl.html)：日志筛选与查看；该链接是指定版本，应结合本机手册。
