## 归档和压缩不同

`tar` 把多个文件打包；gzip 等算法压缩数据。`.tar.gz` 通常表示先打包再 gzip 压缩。

```bash
# 在 ~/linux-lab 内练习，backup 与 src 是两个不同目录
tar -czf backup/src.tar.gz src        # c 创建、z gzip、f 指定归档文件
tar -tzf backup/src.tar.gz            # 先查看包内路径
mkdir -p restored
tar -xzf backup/src.tar.gz -C restored # x 解包到单独目录
```

解压不可信归档前应查看路径，并使用普通用户、独立空目录，不要把系统根目录作为解压目标。提取同名文件可能覆盖原文件。

## rsync 增量同步

```bash
rsync -av --dry-run ./src/ ./backup/src/  # 先预览，不修改目标
rsync -av ./src/ ./backup/src/            # 确认后同步，可能更新同名文件
```

源路径结尾的 `/` 通常表示复制目录内容，不带 `/` 可能把目录本身作为一层复制。执行前先用 `--dry-run` 检查实际结果。

> [!warning] 同步不等于备份
> 同步可把误修改传播到目标。`--delete` 还会删除目标中源端没有的文件，不适合作为初学默认选项。真正备份应考虑版本、独立存储和恢复测试。
