## 命令结构

```text
命令名 [选项] [操作对象]
ls     -lh    /etc
```

`ls` 列出文件；`-l` 使用长格式；`-h` 以易读单位显示大小；`/etc` 是目标目录。

手册里的 `[参数]` 表示可选，`<文件名>` 常表示占位符，通常不要把尖括号原样输入 Shell，因为 `<`、`>` 有重定向含义。

## 必会快捷键

| 按键 | 作用 |
|---|---|
| Tab | 补全命令或路径 |
| ↑ / ↓ | 浏览历史命令 |
| Ctrl+C | 通常向前台进程组发送 SIGINT，请求中断 |
| Ctrl+D | 空输入时向程序表示 EOF，Shell 中常用于退出 |
| Ctrl+L | 清理终端显示，不删除文件 |
| Ctrl+R | Bash 中搜索历史命令 |
| Ctrl+Z | 通常暂停前台作业，不是终止 |

## 不记得命令时怎样查

```bash
ls --help
man ls
man 2 read              # 第 2 类手册：系统调用
man 3 printf            # 第 3 类手册：库函数
help cd                 # Bash 内建命令的帮助
type cd                 # 看命令是内建、别名还是外部程序
command -v gcc          # 查找当前 PATH 中的 gcc
```

`man` 和 `less` 中常用：`/关键字` 搜索，`n` 下一个，`q` 退出。

## 成功、失败与退出码

```bash
test -f ./notes.txt
printf '上条命令退出码：%s\n' "$?"
```

退出码 `0` 通常代表成功，非零代表失败或其他状态，具体看命令文档。例如 `grep` 的 `1` 表示没有匹配，不一定是运行故障。

```bash
gcc main.c -o app && ./app        # 编译成功才运行
test -f settings.ini || printf '配置文件不存在\n'
```
