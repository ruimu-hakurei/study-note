## 程序不等于进程

程序是磁盘上的代码文件；进程是它运行时的实例，拥有 PID、虚拟地址空间、文件描述符和权限身份。线程是进程内的执行流，多个线程共享进程资源，需要同步保护共享数据。

```bash
ps aux                        # 当前进程快照
ps -p 1234 -o pid,ppid,stat,%cpu,%mem,cmd
pgrep -af 'my_app'             # 查找候选进程，执行 kill 前再次核对
top                           # 动态观察 CPU/内存
```

常见进程状态：`R` 可运行/运行、`S` 可中断睡眠、`D` 不可中断等待、`T` 停止、`Z` 僵尸。僵尸进程已经结束，通常需由父进程收取退出状态；重复 kill 它没有意义。

## 结束进程应先温和再强制

```bash
kill -TERM 1234                # 1234 是示意，必须换成已核对的 PID
```

SIGTERM 给程序清理资源的机会；SIGKILL 无法捕获和清理，可能丢失未保存数据。不要习惯性使用 `kill -9`，也不要用宽泛的进程名批量结束无关程序。

## 前台、后台、暂停

```bash
./my_app &                    # 后台运行，但不等于持久服务
jobs -l                       # 当前 Shell 的作业列表
fg %1                         # 把作业 1 带回前台
bg %1                         # 让暂停的作业 1 在后台继续
```

`Ctrl+Z` 是暂停，不是“放后台继续跑”；需要 `bg` 恢复。想保留交互会话可学习 tmux；需要长期可靠运行的服务应交给服务管理器，而非仅加一个 `&`。
