## 内核、发行版、Shell 和终端

| 名称 | 是什么 | 可以怎样理解 |
|---|---|---|
| Linux 内核 | 管理 CPU、内存、设备、进程和系统调用 | 系统资源管理者 |
| 发行版 | 内核加工具、软件包管理器和系统配置 | 完整可使用的操作系统，如 Debian、Ubuntu、Fedora |
| Shell | 解释命令并启动程序，如 Bash | 你与程序之间的命令解释器 |
| 终端 | 接收键盘输入、显示字符输出的界面 | Shell 所在的交互窗口 |

```text
你输入命令
    ↓
终端 → Bash 解析参数、引号、管道与重定向
    ↓
运行程序，例如 ls、gcc、python3
    ↓ 系统调用
Linux 内核 → CPU / 内存 / 文件系统 / 网络 / 设备
```

## 与 STM32、FreeRTOS 的联系

FreeRTOS 通常让多个任务在同一地址空间内运行。Linux 的普通进程通常拥有各自的虚拟地址空间，内核负责权限隔离和资源管理；同一进程内的线程共享地址空间等资源，但各有执行现场和栈。

```text
FreeRTOS：任务 → 调度 → MCU 外设
Linux：进程/线程 → 系统调用 → 内核驱动 → 外设
```

用户程序一般通过文件、设备接口、库和系统调用访问硬件，而不是任意读写物理地址。

## 先认识当前环境

```bash
uname -r                # 查看内核版本，不等于发行版版本
uname -m                # 查看体系结构，例如 x86_64、aarch64
cat /etc/os-release     # 查看发行版信息
whoami                  # 当前用户名
id                      # UID、GID 和所属用户组
```
