## 磁盘空间与目录大小

```bash
df -h                          # 各文件系统容量和剩余空间
df -i                          # inode 使用量，大量小文件也可能耗尽 inode
du -sh ./project               # 目录及内容实际占用空间
du -h --max-depth=1 ./project   # GNU du：找出哪个子目录较大
lsblk -f                       # 块设备、文件系统和挂载信息
findmnt                        # 查看挂载关系
```

`df` 看整个文件系统，`du` 统计可遍历目录。两者不一致可能因为已删除但仍被进程打开的文件、保留空间、权限或挂载边界等，不要直接认定统计出错。

## 挂载是什么意思

Linux 把另一个文件系统接到目录树中的某个目录，而不是必须分配一个 Windows 风格盘符：

```text
设备上的文件系统 → 挂载到 /mnt/data → 通过这个路径访问文件
```

挂载到非空目录会暂时遮住原有内容，不会自动搬走或合并。卸载前应停止使用该文件系统的程序。

> [!danger] 磁盘命令不要试着猜
> `mkfs`、`dd`、分区操作和部分修复命令可能不可逆地覆盖数据。先用 `lsblk -f`、`findmnt` 确认设备、分区、挂载点与备份；本篇不提供可以盲目执行的格式化命令。

## 内存：不要只看 free 一列

```bash
free -h
cat /proc/meminfo
```

Linux 会利用空闲 RAM 缓存文件，提高 I/O 性能。`free` 较小不必然说明内存不足，通常还应关注 `available`、交换空间使用、实际延迟和内核日志。

```text
进程虚拟地址空间
├─ 程序代码、共享库、映射区
├─ 堆：动态分配对象等
└─ 各线程栈
        ↓ 页表映射
物理内存 / 按需分配 / 共享页面 / 可能的交换空间
```

`malloc(1024)` 返回用户空间地址，不等于拿到物理地址。虚拟内存大小也不等于进程此刻实际驻留的物理内存大小。调试 C 指针时要区分地址空间、对象生命周期和真实越界，而不是凭指针数值猜 RAM 位置。
