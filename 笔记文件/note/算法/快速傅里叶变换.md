# 快速傅里叶变换（FFT）

> 对离散傅里叶变换（DFT）的代数解剖——将 $O(N^2)$ 暴力劈碎成 $O(N \log N)$。
> 这是 1965 年 Cooley-Tukey 基-2 时间抽取快速傅里叶变换（Radix-2 DIT FFT）的完整推导与实现。

---

## 一、锁定原罪：庞大的算力黑洞

从最原始的离散傅里叶变换（DFT）公式开始。假设有 $N$ 个时域数据点 $x[n]$，要算出 $N$ 个频域数据点 $X[k]$：

$$X[k] = \sum_{n=0}^{N-1} x[n] e^{-j\frac{2\pi}{N} k n}$$

为了书写方便，定义核心代数符号——**旋转因子（Twiddle Factor）**：

$$W_N = e^{-j\frac{2\pi}{N}}$$

原始公式简写为：

$$X[k] = \sum_{n=0}^{N-1} x[n] W_N^{kn}$$

> **算力灾难**：算出一个 $X[k]$ 需 $N$ 次复数乘法；算出全部 $N$ 个 $X[k]$ 需 $N \times N = N^2$ 次。若 $N = 1024$，超过 100 万次复数乘法。

---

## 二、大自然的后门：旋转因子的特权

旋转因子 $W_N$ 在复平面上有两个极其关键的几何性质，这是后续降维的绝对武器：

### 2.1 可约性（折叠降维）

$$W_N^{2} = \left( e^{-j\frac{2\pi}{N}} \right)^2 = e^{-j\frac{2\pi}{N/2}} = W_{N/2}$$

**物理意义**：步长放大一倍，等价于把总点数 $N$ 砍掉一半。

### 2.2 对称性（反向翻转）

$$W_N^{k + N/2} = W_N^k \cdot W_N^{N/2} = W_N^k \cdot e^{-j\pi} = -W_N^k$$

**物理意义**：在圆上多转半圈（$180^\circ$），等价于乘以负一（反向）。

---

## 三、大劈裂：时间抽取法（DIT）

FFT 的核心思想是**分而治之**。既然 $N$ 个点一起算太慢，且 $N$ 是 2 的整数次幂，就把时域数组 $x[n]$ 按照索引 $n$ 的**奇数**和**偶数**劈成两半：

- **偶数索引**：$n = 2r$
- **奇数索引**：$n = 2r + 1$

其中，新的扫描指针 $r$ 从 $0$ 遍历到 $N/2 - 1$。

把奇偶两派代回原始公式：

$$X[k] = \sum_{r=0}^{N/2-1} x[2r] W_N^{k(2r)} + \sum_{r=0}^{N/2-1} x[2r+1] W_N^{k(2r+1)}$$

---

## 四、代数提取与降维坍缩

盯住后面的**奇数项**，把多出来的 $W_N^k$ 强行提取到求和符号外面：

$$X[k] = \sum_{r=0}^{N/2-1} x[2r] W_N^{2kr} + W_N^k \sum_{r=0}^{N/2-1} x[2r+1] W_N^{2kr}$$

现在，召唤**可约性武器** $W_N^2 = W_{N/2}$，将所有的 $W_N^{2kr}$ 直接降维替换：

$$X[k] = \sum_{r=0}^{N/2-1} x[2r] W_{N/2}^{kr} + W_N^k \sum_{r=0}^{N/2-1} x[2r+1] W_{N/2}^{kr}$$

**神迹在这里降临：** 仔细看那两个求和号里的东西——

- 前半部分，刚好是一个长度为 $N/2$ 的偶数序列的 DFT，定义为 $G[k]$
- 后半部分，刚好是一个长度为 $N/2$ 的奇数序列的 DFT，定义为 $H[k]$

整个庞大的 $N$ 点 DFT，被完美等价于两个 $N/2$ 点 DFT 的线性组合：

$$X[k] = G[k] + W_N^k H[k]$$

> 注意：因为 $G[k]$ 和 $H[k]$ 的长度只有 $N/2$，所以此公式目前只能算出前一半的频谱，即 $k$ 从 $0$ 到 $N/2 - 1$。

---

## 五、蝶形运算：一箭双雕的绝杀

前半段的频谱算出来了，那后半段频谱（第 $k + N/2$ 个点）怎么办？难道要重新暴力算一遍吗？

把 $k + N/2$ 代入刚才的公式：

$$X[k + N/2] = G[k + N/2] + W_N^{k + N/2} H[k + N/2]$$

大自然给出了极其慷慨的馈赠：

1. $G$ 和 $H$ 本身就是 $N/2$ 点的 DFT，具有周期性，所以 $G[k + N/2] = G[k]$，$H[k + N/2] = H[k]$
2. 召唤**对称性武器**：$W_N^{k + N/2} = -W_N^k$

代入后瞬间坍缩：

$$X[k + N/2] = G[k] - W_N^k H[k]$$

---

## 六、终极数学闭环：蝶形公式组

把第四步和第五步的结果放在一起，得到数字信号处理史上最伟大的公式组——**蝶形运算（Butterfly Operation）**：

$$
\boxed{
\begin{aligned}
X[k]       &= G[k] + W_N^k H[k] \\[4pt]
X[k + N/2] &= G[k] - W_N^k H[k]
\end{aligned}
}
$$

### 这意味着什么？

只要算出前半段的 $G[k]$ 和 $H[k]$，做一次乘法 $W_N^k H[k]$，就可以**同时得到**频域上的两个点：

- 前一个点用**加法** → $X[k]$
- 后一个点用**减法** → $X[k + N/2]$

计算量当场腰斩。

---

## 七、递归迭代：$\log_2 N$ 层不断劈裂

既然 $N$ 点可以劈成两个 $N/2$ 点，那么 $N/2$ 点就可以继续往下劈成 $N/4$ 点……直到最后只剩下 2 个点的加减法。

递归树的结构如下：

```
N 点 DFT
├── N/2 点 DFT (偶数)
│   ├── N/4 点 DFT
│   │   ├── N/8 点 DFT
│   │   │   └── ... 直到 2 点
│   │   └── N/8 点 DFT
│   └── N/4 点 DFT
└── N/2 点 DFT (奇数)
    ├── N/4 点 DFT
    └── N/4 点 DFT
```

### 复杂度分析

- 递归深度：$\log_2 N$ 层
- 每层合并时需做 $\frac{N}{2}$ 次复数乘法（蝶形运算）
- 总乘法次数：$\frac{N}{2} \cdot \log_2 N$

$$
\boxed{O(N^2) \;\longrightarrow\; O(N \log N)}
$$

> 当 $N = 1024$ 时：$N^2 \approx 10^6$，而 $\frac{N}{2}\log_2 N \approx 5120$，**提速约 200 倍**。

## 八、裸机 C 语言 FFT 实现

以下是最精简的基-2 原地 FFT 实现，包含两个阶段：位反转重排 + 蝶形网络。

```c
#include <math.h>
#include <stdint.h>

// 定义复数结构体，对应现实世界中的振幅与相位
typedef struct {
    float real; // 实部
    float imag; // 虚部
} Complex32_t;

#define PI 3.14159265358979323846f

/**
 * @brief  基-2 原地快速傅里叶变换 (Radix-2 DIT FFT)
 * @param  x: 输入输出共用的复数数组（原地计算 In-place）
 * @param  N: 采样点数（必须是 2 的整数次幂，如 16, 1024）
 */
void FFT_Compute(Complex32_t *x, uint16_t N) 
{
    uint16_t i, j, k, step;
    float temp_real, temp_imag;
    float cos_w, sin_w;
    
    // 计算 FFT 的层数 (比如 N=16 时，层数 log2N = 4)
    uint16_t log2N = 0;
    while ((1 << log2N) < N) {
        log2N++;
    }

    // ========================================================
    // 第 1 阶段：绝对粉碎（雷德算法 Bit-Reversal 位反转）
    // ========================================================
    j = 0;
    for (i = 0; i < N - 1; i++) {
        if (i < j) {
            // 如果原始索引小于反转后的索引，执行物理交换
            Complex32_t temp = x[i];
            x[i] = x[j];
            x[j] = temp;
        }
        k = N >> 1;
        while (k <= j) {
            j -= k;
            k >>= 1;
        }
        j += k;
    }

    // ========================================================
    // 第 2 阶段：蝶形网络升华（多层嵌套重组）
    // ========================================================
    // 最外层循环：一层一层向上合并积木（对应图纸上的跨度翻倍）
    for (uint16_t stage = 1; stage <= log2N; stage++) {
        
        uint16_t span = 1 << (stage - 1);         // 当前蝶形交叉的跨度：1, 2, 4, 8...
        uint16_t block_size = span << 1;          // 当前处理的积木大小：2, 4, 8, 16...
        
        // 核心旋转齿轮的基础角度
        float angle = -PI / span; 

        // 中间层循环：在整个数组中滑动，处理每一个独立的积木块
        for (i = 0; i < N; i += block_size) {
            
            // 最内层循环：在当前积木块内部，执行蝶形交叉！
            for (j = 0; j < span; j++) {
                
                // 实时计算当前的旋转因子 W (真实的工程中这里会查表)
                cos_w = cosf(j * angle);
                sin_w = sinf(j * angle);
                
                // 锁定上下路参与交配的两个内存地址
                uint16_t top_idx = i + j;
                uint16_t btm_idx = top_idx + span;
                
                // 提取下路数据并乘以旋转齿轮 (复数乘法)
                temp_real = x[btm_idx].real * cos_w - x[btm_idx].imag * sin_w;
                temp_imag = x[btm_idx].real * sin_w + x[btm_idx].imag * cos_w;
                
                // 蝶形绝杀，一箭双雕！(原地覆盖更新)
                // 后半段减法 (底路)
                x[btm_idx].real = x[top_idx].real - temp_real;
                x[btm_idx].imag = x[top_idx].imag - temp_imag;
                
                // 前半段加法 (顶路)
                x[top_idx].real = x[top_idx].real + temp_real;
                x[top_idx].imag = x[top_idx].imag + temp_imag;
            }
        }
    }
}
```

### 代码核心要点

| 阶段 | 核心操作 | 关键变量 |
|---|---|---|
| **位反转** | 雷德算法将时域数据按位反转顺序重排 | `j` = 反转后的索引 |
| **蝶形网络** | 三层循环：stage → block → butterfly | `span` = 当前蝶形跨度 |
| **旋转因子** | 实时计算 $W_N = e^{-j \cdot \text{angle} \cdot j}$ | `angle` = $-\pi / \text{span}$ |
| **蝶形更新** | `top = A + W·B`, `btm = A - W·B` | 原地覆盖，一箭双雕 |

---

## 九、关键总结

1. **旋转因子的两个性质**是可约性与对称性，这是 FFT 降维的数学根基
2. **时间抽取（DIT）**按索引奇偶劈裂时域数据，递归深度 $\log_2 N$
3. **蝶形运算**一次复数乘法得到两个频域点，加法得前半点、减法得后半点
4. **位反转重排**确保递归展开后的数据对齐，雷德算法 $O(N)$ 完成
5. **原地计算（In-place）**不额外分配内存，输入输出共用同一数组
6. 最终复杂度从 $O(N^2)$ 降为 $O(N \log N)$，$N=1024$ 时提速约 200 倍
