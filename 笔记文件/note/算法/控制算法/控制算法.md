# 控制算法笔记

> 从经典 PID 到现代控制理论（状态空间 → 卡尔曼滤波 → LQR），按「底层原理 → 应用场景 → 代码实现」三层结构组织。

---

## 学习路线

```
PID（入门，单变量）→ 状态空间方程（多变量建模）→ 协方差矩阵（噪声数学基础）
                                              ├→ 卡尔曼滤波（最优估计）
                                              └→ LQR（最优控制）
                        卡尔曼 + LQR = LQG（最优估计 + 最优控制 → 完整现代控制方案）
```

## 算法选型速查

| 你的需求 | 推荐方案 |
|----------|----------|
| 控一个量（温度/转速），能试凑 | **PID**，增量式，半天搞定 |
| 多变量耦合（平衡车/无人机） | **LQR**，先建模再求解 |
| 传感器噪声大，读不到某些状态 | **卡尔曼滤波** 做状态估计 |
| 既要估计又要控制 | **卡尔曼 + LQR = LQG** |

> 复杂度排序：PID < LQR < 卡尔曼滤波 < LQG
