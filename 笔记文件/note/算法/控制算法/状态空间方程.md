# 状态空间方程

> 现代控制理论的核心基石：把系统从"黑盒"拆成"白盒"，用矩阵语言描述系统内部每一个状态的演化。

---

## 底层

### 经典控制 vs 现代控制

| | 经典控制（PID/传递函数） | 现代控制（状态空间） |
|------|--------------------------|---------------------------|
| 视角 | 黑盒：只看输入→输出 | 白盒：监控内部每一个状态 |
| 数学工具 | 拉普拉斯变换、传递函数 | 矩阵代数、微分方程 |
| 处理对象 | SISO（单入单出） | MIMO（多入多出）天然支持 |
| 设计方法 | 试凑、经验公式 | 数学优化（LQR、卡尔曼） |

### 连续时间标准形式

对于一个线性时不变（LTI）系统：

**状态方程（描述内部动态演化）：**

$$\dot{x}(t) = Ax(t) + Bu(t)$$

**输出方程（描述状态到传感器的映射）：**

$$y(t) = Cx(t) + Du(t)$$

| 符号 | 名称 | 工程意义 |
|------|------|----------|
| $x(t)$ | 状态向量 | 系统内部核心变量（位置、速度、角度、角速度...） |
| $u(t)$ | 输入向量 | 外部控制量（PWM 占空比、电压、力...） |
| $y(t)$ | 输出向量 | 传感器能读到的量（编码器、陀螺仪...） |
| $A$ | 系统矩阵 | **系统的灵魂**——质量、摩擦、转动惯量等物理特性 |
| $B$ | 输入矩阵 | 控制力如何分配并影响各状态 |
| $C$ | 观测矩阵 | 内部状态如何投射到传感器读数 |
| $D$ | 前馈矩阵 | 输入直接到输出的路径（机械系统通常 $D=0$） |

**一句话理解：**
- $A$ 是"天地法则"（重力、惯性、摩擦），决定系统自身的演化
- $B$ 是"逆天改命的手段"（电机发力），你唯一能控制的
- $C$ 是"管中窥豹的小孔"（传感器），你唯一能看到的

### 离散化：从数学走向单片机

微控制器是周期采样的（如每 5ms 一次中断），需要把连续方程离散化：

$$x_{k+1} = A_d x_k + B_d u_k$$
$$y_k = C_d x_k + D_d u_k$$

**欧拉法近似**（$T_s$ 足够小时可用）：

$$\dot{x} \approx \frac{x_{k+1} - x_k}{T_s}$$

代入 $\dot{x} = Ax + Bu$：

$$x_{k+1} = (I + A T_s) x_k + (B T_s) u_k$$

即：**$A_d = I + A T_s$**，**$B_d = B T_s$**，**$C_d = C$**，**$D_d = D$**。

> 更精确的离散化用**零阶保持器 (ZOH)**，MATLAB 的 `c2d` 函数自动完成。

## 应用

### 案例一：直流减速电机

**状态 $x = [i, \omega]^T$**（电流 + 角速度），**输入 $u$** = 电压：

$$\begin{bmatrix} \dot{i} \\ \dot{\omega} \end{bmatrix} =
\begin{bmatrix} -\frac{R}{L} & -\frac{K_e}{L} \\ \frac{K_t}{J} & -\frac{b}{J} \end{bmatrix}
\begin{bmatrix} i \\ \omega \end{bmatrix} +
\begin{bmatrix} \frac{1}{L} \\ 0 \end{bmatrix} u(t)$$

$$y(t) = \begin{bmatrix} 0 & 1 \end{bmatrix} \begin{bmatrix} i \\ \omega \end{bmatrix}$$

**矩阵解读：**
- $A$ 矩阵的 $-\frac{R}{L}$ 是电阻消耗电流，$-\frac{b}{J}$ 是摩擦消耗转速，$K_t$ 和 $K_e$ 把电流和转速耦合在一起
- $B$ 矩阵第二行是 0 → 电压不能直接改变转速，必须通过电流→力矩→转速逐步建立
- $C$ 矩阵 $[0, 1]$ → 编码器只能看到转速，看不到电流

### 案例二：自平衡小车（倒立摆）

**状态 $x = [p, v, \theta, \dot{\theta}]^T$**（位移 + 速度 + 倾角 + 角速度），**输入 $u$** = 电机推力：

- $A$ 矩阵包含重力项：当 $u=0$ 时，重力会算出 $\ddot{\theta} > 0$，小车在下一秒加速倒下
- $B$ 矩阵描述推力如何同时影响车轮位移和车身倾角
- $C$ 矩阵：如果有 MPU6050（角度+角速度）+ 编码器（位移），则 $C$ 提取 $[p, \theta, \dot{\theta}]$，过滤掉线速度 $v$

## 代码

### 离散状态空间方程的单片机实现

```c
/* 状态维度 */
#define N_STATE  4  // [位移, 速度, 倾角, 角速度]
#define N_INPUT  1  // 电机推力

/* 离线算好的离散矩阵（Ts = 5ms） */
const float Ad[N_STATE][N_STATE] = {
    {1.000, 0.005, 0.000, 0.000},
    {0.000, 0.998, 0.014, 0.000},
    {0.000, 0.000, 1.000, 0.005},
    {0.000, -0.001, 0.150, 1.000}
};

const float Bd[N_STATE][N_INPUT] = {
    {0.000},
    {0.003},
    {0.000},
    {0.006}
};

float x[N_STATE];   // 当前状态向量

/**
 * @brief  状态预测（定时器中断中调用）
 *         计算 x_{k+1} = Ad * x_k + Bd * u_k
 */
void StateSpace_Predict(float u)
{
    float x_new[N_STATE] = {0};

    // 矩阵乘法：Ad * x
    for (int i = 0; i < N_STATE; i++)
    {
        for (int j = 0; j < N_STATE; j++)
            x_new[i] += Ad[i][j] * x[j];
        x_new[i] += Bd[i][0] * u;   // + Bd * u
    }

    // 更新状态
    for (int i = 0; i < N_STATE; i++)
        x[i] = x_new[i];
}
```

### 完整控制循环（定时器中断 5ms）

```
1. 读传感器 → y_k（编码器位移 + MPU6050 角度/角速度）
2. 卡尔曼滤波 → 估计 x_k（包括读不到的速度 v）
3. u_k = -K * x_k（LQR 计算控制量）
4. 输出 PWM 到电机
5. StateSpace_Predict(u_k) → 预测 x_{k+1}（可选，卡尔曼内部已做）
```

## 高级概念（通向最优控制）

有了 $A, B, C$ 矩阵后，可以解锁以下算法：

| 概念 | 解决的数学问题 | 对应算法 |
|------|---------------|----------|
| **能控性** | 用 $u$ 能到达所有状态吗？ | 分析 $(A, B)$ → 决定能否用 LQR |
| **能观性** | 通过 $y$ 能反推所有状态吗？ | 分析 $(A, C)$ → 决定是否需要卡尔曼滤波 |
| **状态观测器** | 能观但没传感器怎么知道状态？ | Luenberger 观测器 |
| **最优估计** | 传感器有噪声，怎么融合？ | 卡尔曼滤波 |
| **最优控制** | 怎么找最优 $u$？ | LQR ($u = -Kx$) |
| **线性化** | 非线性系统（含 $\sin\theta$）怎么办？ | 在平衡点泰勒展开，$\sin\theta \approx \theta$ |

## 连续模型推导附录

以下展示直流电机的 $A$ 矩阵是如何从物理定律拼接出来的。

**电学部分（KVL）**：$u = Ri + L\dot{i} + K_e\omega \Rightarrow \dot{i} = -\frac{R}{L}i - \frac{K_e}{L}\omega + \frac{1}{L}u$

**力学部分（牛顿第二定律旋转形式）**：$J\dot{\omega} = K_t i - b\omega \Rightarrow \dot{\omega} = \frac{K_t}{J}i - \frac{b}{J}\omega$

**合并为矩阵形式**：

$$\begin{bmatrix} \dot{i} \\ \dot{\omega} \end{bmatrix} =
\begin{bmatrix} -\frac{R}{L} & -\frac{K_e}{L} \\ \frac{K_t}{J} & -\frac{b}{J} \end{bmatrix}
\begin{bmatrix} i \\ \omega \end{bmatrix} +
\begin{bmatrix} \frac{1}{L} \\ 0 \end{bmatrix} u$$

> 本质上就是把**电学定律**和**力学定律**用矩阵拼接在一起。$A$ 矩阵的对角线是各自的自然损耗（电阻耗电、摩擦减速），非对角线是机电耦合（电流产力矩、转速生反电动势）。
