PID（比例 - 积分 - 微分控制）是工业控制、嵌入式系统中应用最广的闭环控制算法，核心思想是**通过反馈得到偏差，再对偏差进行比例、积分、微分三种运算，组合出控制量，让被控量稳定跟随设定值**。小到恒温杯、电机调速，大到工业炉温、无人机飞控，几乎都能看到它的身影。

---

## 一、先搞懂核心：闭环与偏差

在讲 PID 之前，先明确几个基础概念：

- **设定值 SP**：你想要的目标值（比如设定水温 50℃、电机转速 1000 转 / 分）
- **过程值 PV**：传感器实际测到的当前值（比如实际水温 46℃、当前转速 920 转 / 分）
- **偏差 $e(t)$**：设定值与过程值的差，即 $e(t) = SP - PV$
- **控制量 $u(t)$**：PID 输出的、送给执行机构的信号（比如加热功率、电机 PWM 占空比）

开环控制是 "给多少输出就多少，不管结果"；闭环 PID 则是**盯着偏差调输出，偏差大就使劲调，偏差小就慢慢调，没偏差就稳住**。

完整的 PID 控制由**比例 (P)、积分 (I)、微分 (D)**三个独立环节叠加而成，三个环节各司其职，下面逐个拆解。

---

## 二、三个环节的原理与作用

### 1. 比例环节 P（Proportion）

#### 公式

$$u_p(t) = K_p \cdot e(t)$$

$K_p$ 为比例增益，决定比例作用的强弱。

#### 物理意义

控制力度和偏差大小**成正比**：偏差越大，输出的控制力度越强；偏差越小，控制力度越弱。就像弹簧，拉得越长，回弹的力越大。

#### 作用

- 是 PID 的基础调节力，**快速响应偏差**，让被控量向设定值靠近
- $K_p$ 越大，响应速度越快，稳态偏差越小

#### 致命缺点：存在静差（稳态误差）

纯比例控制永远无法让偏差等于 0。

> 举个例子：用 P 控制热水器加热到 50℃。 当水温接近 50℃时，偏差越来越小，加热功率也越来越小；最终会在某个温度（比如 46℃）达到平衡 —— 此时加热功率刚好等于散热量。 剩下的 4℃偏差就是**静差**：只有存在这个偏差，P 环节才能输出足够的功率抵消散热，一旦偏差为 0，加热功率也为 0，水温又会降下去。

#### 参数影响

- $K_p$ 太小：响应慢、静差大
- $K_p$ 太大：响应快，但容易超调、振荡，系统不稳定

---

### 2. 积分环节 I（Integral）

#### 公式

$$u_i(t) = \frac{K_p}{T_i} \int_0^t e(\tau) \, d\tau$$

$T_i$ 为积分时间，$T_i$ 越小，积分作用越强。

#### 物理意义

对偏差随时间**累积求和**：只要偏差存在，积分就会一直累加，控制力度就会持续增大；直到偏差为 0，积分才停止累积，输出保持稳定。 一句话：**哪里有偏差，就往哪里积分，直到偏差消失**。

#### 核心作用

**消除静差**—— 这是比例环节做不到的事。 还是热水器的例子：加入积分后，即使水温到了 46℃偏差很小，积分也会慢慢累加，继续增大加热功率，推着水温继续上升，直到精准到达 50℃、偏差为 0，积分才停下。

#### 缺点

1. **滞后性强、易超调** 积分是 "累加过去的偏差"，当偏差已经开始反向减小时，积分还在累积之前的正偏差，导致输出继续增大，让被控量冲过设定值，产生超调。
2. **积分饱和** 如果系统长时间达不到设定值（比如大偏差启动），积分项会累积到非常大的值，让输出直接饱和（比如加热功率拉满 100%）；即使后续偏差反向，积分需要先 "释放" 完之前的累积量，输出才会下降，最终导致超调更大、恢复时间更长。

#### 参数影响

- $T_i$ 越小（积分越强）：消除静差越快，但超调、振荡越严重
- $T_i$ 越大（积分越弱）：超调小，但消除静差慢

---

### 3. 微分环节 D（Differential）

#### 公式

$$u_d(t) = K_p \cdot T_d \cdot \frac{de(t)}{dt}$$

$T_d$ 为微分时间，$T_d$ 越大，微分作用越强。

#### 物理意义

根据偏差的**变化速率**提前动作 —— 偏差变化越快，微分输出越大。 相当于 "预判刹车"：如果偏差正在快速减小，说明系统马上就要冲到设定值了，微分提前输出反向力，拉住系统，避免冲过头。

#### 作用

- **抑制超调、减小振荡**，给系统加阻尼
- 加快动态响应，缩短调节时间

#### 缺点

**对高频噪声极度敏感**。 传感器的干扰、信号毛刺变化率非常大，微分会把噪声直接放大，导致输出剧烈抖动，反而让系统不稳定。所以噪声大的系统（比如流量、压力控制）通常不用微分。

#### 参数影响

- $T_d$ 越大（微分越强）：抑制超调效果越好，但抗干扰能力越差，易抖动
- $T_d$ 太小：几乎没作用

## 三、PID 完整公式与数字实现

### 1. 连续域理想 PID 公式

三个环节叠加，得到完整的模拟 PID 输出：

$$u(t) = K_p \left[ e(t) + \frac{1}{T_i} \int_0^t e(\tau) \, d\tau + T_d \cdot \frac{de(t)}{dt} \right]$$

工业上通常用三个参数整定，而不是单独的积分增益、微分增益，物理意义更直观。

### 2. 数字 PID（嵌入式 / 单片机常用）

单片机是周期采样的，无法连续运算，需要把连续公式离散化：用**求和代替积分**，用**差分代替微分**。 设采样周期为 $T_s$，第 $k$ 次采样的偏差为 $e(k)$，有两种最常用的实现形式。

#### （1）位置式 PID

输出的是**控制量的绝对数值**（比如阀门开度 0~100%、PWM 占空比 0~1000），直接对应执行机构的位置。

##### 公式

$$u(k) = K_p \cdot e(k) + K_i \cdot \sum_{i=0}^{k} e(i) + K_d \cdot [e(k) - e(k-1)]$$

其中：

- 积分系数 $K_i = K_p \cdot \dfrac{T_s}{T_i}$
- 微分系数 $K_d = K_p \cdot \dfrac{T_d}{T_s}$

##### 特点

- 优点：直观，适合执行机构不带记忆的场景（比如可控硅调功、模拟阀门）
- 缺点：积分项是全量累加，容易积分饱和；输出是全量，一旦程序出错影响大

#### （2）增量式 PID

输出的是**本次控制量与上次控制量的差值** $\Delta u(k)$，执行机构自己累积这个增量得到实际位置（比如步进电机、脉冲输出的调速系统）。

##### 公式（由位置式前后两项相减推导）

$$\Delta u(k) = K_p \cdot [e(k) - e(k-1)] + K_i \cdot e(k) + K_d \cdot [e(k) - 2e(k-1) + e(k-2)]$$

##### 特点

- 优点：
    1. 输出是增量，误动作影响小，安全性高
    2. 积分影响小，不易出现积分饱和
    3. 手动 / 自动模式切换时冲击小
- 缺点：需要执行机构自带积分特性，存在累积误差

> 嵌入式开发中，电机调速、步进电机控制优先用增量式；温度、液位等模拟量控制常用位置式。

## 四、PID 参数整定方法（工程实用版）

参数整定是 PID 落地的核心，这里讲两种最常用的方法，新手优先用试凑法。

### 1. 试凑法（经验法，最通用）

核心口诀：**先比例，后积分，最后微分**，一步步加，一步步调。

1. **第一步：纯 P 调节打底**
    - 把积分关闭（$T_i$ 设为无穷大 / $K_i = 0$），微分关闭（$T_d = 0$ / $K_d = 0$）
    - $K_p$ 从小到大慢慢加，观察系统响应
    - 直到系统响应速度尚可，出现小幅振荡；如果出现持续等幅振荡，说明 $K_p$ 太大，回退到振荡消失时的 0.6~0.7 倍
2. **第二步：加入积分消静差**
    - 保持 $K_p$ 不变，$T_i$ 从大往小调（积分作用从弱到强）
    - 目标：消除静差，同时超调在可接受范围内
    - 如果超调变大、振荡加剧，说明积分太强，增大 $T_i$
3. **第三步：加入微分抑超调**
    - 保持不变，$T_d$ 从小往大调
    - 目标：减小超调，加快稳定
    - 如果输出出现高频抖动，说明微分太强，减小 $T_d$

最后反复微调三个参数，直到满足 "响应快、超调小、稳态稳" 的要求。

### 2. 齐格勒 - 尼科尔斯法（Z-N 临界比例度法）

适合允许做临界振荡实验的系统，通过实验得到初始参数，再微调。

1. 纯 P 控制，增大 $K_p$ 直到系统出现**持续等幅振荡**
2. 记录此时的临界增益 $K_{cr}$ 和临界振荡周期 $T_{cr}$
3. 按下表计算初始参数：

| 控制类型 | $K_p$ | $T_i$ | $T_d$ |
|---|---|---|---|
| P | $0.5 K_{cr}$ | - | - |
| PI | $0.45 K_{cr}$ | $0.83 T_{cr}$ | - |
| PID | $0.6 K_{cr}$ | $0.5 T_{cr}$ | $0.125 T_{cr}$ |

> 注意：这个公式得到的参数超调通常偏大，仅作为初始值，必须手动微调。

## 五、常见问题与调整方向速查表

| 现象 | 核心原因 | 调整方向 |
|---|---|---|
| 稳态静差大、始终达不到设定值 | 比例弱 / 积分缺失或太弱 | 增大 $K_p$；减小 $T_i$（加强积分） |
| 超调量大、冲过设定值很多 | 比例太强 / 积分太强 | 减小 $K_p$；增大 $T_i$（减弱积分）；增大 $T_d$ |
| 系统持续振荡、不稳定 | 比例太强 / 微分过强 | 减小 $K_p$；减小 $T_d$；适当增大 $T_i$ |
| 响应慢、上升时间很长 | 比例弱 / 积分弱 | 增大 $K_p$；减小 $T_i$；适当加微分 |
| 输出高频抖动、噪声大 | 微分太强 / 反馈信号干扰大 | 减小 $T_d$；给反馈加滤波；改用微分先行 PID |
| 大偏差启动后超调特别大、恢复慢 | 积分饱和 | 加积分分离、限幅等抗饱和算法 |

## 六、工程中常用的改进型 PID

理想 PID 在实际场景中会有各种问题，因此衍生出很多改进版本：

1. **积分分离 PID**：偏差大于阈值时关闭积分，避免大偏差下积分累积过多；偏差小于阈值再投入积分，大幅降低超调。
2. **遇限削弱积分**：输出达到上下限后，只累加能让输出往回走的偏差，停止累加会加剧饱和的偏差，解决积分饱和。
3. **微分先行 PID**：只对反馈值 PV 做微分，不对设定值 SP 做微分，避免设定值突变时微分输出跳变冲击系统。
4. **带死区的 PID**：偏差小于死区阈值时视为 0，输出保持不变，避免执行机构频繁动作，延长寿命。

---

## 七、不同场景的 PID 选型规律

- **温度控制**：滞后大、响应慢 → 用完整 PID，$T_i$ 较长，$T_d$ 较大
- **流量 / 压力控制**：响应快、噪声大 → 只用 PI，**不用微分**
- **液位控制**：要求不高用 P，要求高用 PI，一般不用 D
- **电机调速**：响应较快 → 常用 PI，要求高可加弱微分抑制波动

## 附：增量式 PID 简易 C 语言实现（嵌入式通用）

```c
typedef struct {
    float Kp;         // 比例增益
    float Ki;         // 积分系数
    float Kd;         // 微分系数
    float err;        // 当前偏差
    float last_err;   // 上一次偏差
    float prev_err;   // 上上次偏差
    float output;     // 输出增量
    float max_output; // 输出限幅最大值
    float min_output; // 输出限幅最小值
} PID_IncTypeDef;

/**
 * @brief  增量式PID计算
 * @param  pid: PID结构体指针
 * @param  set: 设定值SP
 * @param  cur: 当前反馈值PV
 * @retval 控制量增量
 */
float PID_IncCalc(PID_IncTypeDef *pid, float set, float cur)
{
    // 1. 计算当前偏差
    pid->err = set - cur;
    
    // 2. 增量式PID公式
    pid->output = pid->Kp * (pid->err - pid->last_err)
                + pid->Ki * pid->err
                + pid->Kd * (pid->err - 2*pid->last_err + pid->prev_err);
    
    // 3. 输出限幅
    if(pid->output > pid->max_output)
        pid->output = pid->max_output;
    else if(pid->output < pid->min_output)
        pid->output = pid->min_output;
    
    // 4. 更新偏差历史
    pid->prev_err = pid->last_err;
    pid->last_err = pid->err;
    
    return pid->output;
}
```
