# LQR 线性二次型调节器

> 最优控制的入门算法：用数学方法直接算出最优反馈增益 $K$，替代 PID 的反复试凑。

---

## 底层

### LQR 解决什么问题

PID 的痛点：参数靠试凑，三个参数 ($K_p, K_i, K_d$) 彼此耦合，调了半天不知道是不是最优。

LQR 的思路：**你先说清楚"想要什么"（定义代价函数），然后数学帮你算出最优解。**

### 代价函数

定义一个二次型代价函数 $J$，包含两部分惩罚：

$$J = \sum_{k=0}^{\infty} (x_k^T Q x_k + u_k^T R u_k)$$

| 项 | 含义 | 调大则... |
|------|------|-----------|
| $x_k^T Q x_k$ | 状态偏离代价 | 系统响应更快、更"紧" |
| $u_k^T R u_k$ | 控制能量代价 | 输出更平滑、更省电 |

> $Q$ 和 $R$ 是**权重矩阵**，对角线元素越大惩罚越重。相比 PID 的三个参数，LQR 的参数有**明确的物理含义**。

### 最优控制律

解出来是一个极其简洁的线性反馈：

$$u_k = -K x_k$$

$K$ 是一个常数矩阵，**离线算好，在线只做一次矩阵乘法**。控制量 = 当前状态 × 反馈增益，没有积分、没有微分。

### 黎卡提方程

$K$ 是怎么来的？通过求解**离散时间代数黎卡提方程 (DARE)**：

$$P = Q + A^T P A - A^T P B (R + B^T P B)^{-1} B^T P A$$

$$K = (R + B^T P B)^{-1} B^T P A$$

推导思路（动态规划）：
1. 从最后一拍往前倒推
2. 每一步对 $u$ 求导找极值
3. 无穷时域下 $P$ 矩阵收敛到定值 → $K$ 也是常数

---

## 应用

| 场景 | 说明 |
|------|------|
| 自平衡小车 | 4 维状态（位移、速度、倾角、角速度）× 1 维控制 → $K$ 是 1×4 向量 |
| 无人机姿态控制 | 多轴耦合系统，LQR 天然处理 MIMO |
| 倒立摆 | LQR 的标准教学案例 |
| 电机伺服控制 | 位置+速度双状态反馈 |
| 航天器姿态 | LQR 是 GNC（制导导航控制）的基础 |

### LQR vs PID

| | LQR | PID |
|------|-----|-----|
| 设计方式 | 数学求解 | 经验试凑 |
| 适用系统 | MIMO 多入多出 | SISO 单入单出 |
| 参数含义 | $Q$=性能, $R$=节能（物理意义明确） | $K_p, K_i, K_d$（抽象） |
| 最优性 | 数学上最优 | 没有最优保证 |
| 计算量 | 一次矩阵乘法 | 三次乘加 |
| 抗扰动 | 需要配合观测器 | 积分项天然抗扰动 |

> 工程建议：简单系统用 PID，多变量耦合系统（如平衡车、四旋翼）优先考虑 LQR。

## 代码

### 在 MATLAB/Python 中离线计算 $K$

这一步在电脑上完成，算出的 $K$ 作为常数写入单片机：

```python
# Python 版本（需要 control 库）
import control
import numpy as np

# 连续系统矩阵 A, B（来自物理建模）
A = np.array([[0, 1, 0, 0],
              [0, -0.1, 2.8, 0],
              [0, 0, 0, 1],
              [0, -0.2, 30.0, 0]])
B = np.array([[0], [0.5], [0], [1.2]])

# 权重矩阵
Q = np.diag([100, 1, 50, 1])   # 重点惩罚位移和角度
R = np.array([[0.1]])           # 限制控制量

# 离散化（Ts = 5ms）
Ts = 0.005
sys_d = control.c2d(control.ss(A, B, np.eye(4), np.zeros((4,1))), Ts)
Ad = sys_d.A
Bd = sys_d.B

# 求解 LQR
K, S, E = control.dlqr(Ad, Bd, Q, R)
print("K =", K)  # 把这个矩阵写入单片机
```

```matlab
% MATLAB 版本

disp(K);  % 把这个矩阵写入单片机
```

### 单片机 C 代码（在线执行）

```c
/* 离线算好的反馈增益 K（1×4），烧录为常数 */
const float K[4] = {-25.3f, -8.7f, -18.2f, -3.1f};  // 示例值

/* 状态向量（来自传感器+卡尔曼滤波/观测器） */
float x[4];  // [位移, 速度, 倾角, 角速度]

/**
 * @brief  LQR 控制量计算
 * @retval 控制量 u（PWM 占空比等）
 */
float LQR_Compute(void)
{
    float u = 0;
    for (int i = 0; i < 4; i++)
        u -= K[i] * x[i];         // u = -K * x
    return u;
}

/* 放在定时器中断里，每 5ms 调用一次：
 *   1. 读传感器 → 更新 x
 *   2. u = LQR_Compute()
 *   3. 输出 u 到电机 PWM
 */
```

### LQR + 卡尔曼滤波 = LQG

LQR 假设所有状态 $x$ 都能量测到。现实中很多状态量不到（比如平衡车的线速度），需要**卡尔曼滤波**或**状态观测器**来估计。

```
传感器 → 卡尔曼滤波 → 估计状态 \hat{x} → LQR → 控制量 u → 电机
         ↑                                    ↑
    离线算好的增益                        离线算好的 K
```

这就是 **LQG (Linear Quadratic Gaussian)** 控制——分离原理告诉我们：**最优估计 + 最优控制 = 最优系统**。

## 调参指南

| 现象 | 调整方向 |
|------|----------|
| 响应太慢、回位拖沓 | 增大 $Q$（对应位置/角度的权重） |
| 电机疯狂震荡、输出抖动 | 增大 $R$（限制控制量），或减小 $Q$ |
| 稳态有偏差（回不到零点） | 先检查是否有积分项——LQR 不能消静差！需要加积分器或改用 LQI |
| 超调过大 | 增大 $R$，减小 $Q$ |
| 某个状态特别差 | 增大 $Q$ 中该状态对应的对角线元素 |

> **核心调参思路**：$Q$ 对角线上的值 = 对应状态的"重要性"，$R$ = "省电/平滑"程度。先固定 $R=1$，调 $Q$；满意后微调 $R$。

## 推导附录

以下为 LQR 从动态规划倒推完整过程的摘要，方便理解 $K$ 的来源。

**离散系统**：$x_{k+1} = A x_k + B u_k$

**代价函数（有限时域 $N$）**：
$$J = x_N^T Q_f x_N + \sum_{k=0}^{N-1} (x_k^T Q x_k + u_k^T R u_k)$$

**倒推法（动态规划）**：

从最后一拍 $N-1 \to N$ 开始，代价 $J_{N-1}$ 代入 $x_N = A x_{N-1} + B u_{N-1}$，展开后对 $u_{N-1}$ 求导令为 0：

$$\frac{\partial J_{N-1}}{\partial u_{N-1}} = 2(R + B^T Q_f B)u_{N-1} + 2(B^T Q_f A)x_{N-1} = 0$$

解出：$u_{N-1} = -K_{N-1} x_{N-1}$，其中 $K_{N-1} = (R + B^T Q_f B)^{-1} B^T Q_f A$

将最优 $u_{N-1}$ 代回 $J_{N-1}$，发现 $J_{N-1}$ 化简为 $x_{N-1}^T P_{N-1} x_{N-1}$——和终点代价形式一模一样！

**黎卡提递推**：
$$P_{k} = Q + A^T P_{k+1} A - A^T P_{k+1} B (R + B^T P_{k+1} B)^{-1} B^T P_{k+1} A$$

当 $N \to \infty$，$P$ 收敛到定值 $P_\infty$，反馈增益也固定为：

$$K = (R + B^T P_\infty B)^{-1} B^T P_\infty A$$
