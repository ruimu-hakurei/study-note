# 底盘运动学解算

> [!abstract] 核心思路
> 当底盘一边平移、一边旋转时，先计算每个轮组所在位置的速度，再把速度分解为“行进速度”和“舵向角度”，最后换算成电机目标。
>
> **轮组所在位置的速度 = 底盘参考点的平移速度 + 绕参考点旋转产生的速度。**

本文沿用原笔记的工程约定，讨论可独立转向的舵轮底盘。由底盘速度求各轮组速度与角度，属于逆运动学解算。

## 1. 坐标系与符号约定

### 1.1 车体坐标系

俯视底盘，规定 $X+$ 向右、$Y+$ 向前：

```text
                 车头方向
                    Y+
                    ↑
                    |
                    O────────→ X+
                              车身右侧
```

$O$ 是选定的底盘参考点，也是描述整车平移速度的原点，不一定是实际的瞬时旋转中心。

### 1.2 符号与单位

| 符号 | 含义 | 物理量单位 |
| --- | --- | --- |
| $V_x$ | 参考点向右的平移速度分量 | m/s |
| $V_y$ | 参考点向前的平移速度分量 | m/s |
| $V_w$ | 底盘角速度，**俯视顺时针为正** | rad/s |
| $x_i$ | 第 $i$ 个轮组相对原点的左右位置 | m |
| $y_i$ | 第 $i$ 个轮组相对原点的前后位置 | m |
| $v_{ix}$ | 第 $i$ 个轮组所在位置的向右速度分量 | m/s |
| $v_{iy}$ | 第 $i$ 个轮组所在位置的向前速度分量 | m/s |

大写 $V_x,V_y,V_w$ 描述整车运动；小写 $v_{ix},v_{iy}$ 描述各轮组所在位置的运动。$x_i,y_i$ 是**安装位置，不是速度**，下标 $i$ 是轮组编号。

这里的速度指相对地面的运动速度，分量用当前车体坐标轴表示；轮组安装位置在车体坐标系中保持不变。

> [!important] 两种正方向要分开记
> - 底盘旋转命令 $V_w$：顺时针为正。
> - `atan2f(vy, vx)` 求出的方向角：从 $X+$ 轴起，逆时针为正。
>
> 两者描述不同的量，可以采用不同约定，但不能混用。

## 2. 从底盘速度求轮组速度

### 2.1 核心公式

$$
\boxed{
\begin{aligned}
v_{ix} &= V_x + V_w y_i \\
v_{iy} &= V_y - V_w x_i
\end{aligned}
}
$$

其中 $V_w y_i$ 与 $-V_w x_i$ 是旋转产生的速度分量。相邻字母表示乘法。

### 2.2 用三角函数推导旋转位移

先忽略参考点的平移，把轮组位置想象成一根刚性杆的末端：杆的一端固定在 $O$，长度为 $r$。

**推导时固定观察坐标轴**：取某一时刻与车体坐标轴重合、随后不随车体旋转的坐标轴。下面的新旧坐标都在这组固定轴中比较；并不是对车体坐标系中不变的安装坐标直接求导。

设初始杆与 $X+$ 轴的夹角为 $\alpha$，按逆时针测量，则：

$$
x_i = r\cos\alpha,\qquad y_i = r\sin\alpha
$$

顺时针转过 $\Delta\theta$ 后，夹角减小：

$$
\alpha' = \alpha - \Delta\theta
$$

因此，新坐标为：

$$
x_i' = r\cos(\alpha-\Delta\theta),\qquad
y_i' = r\sin(\alpha-\Delta\theta)
$$

使用差角公式：

$$
\begin{aligned}
\cos(A-B) &= \cos A\cos B + \sin A\sin B \\
\sin(A-B) &= \sin A\cos B - \cos A\sin B
\end{aligned}
$$

展开横坐标，再代入 $r\cos\alpha=x_i$、$r\sin\alpha=y_i$：

$$
\begin{aligned}
x_i'
&= r\cos\alpha\cos\Delta\theta + r\sin\alpha\sin\Delta\theta \\
&= x_i\cos\Delta\theta + y_i\sin\Delta\theta
\end{aligned}
$$

同理，纵坐标为：

$$
\begin{aligned}
y_i'
&= r\sin\alpha\cos\Delta\theta - r\cos\alpha\sin\Delta\theta \\
&= -x_i\sin\Delta\theta + y_i\cos\Delta\theta
\end{aligned}
$$

**加号和减号来自“顺时针使夹角减小”，以及三角函数的差角公式。**

### 2.3 从位移得到瞬时速度

当 $\Delta\theta$ 很小，且角度使用**弧度**时：

$$
\sin\Delta\theta\approx\Delta\theta,\qquad
\cos\Delta\theta\approx1
$$

所以：

$$
x_i'\approx x_i+y_i\Delta\theta,\qquad
y_i'\approx y_i-x_i\Delta\theta
$$

减去原坐标，得到旋转造成的位移：

$$
\Delta x_i\approx y_i\Delta\theta,\qquad
\Delta y_i\approx-x_i\Delta\theta
$$

两边除以 $\Delta t$，再取 $\Delta t\to0$ 的极限。顺时针角速度为：

$$
V_w=\lim_{\Delta t\to0}\frac{\Delta\theta}{\Delta t}
$$

于是旋转产生的瞬时速度为：

$$
v_{\text{旋转},ix}=V_w y_i,\qquad
v_{\text{旋转},iy}=-V_w x_i
$$

加上参考点的平移速度，就得到本节开头的核心公式。小角度近似用于推导极限，得到的**瞬时速度关系是精确的**。

### 2.4 用特殊情况检查符号

| 工况 | 代入结果 | 直观含义 |
| --- | --- | --- |
| 纯平移：$V_w=0$ | $v_{ix}=V_x,\ v_{iy}=V_y$ | 各轮组速度相同 |
| 纯顺时针旋转，轮组在正前方：$x_i=0,\ y_i>0$ | $v_{ix}>0,\ v_{iy}=0$ | 前方轮组向右运动 |
| 纯顺时针旋转，轮组在正右方：$x_i>0,\ y_i=0$ | $v_{ix}=0,\ v_{iy}<0$ | 右侧轮组向后运动 |

纯旋转两行均假设 $V_x=V_y=0$、$V_w>0$。若工程改为逆时针角速度为正，旋转项的符号需要相应改变。

## 3. 从速度分量求行进速度与方向

### 3.1 行进速度大小

根据勾股定理：

$$
s_i=\sqrt{v_{ix}^2+v_{iy}^2}
$$

$s_i$ 是轮组所需的线速度大小，单位为 m/s，**还不是行进电机的转速**。换算成电机转速时还需要轮半径和行进传动比；后文的 `Gear_Ratio` 用于舵向传动。

### 3.2 用 `atan2f()` 求运动方向

```c
float wheel_angle = atan2f(vy, vx);
```

这里的 `vx`、`vy` 分别对应当前轮组的 $v_{ix}$、$v_{iy}$。参数顺序是 `atan2f(y方向分量, x方向分量)`，结果为弧度，范围为 $[-\pi,\pi]$。参见 [Microsoft C 运行库文档](https://learn.microsoft.com/en-us/cpp/c-runtime-library/reference/atan-atanf-atanl-atan2-atan2f-atan2l?view=msvc-170)。

| `vx` | `vy` | 运动方向 | 返回角度 |
| --- | --- | --- | --- |
| 1 | 0 | 向右 | $0$ |
| 0 | 1 | 向前 | $\pi/2$ |
| -1 | 0 | 向左 | 通常为 $\pi$，负零边界可为 $-\pi$ |
| 0 | -1 | 向后 | $-\pi/2$ |
| 1 | 1 | 右前方 | $\pi/4$ |

例如 `vx = 1`、`vy = 1`，则：

$$
\theta_i=\frac{\pi}{4}\approx0.7854\ \text{rad}=45^\circ
$$

> [!tip] 零速时没有确定的运动方向
> 当两个速度分量都为零时，几何上无法确定朝向。实际控制中通常在速度低于阈值时保持上一舵角，避免根据零值或微小噪声反复转舵；原笔记片段未展示这一处理。

## 4. 舵向优化：少转舵，配合行进轮反转

### 4.1 先将弧度转换成度

```c
wheel_angle *= (180.0f / PI);
```

转换关系为：

$$
\theta_{\text{deg}}=\theta_{\text{rad}}\frac{180}{\pi}
$$

`*=` 表示乘以右侧数值后写回原变量。原笔记中 `Turn_Optimize()` 按度数计算，因此调用前先转换单位。

### 4.2 `Turn_Optimize()` 的作用

```c
wheel_angle = Turn_Optimize(
    &motors[0],
    wheel_angle,
    motors[0].prv.total_angle
);
```

| 参数 | 本文采用的解释 |
| --- | --- |
| `&motors[0]` | 舵向电机对象的地址；`&` 是取地址运算符 |
| `wheel_angle` | 待优化的轮组方向角，单位为度 |
| `motors[0].prv.total_angle` | 用于比较的当前角度；须与目标角处于相同机械侧、单位和零点约定 |

传入指针使函数可以访问和修改对象；**具体修改哪些字段，取决于函数实现**。

舵向优化利用下面的等效关系：

$$
(s_i,\theta_i)\quad\Longleftrightarrow\quad(-s_i,\theta_i+180^\circ)
$$

也就是说，轮组朝向反过来，同时让行进轮反转，产生的运动方向仍然相同。这也是 [WPILib 舵轮优化](https://docs.wpilib.org/en/stable/docs/software/kinematics-and-odometry/swerve-drive-kinematics.html#module-angle-optimization)采用的原理。

例如当前舵角为 $0^\circ$，要求运动方向为 $170^\circ$：

| 方案 | 舵向目标 | 行进轮方向 | 转舵量 |
| --- | --- | --- | --- |
| 直接转向 | $170^\circ$ | 正转 | $+170^\circ$ |
| 等效优化 | $-10^\circ$ | 反转 | $-10^\circ$ |

第二种方案转舵更少。按照原笔记的描述，优化后可能得到：

```c
wheel_angle = -10.0f;
MinAng_sign = -1;
```

因此，优化后的有符号行进速度应配套使用方向系数：

$$
s_{i,\text{cmd}}=\text{MinAng\_sign}\cdot s_i
$$

**舵角与反转系数必须使用同一次优化的结果。** 原笔记未附 `Turn_Optimize()` 的函数体，`MinAng_sign` 的保存位置和更新方式仍需以工程源码为准。

### 4.3 跨越一圈边界

当前角为 $350^\circ$、目标方向为 $10^\circ$ 时，在连续累计角表示下，可以把目标写成 $370^\circ$，表示继续转 $20^\circ$。

这里的 $370^\circ$ 与 $10^\circ$ 朝向相同，但数值表达了不同的累计位置。能否直接使用这种目标，取决于反馈角的表示、机械限位和控制接口。

## 5. 从轮组舵角换算成电机位置

### 5.1 将优化后的度数转回弧度

```c
wheel_angle = wheel_angle * PI / 180.0f;
```

$$
\theta_{\text{rad}}=\theta_{\text{deg}}\frac{\pi}{180}
$$

例如 $-10^\circ\approx-0.1745\ \text{rad}$。先转成度、再转回弧度，是因为原笔记中的接口约定不同：

```text
atan2f()：弧度 → Turn_Optimize()：度 → 电机位置目标：弧度
```

### 5.2 乘以舵向传动比

```c
wheel_angle *= Gear_Ratio;
```

原笔记给出的舵向传动比是：

$$
G=\text{Gear\_Ratio}=\frac{86}{20}=4.3
$$

按这里采用的定义，轮组转向 1 圈，需要舵向电机转动 4.3 圈。因此，在零点对齐、方向已统一的前提下：

$$
\theta_{\text{motor}}=G\,\theta_{\text{module}}
$$

输入、输出都为弧度，但从**轮组侧**换到了**电机侧**。例如轮组目标为 $-10^\circ$：

$$
\theta_{\text{motor}}=-10\frac{\pi}{180}\times4.3
\approx-0.7505\ \text{rad}
$$

电机侧约为 $-43^\circ$，对应轮组侧的 $-10^\circ$。若代码中直接定义该比例，应使用 `86.0f / 20.0f`，避免 C 语言整数除法把 `86 / 20` 算成 4。

> [!important] 核对当前角度的机械侧
> `Turn_Optimize()` 比较的是轮组目标方向和当前方向。如果 `total_angle` 实际记录的是电机轴角，就必须先按传动比、方向和零点换算到轮组侧，或在函数内部完成等价处理；不能直接把电机侧角度与轮组侧角度比较。

### 5.3 保存位置目标

```c
motors[0].prv.target_pos = wheel_angle;
```

这句将计算结果保存到电机对象的目标位置字段。本片段按原笔记将其解释为**电机侧弧度**。

赋值语句本身只更新字段。原笔记说明后续控制代码通过 `DM_mit_ctrl()` 发送给达妙电机；实际发送位置、接口单位和调用顺序需在工程代码中核对。

## 6. 完整流程与数值例子

### 6.1 原笔记代码片段汇总

下面按原有顺序合并舵向计算片段。它依赖工程中的 `Turn_Optimize()`、电机对象和宏定义，不是独立可运行程序。

```c
// vx、vy：当前轮组的速度分量
float wheel_angle = atan2f(vy, vx);       // 轮组方向，rad
wheel_angle *= (180.0f / PI);            // 轮组方向，deg

wheel_angle = Turn_Optimize(
    &motors[0],
    wheel_angle,
    motors[0].prv.total_angle             // 须确认机械侧、单位和零点一致
);                                       // 优化后的轮组目标，deg

wheel_angle = wheel_angle * PI / 180.0f;  // 轮组目标，rad
wheel_angle *= Gear_Ratio;               // 电机侧目标，rad
motors[0].prv.target_pos = wheel_angle;   // 保存位置目标
```

### 6.2 右前方运动示例

假设当前轮组舵角为 $0^\circ$，速度分量为 $v_{ix}=1\ \text{m/s}$、$v_{iy}=1\ \text{m/s}$，舵向传动比为 4.3，零点与方向均已对齐。

| 步骤 | 结果 | 此时表示什么 |
| --- | --- | --- |
| 求速度大小 | $\sqrt{2}\approx1.4142\ \text{m/s}$ | 行进线速度大小 |
| `atan2f(vy, vx)` | $0.7854\ \text{rad}$ | 原始轮组运动方向 |
| 乘 $180/\pi$ | $45^\circ$ | 轮组方向，度 |
| `Turn_Optimize()` | $45^\circ$，方向系数 $+1$ | 转舵 45°，行进轮正转 |
| 乘 $\pi/180$ | $0.7854\ \text{rad}$ | 轮组侧目标弧度 |
| 乘 4.3 | $3.3772\ \text{rad}$ | 电机侧目标弧度 |
| 写入 `target_pos` | $3.3772$ | 保存的位置目标 |

> [!summary] 阅读代码时抓住三件事
> 1. 速度分量由平移项与旋转项相加得到，正负号由坐标约定决定。
> 2. 舵向优化必须同时考虑舵角和行进轮的正反转。
> 3. `wheel_angle` 先后表示轮组弧度、轮组度数、轮组弧度、电机弧度；每一步都要分清**单位和机械侧**。
