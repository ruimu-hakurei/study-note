# 流程控制与循环

> 控制流只有三件事：**顺序执行、按条件分支、回到前面重复**；`break`、`continue` 和 `return` 只是改变下一条要执行的语句。

---

## 一、条件到底怎样判真

C 没有要求条件表达式必须产生 `bool`：

- 数值为 `0` 表示假。
- 非零数值表示真。
- 空指针表示假，非空指针表示真。

```c
int count = 3;

if (count) {          // 等价于 count != 0
    puts("还有数据");
}
```

常见关系与逻辑运算符：

| 类别 | 运算符 | 结果 |
|---|---|---|
| 比较 | `< <= > >= == !=` | 成立为 1，不成立为 0 |
| 逻辑与 | `&&` | 两边都真才真 |
| 逻辑或 | `||` | 至少一边真就真 |
| 逻辑非 | `!` | 真变假、假变真 |

### 短路求值与执行顺序

`&&` 左边为假时不再算右边，`||` 左边为真时不再算右边。这不只是优化，还常用于保护危险操作：

```c
if (p != NULL && *p > 0) {
    // 只有 p 非空时才会执行 *p，避免解引用空指针
}
```

> ⚠️ `=` 是赋值，`==` 才是相等比较。`if (x = 0)` 会把 `x` 改成 0，然后条件恒假。编译警告通常能发现这类错误。

## 二、`if`、`else if` 与 `else`

```c
if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';
} else {
    grade = 'C';
}
```

分支从上到下判断，一旦某个条件成立，其余分支就不会执行。因此范围判断通常要从更严格的一端开始。

即使分支只有一句，也建议保留大括号：

```c
if (ready) {
    start_motor();
}
```

这样以后增加语句时，不会因为漏加大括号而让代码悄悄跑出分支。

## 三、`switch`：对离散值做多路分支

### 1. 标准结构

```c
switch (expression) {
    case CONSTANT_1:
        /* 处理第 1 种值 */
        break;

    case CONSTANT_2:
        /* 处理第 2 种值 */
        break;

    default:
        /* 所有 case 都不匹配 */
        break;
}
```

执行时先计算 `expression` 一次，再跳到匹配的 `case` 标签；找不到匹配项时跳到 `default`，没有 `default` 就直接离开 `switch`。

### 2. 硬性规则

1. 控制表达式必须具有**整数类型或枚举类型**；不能直接用浮点数或字符串。
2. `case` 后必须是整型常量表达式，例如字面量、枚举常量或可在编译期确定的整数表达式，不能是普通变量。
3. 同一个 `switch` 中，转换后的 `case` 值不能重复。
4. `default` 可选，而且语法上可以放在任意位置；习惯上放在末尾最清晰。
5. `break` 不是语法强制要求，但多数互斥分支都需要它。

原笔记将规则简化成“只能是整数/字符，`break` 必写”。更准确地说，`char` 本来就是整数类型，而遗漏 `break` 会发生**贯穿**，有时正是程序故意需要的行为。

### 3. 贯穿与合并 `case`

```c
switch (month) {
    case 1:
    case 3:
    case 5:
    case 7:
    case 8:
    case 10:
    case 12:
        days = 31;  // 多个标签共享同一段代码
        break;

    case 4:
    case 6:
    case 9:
    case 11:
        days = 30;
        break;

    default:
        days = 0;
        break;
}
```

若一个有语句的分支要故意贯穿到下一个分支，应写清注释：

```c
case ROLE_ADMIN:
    enable_admin_tools();
    /* 有意贯穿：管理员也拥有普通用户权限 */
case ROLE_USER:
    enable_user_tools();
    break;
```

### 4. `switch` 与 `if` 怎么选

| 问题 | 更自然的写法 |
|---|---|
| 是否等于几个离散常量 | `switch` |
| 范围、大小关系、多个逻辑条件 | `if` / `else if` |
| 字符串内容是否相同 | `strcmp` 配合 `if` |

## 四、三种循环的执行模型

### 1. `for`：把循环三要素放在一起

```c
for (int i = 0; i < 5; ++i) {
    printf("%d ", i);
}
```

执行顺序：

```text
初始化（一次）
      │
      ▼
判断条件 ──假──→ 离开循环
      │真
      ▼
   循环体
      │
      ▼
  迭代表达式
      └────────→ 回到判断条件
```

### 2. `while`：先判断，再执行

```c
int i = 0;
while (i < 5) {
    printf("%d ", i);
    ++i;
}
```

### 3. `do-while`：先执行一次，再判断

```c
int choice;
do {
    printf("请输入 0 退出：");
    scanf("%d", &choice);
} while (choice != 0);  // 末尾分号不能漏
```

即使条件最初是假，`do-while` 的循环体也至少执行一次，适合菜单、先输入再校验等场景。

### 4. `for` 与 `while` 不是能力不同

原笔记的口诀“固定次数用 `for`，次数未知用 `while`”是很好的选型经验，但不是语法限制。二者都能表达同样的循环：

```c
for (initialization; condition; iteration) {
    body;
}

/* 常见情况下可改写为 */
initialization;
while (condition) {
    body;
    iteration;
}
```

需要特别注意：一旦循环体里有 `continue`，机械改写可能改变行为，因为 `for` 的 `continue` 会先执行迭代表达式，而 `while` 的 `continue` 会直接回到条件判断。

## 五、`break` 与 `continue` 的精确目标

| 语句 | 作用 | 可以出现在哪里 |
|---|---|---|
| `break` | 离开**最内层**循环或 `switch` | 循环、`switch` |
| `continue` | 结束最内层循环的本轮，进入下一轮 | 循环体内 |
| `return` | 结束当前函数，可把结果带回调用处 | 函数内 |

### 1. `break` 只退出最内层

```c
for (int row = 0; row < 3; ++row) {
    for (int col = 0; col < 3; ++col) {
        if (col == 1) {
            break;  // 只退出 col 循环；row 循环继续
        }
        printf("(%d,%d) ", row, col);
    }
}
```

### 2. `continue` 去哪里

- 在 `for` 中：跳到迭代表达式，然后判断条件。
- 在 `while` 中：直接跳到条件判断。
- 在 `do-while` 中：跳到底部条件判断。

```c
for (int i = 1; i <= 5; ++i) {
    if (i == 3) {
        continue;
    }
    printf("%d ", i);  // 输出 1 2 4 5
}
```

原笔记说“`switch` 只能用 `break`，不能用 `continue`”需要补充上下文：孤立的 `switch` 不是循环，确实不能以它作为 `continue` 目标；但若 `switch` 位于循环内部，`continue` 可以继续**外层循环**。

```c
for (int i = 0; i < 4; ++i) {
    switch (i) {
        case 1:
            continue;  // 合法：继续最近的 for 循环，不是继续 switch
        default:
            printf("%d ", i);
            break;
    }
}
// 输出：0 2 3
```

## 六、边界、死循环与常见错误

### 1. 差一错误

```c
int a[5];
for (int i = 0; i < 5; ++i) {  // 合法下标 0~4，所以是 < 5
    a[i] = i;
}
```

处理数组时，推荐把区间理解为左闭右开 `[0, length)`，循环条件自然写成 `i < length`。

### 2. 多余分号

```c
while (condition);  // 这个分号构成了空循环体
{
    work();          // 这里只是循环结束后的普通代码块
}
```

`do-while` 末尾的分号必须有，普通 `while` 条件后的分号通常是错误，两者不要混淆。

### 3. `continue` 跳过更新

```c
int i = 0;
while (i < 10) {
    if (should_skip(i)) {
        ++i;       // 若更新写在后面，这里必须先更新
        continue;
    }
    work(i);
    ++i;
}
```

若遗漏分支内的 `++i`，循环可能永远停在同一个值。用 `for` 把更新放进迭代表达式，常能减少这种错误。

### 4. 无符号倒数循环

```c
for (size_t i = n; i-- > 0;) {
    printf("%zu ", i);  // 条件先比较旧值，再执行 i--，可安全遍历 n-1 到 0
}
```

不要写 `for (size_t i = n - 1; i >= 0; --i)`：无符号数永远不会小于 0，且 `n == 0` 时初值就已回绕。

## 七、综合示例：循环菜单计算器

这个程序使用 `do-while` 保证菜单至少显示一次，用 `switch` 处理离散操作，用 `continue` 在输入失败后开始下一轮，用 `break` 离开 `switch`，最终由状态变量结束外层循环。

```c
#include <stdio.h>

int main(void)
{
    int running = 1;

    do {
        char op;
        double left;
        double right;
        double result = 0.0;
        int has_result = 1;

        printf("\n请选择 + - * /，输入 q 退出：");
        if (scanf(" %c", &op) != 1) {
            puts("输入结束");
            break;  // 离开 do-while
        }

        if (op == 'q' || op == 'Q') {
            running = 0;
            continue;  // 跳到底部条件判断，此轮不再读取两个数
        }

        printf("请输入两个数：");
        if (scanf("%lf %lf", &left, &right) != 2) {
            int c;
            puts("数字格式错误，本行剩余内容已丢弃");
            while ((c = getchar()) != '\n' && c != EOF) {
                /* 难点：必须消耗造成转换失败的字符，否则下一轮 scanf 会再次卡在原处。 */
            }
            continue;
        }

        switch (op) {
            case '+':
                result = left + right;
                break;
            case '-':
                result = left - right;
                break;
            case '*':
                result = left * right;
                break;
            case '/':
                if (right == 0.0) {
                    puts("除数不能为 0");
                    has_result = 0;
                } else {
                    result = left / right;
                }
                break;
            default:
                puts("未知运算符");
                has_result = 0;
                break;
        }

        if (has_result) {
            printf("结果：%.6g\n", result);
        }
    } while (running);

    puts("程序结束");
    return 0;
}
```

> 这里用 `running` 控制外层循环，是因为 `switch` 内部的 `break` 只会退出 `switch`，不能顺便退出包住它的循环。

## 八、做题判断流程

1. 先问“条件是范围还是离散常量”：范围通常用 `if`，离散常量可用 `switch`。
2. 再问“循环体是否必须先执行一次”：必须则考虑 `do-while`。
3. 能一眼写出初始化、条件、更新时优先 `for`；状态驱动时常用 `while`。
4. 看到 `break`，确认它退出的是哪一个最内层结构。
5. 看到 `continue`，确认本轮必要的状态更新是否已经完成。
6. 最后代入 0 次、1 次、最后一次和越界后一位，检查边界。
