# 链表与动态内存

> 链表不是“会背几个操作”就算掌握。它的本质是：**多个生命周期独立、地址不连续的节点，通过指针保存的地址形成关系；每次修改都必须同时维护链接不变量与所有权不变量**。

---

## 一、从连续数组到分散节点

数组把同类型元素放在一段连续内存中：

```text
数组
+----+----+----+----+
| 10 | 20 | 30 | 40 |
+----+----+----+----+
  ^    ^
  |    +-- 相邻元素地址相差 sizeof(int)
  +------- 数组首元素
```

链表的节点可以由多次 `malloc` 分别得到，物理地址不需要相邻。节点中的 `next` 保存下一个节点的地址：

```text
逻辑顺序：10 -> 20 -> 30

head
  |
  v
地址 0x5000              地址 0x91A0              地址 0x6080
+----------+-----+       +----------+-----+       +----------+------+
| value=10 | next| ----> | value=20 | next| ----> | value=30 | NULL |
+----------+-----+       +----------+-----+       +----------+------+
```

```c
typedef struct Node Node;

struct Node {
    int value;
    Node *next;
};
```

`Node` 内嵌自己的指针而不是完整的 `Node`，所以类型大小有限。每次读 `current->next`，程序都是从当前节点中取出一个地址值，再沿地址访问另一个对象。

| 对比项 | 数组 | 单链表 |
|---|---|---|
| 元素位置 | 连续 | 可分散 |
| 按下标访问 | `O(1)` | 必须从头走，`O(n)` |
| 已知位置后的插入 | 常需搬移后续元素 | 改链接即可，`O(1)` |
| 缓存局部性 | 通常好 | 通常较差 |
| 额外空间 | 很少 | 每个节点有指针与分配器开销 |
| 扩容 | 可能整体重新分配 | 每个节点独立申请 |

> ⚠️ “链表插入是 `O(1)`”有前提：已经拿到插入位置。若先按值查找位置，查找本身仍是 `O(n)`。

## 二、用 `List` 保存头、尾和长度

只有一个 `Node *head` 也能表示链表，但增加尾指针和长度能让尾插、判空和取长度更方便：

```c
typedef struct {
    Node *head;
    Node *tail;
    size_t size;
} List;
```

此类型应始终满足下面的不变量：

1. 空表：`head == NULL`、`tail == NULL`、`size == 0`。
2. 非空表：`head != NULL`、`tail != NULL`、`size > 0`。
3. `tail->next == NULL`。
4. 从 `head` 沿 `next` 恰好能访问 `size` 个节点，最后一个就是 `tail`。
5. 正常链表无环；任何节点最多由该链表拥有一次。
6. `List` 独占拥有所有可达节点，销毁链表时负责逐个 `free`。

```text
空表
+-------------------------------+
| head=NULL | tail=NULL | size=0 |
+-------------------------------+

非空表
+--------------------------------+
| head --+ | tail --------+ | 3   |
+---------|---------------|-------+
          v               v
        [10|*] -> [20|*] -> [30|NULL]
```

每个操作不只要“结果看起来对”，还必须保证返回时所有不变量仍成立。

## 三、头插、尾插、查找与所有权

### 1. 创建节点

```c
static Node *node_create(int value)
{
    Node *node = malloc(sizeof(*node));
    if (node == NULL) {
        return NULL;
    }

    node->value = value;
    node->next = NULL;
    return node; // 所有权：暂时返回给调用者
}
```

申请成功后，调用者必须在两条路径中选一条：

- 把节点链接进某个 `List`，将所有权转移给链表；
- 链接失败或不再需要时，自行 `free(node)`。

### 2. 头插

```text
插入前：head -> A -> B -> NULL
新节点：N

1. N->next = head
2. head = N

插入后：head -> N -> A -> B -> NULL
```

顺序不能反。如果先执行 `head = N`，却还没有保存旧 `head`，原链表入口就丢失了。

### 3. 尾插

有 `tail` 时，非空表尾插只需：

```text
tail->next = N
tail = N
```

但空表没有旧尾节点，必须同时令 `head = N` 和 `tail = N`。这一特殊情况不是语法问题，而是空表不变量决定的。

### 4. 查找返回的是借用指针

如果 `list_find` 返回某个 `Node *`，通常不代表调用者拥有节点。该地址只在节点仍留在链表且链表未销毁期间有效：

```text
List 独占拥有节点
        |
        +---- list_find 返回临时借用地址
                          |
                          +-- 不能 free
                          +-- 节点删除后立即悬空
```

只读查找最好返回 `const Node *`，用类型提醒调用者不要经该接口修改链接。

## 四、`Node **`：统一删除头节点与中间节点

删除节点时真正需要修改的不是“当前节点”，而是**指向当前节点的那个指针槽**：

```text
删除 A：要修改 list.head
list.head ----> A ----> B

删除 B：要修改 A.next
list.head ----> A ----> B ----> C
```

这两个槽的类型都是 `Node *`，它们的地址类型都是 `Node **`。因此可以让 `link` 始终指向“通往当前节点的指针槽”：

```c
Node **link = &list->head;

while (*link != NULL && (*link)->value != target) {
    link = &(*link)->next;
}
```

每一层含义要分清：

| 表达式 | 类型 | 含义 |
|---|---|---|
| `link` | `Node **` | 某个 `Node *` 指针槽的地址 |
| `*link` | `Node *` | 该槽当前指向的节点 |
| `**link` | `Node` | 节点对象本身 |
| `&(*link)->next` | `Node **` | 当前节点内 `next` 指针槽的地址 |

找到目标后，无论目标在头部还是中间，核心删除语句都相同：

```c
Node *victim = *link;
*link = victim->next;  // 让前一个“指针槽”越过 victim
free(victim);
```

```text
删除前：link ---> [某个指针槽] ---> victim ---> next
删除后：link ---> [同一指针槽] ----------------> next
```

如果 `List` 还维护 `tail`，删除尾节点时必须同步更新尾指针。完整实现会额外跟踪 `previous`；这不是 `Node **` 失效，而是 `tail` 属于另一份冗余元数据，也必须维护。

> ⚠️ `free(victim)` 之后不能再读 `victim->next`。必须先保存或完成改链，再释放节点。

## 五、复杂可运行示例：完整单链表

下面的程序实现并验证：头插、尾插、查找、`Node **` 删除、反转、销毁、Floyd 判环和稳定归并排序。难点注释集中解释链接不变量、边界和所有权。

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct Node Node;

struct Node {
    int value;
    Node *next;
};

typedef struct {
    Node *head;
    Node *tail;
    size_t size;
} List;

static void list_init(List *list)
{
    assert(list != NULL);
    *list = (List){0};
}

/*
 * Floyd 判环，并在有环时返回环入口；无环返回 NULL。
 * 返回值是借用地址，调用者绝不能 free。
 */
static const Node *list_cycle_entry(const List *list)
{
    if (list == NULL) {
        return NULL;
    }

    const Node *slow = list->head;
    const Node *fast = list->head;

    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;          // 慢指针每轮走一步
        fast = fast->next->next;    // 快指针每轮走两步

        if (slow == fast) {
            // 难点：相遇后，一指针回到 head；二者都改为每轮走一步。
            // 下一次相遇的位置恰好是环入口。
            const Node *from_head = list->head;
            while (from_head != slow) {
                from_head = from_head->next;
                slow = slow->next;
            }
            return from_head;
        }
    }

    return NULL;
}

static bool list_invariant(const List *list)
{
    if (list == NULL) {
        return false;
    }

    if (list->head == NULL) {
        return list->tail == NULL && list->size == 0;
    }

    if (list->tail == NULL || list->size == 0 ||
        list->tail->next != NULL || list_cycle_entry(list) != NULL) {
        return false;
    }

    size_t count = 0;
    const Node *last = NULL;
    for (const Node *node = list->head; node != NULL; node = node->next) {
        last = node;
        ++count;
    }

    return last == list->tail && count == list->size;
}

static Node *node_create(int value)
{
    Node *node = malloc(sizeof(*node));
    if (node == NULL) {
        return NULL;
    }

    node->value = value;
    node->next = NULL;
    return node;
}

static bool list_push_front(List *list, int value)
{
    assert(list_invariant(list));

    Node *node = node_create(value);
    if (node == NULL) {
        return false; // 失败保证：申请发生在改链之前，原表完全不变
    }

    node->next = list->head;
    list->head = node;

    // 边界：原来为空时，新节点同时是头和尾。
    if (list->tail == NULL) {
        list->tail = node;
    }

    ++list->size;
    assert(list_invariant(list));
    return true; // 所有权：node 已转移给 list
}

static bool list_push_back(List *list, int value)
{
    assert(list_invariant(list));

    Node *node = node_create(value);
    if (node == NULL) {
        return false;
    }

    if (list->tail == NULL) {
        // 边界：空表没有可写的 tail->next。
        list->head = node;
    } else {
        list->tail->next = node;
    }

    list->tail = node;
    ++list->size;
    assert(list_invariant(list));
    return true;
}

static const Node *list_find(const List *list, int target)
{
    if (list == NULL) {
        return NULL;
    }

    for (const Node *node = list->head; node != NULL; node = node->next) {
        if (node->value == target) {
            return node; // 借用：删除该节点或销毁链表后，此地址失效
        }
    }
    return NULL;
}

static bool list_erase_first(List *list, int target)
{
    assert(list_invariant(list));

    Node **link = &list->head;
    Node *previous = NULL;

    while (*link != NULL && (*link)->value != target) {
        previous = *link;

        // 难点：link 不指向节点，而指向“通往下一个候选节点的指针槽”。
        // 第一次可能是 &list->head，之后可能是 &previous->next。
        link = &(*link)->next;
    }

    if (*link == NULL) {
        return false; // 未找到，链表不变
    }

    Node *victim = *link;
    *link = victim->next; // 对头删和中间删除都是同一句

    if (victim == list->tail) {
        // 边界：删唯一节点时 previous 为 NULL，头尾都会变成 NULL。
        list->tail = previous;
    }

    free(victim);         // 所有权：节点从链表脱离后，由此函数释放
    --list->size;
    assert(list_invariant(list));
    return true;
}

static void list_reverse(List *list)
{
    assert(list_invariant(list));

    Node *previous = NULL;
    Node *current = list->head;
    Node *old_head = list->head;

    while (current != NULL) {
        // 难点：改写 current->next 前必须先保存原后继，否则余下链表会失联。
        Node *next = current->next;
        current->next = previous;
        previous = current;
        current = next;
    }

    list->head = previous;
    list->tail = old_head; // 旧头反转后成为新尾；空表时二者仍为 NULL
    assert(list_invariant(list));
}

static Node *split_half(Node *head)
{
    Node *slow = head;
    Node *fast = head->next;

    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }

    Node *second = slow->next;
    slow->next = NULL; // 难点：必须断开，递归处理的才是两条有限子链
    return second;
}

static Node *merge_sorted(Node *left, Node *right)
{
    Node dummy = {0, NULL};
    Node *merged_tail = &dummy;

    while (left != NULL && right != NULL) {
        // 使用 <= 保持稳定性：相等时先取原来位于左半部分的节点。
        Node **chosen = left->value <= right->value ? &left : &right;

        merged_tail->next = *chosen;
        *chosen = (*chosen)->next;
        merged_tail = merged_tail->next;
    }

    merged_tail->next = left != NULL ? left : right;

    // dummy 是栈上哨兵，仅用于简化首节点链接；返回链从不指回 dummy。
    return dummy.next;
}

static Node *merge_sort_nodes(Node *head)
{
    if (head == NULL || head->next == NULL) {
        return head;
    }

    Node *second = split_half(head);
    Node *left = merge_sort_nodes(head);
    Node *right = merge_sort_nodes(second);
    return merge_sorted(left, right);
}

static void list_sort(List *list)
{
    assert(list_invariant(list));

    if (list->size < 2) {
        return;
    }

    // 所有权：排序只重连已有节点，不申请、不释放，也不复制节点。
    list->head = merge_sort_nodes(list->head);

    // 归并函数只返回新头，因此重新寻找并记录新尾。
    Node *tail = list->head;
    while (tail->next != NULL) {
        tail = tail->next;
    }
    list->tail = tail;

    assert(list_invariant(list));
}

static void list_print(const List *list)
{
    if (list == NULL) {
        return;
    }

    for (const Node *node = list->head; node != NULL; node = node->next) {
        printf("%d%s", node->value, node->next == NULL ? "\n" : " -> ");
    }

    if (list->head == NULL) {
        puts("<empty>");
    }
}

static void list_destroy(List *list)
{
    assert(list_invariant(list)); // 前置条件：链表无环且结构完整

    Node *current = list->head;
    while (current != NULL) {
        // 难点：free 后 current 已不再是有效对象，必须提前保存 next。
        Node *next = current->next;
        free(current);
        current = next;
    }

    // 所有节点都已释放；同步恢复合法空表状态。
    list->head = NULL;
    list->tail = NULL;
    list->size = 0;
    assert(list_invariant(list));
}

int main(void)
{
    int exit_code = EXIT_FAILURE;
    int input[] = {7, 3, 9, 3, 1, 8};
    List list;
    list_init(&list);

    for (size_t i = 0; i < sizeof(input) / sizeof(input[0]); ++i) {
        if (!list_push_back(&list, input[i])) {
            fputs("out of memory\n", stderr);
            goto cleanup; // 失败路径：销毁此前已经成功加入的节点
        }
    }

    if (!list_push_front(&list, 10)) {
        fputs("out of memory\n", stderr);
        goto cleanup;
    }

    printf("initial : ");
    list_print(&list);

    const Node *found = list_find(&list, 9);
    printf("find 9  : %s\n", found == NULL ? "no" : "yes");
    // 边界：found 只是借用地址。若删除该节点，之后就不能再解引用 found。

    (void)list_erase_first(&list, 3); // 只删除第一次出现的 3
    printf("erase 3 : ");
    list_print(&list);

    list_reverse(&list);
    printf("reverse : ");
    list_print(&list);

    list_sort(&list);
    printf("sorted  : ");
    list_print(&list);

    printf("cycle   : %s\n",
           list_cycle_entry(&list) == NULL ? "no" : "yes");

    exit_code = EXIT_SUCCESS;

cleanup:
    list_destroy(&list);
    return exit_code;
}
```

可能的输出：

```text
initial : 10 -> 7 -> 3 -> 9 -> 3 -> 1 -> 8
find 9  : yes
erase 3 : 10 -> 7 -> 9 -> 3 -> 1 -> 8
reverse : 8 -> 1 -> 3 -> 9 -> 7 -> 10
sorted  : 1 -> 3 -> 7 -> 8 -> 9 -> 10
cycle   : no
```

### 操作复杂度

| 操作 | 时间复杂度 | 是否申请/释放节点 |
|---|---:|---|
| 头插 | `O(1)` | 申请 1 个 |
| 有尾指针的尾插 | `O(1)` | 申请 1 个 |
| 按值查找 | `O(n)` | 否 |
| 删除第一个匹配值 | `O(n)` | 释放至多 1 个 |
| 反转 | `O(n)` | 否，只改链接 |
| Floyd 判环 | `O(n)` 时间、`O(1)` 空间 | 否 |
| 归并排序 | `O(n log n)` | 否，只改链接；递归栈约 `O(log n)` |
| 销毁 | `O(n)` | 释放全部节点 |

> ⚠️ 表中的复杂度指正式操作本身。示例为了教学，在每次修改前后都用 `assert(list_invariant(list))` 做了 `O(n)` 的完整巡检；定义 `NDEBUG` 后这些断言会被移除。实际项目可在调试构建保留重检查，在发布构建只执行必要的局部维护。

## 六、反转时真正维护的循环不变量

反转循环中的三个指针把节点划成两部分：

```text
已经反转的前缀              尚未处理的后缀
NULL <- A <- B              C -> D -> NULL
             ^              ^
          previous       current
```

每轮开始都保持：

- `previous` 是“已反转前缀”的头。
- `current` 是“未处理后缀”的头。
- 两部分加在一起仍恰好包含原链表全部节点。

一轮的顺序是：

```c
Node *next = current->next; // 1. 保存后缀入口
current->next = previous;   // 2. 当前节点转向前缀
previous = current;         // 3. 扩大已反转前缀
current = next;             // 4. 移到剩余后缀
```

若先执行第 2 步却没保存 `next`，原后缀入口会丢失，剩余节点成为无法访问但尚未释放的泄漏对象。

空表和单节点表不需要额外分支：

- 空表时循环零次，`previous` 与 `old_head` 都是 `NULL`。
- 单节点表时循环一次，把唯一节点的 `next` 设为 `NULL`，头尾仍指向它。

## 七、Floyd 判环：快慢指针为什么能找到入口

链表一旦出现环，普通遍历和普通销毁都可能永远循环：

```text
head -> A -> B -> C -> D
                 ^    |
                 +----+
```

Floyd 算法分两阶段：

1. `slow` 每次走 1 步，`fast` 每次走 2 步。若无环，`fast` 最终到 `NULL`；若有环，快指针会在环内追上慢指针。
2. 相遇后把一根指针放回 `head`，两根都每次走 1 步；再次相遇处就是环入口。

第二阶段可用距离关系理解。设：

- 头到环入口距离为 `a`；
- 环入口到第一次相遇点距离为 `b`；
- 环长为 `L`。

第一次相遇时，快指针比慢指针多走整数圈，因此可推出 `a` 与“相遇点继续走到入口的距离”相差整数个环长。于是从头走 `a` 步和从相遇点走 `a` 步会同时到达入口。

> ⚠️ 判出有环不等于链表可以直接销毁。普通 `list_destroy` 以遇到 `NULL` 为终止条件，对有环链表不适用。若程序允许接收损坏链表，应先定位入口、找到环内指向入口的最后节点并断环，再重建 `tail` 与 `size`；更常见的做法是把环视为不变量被破坏，用调试工具追查错误来源。

常见成环原因：

- 尾插时错误地把新尾的 `next` 指向旧节点。
- 拼接两条链时，两条链其实共享节点。
- 删除或反转时使用了已过期的地址。
- 同一节点被重复插入同一条或多条“独占拥有”的链表。

## 八、为什么链表常用归并排序

数组的快速排序可以高效交换下标位置，链表却不能 `O(1)` 随机访问第 `i` 个节点。归并排序只需要顺序访问，尤其适合链表：

```text
原链： 7 -> 3 -> 9 -> 1
              |
              v
拆分： 7 -> 3      9 -> 1
         |            |
         v            v
排序： 3 -> 7      1 -> 9
         \            /
          \          /
           v        v
归并： 1 -> 3 -> 7 -> 9
```

三个关键动作：

1. **拆分**：快慢指针找到中点，并把前半段尾部的 `next` 设为 `NULL`。
2. **递归排序**：分别排序左右子链。
3. **有序归并**：比较两个链头，摘下较小者接到结果尾部。

示例中的排序不创建或销毁节点，只改变 `next`；因此节点所有权仍属于原 `List`，但所有指向“某个节点前驱”的旧借用假设都会失效。

选择相等元素时用 `<=` 先取左链节点，能保持稳定性：相等键的原相对顺序不变。递归版本使用约 `O(log n)` 调用栈；极大链表可改为自底向上的迭代归并，避免递归栈。

## 九、双向循环链表与哨兵节点

单链表只能沿 `next` 向前走。若需要从已知节点 `O(1)` 删除、双向遍历，节点可同时保存 `prev` 与 `next`：

```c
typedef struct DNode DNode;

struct DNode {
    int value;
    DNode *prev;
    DNode *next;
};
```

若仍用 `NULL` 表示两端，插入删除经常需要判断“是不是头”“是不是尾”。把一个不保存业务数据的 **哨兵节点** 永久放在环中，可统一边界。

```text
空表：
          +----------------+
          |                |
          v                |
       [ root ]-------------+
       root.next == &root
       root.prev == &root

非空：
       +-----------------------------------+
       |                                   |
       v                                   |
     [root] <-> [10] <-> [20] <-> [30] <--+
```

不变量变成：

1. `root` 永远存在，绝不能释放。
2. 空表时 `root.next == &root` 且 `root.prev == &root`。
3. 对环内任意节点 `x`，都有 `x->next->prev == x` 与 `x->prev->next == x`。
4. 第一个数据节点是 `root.next`，最后一个是 `root.prev`。
5. 遍历到 `&root` 结束，而不是遍历到 `NULL`。

下面是核心实现：

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdlib.h>

typedef struct DNode DNode;

struct DNode {
    int value;
    DNode *prev;
    DNode *next;
};

typedef struct {
    DNode root;   // 哨兵内嵌在 DList 中，不是 malloc 得到的节点
    size_t size;
} DList;

static void dlist_init(DList *list)
{
    assert(list != NULL);
    list->root.prev = &list->root;
    list->root.next = &list->root;
    list->size = 0;
}

static bool dlist_empty(const DList *list)
{
    return list->root.next == &list->root;
}

static DNode *dnode_create(int value)
{
    DNode *node = malloc(sizeof(*node));
    if (node == NULL) {
        return NULL;
    }
    node->value = value;
    node->prev = NULL;
    node->next = NULL;
    return node;
}

/* 把尚未入链的 node 插到 pos 前面。pos 可以是哨兵。 */
static void dlink_before(DNode *pos, DNode *node)
{
    // 难点：先让新节点记住两侧，再让两侧节点反向指回新节点。
    node->prev = pos->prev;
    node->next = pos;
    pos->prev->next = node;
    pos->prev = node;
}

static bool dlist_push_back(DList *list, int value)
{
    DNode *node = dnode_create(value);
    if (node == NULL) {
        return false; // 申请失败前未改环，原链不变
    }

    // 把节点插到 root 前面，恰好就是插到当前尾节点后面。
    dlink_before(&list->root, node);
    ++list->size;
    return true; // 所有权：node 转移给 list
}

/* 前置条件：node 是 list 中的数据节点，且 node != &list->root。 */
static void dlist_erase(DList *list, DNode *node)
{
    assert(list != NULL);
    assert(node != NULL && node != &list->root);

    // 两侧跨过 node，空表/头/尾都不需要单独分支。
    node->prev->next = node->next;
    node->next->prev = node->prev;

    // 调试习惯：先断开已脱链节点，避免误把旧链接当作仍有效。
    node->prev = NULL;
    node->next = NULL;
    free(node);
    --list->size;
}

static void dlist_destroy(DList *list)
{
    while (!dlist_empty(list)) {
        // 每次删除 root.next；最后会自动恢复 root 自环。
        dlist_erase(list, list->root.next);
    }
}
```

若遍历过程中可能删除当前节点，要先保存后继：

```c
DNode *current = list.root.next;
while (current != &list.root) {
    DNode *next = current->next; // 删除 current 前保存；删除后不能再读 current
    if (current->value < 0) {
        dlist_erase(&list, current);
    }
    current = next;
}
```

> ⚠️ `dlist_erase` 的前置条件很重要。裸指针本身不记录“属于哪条链”，把另一条链的节点传进来会破坏两条链；删除哨兵则会破坏整个表示。生产接口可额外保存所属链信息或只把节点操作暴露在实现文件内部。

## 十、动态内存、借用地址与失效规则

链表代码最常见的问题不是算法思路，而是生命周期：

```c
const Node *borrowed = list_find(&list, 9);
list_erase_first(&list, 9);
printf("%d\n", borrowed->value); // 错误：borrowed 已悬空
```

常见地址失效规则：

| 操作 | 哪些地址仍有效 | 哪些假设失效 |
|---|---|---|
| 头插/尾插 | 原有节点地址仍有效 | 旧尾“仍是尾”的假设失效 |
| 反转 | 所有节点地址仍有效 | 所有前驱/后继关系都改变 |
| 归并排序 | 所有节点地址仍有效 | 顺序与邻接关系改变 |
| 删除节点 | 其他节点地址仍有效 | 被删节点及其成员地址立即失效 |
| 销毁链表 | 无节点地址有效 | 所有借用地址失效 |

因为节点分别分配，改链通常不会移动节点本身；但“地址未变”不代表“它在链中的位置未变”。若外部代码长期保存节点指针，应把有效期与允许的操作写进接口约定。

## 十一、链表调试检查清单

每写完一个修改操作，至少代入空表、单节点和多节点三种情况，并检查：

1. 空表是否保持 `head == tail == NULL`？
2. 非空时 `tail->next` 是否仍为 `NULL`？
3. `size` 是否与从头可达的节点数一致？
4. 修改 `next` 前，是否先保存了仍要访问的后继地址？
5. 新节点申请失败时，原链是否保持不变？
6. 节点脱链后由谁释放？返回的节点指针是拥有还是借用？
7. `free` 后是否还有任何路径解引用旧地址？
8. 同一节点是否可能被重复插入、重复释放或被两条独占链共享？
9. 反转、排序和拼接后，是否重建了 `tail` 等辅助元数据？
10. 若使用循环哨兵，遍历终点是否是哨兵而不是 `NULL`？

> ✅ 链表操作可以概括为三步：先保存不能丢的地址，再改写最少的链接，最后更新所有权与辅助元数据。
