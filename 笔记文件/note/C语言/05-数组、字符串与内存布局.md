# 数组、字符串与内存布局

> 数组解决的是“把一批同类型对象连续放在一起”，字符串则是在字符数组上额外约定“用 `'\0'` 标记结束”。理解连续性、容量和生命周期，比背下标语法更重要。

---

## 一、数组不是指针，而是一整块连续对象

### 1. 数组的本质

```c
int scores[5] = {91, 84, 76, 95, 88};
```

`scores` 的类型是“含 5 个 `int` 的数组”，整个数组对象内部有 5 个连续排列的元素：

```text
scores
低地址                                                       高地址
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ scores[0]│ scores[1]│ scores[2]│ scores[3]│ scores[4]│
│    91    │    84    │    76    │    95    │    88    │
└──────────┴──────────┴──────────┴──────────┴──────────┘
   +0         +1个int     +2个int     +3个int     +4个int
```

相邻元素的起始地址相差 `sizeof(int)` 个字节：

```c
&scores[1] == &scores[0] + 1
scores[3]  == *(scores + 3)
```

> ✅ `a[i]` 按定义等价于 `*(a + i)`。下标语法本质上仍是“地址移动后解引用”。

数组的几个关键性质：

- 所有元素类型相同。
- 元素按下标顺序连续排列。
- 数组长度确定后不能在原地增长或缩短。
- C 不检查下标是否越界。
- 数组对象不能用赋值运算符整体赋值，也不能对数组标识符执行 `++`。

> ⚠️ 原笔记把“数组名”称为“首元素地址的常量”。这个说法便于记忆，但不够准确。`scores` 首先标识的是一个**数组对象**；只是在大多数表达式中，它会转换成指向首元素的指针。它不是一个可以单独存放、修改的指针变量。

### 2. 数组长度与容量

在数组仍保持数组类型的位置，可以这样求元素个数：

```c
size_t count = sizeof scores / sizeof scores[0];
```

也常写成宏：

```c
#define ARRAY_COUNT(a) (sizeof(a) / sizeof((a)[0]))
```

> ⚠️ `ARRAY_COUNT` 只适用于真正的数组。把指针传进去时，分子会变成指针大小，结果没有数组长度的意义。

## 二、`scores`、`&scores[0]` 和 `&scores`

下面三个表达式打印出来的数值地址通常相同，但**类型和步长不同**：

| 表达式 | 类型 | `+ 1` 后跨过 |
|---|---|---|
| `scores`（发生转换后） | `int *` | 一个 `int` |
| `&scores[0]` | `int *` | 一个 `int` |
| `&scores` | `int (*)[5]` | 整个 5 元素数组 |

```c
#include <stdio.h>

int main(void)
{
    int scores[5] = {91, 84, 76, 95, 88};

    printf("scores      = %p\n", (void *)scores);
    printf("&scores[0]  = %p\n", (void *)&scores[0]);
    printf("&scores     = %p\n", (void *)&scores);
    printf("scores + 1  = %p\n", (void *)(scores + 1));
    printf("&scores + 1 = %p\n", (void *)(&scores + 1));

    printf("数组总字节数 = %zu\n", sizeof scores);
    printf("元素个数     = %zu\n", sizeof scores / sizeof scores[0]);
    return 0;
}
```

> ⚠️ `%p` 要接收 `void *`，`sizeof` 的结果类型是 `size_t`，应使用 `%zu`。不要假设 `int` 一定为 4 字节、数据指针一定为 8 字节。

## 三、数组到指针的转换，也叫“数组退化”

### 1. 转换发生在大多数表达式中

当数组出现在大多数表达式里时，它会转换为指向首元素的指针：

```c
int values[4] = {10, 20, 30, 40};
int *p = values;                 // values 转换为 &values[0]
printf("%d\n", *(values + 2));   // 输出 30
```

常见的不转换场景有：

- 作为 `sizeof` 的操作数：`sizeof values` 得到整个数组大小。
- 作为一元 `&` 的操作数：`&values` 得到指向整个数组的指针。
- 字符串字面量直接初始化字符数组：`char text[] = "abc";` 会复制字符。

> ⚠️ 原笔记写成“退化只发生在数组传参时”，这是不准确的。转换发生在**大多数表达式**中；函数形参里的 `int a[10]` 还有一条专门规则——该数组形式会被调整为指针形参。

### 2. 函数形参不会保留数组长度

下面三个声明在函数形参中等价：

```c
void print_values(int values[100], size_t count);
void print_values(int values[],    size_t count);
void print_values(int *values,     size_t count);
```

函数真正接收到的是一个指针值的副本，而不是完整数组副本，所以必须额外传长度：

```c
static void print_values(const int values[], size_t count)
{
    for (size_t i = 0; i < count; ++i) {
        printf("%d%s", values[i], i + 1 == count ? "\n" : " ");
    }
}
```

在这个函数里，`sizeof values` 得到的是指针大小，而不是调用者数组的大小。

## 四、二维数组仍然是一整块连续内存

```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

它的类型是“含 2 个元素的数组”，而每个元素又是“含 3 个 `int` 的数组”：

```text
matrix
┌───────────────────────── 第 0 行 ─────────────────────────┐
│ matrix[0][0] │ matrix[0][1] │ matrix[0][2] │
│       1      │       2      │       3      │
└────────────────────────────────────────────────────────────┘
┌───────────────────────── 第 1 行 ─────────────────────────┐
│ matrix[1][0] │ matrix[1][1] │ matrix[1][2] │
│       4      │       5      │       6      │
└────────────────────────────────────────────────────────────┘

实际是一条连续序列：1, 2, 3, 4, 5, 6
```

在表达式中，`matrix` 转换为“指向首行的指针”，类型为 `int (*)[3]`：

```c
matrix + 1          // 跳过一整行，即 3 个 int
matrix[1]           // 第 1 行；随后通常再转换为 int *
matrix[1][2]        // 等价于 *(*(matrix + 1) + 2)
```

固定列数的传参方式：

```c
static void print_matrix(size_t rows, const int matrix[][3])
{
    for (size_t r = 0; r < rows; ++r) {
        for (size_t c = 0; c < 3; ++c) {
            printf("%d%s", matrix[r][c], c == 2 ? "\n" : " ");
        }
    }
}
```

支持 VLA 的 C99/C11 编译器还可以把列数作为运行期参数：

```c
static void print_vla(size_t rows, size_t cols,
                      const int matrix[rows][cols])
{
    for (size_t r = 0; r < rows; ++r) {
        for (size_t c = 0; c < cols; ++c) {
            printf("%d%s", matrix[r][c], c + 1 == cols ? "\n" : " ");
        }
    }
}
```

> ⚠️ 在二维数组形参中，最外层长度可以省略，但编译器必须知道每一行有多少列，才能计算 `matrix + r` 应跨过多少字节。VLA 从 C11 起属于可选特性，MSVC 等编译器可能不支持。

## 五、C 字符串是“以 `'\0'` 结束的字符序列”

C 没有独立的内置字符串类型。标准库所说的字符串，是从某个字符地址开始，到第一个空字符 `'\0'` 为止的一段字符序列。

```c
char word[] = "cat";
```

内存中实际有 4 个 `char`：

```text
word
┌─────┬─────┬─────┬──────┐
│ 'c' │ 'a' │ 't' │ '\0' │
└─────┴─────┴─────┴──────┘
  [0]   [1]   [2]    [3]

strlen(word) == 3
sizeof word  == 4
```

`sizeof(char)` 永远为 1 字节，但一个字节不由 C 标准保证必须恰好是 8 位；可通过 `CHAR_BIT` 查询。常见桌面系统使用 8 位字节和 ASCII 兼容字符集，字符编码细节见 [[01-数制、字符与数据表示]]。

### 1. 合法字符串与普通字符数组

```c
char a[] = "abc";                  // 4 个元素，末尾自动补 '\0'
char b[4] = "abc";                 // 合法字符串
char c[] = {'a', 'b', 'c', '\0'};  // 合法字符串

char raw[3] = {'a', 'b', 'c'};     // 普通字符数组，不是字符串
char exact[3] = "abc";             // C 允许，但容不下 '\0'，也不是字符串
```

> ⚠️ 对 `raw` 或 `exact` 调用 `strlen`、`printf("%s", ...)` 等字符串函数，会在数组外继续寻找 `'\0'`，行为未定义。编译器可能警告，但“暂时打印正常”不能说明代码正确。

### 2. 字符数组与字符串字面量指针

| 写法 | 字符存在哪里 | 能否修改字符 | 指针能否改指向 |
|---|---|---:|---:|
| `char text[] = "hello";` | `text` 数组自己的存储中 | 可以 | `text` 不是指针变量 |
| `const char *view = "hello";` | 字符串字面量的静态存储中 | 不可以 | 可以 |
| `char *heap_text = malloc(...);` | 动态分配的存储中 | 可以 | 可以 |

```c
char text[] = "hello";
text[0] = 'H';                 // 合法，修改数组副本

const char *view = "hello";
view = "world";                // 合法，只改变 view 保存的地址
// view[0] = 'H';              // 编译器应报错
```

在 C 中，字符串字面量具有静态存储期。尝试修改它的行为未定义；实际系统常把它放进只读区域，因此可能崩溃，但 C 标准并不保证一定以“段错误”的形式失败。

> ✅ 指向字符串字面量时使用 `const char *`，能在编译期阻止误修改。

## 六、存储期比“栈、堆四区”更准确

原笔记使用了常见的“代码区、常量区、全局区、栈区、堆区”模型。它适合观察典型桌面程序，但不是 C 标准规定的固定内存地图。更可靠的判断方式是看对象的**存储期**：

| 存储期 | 常见写法 | 对象何时有效 | 常见实现位置 |
|---|---|---|---|
| 自动存储期 | 普通局部数组 | 进入所在块后到离开该块 | 通常是调用栈 |
| 静态存储期 | 全局数组、`static` 数组、字符串字面量 | 整个程序运行期间 | 数据段或只读数据段 |
| 动态分配存储 | `malloc/calloc/realloc` 得到的区域 | 分配成功后到 `free` 或被 `realloc` 取代 | 通常称为堆 |

作用域和生命周期不是一回事：

- 作用域回答“此处能不能通过这个名字访问对象”。
- 生命周期回答“对象现在是否还存在”。

```c
const char *wrong(void)
{
    char local[] = "hello";
    return local;   // 错误：函数返回后 local 的生命周期结束
}
```

返回之后，即使旧地址数值还留在指针里，那个地址也不再指向一个仍处于生命周期内的 `local` 对象。

## 七、`sizeof` 与 `strlen` 不能互换

| 对比 | `sizeof` | `strlen` |
|---|---|---|
| 本质 | C 运算符 | `<string.h>` 中的函数 |
| 结果 | 对象或类型占多少字节 | 第一个 `'\0'` 前有多少字符 |
| 是否计入 `'\0'` | 只看对象大小，不关心终止符 | 不计终止符 |
| 前提 | 表达式或类型合法 | 参数必须指向可到达终止符的合法字符串 |
| 求值时机 | 非 VLA 通常可在编译期确定；VLA 可在运行期求值 | 运行时逐字符查找 |

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char buffer[10] = "abc";
    const char *view = buffer;

    printf("%zu\n", sizeof buffer);  // 10：整个数组容量
    printf("%zu\n", strlen(buffer)); // 3：当前字符串长度
    printf("%zu\n", sizeof view);    // 指针对象本身的大小
    printf("%zu\n", strlen(view));   // 3：仍从字符内容找到 '\0'
    return 0;
}
```

> ⚠️ `strlen` 不知道容量，也不能安全地“检测一个数组有没有 `'\0'`”。如果给它的范围内没有终止符，它在发现问题前就已经越界了。

## 八、用指针理解 `strlen` 与 `strcmp`

原笔记用指针实现了 `strlen`、`strcpy` 和 `strcmp`。其中“指针向后走到终止符”的模型是正确的，但无容量参数的复制函数很容易溢出，而且比较字符时还要考虑 `char` 的符号性。

```c
#include <stddef.h>

static size_t text_length(const char *text)
{
    const char *end = text;

    while (*end != '\0') {
        ++end;
    }

    /*
     * end 和 text 都指向同一个字符数组，因此可以相减。
     * 差值是终止符前的元素个数。
     */
    return (size_t)(end - text);
}

static int text_compare(const char *left, const char *right)
{
    while (*left != '\0' && *left == *right) {
        ++left;
        ++right;
    }

    /*
     * 标准 strcmp 按 unsigned char 的值比较。
     * 不直接依赖普通 char 在当前平台上是 signed 还是 unsigned。
     */
    unsigned char a = (unsigned char)*left;
    unsigned char b = (unsigned char)*right;
    return (a > b) - (a < b);
}
```

这两个函数与标准库函数一样，都要求输入已经是合法的 `'\0'` 结尾字符串；它们不能从一个裸指针推断缓冲区容量。

原笔记中的简写：

```c
while ((*destination++ = *source++) != '\0') {
    /* 复制 */
}
```

可以复制字符串，但函数若不知道目标容量，就无法阻止缓冲区溢出。工程代码应额外接收容量，并在写入前确认 `源长度 + 1 <= 目标容量`。

## 九、完整示例：带容量检查的字符串追加

这个例子不使用无边界的 `strcat`，而是同时维护“数组容量”和“当前字符串长度”。

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <string.h>

static bool append_text(char destination[], size_t capacity,
                        const char *source)
{
    if (destination == NULL || source == NULL || capacity == 0) {
        return false;
    }

    /*
     * 边界：memchr 最多检查 capacity 个字节。
     * 如果范围内找不到 '\0'，destination 当前就不是一个
     * 能装在该容量中的合法字符串；不能直接调用 strlen(destination)。
     */
    char *end = memchr(destination, '\0', capacity);
    if (end == NULL) {
        return false;
    }

    size_t used = (size_t)(end - destination);
    size_t added = strlen(source);  // 前提：source 本身是合法字符串

    /*
     * 难点：capacity - used - 1 是还能存放的“普通字符数”。
     * 最后的 1 个字节必须留给新的 '\0'。
     */
    if (added > capacity - used - 1) {
        return false;               // 失败前不修改 destination
    }

    /*
     * added + 1 把 source 的终止符也复制过去。
     * memmove 即使 source 与 destination 的区域重叠也能正确复制。
     */
    memmove(destination + used, source, added + 1);
    return true;
}

int main(void)
{
    char message[32] = "C";

    if (!append_text(message, sizeof message, " -> ")
        || !append_text(message, sizeof message, "memory")) {
        fputs("缓冲区容量不足\n", stderr);
        return 1;
    }

    printf("%s\n", message);  // C -> memory
    return 0;
}
```

这个函数始终区分：

- `capacity`：数组一共有多少字节。
- `used`：当前终止符之前已经用了多少字节。
- `added`：新内容有多少字节。
- 末尾终止符还需要额外 1 字节。

## 十、常见错误

### 1. 越界

```c
int values[3] = {1, 2, 3};
values[3] = 4;       // 未定义行为；合法下标只有 0、1、2
```

可以形成 `values + 3` 这个“尾后一位”指针用于比较或结束条件，但不能解引用它。

### 2. 把数组当成可赋值指针

```c
char text[16] = "hello";
// text = "world";   // 编译错误：数组对象不能整体赋值
strcpy(text, "world");
```

调用 `strcpy` 前仍必须确认目标容量足够。

### 3. 忘记终止符空间

容纳长度为 `n` 的普通单字节字符串，至少需要 `n + 1` 个 `char` 元素。

### 4. 在形参中用 `sizeof` 求调用者数组长度

```c
static void wrong(int values[])
{
    size_t n = sizeof values / sizeof values[0]; // 错：values 是指针形参
    (void)n;
}
```

### 5. 误把二维数组当成 `int **`

二维数组没有隐藏的“行指针表”。它转换后是数组指针，详细区别见 [[07-指针数组、数组指针与多级指针]]。

---

## 十一、一句话总结

> ✅ 数组是连续对象；数组表达式通常会转换为首元素指针，但数组本身不是指针。

> ✅ 字符数组只有在可访问范围内存在 `'\0'` 时，才能当作 C 字符串交给字符串函数。

> ✅ `sizeof` 看对象容量，`strlen` 看字符串当前内容长度；函数接收数组参数时必须另外获得长度。
