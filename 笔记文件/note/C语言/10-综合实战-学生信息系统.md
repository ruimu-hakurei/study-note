# 综合实战：学生信息链表与排序索引

> 用链表负责**拥有和管理学生对象**，再用指针数组建立**不拥有对象的排序视图**；这是结构体、链表、指针数组和动态内存最自然的一次汇合。

---

## 一、项目要解决什么问题

我们希望同时得到两种能力：

1. 学生可随时插入、删除，适合用链表保存。
2. 学生可按平均分排序，但排序不应搬动链表节点，适合用指针数组建立索引。

数据关系如下：

```
StudentList（拥有所有节点）
head
 │
 ▼
Node ─────→ Node ─────→ Node ─────→ NULL
 │           │           │
 │拥有       │拥有       │拥有
 ▼           ▼           ▼
Student     Student     Student
 ├─ name ─────→ 堆上的字符串
 └─ grades ───→ 堆上的 double 数组

StudentIndex（只拥有“地址表”，不拥有 Student）
items ──→ [ Student* ][ Student* ][ Student* ]
              │            │            │
              └────借用链表中对象的地址────┘
```

> ✅ **最关键的设计**：链表是对象的拥有者；索引只是观察者。销毁索引时只释放指针数组，不能释放它指向的学生。

---

## 二、所有权契约

| 资源 | 谁拥有 | 谁释放 | 什么时候失效 |
|---|---|---|---|
| `Node` | `StudentList` | `list_delete` / `list_destroy` | 节点被删除或链表销毁 |
| `Student.name` | 所在的 `Student` | `student_destroy` | 学生被销毁 |
| `Student.grades` | 所在的 `Student` | `student_destroy` | 学生被销毁 |
| `StudentIndex.items` | `StudentIndex` | `index_destroy` / 下次成功重建 | 索引被销毁或替换 |
| `items[i]` 指向的学生 | **链表**，索引只借用 | 索引不能释放 | 链表发生删除或整体销毁后可能悬空 |

为了避免误用旧索引，链表每次发生结构变化都会增加 `generation`；索引记录建立时的版本。两者不一致就拒绝读取。

---

## 三、完整可运行代码

下面的程序覆盖：深拷贝、失败回滚、尾插、查找、`Node **` 删除、反转、指针索引、`qsort` 比较器和过期索引检测。

```c
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    int id;
    char *name;          // 所有权：Student 独占这段堆字符串
    double *grades;      // 所有权：Student 独占这段堆数组
    size_t grade_count;
} Student;

typedef struct Node {
    Student value;       // 节点直接拥有一个 Student
    struct Node *next;
} Node;

typedef struct {
    Node *head;
    Node *tail;
    size_t size;
    unsigned long generation;  // 每次结构变化后加 1
} StudentList;

typedef struct {
    Student **items;             // 只拥有地址表，不拥有 Student
    size_t count;
    unsigned long source_generation;
} StudentIndex;

static char *duplicate_string(const char *text)
{
    size_t length;
    char *copy;

    if (text == NULL) {
        return NULL;
    }

    length = strlen(text);
    if (length == SIZE_MAX) {    // 边界：防止 length + 1 溢出
        return NULL;
    }

    copy = malloc(length + 1);
    if (copy != NULL) {
        memcpy(copy, text, length + 1);  // 连同末尾 '\0' 一起复制
    }
    return copy;
}

static void student_destroy(Student *student)
{
    if (student == NULL) {
        return;
    }

    free(student->name);
    free(student->grades);

    /*
     * 难点：free 只释放目标内存，不会自动修改保存地址的指针。
     * 置空不是为了“再次释放”，而是避免后续代码继续误用旧地址。
     */
    student->name = NULL;
    student->grades = NULL;
    student->grade_count = 0;
}

static int student_init(Student *out,
                        int id,
                        const char *name,
                        const double *grades,
                        size_t grade_count)
{
    if (out == NULL || name == NULL ||
        (grade_count != 0 && grades == NULL)) {
        return 0;
    }

    /* 先建立“可安全销毁”的空状态，后面的任一步失败都能回滚。 */
    out->id = id;
    out->name = NULL;
    out->grades = NULL;
    out->grade_count = 0;

    out->name = duplicate_string(name);
    if (out->name == NULL) {
        return 0;
    }

    if (grade_count != 0) {
        if (grade_count > SIZE_MAX / sizeof *out->grades) {
            student_destroy(out);      // 失败路径：释放已经复制的姓名
            return 0;
        }

        out->grades = malloc(grade_count * sizeof *out->grades);
        if (out->grades == NULL) {
            student_destroy(out);      // 失败路径：恢复为空状态
            return 0;
        }

        memcpy(out->grades,
               grades,
               grade_count * sizeof *out->grades);
    }

    out->grade_count = grade_count;
    return 1;
}

static double student_average(const Student *student)
{
    size_t i;
    double sum = 0.0;

    if (student == NULL || student->grade_count == 0) {
        return 0.0;
    }

    for (i = 0; i < student->grade_count; ++i) {
        sum += student->grades[i];
    }
    return sum / (double)student->grade_count;
}

static void list_init(StudentList *list)
{
    list->head = NULL;
    list->tail = NULL;
    list->size = 0;
    list->generation = 0;
}

static int list_append_copy(StudentList *list,
                            int id,
                            const char *name,
                            const double *grades,
                            size_t grade_count)
{
    Node *node;

    if (list == NULL) {
        return 0;
    }

    node = malloc(sizeof *node);
    if (node == NULL) {
        return 0;
    }

    if (!student_init(&node->value, id, name, grades, grade_count)) {
        free(node);                  // 失败路径：节点还没有进入链表
        return 0;
    }
    node->next = NULL;

    if (list->tail == NULL) {        // 边界：空表的 head 和 tail 同时建立
        list->head = node;
        list->tail = node;
    } else {
        list->tail->next = node;
        list->tail = node;
    }

    ++list->size;
    ++list->generation;
    return 1;
}

static Student *list_find(StudentList *list, int id)
{
    Node *current;

    if (list == NULL) {
        return NULL;
    }

    for (current = list->head; current != NULL; current = current->next) {
        if (current->value.id == id) {
            return &current->value;   // 借用：调用者不能 free 返回值
        }
    }
    return NULL;
}

static int list_delete(StudentList *list, int id)
{
    Node **link;
    Node *previous = NULL;

    if (list == NULL) {
        return 0;
    }

    link = &list->head;
    while (*link != NULL) {
        Node *victim = *link;

        if (victim->value.id == id) {
            /*
             * 难点：link 指向“当前节点由哪个指针槽引用”。
             * 删除头节点时它是 &list->head；删除中间节点时它是
             * &previous->next。于是同一句赋值能统一两种情况。
             */
            *link = victim->next;

            if (list->tail == victim) {
                list->tail = previous;  // 边界：删除尾节点要维护 tail
            }

            student_destroy(&victim->value);
            free(victim);
            --list->size;
            ++list->generation;         // 所有旧索引从此过期
            return 1;
        }

        previous = victim;
        link = &victim->next;            // 下一轮改为观察 next 指针槽
    }

    return 0;
}

static void list_reverse(StudentList *list)
{
    Node *previous = NULL;
    Node *current;

    if (list == NULL || list->head == NULL || list->head->next == NULL) {
        return;
    }

    current = list->head;
    list->tail = list->head;             // 原头节点反转后一定成为尾节点

    while (current != NULL) {
        Node *next = current->next;      // 难点：改线前先保存尚未处理的后半链
        current->next = previous;
        previous = current;
        current = next;
    }

    list->head = previous;
    ++list->generation;
}

static void list_print(const StudentList *list)
{
    const Node *current;

    printf("链表顺序（版本 %lu）：\n", list->generation);
    for (current = list->head; current != NULL; current = current->next) {
        printf("  id=%d, name=%s, average=%.2f\n",
               current->value.id,
               current->value.name,
               student_average(&current->value));
    }
}

static void list_destroy(StudentList *list)
{
    Node *current;

    if (list == NULL) {
        return;
    }

    current = list->head;
    while (current != NULL) {
        Node *next = current->next;      // free 前保存下一节点地址
        student_destroy(&current->value);
        free(current);
        current = next;
    }

    list->head = NULL;
    list->tail = NULL;
    list->size = 0;
    ++list->generation;
}

static void index_init(StudentIndex *index)
{
    index->items = NULL;
    index->count = 0;
    index->source_generation = 0;
}

static void index_destroy(StudentIndex *index)
{
    if (index == NULL) {
        return;
    }

    /* 所有权：只释放地址表；items[i] 指向的 Student 属于链表。 */
    free(index->items);
    index->items = NULL;
    index->count = 0;
    index->source_generation = 0;
}

static int index_build(StudentList *list, StudentIndex *index)
{
    Student **new_items = NULL;
    Node *current;
    size_t used = 0;

    if (list == NULL || index == NULL) {
        return 0;
    }

    if (list->size > SIZE_MAX / sizeof *new_items) {
        return 0;
    }

    if (list->size != 0) {
        new_items = malloc(list->size * sizeof *new_items);
        if (new_items == NULL) {
            return 0;                    // 原索引保持不变
        }
    }

    for (current = list->head; current != NULL; current = current->next) {
        /* 难点：数组中复制的是 Student 地址，不复制 Student 内容。 */
        new_items[used++] = &current->value;
    }

    free(index->items);                  // 新索引成功后才替换旧地址表
    index->items = new_items;
    index->count = used;
    index->source_generation = list->generation;
    return 1;
}

static int index_is_current(const StudentList *list, const StudentIndex *index)
{
    return list != NULL && index != NULL &&
           list->generation == index->source_generation;
}

static int compare_student_pointer(const void *left, const void *right)
{
    /*
     * 难点：items 的元素类型是 Student *，而 qsort 传进来的是
     * “元素所在槽位的地址”。因此参数实际指向 Student *，需要
     * 先转成 Student * const *，再解引用一次得到 Student *。
     */
    const Student *a = *(Student * const *)left;
    const Student *b = *(Student * const *)right;
    double average_a = student_average(a);
    double average_b = student_average(b);

    if (average_a != average_b) {
        /* 高分排前；不用强转后相减，避免溢出和精度问题。 */
        return (average_a < average_b) - (average_a > average_b);
    }
    return strcmp(a->name, b->name);
}

static int index_sort(StudentIndex *index,
                      const StudentList *source)
{
    if (!index_is_current(source, index)) {
        return 0;                       // 先阻止悬空指针被 qsort 解引用
    }

    qsort(index->items,
          index->count,
          sizeof index->items[0],
          compare_student_pointer);
    return 1;
}

static int index_print(const StudentIndex *index,
                       const StudentList *source)
{
    size_t i;

    if (!index_is_current(source, index)) {
        printf("索引已经过期，请先重建。\n");
        return 0;
    }

    printf("排序索引（不改变链表顺序）：\n");
    for (i = 0; i < index->count; ++i) {
        printf("  id=%d, name=%s, average=%.2f\n",
               index->items[i]->id,
               index->items[i]->name,
               student_average(index->items[i]));
    }
    return 1;
}

int main(void)
{
    const double grades_chen[] = {92.0, 86.0, 95.0};
    const double grades_li[] = {78.0, 91.0, 84.0, 88.0};
    const double grades_wang[] = {96.0, 94.0};
    const double grades_zhao[] = {88.0, 88.0, 88.0};
    StudentList list;
    StudentIndex index;
    Student *found;

    list_init(&list);
    index_init(&index);

    if (!list_append_copy(&list, 101, "Chen", grades_chen, 3) ||
        !list_append_copy(&list, 102, "Li", grades_li, 4) ||
        !list_append_copy(&list, 103, "Wang", grades_wang, 2) ||
        !list_append_copy(&list, 104, "Zhao", grades_zhao, 3)) {
        fprintf(stderr, "创建学生失败\n");
        index_destroy(&index);
        list_destroy(&list);
        return EXIT_FAILURE;
    }

    list_print(&list);

    found = list_find(&list, 103);
    if (found != NULL) {
        printf("\n查找 103：%s，平均分 %.2f\n",
               found->name, student_average(found));
    }

    if (!index_build(&list, &index) || !index_sort(&index, &list)) {
        fprintf(stderr, "建立排序索引失败\n");
        index_destroy(&index);
        list_destroy(&list);
        return EXIT_FAILURE;
    }
    putchar('\n');
    index_print(&index, &list);

    printf("\n删除 id=102 后尝试读取旧索引：\n");
    list_delete(&list, 102);
    index_print(&index, &list);          // 版本不一致，不会解引用悬空地址

    printf("\n重建索引：\n");
    if (!index_build(&list, &index) || !index_sort(&index, &list)) {
        fprintf(stderr, "重建索引失败\n");
        index_destroy(&index);
        list_destroy(&list);
        return EXIT_FAILURE;
    }
    index_print(&index, &list);

    printf("\n反转链表：\n");
    list_reverse(&list);
    list_print(&list);

    /* 先销毁借用视图，再销毁真正拥有学生对象的链表。 */
    index_destroy(&index);
    list_destroy(&list);
    return EXIT_SUCCESS;
}
```

## 四、三处最难的地方

### 1. 为什么结构体不能直接浅拷贝

`Student` 内含 `name` 和 `grades` 两个指针。如果只写：

```c
Student b = a;
```

复制的是两个地址，`a` 和 `b` 会共同指向同一批动态内存：

```
a.name ──┐
         ├──→ "Chen"
b.name ──┘
```

两边都调用 `student_destroy` 就会重复释放。因此项目通过 `student_init` 深拷贝输入数据，让每个学生独占自己的资源。详见 [[08-结构体、内存对齐与所有权#五、复杂示例：可回滚的 Person 深拷贝|结构体深拷贝]]。

### 2. 为什么删除用 `Node **`

普通 `Node *current` 只能指向节点；`Node **link` 指向的是“保存当前节点地址的槽位”。这个槽位可能是 `head`，也可能是某个节点的 `next`：

```
删除头节点： link ──→ head ──→ [victim]
删除中间：   link ──→ prev.next ──→ [victim]
```

所以 `*link = victim->next` 能统一处理两种情况。详见 [[09-链表与动态内存#四、Node **：统一删除头节点与中间节点|Node 双指针删除]]。

### 3. 为什么 `qsort` 比较器要解引用两次

索引数组的元素是 `Student *`：

```c
Student *items[4];
```

`qsort` 把“数组元素的地址”传给比较器。一个元素本身已经是指针，它的地址自然是 `Student **` 这一层级：

```
left                 *(Student * const *)left
 │                              │
 ▼                              ▼
[ Student * 槽位 ] ─────────→ Student 对象
```

详见 [[07-指针数组、数组指针与多级指针#十二、qsort 为什么会出现“指向指针的指针”|qsort 指针层级]]。

## 五、索引为什么会过期

假设索引还保存着被删除学生的地址：

```
items[1] ──→ Student（位于即将删除的 Node 内）
                         │
                      free(Node)
                         │
                         ▼
items[1] ──→ 已失效地址（悬空指针）
```

释放节点以后，这个地址看起来仍是一个数字，但已经不再指向活着的对象。直接访问 `items[1]->name` 就是 use-after-free。

项目用版本号避免这种访问：删除或反转链表后 `generation` 改变，旧索引在解引用任何元素前就会被判定为过期。

> ⚠️ 版本号只是一种工程防线，不能让悬空地址重新有效。真正的修复仍是销毁或重建索引。

---

## 六、可以继续扩展什么

- 将链表改成按 `id` 查找更快的哈希表
- 给学生增加课程名，形成真正的锯齿数据
- 把索引比较器改为函数参数，支持按姓名、学号或平均分排序
- 保存到文件时逐字段序列化，不要直接写结构体裸字节
- 为每次分配注入失败，测试所有回滚路径
