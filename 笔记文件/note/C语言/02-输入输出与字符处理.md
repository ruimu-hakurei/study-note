# 输入输出与字符处理

> `printf` 和 `scanf` 看似只是在“打印、读取”，本质上却是在用格式字符串告诉库函数：**接下来那块内存应该按什么类型解释**。

---

## 一、标准输入输出的基本模型

引入 `<stdio.h>` 后，程序通常通过三个标准流与外界交互：

```text
键盘/重定向文件 ──→ stdin  ──→ 程序
程序             ──→ stdout ──→ 终端/重定向文件
错误信息         ──→ stderr ──→ 终端/重定向文件
```

- `printf`、`putchar` 默认写到 `stdout`。
- `scanf`、`getchar`、`fgets(..., stdin)` 默认从 `stdin` 读取。
- `fprintf(stderr, ...)` 适合输出错误信息。

输入并不是“从键盘变量直接搬进内存”。终端输入通常先进入缓冲区，按下回车后，字符和换行符 `\n` 都可能留在输入流中。这正是混用 `%d`、`%c`、`getchar` 时容易踩坑的根源。

---

## 二、`printf`：按格式读取实参并输出

### 1. 高频转换说明符

| 格式 | `printf` 期望的实参 | 用途 |
|---|---|---|
| `%d`、`%i` | `int` | 有符号十进制整数 |
| `%u` | `unsigned int` | 无符号十进制整数 |
| `%x`、`%X` | `unsigned int` | 十六进制整数 |
| `%c` | `int` | 单个字符；`char` 会先提升为 `int` |
| `%s` | 指向以 `\0` 结尾字符序列的 `char *` | 字符串 |
| `%f` | `double` | 浮点数；`float` 会提升为 `double` |
| `%e`、`%g` | `double` | 科学计数法、自动选择紧凑形式 |
| `%p` | `void *` | 指针地址，实参应转成 `(void *)` |
| `%zu` | `size_t` | `sizeof`、`strlen` 等结果 |

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    int number = 66;
    char ch = 'A';
    char text[] = "study";
    double pi = 3.1415926;

    printf("整数：%d，十六进制：%X\n", number, (unsigned int)number);
    printf("字符：%c，编码值：%d\n", ch, (int)ch);
    printf("字符串：%s，长度：%zu\n", text, strlen(text));
    printf("默认：%f，保留两位：%.2f\n", pi, pi);
    printf("数组首地址：%p\n", (void *)text);
    return 0;
}
```

> ⚠️ 格式与实参类型不匹配会产生未定义行为，不只是“显示难看”。例如把 `long` 交给 `%d`，函数可能读取错误数量的字节。编译时应开启 `-Wall -Wextra -Wformat=2`。

### 2. 宽度、精度与标志

格式的一般形状是：

```text
%[标志][最小宽度][.精度][长度修饰符]转换字符
```

```c
double value = 3.1415926;
printf("|%8.2f|\n", value);   // 最小宽度 8，保留 2 位小数，默认右对齐
printf("|%-8.2f|\n", value);  // - 表示左对齐
printf("|%08.2f|\n", value);  // 0 表示用前导零填充
printf("%+.1f\n", value);     // + 强制显示正负号
```

`%.2f` 会把输出转换到小数点后两位，通常表现为四舍五入；它只改变**文本显示**，不会改变变量中保存的二进制浮点值。

### 3. `float`、`double` 与 `%f`/`%lf`

这是原笔记中最容易混淆的一组规则：

| 场景 | `float` | `double` | `long double` |
|---|---|---|---|
| `printf` | `%f`（实参会提升为 `double`） | `%f` | `%Lf` |
| `scanf` | `%f`，需要 `float *` | `%lf`，需要 `double *` | `%Lf`，需要 `long double *` |

`printf` 是读“值”，默认实参提升会把 `float` 变成 `double`；在标准 C 的 `printf` 中 `%lf` 也能工作，但这里的 `l` 对浮点转换没有效果，统一写 `%f` 更清楚。`scanf` 是写“对象”，必须根据指针类型知道该写多少字节，所以输入时 `%f` 与 `%lf` 不能混用。

## 三、`scanf`：按格式把文本转换后写入对象

### 1. 为什么通常需要 `&`

```c
int age;
double voltage;

if (scanf("%d %lf", &age, &voltage) != 2) {
    fprintf(stderr, "输入格式错误\n");
}
```

`scanf` 要修改调用者的变量，因此需要它们的地址。这里不是“整数、字符、小数都机械地加 `&`”，而是**每个转换说明符都要求对应类型的指针**：

| 格式 | 必须提供 |
|---|---|
| `%d` | `int *` |
| `%u` | `unsigned int *` |
| `%c` | `char *` |
| `%f` | `float *` |
| `%lf` | `double *` |
| `%s` | 指向可写字符缓冲区的 `char *` |

字符数组传给 `%s` 时写 `scanf("%19s", name)`，不是因为“字符串特殊所以不加 `&`”，而是数组表达式在这里会转换为首元素指针。`&name` 的类型是“数组指针”，与 `%s` 需要的 `char *` 不同。详见 [[05-数组、字符串与内存布局]]。

### 2. 永远检查返回值

`scanf` 返回成功赋值的项目数，读到输入结束且一个项目都没转换时返回 `EOF`。

```c
int x;
int status = scanf("%d", &x);

if (status == 1) {
    printf("读到 %d\n", x);
} else if (status == EOF) {
    puts("输入结束");
} else {
    puts("当前位置不是合法整数");
}
```

不检查返回值就使用 `x`，可能读到未初始化对象，形成未定义行为。

### 3. 空白规则与 `%c` 陷阱

除 `%c`、`%[`、`%n` 外，大多数 `scanf` 转换会先跳过前导空白；格式字符串里的一个空白字符会匹配任意数量的输入空白。

```c
int n;
char ch;

scanf("%d", &n);
scanf("%c", &ch);   // 常常立刻读走上一次输入留下的 '\n'
scanf(" %c", &ch);  // 前导空格要求先跳过所有空白，再读一个非空白字符
```

若空格和换行本身也是有效输入，就不能使用前导空格，应明确处理缓冲区中的每个字符。

### 4. `%s` 必须限制宽度

```c
char name[20];

if (scanf("%19s", name) == 1) {
    printf("你好，%s\n", name);
}
```

宽度 `19` 给末尾 `\0` 留出一个位置。即便如此，`%s` 遇空白就停止，不适合读取带空格的一整行；更稳妥的方案是 `fgets`。

## 四、`getchar` 与 `putchar`：一次处理一个字符

### 1. `getchar` 必须用 `int` 接收

`getchar()` 返回下一个 `unsigned char` 转换后的值，或特殊值 `EOF`。因此不能先存进 `char` 再与 `EOF` 比较，否则某些字节值可能与 `EOF` 混淆。

```c
int c;

while ((c = getchar()) != EOF) {
    putchar(c);  // 原样回显；putchar 也接收 int
}
```

交互式终端中，Windows 常用 `Ctrl+Z` 后回车表示输入结束，Unix 类系统常用 `Ctrl+D`。

### 2. 字符 I/O 与格式化 I/O 对比

| 需求 | 更直接的选择 |
|---|---|
| 读写一个字符，空白也要保留 | `getchar` / `putchar` |
| 把文本转换为多个数值 | `scanf`，但必须检查返回值 |
| 读取完整一行 | `fgets` |
| 按格式输出多种类型 | `printf` |

## 五、`fgets`：优先读取一整行

`fgets(buffer, size, stdin)` 最多读取 `size - 1` 个字符，并保证成功时以 `\0` 结尾。若缓冲区装得下，输入的换行符也会被保留。

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char line[80];

    printf("请输入一行文字：");
    if (fgets(line, sizeof line, stdin) == NULL) {
        fprintf(stderr, "没有读到输入\n");
        return 1;
    }

    line[strcspn(line, "\n")] = '\0';  // 找到换行就替换；没有换行时会落在原有 '\0' 上
    printf("你输入了：%s\n", line);
    return 0;
}
```

若一行长度超过缓冲区，`fgets` 只读取一段，剩余内容仍在输入流中。严格程序还应检查是否读到了 `\n`，并决定继续拼接还是丢弃余下字符。

## 六、字符判断与大小写转换

原笔记使用 `ch += 32`、`ch -= 32` 做大小写转换。这在 ASCII 环境有效，但不具备通用性。标准库 `<ctype.h>` 提供了更清晰的接口：

| 函数 | 判断/转换 |
|---|---|
| `isdigit` | 是否为十进制数字字符 |
| `isalpha` | 是否为字母 |
| `isspace` | 是否为空白字符 |
| `islower` / `isupper` | 是否为小写/大写字母 |
| `tolower` / `toupper` | 转为小写/大写 |

这些函数只接受 `EOF` 或能表示成 `unsigned char` 的值。若数据来自普通 `char`，安全模板是：

```c
unsigned char uc = (unsigned char)ch;
if (isalpha(uc)) {
    ch = (char)toupper(uc);
}
```

字符数字转换仍推荐直接使用 `'0'`，因为 C 标准保证数字字符连续：

```c
int digit = '8' - '0';       // 字符 '8' → 整数 8
char ch = (char)('0' + 5);   // 整数 5 → 字符 '5'
```

## 七、综合示例：逐字符分析并反转字母大小写

程序保留空格和标点，把小写变大写、大写变小写，同时统计字母、数字、空白和其他字符。它同时演示 `getchar` 的 `EOF`、`putchar`、`ctype` 参数规则与循环状态。

```c
#include <ctype.h>
#include <stdio.h>

int main(void)
{
    unsigned long letters = 0;
    unsigned long digits = 0;
    unsigned long spaces = 0;
    unsigned long others = 0;
    int c;

    puts("请输入文本；输入结束后给出统计：");

    while ((c = getchar()) != EOF) {
        // 难点：getchar 返回值已经是 unsigned char 范围或 EOF；排除 EOF 后可安全交给 ctype。
        unsigned char uc = (unsigned char)c;

        if (islower(uc)) {
            ++letters;
            c = toupper(uc);
        } else if (isupper(uc)) {
            ++letters;
            c = tolower(uc);
        } else if (isdigit(uc)) {
            ++digits;
        } else if (isspace(uc)) {
            ++spaces;
        } else {
            ++others;
        }

        if (putchar(c) == EOF) {
            fprintf(stderr, "输出失败\n");
            return 1;
        }
    }

    printf("\n字母=%lu，数字=%lu，空白=%lu，其他=%lu\n",
           letters, digits, spaces, others);
    return 0;
}
```

输入：

```text
Hello C99!
```

转换后的正文为 `hELLO c99!`；换行也会被计入空白字符。

## 八、易错点速查

1. `printf("%f", value)` 需要 `double`；`scanf("%lf", &value)` 才能写入 `double`。
2. `printf`/`scanf` 的格式与实际类型不匹配会导致未定义行为。
3. `scanf` 要检查成功赋值数量，不能假设用户永远输入正确。
4. `%c` 不跳过空白，`" %c"` 才会跳过；两种写法适用于不同需求。
5. `%s` 不读空格，还必须设置最大宽度；读整行优先用 `fgets`。
6. 字符数组传给 `%s` 不写 `&`，原因是数组会转换为 `char *`，不是“字符串天生不用地址”。
7. `getchar` 用 `int` 接收，先判断 `EOF`，再转换或交给字符分类函数。
8. `%.2f` 改的是输出文本，不会把变量本身永久截成两位小数。
