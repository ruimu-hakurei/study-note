# 装饰器（Decorator）

> 闭包的工程应用：不改原函数一行代码，无痛扩展新功能。

> 💡 装饰器 = [[闭包]] + `@` 语法糖。必须先理解闭包再读这篇。

---

## 一、核心诉求

**我想给一个函数加新功能，但我绝对不改这个函数的原有代码。**

这就是装饰器存在的唯一意义。

---

## 二、看一个最朴素的需求

我们有一个核心函数，功能是「打招呼」：

```python
# 原函数：绝对不能改代码！
def say_hello():
    print("你好！")
```

现在需求：调用 `say_hello()` 前后，分别打印「函数开始运行」和「函数运行结束」。

---

## 三、笨办法（千万别这么干）

```python
def say_hello():
    print("函数开始运行")  # 新加的
    print("你好！")       # 原代码
    print("函数运行结束") # 新加的
```

**2 个致命问题：**
1. **破坏了原函数**：万一原函数是别人写的，改了会出 bug
2. **无法复用**：如果有 100 个函数都要加这个功能，你要改 100 次

---

## 四、用闭包解决（装饰器的本质）

还记得[[闭包]]吧？外层函数接收原函数，内层函数加功能 + 调用原函数 → **这就是装饰器！**

```python
# 1. 外层函数：接收要装饰的原函数
def my_decorator(func):
    # 2. 内层函数：加新功能 + 调用原函数（闭包核心）
    def wrapper():
        print("函数开始运行")   # 新加功能：开始
        func()                 # 调用原来的函数
        print("函数运行结束")   # 新加功能：结束
    # 3. 返回内层函数（闭包的规则）
    return wrapper

# --- 手动使用（原始用法）---
def say_hello():
    print("你好！")

new_func = my_decorator(say_hello)  # 用闭包把原函数包起来
new_func()
# 输出：
# 函数开始运行
# 你好！
# 函数运行结束
```

✅ 原函数一行没改，功能加上了！这就是装饰器的本质：**一个专门给函数加功能的闭包。**

---

## 五、`@` 语法糖（最常用）

上面 `new_func = my_decorator(say_hello)` 太麻烦了，Python 给了简写：

```python
@my_decorator          # ← 这行等于 say_hello = my_decorator(say_hello)
def say_hello():
    print("你好！")

say_hello()  # 直接调用，自动生效！
```

---

## 六、通用装饰器（适配任何函数参数）

如果原函数有参数怎么办？用 `*args, **kwargs` 接收一切：

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):     # 接收所有参数
        print("函数开始运行")
        result = func(*args, **kwargs) # 原封不动传进去
        print("函数运行结束")
        return result                  # 返回原函数的结果
    return wrapper

@my_decorator
def add(a, b):
    return a + b

print(add(1, 2))
# 输出：
# 函数开始运行
# 函数运行结束
# 3
```

## 七、工作中最常用的装饰器：计时功能

```python
import time

def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()          # 开始时间
        result = func(*args, **kwargs)
        end = time.time()            # 结束时间
        print(f"耗时：{end - start} 秒")
        return result
    return wrapper

@timer
def test():
    time.sleep(1)   # 暂停1秒
    print("执行完毕")

test()
# 输出：
# 执行完毕
# 耗时：1.00xxx 秒
```

## 八、装饰器的常见应用

| 场景 | 说明 |
|---|---|
| **计时** | 测试函数执行效率 |
| **日志** | 自动记录函数调用信息 |
| **登录验证** | 检查用户权限 |
| **缓存** | 记住计算结果，避免重复计算 |
| **重试** | 失败自动重试（如网络请求） |

---

## 九、终极大白话总结

1. **装饰器 = 一个特殊的闭包**，专门给函数加功能
2. **核心好处**：不修改原函数代码，无痛扩展功能
3. **用法**：`@装饰器名字` 放在函数头上
4. **本质**：`@decorator` 就是 `func = decorator(func)`
