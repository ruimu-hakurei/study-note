# 正则表达式（Regular Expression）

> 用"密语"模式从一堆文本中精准找出你想要的内容。Python 提供 `re` 模块。

---

## 一、为什么需要正则表达式？

日常开发中经常遇到这些场景：
- 从日志中提取数字、日期、IP 地址等关键信息
- 验证用户输入的格式（邮箱、手机号等）
- 批量替换文本中匹配的字符串

用正则就像用通配符搜索，但远比 `*` 和 `?` 强大。

---

## 二、在 Python 里怎么用？

Python 提供一个专门的库叫 `re`（Regular Expression 的缩写）。

### 实战：从日志中提取数字

```python
import re

log = "温度: 23.5度, 湿度: 65%, 电量: 98%"

pattern = r"\d+\.?\d*"
# 意思是：找"一串数字，后面可能跟着个小数点，小数点后可能还有数字"

results = re.findall(pattern, log)
print(results)
# 输出: ['23.5', '65', '98']
```

## 三、常用正则符号速查

| 符号 | 含义 | 示例 |
|---|---|---|
| `\d` | 数字 0-9 | `\d+` 匹配一串数字 |
| `\w` | 字母、数字、下划线 | `\w+` 匹配一个单词 |
| `\s` | 空白字符（空格、Tab、换行） | |
| `.` | 任意字符（除换行） | `a.b` 匹配 a+b、a-b 等 |
| `+` | 1个或多个 | `\d+` 至少一个数字 |
| `*` | 0个或多个 | `\d*` 可能没有数字 |
| `?` | 0个或1个（可选） | `\.?\d*` 小数点可选 |
| `[abc]` | a、b、c 中任意一个 | `[A-F]` 大写 A-F |
| `^` | 字符串开头 | `^The` 以 The 开头 |
| `$` | 字符串结尾 | `end$` 以 end 结尾 |

---

## 四、`re` 模块常用函数

| 函数 | 作用 | 返回值 |
|---|---|---|
| `re.findall(pattern, text)` | 找到所有匹配 | [[列表]] |
| `re.search(pattern, text)` | 找到第一个匹配 | Match 对象或 None |
| `re.match(pattern, text)` | 从开头匹配 | Match 对象或 None |
| `re.sub(pattern, repl, text)` | 查找替换 | 新字符串 |
| `re.split(pattern, text)` | 按模式分割 | [[列表]] |

---

## 五、提取浮点数的例子

```python
import re

data = "X=0.12 Y=-0.03 Z=9.81"

# 提取所有浮点数（包括负数）
values = re.findall(r"-?\d+\.\d+", data)
print(values)
# 输出: ['0.12', '-0.03', '9.81']
```
