# 继承（Inheritance）

> 子类自动获得父类的全部属性和方法，代码复用的终极武器。

---

## 一、核心概念

- **父类（基类）**：包含通用属性和方法。比如 `Person` 类，有 `name`、`age`、`run()` 这些所有人都有的特征。
- **子类（派生类）**：继承父类的一切，还能加自己的特有功能。比如 `Student` 继承 `Person`，再加 `student_id`、`study()`。

> 核心作用：**代码复用**，不用重复写一样的代码。

---

## 二、单继承的基本语法

```python
# 1. 先写父类（通用模板）
class Person:
    def __init__(self, name, age):
        self.name = name   # 所有人都有名字
        self.age = age     # 所有人都有年龄
        self.weight = 50   # 所有人都有体重

    def run(self):
        self.weight -= 1
        print(f"{self.name}跑步后体重：{self.weight}kg")

# 2. 子类继承父类，括号里写父类名
class Student(Person):
    # 不用重复写 __init__、run 这些父类已有的方法！
    def study(self):  # 子类自己的特有方法
        print(f"{self.name}在写作业")
```

使用时，子类可以直接调用父类的方法：

```python
xm = Student("小明", 18)
xm.run()   # 直接用父类的 run() 方法
xm.study() # 用自己的 study() 方法
```

## 三、子类扩展/重写父类功能

### ① 重写父类方法

如果觉得父类的方法不适合子类，可以重写一个同名方法：

```python
class Student(Person):
    # 重写父类的 run() 方法
    def run(self):
        self.weight -= 0.5  # 学生跑步减重更少
        print(f"学生{self.name}跑步后体重：{self.weight}kg")
```

### ② 用 `super()` 调用父类方法

如果子类要加新属性（比如学号），需要重写 `__init__`，这时**必须**用 `super()` 调用父类的 `__init__`，不然父类的属性不会被初始化：

```python
class Student(Person):
    def __init__(self, name, age, student_id):
        # 调用父类的 __init__，初始化 name、age、weight
        super().__init__(name, age)
        # 子类自己的新属性
        self.student_id = student_id

    def __str__(self):
        return f"学号{self.student_id}的{self.name}，当前体重：{self.weight}kg"
```

> ⚠️ 如果忘了 `super().__init__()`，父类的 `name`、`age`、`weight` 都不会被初始化！

## 四、多继承（简单了解）

一个子类可以同时继承多个父类，拿到所有父类的属性和方法：

```python
class Learner:
    def learn(self):
        print("在学习新知识")

# Student 同时继承 Person 和 Learner
class Student(Person, Learner):
    pass

xm = Student("小明", 18)
xm.run()    # 来自 Person
xm.learn()  # 来自 Learner
```

## 五、完整示例

```python
# 父类：Person
class Person:
    def __init__(self, name):
        self.name = name
        self.weight = 50

    def run(self):
        self.weight -= 1

    def eat(self):
        self.weight += 2

    def drink(self):
        self.weight += 0.5

# 子类：Student 继承 Person
class Student(Person):
    def __str__(self):
        return f"{self.name}的当前体重：{self.weight}kg"

# 主程序入口
if __name__ == '__main__':
    xm = Student("小明")
    xm.run()
    xm.eat()
    xm.drink()
    print(xm)

# 运行结果：小明的当前体重：51.5kg
```

---

## 六、总结

1. 继承让子类直接复用父类的代码，减少重复劳动
2. 子类可以加自己的方法，也可以重写父类的方法
3. `super()` 是子类调用父类方法的关键工具
4. Python 支持多继承，但单继承更常用、更清晰
