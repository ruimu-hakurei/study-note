# 元组（Tuple）

> 不可变的序列，用 `()` 包裹。适合存储不需要修改的固定数据。

---

## 一、为什么需要元组？

列表可以随便增删改，但有些数据你不希望被意外修改——比如 PID 参数、坐标、串口配置。这时候用元组更安全。

---

## 二、创建元组

```python
# 一个存储坐标的元组
point = (10, 20)

# 一个存储 PID 参数的元组（比例、积分、微分）
pid_params = (1.5, 0.2, 0.05)

# ⚠️ 特别注意：如果元组只有一个元素，必须加个逗号
single_val = (5,)   # 这才是元组
not_a_tuple = (5)   # 这只是个数字 5，括号被当成了数学括号
```

---

## 三、访问元素

### 通过索引

```python
ports = ("UART1", "I2C", "SPI", "UART2")

# 找第一个元素 (从 0 开始)
print(ports[0])   # 输出: UART1

# 找最后一个元素
print(ports[-1])  # 输出: UART2
```

### 切片：拿取中间一部分

返回一个新元组，不影响原元组。

```python
print(ports[1:3])  # 输出: ('I2C', 'SPI')
```

---

## 四、元组 vs 列表

| 特性 | [[列表]] | [[元组]] |
|---|---|---|
| 可变性 | 可增删改 | **不可变**（创建后不能改） |
| 语法 | `[ ]` | `( )` |
| 速度 | 较慢 | 较快 |
| 适用场景 | 需要频繁修改的数据 | 固定的配置、坐标、参数 |
| 安全性 | 可能被误改 | 不可变，更安全 |

---

## 五、元组的"不可变"到底什么意思？

```python
pid = (1.5, 0.2, 0.05)

# ❌ 这会报错！
pid[0] = 2.0  # TypeError: 'tuple' object does not support item assignment

# ✅ 但你可以整体重新赋值
pid = (2.0, 0.3, 0.06)  # 这是新建了一个元组，不是修改原来的
```
