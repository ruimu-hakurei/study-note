# 集合（Set）

> 无序、不重复的元素集合，用 `{}` 或 `set()` 创建。两大核心能力：**去重**和**极速查找**。

---

## 一、去重：Set 的标志性功能

如果你把一堆有重复的数据丢进 Set，它会自动把重复的删掉，只保留唯一的值。

```python
# 假设你在连续读取传感器状态，收到了很多重复的警告
warnings = ["电压低", "过热", "电压低", "正常", "过热", "电压低"]

# 直接把它转成集合，瞬间去重！
unique_warnings = set(warnings)
print(unique_warnings)
# 输出: {'正常', '电压低', '过热'}
```

> 💡 注意集合是无序的，输出顺序可能和输入不同。

---

## 二、极速查找（Hash 表）

如果你想判断一个东西"在不在"一堆数据里，用 `in` 关键字查找，Set 的速度比 List 快成百上千倍。

| 操作 | 原理 | 速度 |
|---|---|---|
| List 查找 | 像翻书一样一页一页找 | 慢 |
| Set 查找 | 像查字典一样直接翻到那一页 | 极快 |

```python
valid_IDs = {"ID001", "ID045", "ID999"}
if "ID045" in valid_IDs:
    print("身份验证通过！")
```

## 三、数学集合运算（高级玩法）

把两个 Set 当成数学里的两个集合，做交、并、差运算。

```python
group_A = {"DEV_1", "DEV_2", "DEV_3"}
group_B = {"DEV_2", "DEV_3", "DEV_4"}
```

### ① 交集（A ∩ B）：两边都有的

```python
print(group_A & group_B)  # 输出: {'DEV_2', 'DEV_3'}
```

### ② 并集（A ∪ B）：全部合并去重

```python
print(group_A | group_B)  # 输出: {'DEV_1', 'DEV_2', 'DEV_3', 'DEV_4'}
```

### ③ 差集（A - B）：只在 A 里，不在 B 里的

```python
print(group_A - group_B)  # 输出: {'DEV_1'}
```

### ④ 对称差集（A ⊕ B）：各自独有的（去掉共有的）

```python
print(group_A ^ group_B)  # 输出: {'DEV_1', 'DEV_4'}
```

| [[列表]] | ✅ | ✅ | ✅ | 索引 `[0]` |
