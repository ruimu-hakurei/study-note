# 闭包（Closure）

> 内部函数"记住"外层函数的变量，即使外层函数已经执行完毕，变量也不会被销毁。

> ⚠️ 闭包是理解[[装饰器]]的**唯一前提**。学不会闭包就看不懂装饰器。

---

## 一、先搞懂基础：普通函数的变量，用完就消失

```python
def say():
    word = "你好"   # 这个变量只属于 say 函数内部
    print(word)

say()  # 输出：你好

# 试着在函数外面打印 word
print(word)  # ❌ 报错！NameError: name 'word' is not defined
```

**大白话解释：**
1. 调用 `say()` 时，电脑在内存里临时开辟一块小空间，把变量 `word` 放进去
2. 当 `say()` 代码执行完毕，这块临时空间直接被清空销毁
3. 所以函数执行完，`word` 就彻底消失了

---

## 二、第二步：函数里面再套一个函数（函数嵌套）

```python
def outer():
    num = 10
    print("外层变量：", num)

    def inner():   # 内部函数
        print("内层读取变量：", num)  # 可以直接读外层的 num

    inner()  # 直接在内部调用 inner

outer()
# 输出：
# 外层变量： 10
# 内层读取变量： 10
```

现在的情况：
- 内部函数 `inner` **能读到**外层函数 `outer` 的变量 `num`
- 但是！当 `outer` 执行结束后，`num` 依然会被销毁，和普通函数没区别
- 这一步只是「函数嵌套」，**还不是闭包**

---

## 三、第三步：核心改动 → 把内部函数「拿出去」（诞生闭包）

重点来了：**不在外层函数里调用内部函数，而是把内部函数返回给外部使用。**

```python
def outer():
    num = 10

    def inner():
        print("我读到的 num：", num)

    # 关键：返回【函数本身】，不要加括号！
    return inner

# 1. 调用 outer()，拿到内部函数 inner，存到变量 f 里
f = outer()

# 2. 现在我们在函数外面，调用 inner
f()
# 输出：我读到的 num： 10
```

### 逐行拆解「发生了什么」

1. **执行 `f = outer()`**
   - 进入 `outer` 函数，创建变量 `num = 10`
   - 创建内部函数 `inner`
   - 执行 `return inner`：把 `inner` 这个函数本体交给外面的变量 `f`
   - `outer` 函数执行完毕

2. **按照普通规则**：`outer` 执行完，里面的 `num` 本该被销毁

3. **但是！** 因为 `inner` 函数一直引用着 `num`，并且 `inner` 还被外面的 `f` 牢牢拿着，电脑为了保证 `f()` 能正常运行，**不敢删除 `num`**

4. **执行 `f()`**，本质就是执行 `inner()`，依然能读到 `num`

> ✅ **闭包 = 内部函数 + 它留住的那些外层变量**

---

## 四、最容易卡壳的点：`nonlocal` 关键字

上面的例子只是**读取**外层变量。现在试着**修改**它：

### 情况 1：直接修改，会报错

```python
def outer():
    num = 1

    def inner():
        num = num + 1  # ❌ 报错！想让数字+1
        print(num)

    return inner

f = outer()
f()  # UnboundLocalError!
```

**原因**：Python 误以为 `num = num + 1` 是在 `inner` 内部新建局部变量，不是修改外层的 `num`。

### 情况 2：加 `nonlocal` 修复

```python
def outer():
    num = 1

    def inner():
        nonlocal num  # 声明：num 来自外层函数
        num = num + 1
        print(num)

    return inner

f = outer()

f()  # 输出: 2
f()  # 输出: 3
f()  # 输出: 4
```

完美运行，而且 `num` 的值会一直累加——这就是闭包**「保存状态」**的能力。

---

## 五、闭包 vs self（面向对象）

| 特性 | 闭包 | [[面向对象编程]] 的 self |
|---|---|---|
| 保存状态 | `nonlocal` 变量 | `self.xxx` 属性 |
| 实现方式 | 函数嵌套 | 类 + `__init__` |
| 适用场景 | 轻量级状态保持 | 复杂对象建模 |

两者都能让函数"拥有记忆"。
