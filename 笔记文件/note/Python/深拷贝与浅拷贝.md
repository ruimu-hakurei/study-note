# 深拷贝与浅拷贝（Deep Copy & Shallow Copy）

> 浅拷贝只复制"外壳"，里面的嵌套对象还是同一份；深拷贝则把外壳和里面所有嵌套的东西全部复制一份新的。

> ⚠️ 搞不懂深浅拷贝，就理解不了为什么改了 `b` 列表，`a` 列表也跟着变了。

---

## 一、问题的起点：为什么 `=` 赋值不管用？

先看一段令人困惑的代码：

```python
a = [1, 2, 3]
b = a          # 你以为把 a 的内容复制给了 b

b.append(4)

print(a)  # [1, 2, 3, 4]  ← 卧槽，a 怎么也变了？？
print(b)  # [1, 2, 3, 4]
```

**大白话解释：**

`b = a` 根本没创建新列表！它只是给同一个列表对象多贴了一个标签。

```
a ──────┐
        ├──→ [1, 2, 3]    ← 同一个对象
b ──────┘
```

用 `id()` 验证一下，铁证如山：

```python
a = [1, 2, 3]
b = a

print(id(a))  # 比如 140234567890
print(id(b))  # 140234567890  ← 一模一样！
print(a is b) # True
```

> ✅ **核心结论**：`=` 是"贴标签"，不是"复制"。想要真正的复制，得用专门的拷贝方法。

---

## 二、先搞懂：什么是"可变对象"和"不可变对象"

在聊深浅拷贝之前，必须理解这个概念，因为深浅拷贝的行为在这两种对象身上**截然不同**。

| 分类 | 类型 | 特点 | 拷贝行为 |
|---|---|---|---|
| **不可变对象** | `int`, `float`, `str`, `tuple` | 创建后不能修改 | 怎么拷都无所谓 |
| **可变对象** | `list`, `dict`, `set` | 可以原地增删改 | 深浅拷贝行为完全不同 |

### 不可变对象的"假修改"

```python
s = "hello"
s = s + " world"  # 看起来像改了 s，其实是创建了一个全新的字符串
```

### 可变对象的"真修改"

```python
lst = [1, 2, 3]
lst.append(4)     # 真正在原对象上动了刀，id 都没变
```

> ⚠️ **深浅拷贝只对「可变对象」有意义。** 不可变对象你爱怎么拷都行，反正改它本质都是创建新对象。

## 三、浅拷贝（Shallow Copy）：只复制第一层

### Python 里怎么实现浅拷贝

```python
# 方法 1：用 .copy() 方法
b = a.copy()

# 方法 2：用 list() / dict() 构造
b = list(a)

# 方法 3：切片（仅限于列表）
b = a[:]

# 方法 4：copy 模块
import copy
b = copy.copy(a)
```

### 浅拷贝能解决什么问题？

对于**只有一层**的列表，浅拷贝完全够用：

```python
a = [1, 2, 3]
b = a.copy()    # 浅拷贝

b.append(4)

print(a)  # [1, 2, 3]      ← a 完全不受影响！
print(b)  # [1, 2, 3, 4]
```

此时内存里是这样的：

```
a ────→ [1, 2, 3]          ← 两个独立的对象
b ────→ [1, 2, 3, 4]
```

### 浅拷贝的致命缺陷：嵌套对象

一旦列表里**嵌套了可变对象**（比如列表套列表），浅拷贝就露馅了：

```python
a = [[1, 2], [3, 4]]
b = a.copy()   # 浅拷贝

b[0].append(999)   # 只改了 b 的第一个子列表

print(a)  # [[1, 2, 999], [3, 4]]   ← a 也跟着变了！
print(b)  # [[1, 2, 999], [3, 4]]
```

**为什么会这样？** 画出内存图就明白了：

```
浅拷贝前：
a ────→ [ 指针0 , 指针1 ]
            │        │
            ▼        ▼
         [1,2]    [3,4]

浅拷贝后：
a ────→ [ 指针0 , 指针1 ]
            │   │    │   │
            │   │    │   └──────────┐
            │   │    └──────┐       │
            ▼   ▼           ▼       ▼
b ────→ [ 指针0 , 指针1 ]
            │        │
            ▼        ▼
         [1,2]    [3,4]     ← 子列表还是同一份！
```

> 浅拷贝只复制了**外层容器的壳**，里面的子对象指针还是指向原来的地址。所以改子对象，两边都受影响。

用 `id()` 再次铁证：

```python
a = [[1, 2], [3, 4]]
b = a.copy()

print(id(a))       # 不同 ← 外层确实复制了
print(id(b))       # 不同

print(id(a[0]))    # 140234567890
print(id(b[0]))    # 140234567890  ← 里面还是同一个！
```

## 四、深拷贝（Deep Copy）：递归复制一切

```python
import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)   # 深拷贝

b[0].append(999)

print(a)  # [[1, 2], [3, 4]]       ← a 纹丝不动！
print(b)  # [[1, 2, 999], [3, 4]]
```

内存图：

```
a ────→ [ 指针0 , 指针1 ]
            │        │
            ▼        ▼
         [1,2]    [3,4]          ← 完全独立的两棵树

b ────→ [ 指针0 , 指针1 ]
            │        │
            ▼        ▼
         [1,2]    [3,4]          ← 每一层都是新创建的
```

> **深拷贝 = 递归复制**。从外到里，每一层嵌套都创建全新的对象。改任何一个，都不会影响原对象。

---

## 五、一张表总结三种操作

| 操作 | 外层是新对象？ | 内层子对象独立？ | 语法 |
|---|---|---|---|
| **直接赋值** `=` | ❌ 否 | ❌ 否 | `b = a` |
| **浅拷贝** | ✅ 是 | ❌ 否（共享） | `a.copy()` / `a[:]` / `copy.copy(a)` |
| **深拷贝** | ✅ 是 | ✅ 是（完全独立） | `copy.deepcopy(a)` |

## 六、实战：什么时候用哪种？

### 场景 1：列表里全是不可变元素 → 浅拷贝足矣

```python
a = [1, 2, 3, "hello", (4, 5)]
b = a.copy()   # 够用了，省内存
```

### 场景 2：列表嵌套列表 / 字典 → 必须深拷贝

```python
board = [[0]*3 for _ in range(3)]   # 3×3 棋盘
backup = copy.deepcopy(board)       # 做备份，确保互不影响
```

### 场景 3：字典里套字典（常见于配置文件）

```python
config = {
    "database": {"host": "localhost", "port": 3306},
    "cache": {"type": "redis", "ttl": 300}
}

import copy
config_backup = copy.deepcopy(config)

# 改备份不影响原配置
config_backup["database"]["port"] = 3307
print(config["database"]["port"])  # 3306 ← 原封不动
```

### 场景 4：对象包含引用 → 深拷贝

```python
import copy

class Player:
    def __init__(self, name, inventory):
        self.name = name
        self.inventory = inventory   # inventory 是个列表

p1 = Player("小明", ["剑", "盾"])
p2 = copy.deepcopy(p1)

p2.inventory.append("药水")

print(p1.inventory)  # ['剑', '盾']          ← p1 不受影响
print(p2.inventory)  # ['剑', '盾', '药水']
```

## 七、一个助记故事

想象你有一本通讯录（外层列表），里面记着 3 个朋友的地址（内层列表）：

- **直接赋值 `=`**：你只是给这本通讯录又贴了个标签。你烧掉其中一本，另一本也没了——因为它们**就是同一本**。

- **浅拷贝**：你复印了通讯录的封面和目录页，但每个朋友条目下面写的还是原来的地址。你拿着复印件去朋友家敲门，敲的**还是同一扇门**。

- **深拷贝**：你不仅复印了通讯录，还克隆了通讯录里的所有人。两个世界、两套人、两个家。改一个世界，完全不影响另一个世界。
