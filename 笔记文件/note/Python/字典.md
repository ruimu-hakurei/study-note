# 字典（Dictionary）

> 键值对（Key-Value）映射容器，用 `{}` 包裹。像查字典一样，用"标签"来找"内容"。

---

## 一、为什么需要字典？

列表用数字索引 `[0]` `[1]` 访问，但很多时候你希望用"名字"来访问——比如用 `"speed"` 而不是 `[0]` 来取速度值。

```python
car_status = {
    "speed": 1.5,           # 速度标签对应的值是 1.5
    "direction": "前进",    # 方向标签对应的值是 "前进"
    "battery_low": False    # 电量低警告对应的值是 False
}
```

## 二、基本操作（增删查改）

### ① 查

有两种方式，**非常推荐 `.get()` 方法**。

```python
pid_config = {"P": 10, "I": 0.5, "D": 2}

# 方法 1：直接用中括号
print(pid_config["P"])  # 输出: 10
# ❌ 危险：如果查一个不存在的标签（比如 pid_config["Z"]），程序会直接崩溃报错 KeyError

# 方法 2：使用 .get() 方法（安全模式）
print(pid_config.get("I"))       # 输出: 0.5
print(pid_config.get("Z"))       # 输出: None（找不到就返回 None，不会崩溃）
print(pid_config.get("Z", 0))    # 进阶：如果找不到 "Z"，就默认返回 0
```

### ② 增和改（合并为一个动作）

只要指着标签赋值：如果有这个标签就修改，没有就新建。

```python
pid_config["P"] = 15          # "P" 存在，修改成 15 (改)
pid_config["Max_Speed"] = 100 # "Max_Speed" 不存在，新建一个标签 (增)

print(pid_config)
# 输出: {'P': 15, 'I': 0.5, 'D': 2, 'Max_Speed': 100}
```

### ③ 删

```python
removed_val = pid_config.pop("I")
print(removed_val)  # 输出: 0.5 (拿走了 I 的值)
```

## 三、三大遍历法宝

```python
sensor_data = {"acc_x": 0.1, "acc_y": 0.5, "acc_z": 9.8}

# 1. .keys() —— 只拿标签 (键)
for k in sensor_data.keys():
    print("读取到了传感器:", k)

# 2. .values() —— 只拿数据 (值)
for v in sensor_data.values():
    print("数值是:", v)

# 3. .items() —— 标签和数据一起拿（最常用 🌟）
for k, v in sensor_data.items():
    print(f"传感器 {k} 的当前值是 {v}")
```

## 四、字典 vs 列表 vs 集合

| 特性 | [[字典]] | [[列表]] | [[集合]] |
|---|---|---|---|
| 底层 | Hash 表 | 动态数组 | Hash 表 |
| 查找速度 | 极快 O(1) | 慢 O(n) | 极快 O(1) |
| 访问方式 | 标签 `["key"]` | 索引 `[0]` | `in` 判断 |
| 典型用途 | 配置、传感器数据 | 有序数据序列 | 去重、成员判断 |
