# 魔法方法（Magic Methods）

> Python 里的"钩子（Hooks）"。当你执行普通操作（如 `print()` 或 `a + b`）时，Python 在背后偷偷调用这些方法。

---

## 一、魔法方法是什么？

以双下划线开头和结尾的方法，比如 `__init__`、`__str__`。你不是直接调用它们，而是 Python 在特定时机自动调用。

魔法方法不需要主动调用，Python 在特定时机自动触发它们。

---

## 二、最常用的魔法方法

### 1. `__init__`：对象的"初始化中断"

- **触发时机**：创建对象（实例化）的那一刻
- **作用**：给对象的属性赋初始值，就像新设备的"出厂设置"

```python
class SmartCar:
    def __init__(self, name):
        self.name = name
        self.battery = 100
        print(f"【系统日志】{self.name} 已通电，电量 {self.battery}%")

car = SmartCar("小智")  # 这一行自动触发 __init__
```

### 2. `__str__`：对象的"自我介绍"

- **触发时机**：执行 `print(对象)` 或 `str(对象)` 时
- **作用**：让对象"说人话"，返回易读的字符串

没有 `__str__` → `print(对象)` 输出冷冰冰的内存地址  
有 `__str__` → `print(对象)` 输出你定义的描述

```python
class SmartCar:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        # 这个方法必须返回一个字符串
        return f"我是平衡车【{self.name}】，目前状态良好。"

car = SmartCar("小智")
print(car)  # 自动调用 __str__，输出：我是平衡车【小智】，目前状态良好。
```

### 3. `__del__`：对象的"临终遗言"（析构方法）

- **触发时机**：对象被销毁时（程序结束 / `del 对象`）
- **作用**：清理现场——关电机、关串口、释放文件

```python
class SmartCar:
    def __del__(self):
        # 相当于 C 语言里的释放内存或停止硬件
        print("【安全提醒】对象已销毁，正在紧急制动并切断电源...")

car = SmartCar("小智")
del car  # 手动销毁，触发 __del__
```

## 三、运算类魔法方法

让对象支持 `+` `-` `*` 等运算符。

| 方法 | 运算符 | 说明 |
|---|---|---|
| `__add__(self, other)` | `+` | 加法 |
| `__sub__(self, other)` | `-` | 减法 |
| `__mul__(self, other)` | `*` | 乘法 |

```python
class Num:
    def __init__(self, n):
        self.n = n

    def __add__(self, other):
        return self.n + other.n

a = Num(10)
b = Num(20)
print(a + b)  # 自动调用 __add__，输出 30
```

## 四、索引取值魔法方法

让对象像[[列表]]一样用 `[]` 取值。

| 方法 | 作用 |
|---|---|
| `__getitem__` | 取值 `obj[0]` |
| `__setitem__` | 赋值 `obj[0] = x` |
| `__delitem__` | 删除 `del obj[0]` |

```python
class MyList:
    def __init__(self):
        self.data = [1, 2, 3]

    def __getitem__(self, idx):
        return self.data[idx]

ml = MyList()
print(ml[0])  # 输出: 1
```

## 五、更多常用魔法方法

### `__len__`：`len(对象)` 自动调用

```python
class MyStr:
    def __init__(self, s):
        self.s = s
    def __len__(self):
        return len(self.s)

ms = MyStr("python")
print(len(ms))  # 输出: 6
```

### `__eq__`：`对象1 == 对象2` 触发

```python
class Cat:
    def __init__(self, color):
        self.color = color
    def __eq__(self, other):
        return self.color == other.color

c1 = Cat("黑")
c2 = Cat("黑")
print(c1 == c2)  # 输出: True
```
