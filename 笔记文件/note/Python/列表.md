# 列表（List）

> Python 中最常用的可变序列容器，用 `[]` 包裹，就像一个有编号的零件盒。

---

## 一、为什么需要列表？

在实际项目中，你经常需要管理"一组东西"：传感器列表、电机列表、串口列表等等。列表就是用来放这些东西的容器。

---

## 二、增（添加元素）

### append(x)：在末尾追加

```python
parts = ["电机", "轮子"]
parts.append("电池")
print(parts)  # 输出: ['电机', '轮子', '电池']
```

### extend(iterable)：批量追加

把一个列表里的所有元素逐个加进另一个列表。

```python
parts = ["电机", "轮子"]
new_parts = ["螺丝", "螺母"]
parts.extend(new_parts)
print(parts)  # 输出: ['电机', '轮子', '螺丝', '螺母']
```

> 💡 对比: 如果用 `append(new_parts)` 会变成 `['电机', '轮子', ['螺丝', '螺母']]`

### insert(i, x)：在指定位置插入

```python
parts = ["电机", "轮子"]
# 在索引 1 (轮子的位置) 插入"主板"
parts.insert(1, "主板")
print(parts)  # 输出: ['电机', '主板', '轮子']
```

---

## 三、删（移除元素）

### remove(x)：精准移除指定内容

只删掉第一个匹配的元素。

```python
parts = ["电机", "螺丝", "轮子", "螺丝"]
parts.remove("螺丝")  # 只删掉第一个碰到的"螺丝"
print(parts)  # 输出: ['电机', '轮子', '螺丝']
```

### pop(\[i\])：按位置弹出（并拿走它）

```python
parts = ["电机", "主板", "轮子"]
last_part = parts.pop()  # 拿走最后一个
print(last_part)         # 输出: 轮子
print(parts)             # 输出: ['电机', '主板']

second_part = parts.pop(1)  # 拿走索引为 1 的
print(second_part)       # 输出: 主板
```

### clear()：清空列表

```python
parts = ["电机", "轮子"]
parts.clear()
print(parts)  # 输出: []
```

---

## 四、查（查找与统计）

### index(x\[, start\[, end\]\])：查找位置

```python
parts = ["电机", "主板", "轮子", "主板"]
pos = parts.index("主板")
print(pos)  # 输出: 1 (第一个"主板"的位置)
```

### count(x)：统计出现次数

```python
screws = ["大螺丝", "小螺丝", "小螺丝", "大螺丝", "小螺丝"]
num = screws.count("小螺丝")
print(num)  # 输出: 3
```

---

## 五、排序与反转

### sort(\*, key=None, reverse=False)：原地排序

```python
nums = [3, 1, 4, 1, 5, 9]

# 默认从小到大
nums.sort()
print(nums)  # 输出: [1, 1, 3, 4, 5, 9]

# 从大到小
nums.sort(reverse=True)
print(nums)  # 输出: [9, 5, 4, 3, 1, 1]
```

> 💡 字符串排序默认按字母顺序（中文按 Unicode 编码排）

### reverse()：原地反转

```python
letters = ["a", "b", "c"]
letters.reverse()
print(letters)  # 输出: ['c', 'b', 'a']
```

---

## 六、复制

### copy()：浅拷贝（复制一个新盒子）

```python
original = ["电机", "轮子"]
backup = original.copy()

backup.append("电池")
print(original)  # 原列表不变: ['电机', '轮子']
print(backup)    # 新列表变了: ['电机', '轮子', '电池']
```

> ⚠️ 直接 `=` 赋值只是贴标签，两个变量指向同一个列表。要用 `.copy()` 才是真正的复制。
