# GP时钟系统 (RCC)

> STM32F103C8T6 时钟树与各外设时钟开启速查

---

## 底层

### 时钟树结构

STM32F103 的时钟从源头到外设经过三级分发：

```
                ┌─ /2 ──→ USB预分频 (48MHz)
HSE (8MHz) ─→ PLL (×9=72MHz) ─→ SYSCLK (72MHz)
HSI (8MHz) ─┘                 ├─→ HCLK = AHB总线 (72MHz) ─→ APB2 (72MHz max) ─→ GPIO/AFIO/USART1/SPI1/ADC1/TIM1
                               └─→ APB1 (36MHz max) ─→ TIM2~4/USART2~3/I2C/SPI2/CAN
```

**关键点：**
- HSE（外部高速晶振）通常 8MHz，经 PLL 倍频到 72MHz 作为系统时钟
- **APB1 最高 36MHz**（系统时钟的一半），TIM2~4、USART2/3、I2C、CAN 都挂在这条总线上
- **APB2 最高 72MHz**，GPIO、USART1、SPI1、ADC1、TIM1 挂在上面
- **定时器时钟**：如果 APB 预分频 ≠ 1，则定时器时钟 = 2×APB 时钟（所以 APB1 的定时器实际跑 72MHz）

### STM32F103C8T6 定时器资源

| 类型 | 编号 | 总线 | 功能 |
|------|------|------|------|
| 高级定时器 | TIM1 | APB2 | 通用定时器全部功能 + 重复计数器、死区生成、互补输出、刹车输入 |
| 通用定时器 | TIM2、TIM3、TIM4 | APB1 | 定时中断、内外时钟源、输入捕获、输出比较、编码器接口、主从触发 |
| 基本定时器 | TIM6、TIM7 | APB1 | 仅定时中断、主模式触发 DAC |

---

## 应用

时钟配置是所有外设的第一步。上电后默认使用内部 HSI (8MHz)，实际项目需要：
1. 配置 HSE + PLL → 72MHz SYSCLK
2. 每个外设使用前必须**先开启对应总线时钟**，否则寄存器写不进去

## 代码

### 标准库

```c
/* ===== APB2 总线外设时钟 ===== */
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);   // GPIO
RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);    // AFIO（复用/重映射/中断）
RCC_APB2PeriphClockCmd(RCC_APB2Periph_USART1, ENABLE);  // USART1
RCC_APB2PeriphClockCmd(RCC_APB2Periph_SPI1, ENABLE);    // SPI1
RCC_APB2PeriphClockCmd(RCC_APB2Periph_ADC1, ENABLE);    // ADC1
RCC_APB2PeriphClockCmd(RCC_APB2Periph_TIM1, ENABLE);    // TIM1（高级定时器）

/* ===== APB1 总线外设时钟 ===== */
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);    // TIM2（通用定时器）
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE);    // TIM3
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM4, ENABLE);    // TIM4
RCC_APB1PeriphClockCmd(RCC_APB1Periph_I2C2, ENABLE);    // I2C2
RCC_APB1PeriphClockCmd(RCC_APB1Periph_CAN1, ENABLE);    // CAN1

/* ===== ADC专用时钟分频 ===== */
// ADC时钟来自APB2，但最高14MHz，72MHz时必须6或8分频
RCC_ADCCLKConfig(RCC_PCLK2_Div6);  // 72/6 = 12MHz（推荐）
// RCC_ADCCLKConfig(RCC_PCLK2_Div8); // 72/8 = 9MHz
```
