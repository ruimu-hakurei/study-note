# Keil‑MDK‑ARM（uVision5 /uVision4）全套快捷键整理

> 分为：编辑快捷键、查找跳转、编译调试、窗口视图、实用快捷键，最常用标⭐

## 一、代码编辑（写代码最高频）

表格

|快捷键|功能说明|
|---|---|
|⭐`Ctrl + S`|保存当前文件|
|⭐`Ctrl + Z`|撤销|
|⭐`Ctrl + Y`|恢复 / 重做|
|⭐`Ctrl + X`|剪切选中内容|
|⭐`Ctrl + C`|复制|
|⭐`Ctrl + V`|粘贴|
|`Ctrl + A`|全选|
|`Tab`|选中代码向右缩进|
|`Shift + Tab`|选中代码向左缩进|
|⭐`Ctrl + ]`|跳到匹配的括号 `( ) { } [ ]`|
|`Ctrl + Shift + Z`|撤销缩进|
|`Ctrl + Shift + U`|选中内容**大写**|
|`Ctrl + U`|选中内容**小写**|
|`Ctrl + K`|插入注释 `//`|
|`Ctrl + Shift + K`|移除注释 `//`|
|`Ctrl + /`|（新版本）单行注释切换|
|`Shift + Enter`|在光标下方新开一行（不用跑到行尾）|

## 二、查找 & 跳转（非常重要）

表格

|快捷键|功能说明|
|---|---|
|⭐`Ctrl + F`|查找|
|⭐`Ctrl + H`|查找并替换|
|⭐`F3`|查找下一个|
|⭐`Shift + F3`|查找上一个|
|⭐`Ctrl + F4`|关闭当前编辑器标签页|
|⭐`F12`|**跳转到函数 / 变量定义处**|
|⭐`Ctrl + F12`|查找函数声明|
|⭐`Alt + ←`|返回上一处光标位置（回退跳转）|
|⭐`Alt + →`|前进|
|`Ctrl + G`|跳转到指定行号|

## 三、编译、工程操作

表格

|快捷键|功能说明|
|---|---|
|⭐`F7`|**编译当前修改文件 (Build)**|
|⭐`Ctrl + F7`|**全部重新编译 (Rebuild)**|
|⭐`Alt + F7`|打开工程选项（魔术棒）|

> Build (F7)：增量编译，快；Rebuild (Ctrl+F7)：全编译，清理缓存，改头文件后一定要用。

## 四、调试模式快捷键（进入 Debug 后生效）

表格

|快捷键|功能说明|
|---|---|
|⭐`Ctrl + F5`|**开始 / 进入调试**|
|⭐`F5`|**全速运行 Run**|
|⭐`F11`|**单步进入（Step‑into，跳进函数内部）**|
|⭐`F10`|**单步跳过（Step‑over，不进函数）**|
|⭐`Shift + F11`|**单步跳出（Step‑out，跳出当前函数）**|
|⭐`Ctrl + Shift + F5`|**复位程序 Reset**|
|⭐`Esc`|停止运行|
|⭐`F9`|**添加 / 取消断点**|
|`Ctrl + F9`|禁用断点|
|`Ctrl + Shift + F9`|清除所有断点|

## 五、窗口视图快捷键

表格

| 快捷键                          | 功能          |
| ---------------------------- | ----------- |
| `Ctrl + E`                   | 编辑器与反汇编窗口切换 |
| `View -> Status Window` 无快捷键 | 调出调试命令窗口    |
