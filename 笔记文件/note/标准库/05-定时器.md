# 定时器 (TIM)

> 时基单元、定时中断、输出比较 (PWM)、输入捕获 (频率/占空比)、编码器接口

---

## 底层

### 时基单元

时基单元是定时器最核心的部分，由三个寄存器构成：

```
CK_PSC (输入时钟)
    │
    ▼
PSC 预分频器 (16位)  — 对输入时钟分频，分频数 = PSC + 1
    │
    ▼ CK_CNT
CNT 计数器 (16位)    — 对分频后的时钟计数，每个上升沿 +1
    │
    ▼
ARR 自动重装寄存器 (16位) — CNT 到达 ARR 时归零，触发更新事件/中断
```

**关键公式：**
- 计数器溢出频率：`CK_CNT_OV = CK_PSC / (PSC + 1) / (ARR + 1)`
- 溢出时间：`T_OV = (PSC + 1) × (ARR + 1) / CK_PSC`

> 例：72MHz时钟，PSC=7200-1，ARR=10000-1 → 溢出频率 = 72M/7200/10000 = 1Hz（1秒定时）

### 时钟源选择

| 模式 | 说明 |
|------|------|
| 内部时钟 | RCC 提供，最常用。基本定时器只能用这个 |
| 外部时钟模式1 | 来自 ETR 引脚或 ITRx 或 TIx（CH1/CH2 引脚边沿）|
| 外部时钟模式2 | 仅来自 ETR 引脚 |

### 输出比较 (OC) 原理

输出比较通过比较 CNT 和 CCR 来产生 PWM 波形：

```
CNT 从 0 → ARR 递增计数
    │
    ├── CNT < CCR → 输出有效电平（PWM模式1）或无效电平（PWM模式2）
    └── CNT ≥ CCR → 输出无效电平（PWM模式1）或有效电平（PWM模式2）
```

**PWM 参数公式：**
- **频率**：`Freq = CK_PSC / (PSC + 1) / (ARR + 1)`
- **占空比**：`Duty = CCR / (ARR + 1)`
- **分辨率**：`Reso = 1 / (ARR + 1)`（占空比最小变化步距）

**常用配置速查：**

| 应用 | PSC | ARR | 频率 | 说明 |
|------|-----|-----|------|------|
| 呼吸灯 | 720-1 | 100-1 | 1kHz | 大 ARR 提供平滑过渡 |
| 舵机 | 72-1 | 20000-1 | 50Hz | CCR 单位 = 1μs，500~2500 对应 0°~180° |
| 电机 | 36-1 | 100-1 | 20kHz | ≥20kHz 避免人耳可听蜂鸣声 |
| 测 PWM | 1-1 | 65535 | 72MHz | Period 拉满防止溢出 |

### 输出比较模式

| 模式 | CNT=CCR 时 REF 行为 |
|------|---------------------|
| 冻结 (Timing) | 保持原状态不变 |
| 匹配时置有效电平 (Active) | 置有效电平 |
| 匹配时置无效电平 (Inactive) | 置无效电平 |
| 匹配时电平翻转 (Toggle) | 电平翻转 |
| PWM模式1 | CNT<CCR 有效，CNT≥CCR 无效 |
| PWM模式2 | CNT<CCR 无效，CNT≥CCR 有效 |

### 输入捕获 (IC) 原理

输入捕获在引脚检测到边沿跳变时，将当前 CNT 值锁存到 CCR 中：

```
引脚 → 边沿检测（滤波、分频）→ 触发捕获 → CNT→CCR
```

- IC 需要配合**从模式复位**和 **TRGI 触发源**来实现自动清零 CNT
- 常用配置：TI1FP1 作为触发源 → 触发从模式复位（每个上升沿复位 CNT）
- 测周法：两次上升沿之间的 CNT 差值 = 信号周期（以定时器时钟为单位）

### 测频法 vs 测周法

| 方法 | 原理 | 公式 | 适用 |
|------|------|------|------|
| 测频法 | 闸门时间T内计上升沿次数N | fₓ = N/T | 高频信号 |
| 测周法 | 两个上升沿内以fc计次得N | fₓ = fc/N | 低频信号 |

- **中界频率**：两种方法误差相等时的频率，fm = √(fc/T)
- 测周法频率相对误差 ≈ 周期相对误差（微分近似，前提是 ΔT ≪ T）
- 测周法的频率范围：最低 = fc/65535（CNT 刚好记满），最高取决于精度要求

### 编码器接口原理

编码器接口是定时器的一种特殊模式，通过 CH1 和 CH2 引脚接收 A/B 相正交编码信号：

```
正转：A超前B90° → CNT递增
反转：B超前A90° → CNT递减
```

- 只在 TI1FP1 和 TI2FP2 边沿跳变时计数
- ARR 自动设为 65535，计数方向自动处理
- 读 CNT 的增量即为角度变化量

### 定时器中断深度解析

#### 1. 更新中断不是“CNT 到 ARR 就直接进 CPU”

完整链路是：

```
TIMxCLK
  │
  ▼
PSC 分频 → CNT 计数 → 溢出/重装
                         │
                         ▼
                    产生 Update Event
                         │
          ┌──────────────┴──────────────┐
          ▼                             ▼
装载 PSC/ARR 预装值、更新内部状态       SR.UIF = 1
                                        │ DIER.UIE = 1？
                                        ▼
                                   NVIC TIMx_IRQn
                                        │
                                        ▼
                                   TIMx_IRQHandler
```

要分清两个概念：

- **更新事件（UEV）**：定时器内部动作，可装载预分频/自动重装预装值、复位计数器等。
- **更新中断（UI）**：更新事件把 `UIF` 置位，并且 `UIE` 与 NVIC 都使能后，CPU 才进入 ISR。

所以即使没有开中断，更新事件仍可能发生；反过来，只开 NVIC 而没有 `TIM_IT_Update` 也不会得到周期 ISR。

#### 2. 先确认真正的 TIMxCLK

STM32F103 中常见规律：

| APB 预分频 | 定时器内核时钟 |
|---|---|
| APB 分频为 1 | `TIMxCLK = PCLKx` |
| APB 分频大于 1 | `TIMxCLK = 2 × PCLKx` |

TIM2~TIM7 通常挂 APB1，TIM1/TIM8 通常挂 APB2。例如系统 72 MHz、APB1 为 36 MHz（分频 2）时，TIM2 的内核时钟仍是 72 MHz，而不是 36 MHz。

```text
更新频率 = TIMxCLK / (PSC + 1) / (ARR + 1)
```

> ⚠️ 定时器频率算错一倍，最常见原因就是漏掉“APB 分频不为 1 时定时器时钟乘 2”。

#### 3. 同一个 TIM IRQ 可能有多个来源

| 标志/使能 | 事件 | 常见应用 |
|---|---|---|
| `UIF/UIE` | 更新/溢出 | 周期任务、系统心跳 |
| `CC1IF/CC1IE` ... | 捕获或比较匹配 | 测脉宽、输出比较调度 |
| `CCxOF` | 输入捕获过捕获 | 记录捕获数据来不及读取 |
| `TIF/TIE` | 触发输入事件 | 外部同步、从模式 |
| `BIF/BIE` | 高级定时器刹车事件 | 电机 PWM 紧急关断 |

TIM2 这类通用定时器的一个 IRQHandler 可以同时收到更新和多个 CC 通道请求，应使用独立 `if`：

```c
void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) != RESET)
    {
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
        SystemTickMs++;
    }

    if (TIM_GetITStatus(TIM2, TIM_IT_CC1) != RESET)
    {
        uint16_t captured = TIM_GetCapture1(TIM2); // 先保存硬件时间戳
        TIM_ClearITPendingBit(TIM2, TIM_IT_CC1);
        CaptureValue = captured;
        CaptureReady = 1;
    }
}
```

不要用 `else if`，因为更新与捕获可能在进入 ISR 前同时置位。

#### 4. 为什么刚启动就进入一次中断

PSC 是带缓冲的寄存器，配置函数通常通过 `EGR.UG` 产生一次更新事件，让新 PSC 立即装载；这会连带置位 `UIF`。如果先打开 UIE/NVIC，却没有清 UIF，启动 CEN 后就可能立刻进入 ISR。

可靠顺序：

```c
TIM_TimeBaseInit(TIM2, &TIM_TimeBaseInitStructure);
TIM_ClearITPendingBit(TIM2, TIM_IT_Update); // 清初始化产生的 UIF

TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);
/* 配置 NVIC ... */
TIM_Cmd(TIM2, ENABLE);                      // 最后启动计数器
```

若开启 ARR 预装载，运行时写 ARR 先进入影子/预装寄存器，到下一次更新事件才统一生效，这能避免周期中途突变；但也意味着“写完 ARR 立刻生效”的理解不一定成立。

#### 5. 1 ms 中断应该做时基，不要做全部业务

下面用 TIM2 产生 1 ms 时基。ISR 只清标志和递增计数，LED、按键、采样等任务在主循环按时间差调度：

```c
volatile uint32_t SystemTickMs;

void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) != RESET)
    {
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update); // 尽早解除本次中断源
        SystemTickMs++;
    }
}

uint32_t Timer_Millis(void)
{
    return SystemTickMs; // Cortex-M3 对齐的32位读写可单指令完成
}

int main(void)
{
    uint32_t led_last = 0;
    uint32_t key_last = 0;
    uint32_t adc_last = 0;

    Hardware_Init();

    while (1)
    {
        uint32_t now = Timer_Millis();

        /* 无符号时间差可以自然跨过 0xFFFFFFFF → 0 的回绕。 */
        if ((uint32_t)(now - key_last) >= 10U)
        {
            key_last = now;
            Key_ScanNonBlocking();
        }

        if ((uint32_t)(now - adc_last) >= 20U)
        {
            adc_last = now;
            ADC_RequestSample();
        }

        if ((uint32_t)(now - led_last) >= 500U)
        {
            led_last = now;
            LED_Turn();
        }
    }
}
```

这比在 ISR 里直接 `Delay_ms()`、刷新 OLED、打印串口更可靠：高优先级 ISR 能很快退出，其他中断的最大等待时间也更容易估算。

#### 6. 周期误差、延迟与抖动

- **周期误差**：PSC/ARR 只能取整数，目标频率可能无法精确整除。
- **中断延迟**：事件发生到 ISR 第一条指令之间的时间，受当前指令和更高优先级 ISR 影响。
- **抖动**：每次延迟不完全相同。软件翻转 GPIO 的时刻会抖动，而定时器硬件 PWM/OC 边沿不需要等 CPU，精度更高。
- **ISR 超时**：若 ISR 执行时间接近或超过中断周期，UIF 只是一位，多个更新事件可能合并成一次 Pending，软件计数就会少拍。

> ✅ 精确波形交给 PWM/输出比较，精确采样时刻用 TIM 触发 ADC，CPU 中断更适合处理“周期到了以后要安排什么”。

#### 7. 典型应用选择

| 目标 | 推荐机制 |
|---|---|
| 1 ms 软件任务节拍 | 更新中断，ISR 只递增 tick |
| 精确方波/PWM | 输出比较/PWM 硬件，不在 ISR 翻 GPIO |
| 测量外部周期 | 输入捕获锁存 CCR，可在 CC 中断读取 |
| 高频脉冲计数 | 外部时钟模式，CPU 低频读取 CNT |
| 正交编码器 | 编码器接口，CPU 周期读取增量 |
| 电流固定相位采样 | TIM 更新/比较事件硬件触发 ADC |

### 输出比较 (OC) — PWM 输出

> **前置依赖**：时基单元、TIM_Cmd 开启、[[02-GPIO与EXTI|GPIO 初始化]]（OC 通道引脚需查引脚表，设为 AF 复用推挽）

```c
/* OC 初始化 — PWM模式1 */
TIM_OCInitTypeDef TIM_OCInitStructure;
TIM_OCStructInit(&TIM_OCInitStructure);                      // 先填默认值
TIM_OCInitStructure.TIM_OCMode = TIM_OCMode_PWM1;            // PWM模式1
TIM_OCInitStructure.TIM_OCPolarity = TIM_OCPolarity_High;    // 高电平有效
TIM_OCInitStructure.TIM_OutputState = TIM_OutputState_Enable;
TIM_OCInitStructure.TIM_Pulse = 90;                          // CCR 初始值
TIM_OC1Init(TIM2, &TIM_OCInitStructure);                     // 通道1

/* 运行时改占空比 */
void PWM_SetCompare1(uint16_t Compare)
{
    TIM_SetCompare1(TIM2, Compare);  // Compare范围 0~ARR
}

/* 运行时改频率（改PSC） */
void PWM_SetPrescaler(uint16_t Prescaler)
{
    TIM_PrescalerConfig(TIM2, Prescaler, TIM_PSCReloadMode_Immediate);
}
```

### 应用示例：呼吸灯

```c
// PSC=720-1, ARR=100-1 → 1kHz，循环改变 CCR 实现呼吸效果
uint8_t i;
for (i = 0; i <= 100; i++)
{
    Delay_ms(10);
    PWM_SetCompare1(i);
}
for (i = 0; i <= 100; i++)
{
    Delay_ms(10);
    PWM_SetCompare1(100 - i);
}
```

### 应用示例：舵机控制

```c
// PSC=72-1, ARR=20000-1 → 50Hz, CCR=500~2500 对应 0°~180°
void Servo_SetAngle(float Angle)
{
    PWM_SetCompare2(Angle / 180 * 2000 + 500);
}
```

### 应用示例：电机调速（带方向）

```c
// PSC=36-1, ARR=100-1 → 20kHz（避免蜂鸣声）
// 两个 GPIO 控制 H 桥方向，PWM 控制速度
void Motor_SetSpeed(int16_t Speed)
{
    if (Speed >= 0)
    {
        GPIO_SetBits(GPIOA, GPIO_Pin_4);    // 正转
        GPIO_ResetBits(GPIOA, GPIO_Pin_5);
        PWM_SetCompare3(Speed);
    }
    else
    {
        GPIO_SetBits(GPIOA, GPIO_Pin_5);    // 反转
        GPIO_ResetBits(GPIOA, GPIO_Pin_4);
        PWM_SetCompare3(-Speed);
    }
}
```

### 输入捕获 (IC) — 频率 + 占空比测量

> **前置依赖**：时基单元、TIM_Cmd 开启、[[02-GPIO与EXTI|GPIO 初始化]]（CH 引脚设为浮空输入或上拉输入）

**测周法完整配置流程：**

```c
/* 1. IC 初始化 — CH1 上升沿捕获 */
TIM_ICInitTypeDef TIM_ICInitStructure;
TIM_ICStructInit(&TIM_ICInitStructure);                       // 先填默认值
TIM_ICInitStructure.TIM_Channel = TIM_Channel_1;
TIM_ICInitStructure.TIM_ICFilter = 0xF;                       // 滤波，越大抗干扰越强
TIM_ICInitStructure.TIM_ICPolarity = TIM_ICPolarity_Rising;   // 上升沿捕获
TIM_ICInitStructure.TIM_ICPrescaler = TIM_ICPSC_DIV1;         // 不分频
TIM_ICInitStructure.TIM_ICSelection = TIM_ICSelection_DirectTI; // 直连模式
TIM_ICInit(TIM3, &TIM_ICInitStructure);

/* 2. 配置 TRGI 输入源 — 用 TI1FP1 触发 */
TIM_SelectInputTrigger(TIM3, TIM_TS_TI1FP1);

/* 3. 配置从模式 — 触发时复位 CNT */
TIM_SelectSlaveMode(TIM3, TIM_SlaveMode_Reset);

/* 4. 启动定时器 — 必须放在从模式之后 */
TIM_Cmd(TIM3, ENABLE);
```

> **从模式复位机制**：上升沿到来时 → 先触发捕获（CNT→CCR1） → 然后复位 CNT=0。下次上升沿时 CCR1 中存的就是两次上升沿之间的计数值。

**测周法读频率：**
```c
// 假设定时器时钟 = 1MHz（72MHz / PSC+1 = 1MHz，即 1μs 精度）
uint32_t IC_GetFreq(void)
{
    return 1000000 / (TIM_GetCapture1(TIM3) + 1);  // fc / N
}
```

**PWMI 模式（同时测频率和占空比，仅通道1/2）：**
```c
// 在 IC 初始化后用 PWMI 配置替代手动配置从模式
TIM_PWMIConfig(TIM3, &TIM_ICInitStructure);
// CH1 捕获周期（上升沿→上升沿），CH2 捕获高电平时间（上升沿→下降沿）

// 读占空比（%）
uint32_t IC_GetDuty(void)
{
    return (TIM_GetCapture2(TIM3) + 1) * 100 / (TIM_GetCapture1(TIM3) + 1);
}
```

### 编码器接口

> **前置依赖**：[[01-时钟系统#代码|开启 TIM 时钟]]、[[02-GPIO与EXTI|GPIO 初始化]]（CH1/CH2 设为上拉输入）

```c
/* 编码器接口不需要配置时钟源和时基单元（ARR=65535，计数方向自动） */
/* 只需 IC 通道和滤波配置 */

TIM_ICInitTypeDef TIM_ICInitStructure;
TIM_ICStructInit(&TIM_ICInitStructure);
TIM_ICInitStructure.TIM_Channel = TIM_Channel_1;
TIM_ICInitStructure.TIM_ICFilter = 0xF;    // 滤波
TIM_ICInit(TIM3, &TIM_ICInitStructure);
TIM_ICInitStructure.TIM_Channel = TIM_Channel_2;
TIM_ICInit(TIM3, &TIM_ICInitStructure);

/* 配置编码器接口 — 双边沿计数 */
TIM_EncoderInterfaceConfig(TIM3, TIM_EncoderMode_TI12,
    TIM_ICPolarity_Rising, TIM_ICPolarity_Rising);

TIM_Cmd(TIM3, ENABLE);

/* 读取编码器相位 — 强制把无符号 CNT 转成有符号 */
int16_t Encoder_Get(void)
{
    return TIM_GetCounter(TIM3);
}

/* 读取并清零（得到本次增量） */
int16_t Encoder_Get(void)
{
    int16_t Temp;
    Temp = TIM_GetCounter(TIM3);
    TIM_SetCounter(TIM3, 0);
    return Temp;
}
```

void Timer_Init(void)
{

}

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)

    if (htim->Instance == TIM2)

### 输入捕获中断（HAL）

```c
void HAL_TIM_IC_CaptureCallback(TIM_HandleTypeDef *htim)
{
    if (htim->Instance == TIM3 && htim->Channel == HAL_TIM_ACTIVE_CHANNEL_1)
    {
        CaptureValue = HAL_TIM_ReadCapturedValue(htim, TIM_CHANNEL_1);

}
```

启动对应通道需要使用 `HAL_TIM_IC_Start_IT(&htim3, TIM_CHANNEL_1)`，只调用普通 `HAL_TIM_IC_Start()` 不会产生捕获中断。

### 电机（HAL）

```c
void Motor_SetSpeed(int16_t Speed)
{
    if (Speed >= 0)
    {
        HAL_GPIO_WritePin(GPIOA, AIN1_Pin, GPIO_PIN_SET);
        HAL_GPIO_WritePin(GPIOA, AIN2_Pin, GPIO_PIN_RESET);
        PWM_SetCompare1(Speed);
    }
    else
    {
        HAL_GPIO_WritePin(GPIOA, AIN2_Pin, GPIO_PIN_SET);
        HAL_GPIO_WritePin(GPIOA, AIN1_Pin, GPIO_PIN_RESET);
        PWM_SetCompare1(-Speed);
    }
}
```
